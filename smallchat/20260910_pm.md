## 1. Microsoft

### Windows 11 の9月パッチが公開、995件の脆弱性を修正

**要約**: Windows 11向けの2026年9月パッチ（KB5124008、KB5122880）が公開された。タスクバー操作の不具合修正に加え、995件のセキュリティ脆弱性への対応が含まれる大型アップデートとなっている。

**影響**: 業務端末の更新スケジュールを組む運用担当者にとって、パッチ適用の優先度判断や再起動計画に直結する情報。修正件数の多さから、脆弱性検証・回帰テストの工数も増える可能性がある。

**リンク**: [Latest Windows 11 update restores your taskbar control, patches 995 security flaws](https://www.zdnet.com/uncategorized/windows-11-september-2026-update/)

**リンク**: [警察庁と日本マイクロソフトがサイバー事案対策で協定、脅威情報共有と次世代教育で連携](https://www.zaikei.co.jp/article/20260910/869444.html)

## 3. Azure

### Azure Storage向け「User-bound user delegation SAS」がGA

**要約**: Azure Storageにおいて、ユーザー委任SAS（Shared Access Signature）とユーザー単位のバインドを組み合わせた、より安全な認証方式「User-bound user delegation SAS」が一般提供（GA）となった。

**影響**: ストレージアクセスのセキュリティを強化したい開発者にとって、トークンの不正利用リスクを下げる新たな選択肢が増える。既存のSAS運用を見直すきっかけになる。

**リンク**: [Generally Available: User-bound user delegation SAS for Azure Storage](https://azure.microsoft.com/updates?id=569241)

### Azure Ephemeral OS Disk、フルキャッシュ対応がGA

**要約**: VMおよびVMSS向けに、ローカルディスクをキャッシュしてOSディスクとして使う「Ephemeral OS Disk」のフルキャッシュ対応版が一般提供された。

**影響**: 起動速度やI/O性能を重視するワークロードを運用するインフラエンジニアにとって、コスト効率とパフォーマンスの両立を図る新しい構成オプションとなる。

**リンク**: [Generally Available: Azure Ephemeral OS Disk with full caching for VM/VMSS](https://azure.microsoft.com/updates?id=570551)

### 3分でわかるAzure AI Foundry

**要約**: Microsoftが提供する生成AIアプリ・AIエージェント開発向けの統合プラットフォーム「Azure AI Foundry」の要点をコンパクトにまとめた解説記事。

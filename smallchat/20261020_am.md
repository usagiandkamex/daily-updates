# 2026/10/20 テクニカル雑談（午前）

## 1. Microsoft

### AI エージェントを「新しいインサイダー」として守る

**要約**: Microsoft Security Blog が、AI エージェントを組織内の新たなインサイダーとして捉え、セキュリティ側もエージェントの動くスピードに合わせるべきだと論じています。GeekWire は、暴走する AI エージェントを監視・制御するツールを Microsoft が発表したと伝えています。

**影響**: エージェントが社内データや業務システムに触れる場面が増えるほど、人間のユーザーと同様に権限管理・監視・監査が必要になります。導入前に、エージェントの権限範囲とログの取り方を設計しておきたいところです。

**リンク**: [Agents are your newest insiders. Security must move at their speed. - Microsoft](https://www.microsoft.com/en-us/security/blog/2026/10/19/agents-are-your-newest-insiders-security-must-move-at-their-speed/)

### Windows 更新プログラム KB5124010 によるゲーム・アプリのクラッシュを修正

**要約**: BleepingComputer によると、Windows のプレビュー更新 KB5124010 が原因で発生していたゲームやアプリのクラッシュについて、Microsoft が修正を提供しました。別の記事では、最新の Windows 更新で Exchange Server に問題が出ているとも報じられています。

**影響**: 更新プログラムの適用は、いきなり全台展開せず段階的に行うのが安全です。特に Exchange など基幹サーバーは、既知の問題を確認してから適用しましょう。

**リンク**: [Microsoft fixes game, app crashes caused by recent Windows update - BleepingComputer](https://www.bleepingcomputer.com/news/microsoft/microsoft-fixes-game-app-crashes-caused-by-windows-kb5124010-preview-update/)

### Windows 11 の Hybrid Intelligence で Copilot+ PC が進化

**要約**: Windows Central は、Windows 11 の Hybrid Intelligence 機能により、Copilot+ PC がオンデバイスとクラウドのどちらでも AI 処理を実行できるようになると伝えています。

**リンク**: [Windows 11's Hybrid Intelligence features will breathe new life into Copilot+ PCs - Windows Central](https://www.windowscentral.com/microsoft/windows-11/hello-hybrid-intelligence-pcs-microsoft-is-evolving-copilot-pcs-with-new-ai-capabilities-that-are-smart-enough-to-run-on-device-or-in-the-cloud)

## 3. Azure

### Azure Monitor workspace の Metrics usage insights が GA

**要約**: Azure Monitor workspace で、メトリクス使用量の要因を可視化する Metrics usage insights が一般提供になりました。

**影響**: 何がメトリクスのコストや使用量を押し上げているかを把握しやすくなり、監視コストの最適化に役立ちます。

**リンク**: [[Launched] Generally Available: Metrics usage insights for Azure Monitor workspace](https://azure.microsoft.com/updates?id=577165)

### Azure DNS が Traffic Manager のリンクレコードで DNS ベースの負荷分散に対応

**要約**: Azure DNS のレコードを Azure Traffic Manager と直接関連付けることで、DNS ベースの負荷分散を利用できるようになり、一般提供が開始されました。

**影響**: DNS 構成と負荷分散の設定を統合しやすくなります。特にゾーンの頂点（apex）のレコードなどを扱う構成の見直し候補になります。

**リンク**: [[Launched] Generally Available: Azure DNS enables DNS-based load balancing through Traffic Manager linked records](https://azure.microsoft.com/updates?id=573917)

### ConnectWise が Cloud Backup を停止、Microsoft 365 利用者が標的に

**要約**: Cybersecurity Dive によると、ハッカーが Microsoft 365 ユーザーを狙っているとして、ConnectWise が Cloud Backup サービスを停止しました。

**影響**: バックアップ基盤は攻撃者の標的にもなり得ます。M365 のバックアップ手段や連携アプリの権限を見直す機会です。

**リンク**: [ConnectWise suspends Cloud Backup service as hacker targets Microsoft 365 users - Cybersecurity Dive](https://www.cybersecuritydive.com/news/connecwise-suspends-cloud-backup-hacker-microsoft-365/833345/)

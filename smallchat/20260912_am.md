## 3. Azure

### Azure Kubernetes ServiceのAzure Linux with OS Guard、2026年12月に廃止予定

**要約**: Microsoftは、Azure Kubernetes Service（AKS）における「Azure Linux with OS Guard」のサポートを2026年12月10日に終了すると発表した。後継としてAzure Container Linuxへの移行が案内されている。

**影響**: 該当構成でAKSを運用しているチームは、廃止期限までにAzure Container Linuxへの移行計画を立てる必要があり、コンテナホストOSの選定・検証作業が発生する。

**リンク**: [Retirement: Azure Linux with OS Guard in Azure Kubernetes Service](https://azure.microsoft.com/updates?id=571257)

### オンプレミスSMBファイル共有をAzure Filesへエージェントレス移行するプレビュー機能公開

**要約**: Azure Storage Moverが、オンプレミスのSMBファイル共有をAzure Files（SMB）へエージェントレスで移行する機能をパブリックプレビューとして公開した。

**影響**: 移行元サーバーへのエージェント導入なしでファイルデータを移行できるため、オンプレからAzureへのファイルサーバー移行プロジェクトの導入コストと手間を削減できる。

**リンク**: [Public Preview: Agentless migration of on-premises SMB file shares to Azure Files (SMB)](https://azure.microsoft.com/updates?id=570910)

**リンク**: [Azure AI Foundry のカスタム Rubric 評価器で SOC エージェントの品質を測る](https://qiita.com/wfan/items/0a0872c10764e8914c5e)

## 5. セキュリティ

### EUのサイバーレジリエンス法（CRA）、脆弱性報告の「24時間ルール」が施行開始

**要約**: The Registerによると、EUのCyber Resilience Act（CRA）に基づく脆弱性・インシデント報告義務が施行され、悪用中の脆弱性を24時間以内にENISAへ報告する義務が発生する「24時間ルール」が動き出した。ENISAは報告用の単一プラットフォーム（Single Reporting Platform）も稼働開始している。

**影響**: EU市場でデジタル製品を提供する企業は、脆弱性発見から24時間以内の一次報告体制を整備する必要があり、インシデント対応フローやSLAの見直しが急務となる。

**リンク**: [EU's Cyber Resilience Act starts the 24-hour vulnerability clock - The Register](https://www.theregister.com/security/2026/09/11/eus-cyber-resilience-act-starts-the-24-hour-vulnerability-clock/5295821)

### Cisco FMCの脆弱性が悪用され、認証情報窃取とQilinランサムウェア展開に利用される

**要約**: Cisco Firepower Management Center（FMC）の脆弱性が実際に悪用され、攻撃者による認証情報の窃取とQilinランサムウェアの展開に利用されていることがThe Hacker Newsにより報じられた。

**影響**: ネットワークセキュリティ製品自体が攻撃の踏み台となる深刻な事例であり、該当製品を利用する組織は緊急パッチ適用とログ調査による侵害有無の確認が急務となる。

**リンク**: [Cisco FMC Flaws Exploited to Steal Credentials and Deploy Qilin Ransomware - The Hacker News](https://thehackernews.com/2026/09/cisco-fmc-flaws-exploited-to-steal.html)

### ENISAが単一報告プラットフォーム（SRP）を稼働開始、CRA報告義務の受け皿に

**要約**: EUのサイバーセキュリティ機関ENISAは、CRAに基づく脆弱性・インシデント報告を一元的に受け付ける「Single Reporting Platform（SRP）」を稼働開始した。

**影響**: 報告窓口が一本化されることで、複数国・複数当局への個別報告の手間が軽減される一方、EU向け製品を扱う開発者は新プラットフォームへの報告フロー整備が求められる。

**リンク**: [The CRA Single Reporting Platform is launched - ENISA](https://www.enisa.europa.eu/news/the-cra-single-reporting-platform-is-launched)

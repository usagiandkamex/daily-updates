# 2026/08/05 テクニカル雑談（午後）

## 1. Microsoft

### Microsoft、AIバグ報告の急増を受けセキュリティ研究者に累計2,000万ドルを支払い

**要約**: Microsoftは、AIを活用したバグ報告の急増を受けて、セキュリティ研究者に対しこれまでに累計2,000万ドルの報奨金を支払ったことを明らかにした。AI支援ツールによって脆弱性発見のペースが加速していることが背景にある。

**影響**: バグバウンティプログラムの規模拡大は、AIによる脆弱性調査の民主化を示す一方、企業側は報告件数の急増に対応するトリアージ体制の強化が求められる。セキュリティエンジニアはAI活用型の脆弱性診断ツールへの理解を深めておく価値がある。

**参考リンク**: [Microsoft pays security researchers $20M following AI-backed surge in bug reports](https://www.reddit.com/r/microsoft/comments/1vfxzlk/microsoft_pays_security_researchers_20m_following/)

### 「Windows Performance Analyzer MCP」プレビュー公開、トレースログ分析をAIに任せられる

**要約**: MicrosoftはWindowsアプリの動作が遅くなる原因をAIがトレースログから分析してくれるツール「Windows Performance Analyzer MCP」（WPA MCP）をプレビュー公開した。MCP（Model Context Protocol）を通じてAIエージェントと連携する構成になっている。

**影響**: パフォーマンス調査の一次切り分けをAIに任せられるようになれば、Windowsアプリ開発者やサポートエンジニアの診断作業が大幅に効率化される可能性がある。MCP対応ツールの広がりとしても注目したい動き。

**参考リンク**: [アプリが遅い原因をAIがトレースログから分析してくれる「Windows Performance Analyzer MCP」（WPA MCP）、マイクロソフトがプレビュー公開](https://www.publickey1.jp/blog/26/aiwindows_performance_analyzer_mcpwpa_mcp.html)

### ChainDrop：自己増殖型ワームによるサプライチェーン侵害の詳細解説

**要約**: Microsoft Security Blogが、自己増殖する「ChainDrop」ワームによるサプライチェーン侵害の手口を詳細に解説する記事を公開した。攻撃の伝播経路や検知手法について分析している。

**影響**: サプライチェーン攻撃は依存関係を通じて広範囲に影響を及ぼすため、CI/CDパイプラインや依存パッケージの管理を行う開発者・運用担当者は、この種の攻撃パターンを把握し対策を検討する必要がある。

**参考リンク**: [ChainDrop supply chain compromise: Anatomy of a self-propagating worm](https://www.microsoft.com/en-us/security/blog/2026/08/04/chaindrop-supply-chain-compromise-anatomy-self-propagating-worm/)

## 3. Azure

### 機密コンピューティングVM「cc_v5」シリーズ、2026年9月1日に廃止予定

**要約**: Azureは、2026年9月1日をもって機密コンピューティングVMシリーズ「cc_v5」を廃止し、以降は新規利用・購入ができなくなると発表した。既存の利用中VMへの影響についても案内がある。

**影響**: cc_v5シリーズを利用している組織は、廃止までに後継シリーズへの移行計画を立てる必要がある。機密コンピューティングを用いたセキュアなワークロードを運用しているチームは早めの対応が求められる。

**参考リンク**: [Retirement: Nested confidential (cc_v5) VMs will be retired on September 1, 2026](https://azure.microsoft.com/updates?id=568661)

### ネットワークセキュリティ境界に「Perimeter link」機能がパブリックプレビュー

**要約**: Azureのネットワークセキュリティ境界（Network Security Perimeter）機能に、異なる境界間の信頼されたリソースを接続する「Perimeter link」がパブリックプレビューとして提供開始された。

**影響**: マルチテナントやマルチプロジェクト環境で境界を跨いだ通信を安全に構成できるようになるため、クラウドネットワーク設計の柔軟性が向上する。セキュリティアーキテクトは新機能の適用可否を検討する価値がある。

**参考リンク**: [[In preview] Public Preview: Perimeter link feature in network security perimeter](https://azure.microsoft.com/updates?id=568837)

### Azure Private Link、IPv6サポートがパブリックプレビューに

**要約**: Azure Private LinkがIPv6経由でのプライベート接続をサポートするパブリックプレビューを開始した。これによりAzure StorageやAzure SQL DatabaseなどのPaaSサービスにIPv6ベースの接続でプライベートアクセスできるようになる。

**影響**: IPv6移行を進める組織にとって、Private Linkのネットワーク設計における選択肢が広がる。将来的なIPv4アドレス枯渇への備えとしても評価できるアップデート。

**参考リンク**: [[In preview] Public Preview: Azure Private Link support over IPv6](https://azure.microsoft.com/updates?id=568842)

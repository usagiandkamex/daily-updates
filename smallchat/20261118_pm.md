# 2026/11/18 テクニカル雑談（午後）

## 1. Microsoft

### Ignite 2026 で自社開発コーディングAIモデル「MAI Code 2」発表

**要約**: Microsoft は年次イベント Ignite 2026 で、自社開発のコーディング用AIモデルのフラグシップ「MAI Code 2」と、さらに安価な「MAI Code 2 Flash」を発表した。高性能かつ低価格が売りとされている。

**影響**: コーディング支援AIの選択肢が増え、コスト面での比較検討材料になる。既存ツールとの使い分けや、自社の開発フローでの費用対効果を試す価値がある。

**リンク**: [［速報］マイクロソフト、コーディング用AIモデルとして高性能かつ低価格「MAI Code 2」「MAI Code 2 Flash」発表](https://www.publickey1.jp/blog/26/aimai_code_2mai_code_2_flash.html)

### Windows 11 の新しいセキュリティチェックでアプリが起動拒否も

**要約**: Windows 11 PC が Microsoft の新しいセキュリティチェックに通らない場合、アプリが動作を拒否する可能性があると報じられている。Adobe や Battle.net がすでに対応に前向きとのこと。

**影響**: アプリ提供側・利用側の双方で、端末の健全性が動作条件になる流れが強まる。社内端末の構成管理や、アプリ側の対応方針を把握しておきたい。

**リンク**: [Apps could soon refuse to run on your Windows 11 PC if it fails Microsoft's new security check](https://www.windowslatest.com/2026/11/18/apps-could-soon-refuse-to-run-on-your-windows-11-pc-if-it-fails-microsofts-new-security-check-and-adobe-and-battle-net-are-already-on-board/)

### 新しい Microsoft IQ：組織の知識をあらゆるエージェントへ

**要約**: Microsoft は「Microsoft IQ」を刷新し、組織が持つ知識・インテリジェンスをあらゆるエージェントで活用できるようにする方針を示した。

**影響**: 社内データをエージェントに接続する設計が重要になる。権限管理やデータ整備の準備が、エージェント活用の成否を左右しそうだ。

**リンク**: [Introducing the new Microsoft IQ](https://azure.microsoft.com/en-us/blog/introducing-the-new-microsoft-iq-putting-your-organizations-intelligence-to-work-in-every-agent/)

## 2. AI

### Gemini に予約・買い物を代行する「タスク」機能

**要約**: Google は 11 月 17 日（米国時間）、Gemini アプリに用事を任せられる「タスク」モードを追加した。日本を含む複数の国で無料提供が始まり、モデルには Gemini 4 Hydrogen を使う。

**影響**: エージェント型AIが一般消費者向けにも広がる。外部サービスと連携する自動化の UX や、責任範囲・権限設計の参考になる。

**リンク**: [Geminiが電話も支払いも代行する「タスク」モード、日本でも無料で提供開始](https://www.techno-edge.net/article/2026/11/18/5756.html)

### Suno が楽曲向け映像生成「Visuals」を公開

**要約**: AI音楽生成の Suno は、楽曲に合わせた短いMV、歌詞付き動画、ジャケット画像を生成できる新機能「Visuals」を、Web・iOS・Android で公開した。

**影響**: 生成AIがマルチモーダルな制作ワークフローへ広がっている例。コンテンツ生成系機能を持つサービスの設計や権利面の検討にも関わる。

**リンク**: [AIで作った曲にMVも生成　AI音楽のSunoが新機能「Visuals」を公開](https://japan.cnet.com/article/35255083/)

### 「コードを真面目に読まなくなった」──AI時代のレビューの考え方

**要約**: AIに実装を任せ、前提をきちんと整えておけば出力は概ね正しいと感じるようになり、差分を隅々まで追う時間が減ったという開発者の体験談。

**影響**: レビューの重点が「出力の精読」から「前提・仕様の準備」へ移る可能性を示す。ただしテストなど検証手段の整備が前提になる点は意識したい。

**リンク**: [最近、コードを真面目に読まなくなった](https://zenn.dev/hiromoo/articles/reading-less-preparing-more)

## 3. Azure

### Azure Cobalt 200 VM が利用可能に

**要約**: Azure Cobalt 200 VM が利用可能になった。クラウドネイティブアプリ、データベース、開発者ツール、エージェント型AIワークロード向けに、性能と効率の向上をうたっている。

**影響**: Arm ベースの VM で価格性能比の改善が見込める。既存ワークロードのベンチマークや移行検討のきっかけになる。

**リンク**: [Azure Cobalt 200 VMs now available](https://azure.microsoft.com/en-us/blog/azure-cobalt-200-vms-now-available-proven-on-real-workloads-and-built-for-the-agentic-era/)

### Azure Catalyst によるエージェント型モダナイゼーション

**要約**: Ignite 2026 で、Azure Catalyst によるエージェント型のモダナイゼーションと、新しいAIインフラの革新が紹介された。モデル・シリコン・クラウドインフラを一体で設計する方針。

**影響**: レガシーアプリの近代化をエージェントで支援する流れが本格化する。移行計画のあり方に影響しそうだ。

**リンク**: [Introducing Azure Catalyst agentic modernization and new AI infrastructure innovations](https://azure.microsoft.com/en-us/blog/introducing-azure-catalyst-agentic-modernization-and-new-ai-infrastructure-innovations/)

### Azure Disk Storage の不変スナップショットがパブリックプレビュー

**要約**: Azure Disk Storage の不変（immutable）スナップショットがパブリックプレビューになった。Azure Backup の immutable vault を補完する機能。

**影響**: ランサムウェア対策としてバックアップの改ざん・削除耐性を高められる。DR 設計の見直し候補になる。

**リンク**: [Public Preview: Immutable snapshots for Azure Disk Storage](https://azure.microsoft.com/updates?id=581503)

## 2. AI

### 「Jev」を使った意味検索 grep ツール「jev-semgrep」が公開

**要約**: TypeSafe AI の新モデル「Jev」を使い、正規表現ではなく「意味」でコード行を検索できる grep ツール「jev-semgrep」が GitHub で公開された。AND/OR/NOT で意味条件を組み合わせられ、日英クロス言語検索も可能。

**影響**: 従来の正規表現ベース検索では拾えなかった「意図」ベースの検索が可能になり、多言語混在コードベースや大規模リポジトリの調査工数削減が期待できる。

**リンク**: [GitHub - uehaj/jev-semgrep: grep by meaning, across languages](https://github.com/uehaj/jev-semgrep)

### Dify v1.6.0 で双方向 MCP 対応、Enterprise 導入視点での解説記事が公開

**要約**: Dify v1.6.0 で外部 MCP サーバーをツールとして呼び出す機能と、Dify 自身を MCP サーバーとして公開する機能の両方が追加されたことを、Enterprise 導入検討者の視点で解説する記事が Zenn に投稿された。

**影響**: MCP 対応により Dify を既存のエージェント基盤や社内ツール群と柔軟に連携できるようになり、企業内でのエージェント統合設計の選択肢が広がる。

**リンク**: [DifyをMCPサーバーとして公開する — v1.6.0の双方向MCP対応をEnterprise導入の視点で読む](https://zenn.dev/sidejob/articles/ae664ab8bcaf38cdd)

### 文章を生成しないAI「Jev」でCosmos DBのRAG検索結果をフィルタする検証

**要約**: TypeSafe AI が2026年9月に発表した、Choice/Score/Noul という判定機能に特化し文章を生成しない AI モデル「Jev」を使い、Cosmos DB の RAG 検索結果を絞り込む検証が行われた。

**影響**: 生成コストのかかる LLM を使わずに軽量な判定モデルで RAG のフィルタリング精度を上げる手法は、レイテンシとコストの両面で実用的な選択肢になりうる。

**リンク**: [文章を生成しないAI「Jev」でCosmos DBのRAG検索結果をフィルタしてみた](https://zenn.dev/nomhiro/articles/jev-cosmosdb-rag-filter-poc)

**要約**: Claude Code、Codex、GitHub Copilot、Gemini CLI といった複数の AI コーディングツールに影響するゼロクリックのリモートコード実行脆弱性「Plugin4Shell」が報告された。

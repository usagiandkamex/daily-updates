# 2026/10/25 テクニカル雑談（午後）

## 1. Microsoft

### Windows 11 のネイティブ UI フレームワーク（WinUI）は終了しない？

**要約**: Windows Latest によると、Microsoft は Windows 11 のネイティブアプリフレームワーク（WinUI）を今回は廃止しないと約束した。ただし過去に Silverlight や UWP で方針が変わった経緯があり、開発者側には懐疑的な見方も残っている。

**影響**: Windows ネイティブアプリを開発・保守しているエンジニアにとって、技術選定の安心材料になり得る。一方で、過去の経緯から移行コストや将来のロードマップは引き続き注視しておきたい。

**リンク**: [Windows 11's native WinUI isn't being killed this time, Microsoft promises, but developers have heard that before - Windows Latest](https://www.windowslatest.com/2026/10/25/windows-11s-native-app-framework-isnt-being-killed-this-time-microsoft-promises-after-silverlight-and-uwp/)

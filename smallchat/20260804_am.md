### Azure SQL Database／Managed Instance：直近7日間のバックアップが自動的に不変（Immutable）に

**要約**: Azure SQL Database と Azure SQL Managed Instance において、直近 7 日間のバックアップに対して自動的に不変性（Immutability）が適用されるようになった。ランサムウェアや誤操作によるバックアップ改ざんを防ぐセキュリティ強化の一環。

**参考リンク**: [Generally Available: Immutability to the most recent seven days of backups on Azure SQL Database and Azure SQL Managed Instance](https://azure.microsoft.com/updates?id=568339)

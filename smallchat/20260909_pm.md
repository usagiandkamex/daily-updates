## 1. Microsoft

### Microsoft Defenderに「ShieldCrash」ゼロデイ、SYSTEM権限奪取の恐れ

**要約**: Microsoft Defenderに新たなゼロデイ脆弱性「ShieldCrash」が確認され、悪用されるとSYSTEM権限が奪取される可能性がある。既存の「ShieldBreak」パッチもバイパス可能というPoCが研究者から公開されている。

**影響**: エンドポイント保護の中核であるDefenderの脆弱性は影響範囲が広く、パッチ適用と緩和策の即時確認が必要。セキュリティ担当者は関連するPatch Tuesday更新の適用状況を優先的に点検すべき。

**リンク**: [New Microsoft Defender 'ShieldCrash' zero-day grants SYSTEM access - BleepingComputer](https://www.bleepingcomputer.com/news/security/new-microsoft-defender-shieldcrash-zero-day-grants-system-access/)

### 9月のPatch Tuesdayで約1,000件の脆弱性を修正、CISAは2件の悪用を警告

**要約**: Microsoftは9月のPatch Tuesdayで過去最多クラスとなる約1,000件（記事によっては972〜973件）の脆弱性を修正。CISAはこのうち2件がすでに実際に悪用されていると警告している。

**影響**: 修正対象が非常に多いため、優先度付けが重要。特に悪用が確認された脆弱性を含む更新プログラムは緊急度高く適用する必要があり、パッチ適用計画の見直しが求められる。

**リンク**: [Microsoft posts nearly 1,000 bugs for Patch Tuesday as CISA warns two being exploited - The Record from Recorded Future News](https://therecord.media/microsoft-patch-tuesday-september-2026)

## 5. セキュリティ

### SAPカーネルにCVSS 10.0の重大脆弱性、未認証RCEが可能

**要約**: SAPがカーネルの重大な脆弱性を修正。CVSSスコアは最大値の10.0で、認証なしにリモートコード実行（RCE）が可能な深刻な内容だとThe Hacker Newsが報じている。

**影響**: SAPシステムは企業の基幹業務を支えるため、この脆弱性を放置すると業務停止や情報漏えいの重大リスクにつながる。速やかなパッチ適用が最優先事項となる。

**リンク**: [SAP Patches CVSS 10.0 Kernel Flaw Enabling Unauthenticated Remote Code Execution - thehackernews.com](https://thehackernews.com/2026/09/sap-patches-cvss-100-kernel-flaw.html)

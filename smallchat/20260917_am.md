# 2026/09/17 テクニカル雑談（午前）

## 1. Microsoft

### Microsoft 365で新たな大規模障害、502/503エラーが多発

**要約**: Microsoft 365で新たなアウテージが発生し、ユーザーから502および503エラーが多数報告されている。

**影響**: 業務基盤としてMicrosoft 365に依存する組織にとって、可用性リスクの再確認が必要。障害対応手順やフェイルオーバー先の整備が改めて重要になる。

**リンク**: [Microsoft 365 Hit by New Outage as Users Report Widespread 502 and 503 Errors](https://cybersecuritynews.com/microsoft-365-hit-by-new-outage/)

### Devin、仮想環境でmacOSの提供を開始

**要約**: コーディングAIエージェントのDevinが、これまでのUbuntu LinuxやWindowsに加え、ホスト型仮想環境でmacOSの提供を開始した。Macの実機なしでコード生成・テスト・デバッグ・実行、さらにApp Store配信前のベータ公開まで一貫して行える。

**影響**: iOS/macOSアプリ開発の自動化・CI/CD統合が進めやすくなり、実機管理コストを削減できる可能性がある。モバイル開発チームのワークフロー刷新につながりそう。

**リンク**: [Devinが仮想環境でmacOSの提供開始](https://www.publickey1.jp/blog/26/devinmacosmacdevinappstore.html)

### 日本エネルギー経済研究所、Microsoft 365の6アカウントに不正アクセス

**要約**: 日本エネルギー経済研究所でMicrosoft 365の6アカウントに不正アクセスがあり、2,798件のファイルがダウンロードされ情報漏えいが発生した。

**影響**: クラウドサービスのアカウント管理・多要素認証の徹底が改めて求められる事例。SaaS利用組織はアクセスログ監視の強化を検討すべき。

**リンク**: [日本エネルギー経済研究所、Microsoft 365の6アカウントに不正アクセス](https://rocket-boys.co.jp/security-measures-lab/ieej-m365-6-accounts-2798-files-report/)

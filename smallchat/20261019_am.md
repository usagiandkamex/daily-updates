## 1. Microsoft

### dotnetup：.NET ツールチェーンマネージャがプレビュー公開

**要約**: Microsoft が、.NET の CLI ツール、C# コンパイラ、ビルドエンジン、ランタイムなどのツールチェーンをまとめてインストールし、バージョン管理もできる「dotnetup」をパブリックプレビューとして公開しました。複数バージョンの .NET 環境を管理できるとのことです。

**影響**: プロジェクトごとに異なる .NET バージョンを使う開発者や CI 環境のセットアップが楽になりそうです。nvm や rustup のような感覚で .NET を扱えるかが注目点です。

**リンク**: [マイクロソフト、.NETのツールチェーンマネージャ「dotnetup」プレビュー公開。複数バージョンの.NET環境を管理可能](https://www.publickey1.jp/blog/26/netdotnetupnet.html)

### Windows 11 が今も MS-DOS 形式のファイル名を使う理由

**要約**: Windows 11 でいまだに MS-DOS 由来のファイル名（8.3 形式など）が使われている理由と、それを変更できない事情を Microsoft が説明したと Windows Latest が報じています。

**影響**: 後方互換性を守るために古い仕様が残り続ける典型例です。レガシー前提のツールやスクリプトを書く際は、こうした互換レイヤーの存在を意識しておくと役立ちます。

**リンク**: [Microsoft explains why Windows 11 still uses MS-DOS file names, and why it can’t change them - Windows Latest](https://www.windowslatest.com/2026/10/18/microsoft-explains-why-windows-11-still-uses-ms-dos-file-names-and-why-it-cant-change-them/)

### Windows 11 の新しい検索体験

**要約**: Windows Central が、Windows 11 に導入される新しい Search 体験について、今後の変更点と重要性を FAQ 形式で解説しています。

**影響**: 検索は日常的に使う基本機能のため、挙動の変化は開発者の作業フローにも影響します。正式展開前に変更内容を把握しておくと安心です。

**リンク**: [Windows 11’s new Search experience raises big questions — we break down what’s coming and why it matters - Windows Central](https://www.windowscentral.com/microsoft/windows-11/windows-11-will-get-a-new-search-experience-faq)

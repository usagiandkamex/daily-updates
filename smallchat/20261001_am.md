## 3. Azure

### NVv3 / NVv4 シリーズ VM が 2026/9/30 に廃止

**要約**: Azure は 2026 年 9 月 30 日付で、NVv3 シリーズ（Standard_NV12s_v3 など）と NVv4 シリーズ（Standard_NV4as_v4 など）の仮想マシンを廃止しました。

**影響**: 該当 SKU を使っているワークロードは、代替 SKU への移行状況をすぐに確認する必要があります。

**リンク**: [Retirement: NVv3-series Azure Virtual Machines](https://azure.microsoft.com/updates?id=573414) / [Retirement: NVv4-series Azure Virtual Machines](https://azure.microsoft.com/updates?id=573415)

### GitHub Copilot 向け Azure canvases と azd の 9 月まとめ

**要約**: Azure の各種ツールやダッシュボード、ガイド付きワークフローを GitHub Copilot と並べて使える共有ワークスペース「Azure canvases」が発表されました。また、Azure Developer CLI（azd）の 9 月のリリースでは、拡張機能管理が依存関係を考慮したアンインストールやバージョン付きコントラクトに対応したと紹介されています。

**リンク**: [Announcing: Azure canvases for GitHub Copilot](https://azure.microsoft.com/updates?id=573385) / [Everything released in September 2026 for Azure Developer CLI](https://devblogs.microsoft.com/azure-sdk/azure-developer-cli-azd-september-2026/)

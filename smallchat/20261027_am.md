## 5. セキュリティ

### HTTP2Shell の影響は .NET 以外にも拡大

**要約**: HTTP2Shell 脆弱性は HTTP に限らず、.NET、FFmpeg、ClickHouse、Apache Arrow にも影響すると報じられています。

**影響**: Brotli を利用するライブラリや製品が広範囲に及ぶため、依存関係の棚卸しとパッチ適用状況の確認が重要です。

**リンク**: [HTTP2Shell Vulnerability Extends Beyond HTTP, Affecting .NET, FFmpeg, ClickHouse, and Apache Arrow - CyberSecurityNews](https://cybersecuritynews.com/http2shell-vulnerability/)

### PHP の深刻な脆弱性（PHP2Shell）への緊急パッチ

**要約**: 2026年10月21日、PHP2Shell と呼ばれる深刻な脆弱性を修正する PHP 8 系の緊急パッチが配信されました。Classi は、これを受けて Docker Official Image のビルドシステムを社内構築した事例を紹介しています。

**影響**: PHP を使うシステムは早急な更新が必要です。自前でイメージを素早く更新できる仕組みの有無が対応速度を左右します。

**リンク**: [pixiv社の爆速PHPアップデートを参考に、社内で Docker Official Image のビルドシステムを作った話 - Classi開発者ブログ](https://tech.classi.jp/entry/2026/10/26/163000)

## 3. Azure

### Azure Multicloud Interconnect、パブリックプレビュー開始

**要約**: AzureとAWSなど対応クラウド間のプライベート接続を提供する新サービス「Azure Multicloud Interconnect」がパブリックプレビューとして発表された。AWSとの協業も明らかにされている。

**影響**: マルチクラウド構成におけるネットワーク接続の管理・コストが簡素化される可能性があり、複数クラウドを併用する構成を検討するチームにとって選択肢が広がる。

**リンク**: [Public Preview: Azure Multicloud Interconnect](https://azure.microsoft.com/updates?id=570364)

### Azure VMのディスク単位レジリエンシーがプレビューに

**要約**: アタッチされたマネージドディスクへのアクセスを長期間失った場合に自動でVMを再起動・復旧する「Per-disk resiliency」機能がパブリックプレビューとして提供開始された。

**影響**: ディスク障害時の可用性向上に寄与し、運用チームの障害対応負荷を軽減できる可能性がある。

**リンク**: [Public Preview: Per-disk resiliency for Azure VMs](https://azure.microsoft.com/updates?id=569711)

### Azure SRE AgentにMCPサーバー連携ツールを提供

**要約**: Azure Connector Namespaceを使って、Azure SRE AgentにMCPサーバーへのアクセスを持たせ、運用ツールを利用できるようにする方法が紹介されている。

**影響**: AIエージェントによる運用自動化（SRE業務）を進めるチームにとって、既存のオペレーショナルツールとの連携方法の具体例として参考になる。

**リンク**: [Power Azure SRE Agent with the tools it needs](https://devblogs.microsoft.com/azure-sdk/power-azure-sre-agent-with-connector-namespace/)

### AIの普及で「低深刻度」の脆弱性がより危険になっている

**要約**: AIによる情報収集・攻撃の自動化が進んだことで、従来は軽視されがちだった「低深刻度」の脆弱性が組み合わさることでより大きなリスクにつながるとの指摘がなされている。

**影響**: 脆弱性管理を深刻度スコアだけで判断せず、AIによる攻撃チェーンの構築リスクを踏まえた評価が必要になりつつある。

# 2026/08/21 テクニカル雑談（午前）

## 1. Microsoft

### Windows 11の8月更新でゲームがクラッシュする不具合

**要約**: Windows 11の8月Patch Tuesday（KB5121003等）適用後、一部のPCゲームで深刻なクラッシュが発生していることをMicrosoftが認め、調査中と発表。ゲーム開発元Embark Studios（ARC Raiders）も問題を確認し、暫定的な回避策を案内している。

**影響**: セキュリティ更新の適用と安定性のトレードオフが再び顕在化した事例。企業のPC管理者は月例更新の適用前に、既知の不具合情報を確認するプロセスを見直す必要がある。

**リンク**: [Microsoft says August Windows updates may cause gaming issues](https://www.bleepingcomputer.com/news/microsoft/microsoft-august-windows-updates-may-cause-gaming-issues-reboots/)

### Task ManagerがAIワークロード監視に対応

**要約**: MicrosoftはWindowsのTask ManagerにAIワークロード（NPU利用状況など）の監視機能を追加すると発表。GPU/CPU/メモリと同様に、ローカルで動くAI推論処理の負荷を可視化できるようになる。

**影響**: ローカルLLMやCopilot+ PC向けアプリを開発するエンジニアにとって、実機でのリソース使用状況をより詳細に把握できるようになり、パフォーマンスチューニングがしやすくなる。

**リンク**: [Microsoft gives Task Manager another task: Watching AI workloads](https://www.theregister.com/os-platforms/2026/08/20/microsoft-gives-task-manager-another-task-watching-ai-workloads/5290448)

### Microsoft Entraのアイデンティティガバナンス機能拡張

**要約**: Microsoft Entraにアイデンティティガバナンスとクラウド同期に関する機能拡張が発表された。既存のアクセス管理・監査機能が強化される内容。

**影響**: 企業のID管理担当者やセキュリティエンジニアにとって、アクセス権のライフサイクル管理やコンプライアンス対応をより自動化しやすくなる可能性がある。

**リンク**: [Microsoft Entra Update Expands Identity Governance and Cloud Sync](https://petri.com/microsoft-entra-update-identity-governance-cloud-sync/)

## 3. Azure

**要約**: 2026年8月より、Azure Copilotのユーザーがエージェントに直接アクセスできるようになり、質問からアクションへの移行がより迅速に行えるようになった。

**影響**: Azure運用担当者にとって、トラブルシューティングやリソース操作をCopilot経由でより直接的に実行できるようになり、運用の自動化・効率化が進む。

**リンク**: [Announcing: Azure Copilot introduces direct access to agents](https://azure.microsoft.com/updates?id=569685)

### ゲートウェイの集約プレフィックス広告がGA

**要約**: Azure VPN GatewayやExpressRoute Gatewayにおいて、集約（サマリー）されたプレフィックスでのルート広告機能が一般提供（GA）となった。

**影響**: 大規模なハイブリッドネットワーク環境で、ルートテーブルのエントリ数を削減しつつ経路管理を簡素化できるため、ネットワークエンジニアの運用負荷軽減につながる。

**リンク**: [[Launched] Generally Available: Summarized advertised gateway prefixes for route advertisement](https://azure.microsoft.com/updates?id=569743)

### MetaがAzureの主要AI顧客に

**要約**: Metaが大規模なAIワークロードのためにMicrosoft Azureクラウドの主要顧客となったと報じられた。詳細な契約内容は明らかにされていないが、複数のメディアが同様の報道をしている。

**影響**: ハイパースケーラー間の顧客獲得競争が激化する中、Azureのインフラ需要増加は、クラウドキャパシティやGPUリソースの確保競争にも影響する可能性がある。

**リンク**: [Meta becomes major AI customer of Microsoft's Azure cloud - report](https://www.investing.com/news/company-news/meta-becomes-major-ai-customer-of-microsofts-azure-cloud--report-93CH-4869381)

## 5. セキュリティ

### isolated-vmにサンドボックス脱出の脆弱性

**要約**: Node.js向けサンドボックスライブラリ「isolated-vm」に、サンドボックス化されたJavaScriptがホスト環境にエスケープできる脆弱性が発見された。悪用されるとリモートコード実行（RCE）につながる可能性がある。

**影響**: isolated-vmを利用してユーザー提供コードを実行するサービス（プラグインシステムやコード実行環境など）は早急にパッチ適用状況を確認する必要がある。

**リンク**: [Isolated-vm Flaw Lets Sandboxed JavaScript Escape to Host for Potential RCE](https://thehackernews.com/2026/08/isolated-vm-flaw-lets-sandboxed.html)

### CISAがMLflowの脆弱性を既知の悪用脆弱性カタログに追加

**要約**: 米CISAが機械学習プラットフォーム「MLflow」の脆弱性を、実際に悪用が確認された脆弱性のカタログ（KEV）に追加した。

**影響**: MLflowを社内のML運用基盤として利用している組織は、該当する脆弱性の有無を確認し、CISAの是正期限に沿ったパッチ適用が求められる。

**リンク**: [U.S. CISA adds an MLflow flaw to its Known Exploited Vulnerabilities catalog](https://securityaffairs.com/197558/hacking/u-s-cisa-adds-a-mlflow-flaw-to-its-known-exploited-vulnerabilities-catalog.html)

### NISTが脆弱性データベースの近代化を検討

**要約**: NISTがAIの進化に伴い、National Vulnerability Database（NVD）を機械可読・機械速度での消費を前提とした形に再設計する必要性を検討していると報じられた。専門家は「脆弱性発見の経済性が変わった」と指摘している。

**影響**: 脆弱性情報の収集・分析を自動化しているセキュリティチームにとって、NVDのデータ形式や更新頻度の変化は既存の脆弱性管理パイプラインに影響しうるため、今後の動向を注視する価値がある。

**リンク**: ['The economics of vulnerability discovery have changed': NIST wants to modernize the National Vulnerability Database amid AI advances](https://www.itpro.com/security/nist-national-vulnerability-database-modernization-machine-speed-consumption)

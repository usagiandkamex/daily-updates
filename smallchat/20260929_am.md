# 2026/09/29 テクニカル雑談（午前）

## 1. Microsoft

### Teams のチャット一覧から Copilot ショートカットが消える

**要約**: Microsoft は来月、Teams のチャット一覧から Copilot のショートカットを削除する予定と報じられています。他のアプリに続く動きとのことです。

**影響**: Copilot の導線が整理される流れです。社内で Teams 経由の Copilot 利用を案内している場合は、操作手順書の更新を検討したほうがよさそうです。

**リンク**: [Microsoft will remove the Copilot shortcut from the Teams chat list next month - Windows Central](https://www.windowscentral.com/artificial-intelligence/microsoft-copilot/microsoft-teams-is-the-latest-app-to-lose-a-copilot-shortcut)

### Edge の Internet Explorer モードのサポート終了

**要約**: Microsoft が Edge の Internet Explorer モードのサポートを終了すると報じられています。

**影響**: 社内の古い Web アプリを IE モードで動かしている組織では、移行計画が必要になります。対象システムの棚卸しを早めに進めたいところです。

**リンク**: [Microsoft is ending support for Internet Explorer mode in Edge - Mashable](https://mashable.com/tech/microsoft-ending-internet-explorer-mode-in-edge)

### 次の Windows 更新で古いプリンターが使えなくなる可能性

**要約**: 次の Windows 更新により、古いプリンターが使えなくなる可能性があると報じられています。

**影響**: プリンタードライバーや旧式デバイスを扱う環境では、更新前に対象機器の互換性確認が必要です。

**リンク**: [The next Windows update might make your old printer obsolete (as in, you'll need a new one) - How-To Geek](https://www.howtogeek.com/next-windows-update-might-make-old-printer-obsolete-youll-need-new-one/)

## 2. AI

### AIに「推測するな」と指示するだけで架空データが減少

**要約**: ウェブページから情報を抽出させる際に「ページに値がなければ null を使い、推測しないでください」と指示するだけで、存在しない値を作り出す割合が 70.7% から 20.2% に低下したという実験結果が公開されました。

**影響**: プロンプトの一文で幻覚を大きく減らせる可能性があります。スクレイピングや RAG 系のパイプラインでは、「わからなければ null」を明示するのが手軽な対策になります。

**リンク**: [AIに「推測するな」と指示するだけで架空データが70％から20％に減少したという実験結果](https://gigazine.net/news/20260928-ai-do-not-guess/)

### AWS が Strands ハーネスをオープンソースで公開

**要約**: AWS は AI エージェントを自作できるツール「Strands ハーネス」を公開しました。GPT、Claude、Gemini、Ollama など主要な LLM を入れ替えて使え、任意のコンテナ環境にデプロイできます。

**影響**: 特定の LLM に依存しないエージェント基盤を選べるため、モデル切り替えやロックイン回避の選択肢が増えます。

**リンク**: [AWS、AIエージェントを自作できるツール「Strandsハーネス」をオープンソースで公開](https://www.publickey1.jp/blog/26/awsaistrandsllm.html)

### gpt-live-1：会話とバックエンドを分離する音声モデル

**要約**: gpt-live-1 は音声対話を担当し、検索や深い推論、ツール選択などをバックエンドに委譲するフルデュプレックス音声モデルとして解説されています。1 つのモデルがすべてを担う gpt-realtime-2.1 とは役割が異なります。

**影響**: 音声エージェントを作る際、会話の応答性と重い処理を分けて設計する考え方の参考になります。

**リンク**: [gpt-live-1 技術解説：会話とバックエンドの分離、Function Calling / Jev の実行経路の可視化](https://qiita.com/nohanaga/items/739bdb2d02ba62548aaf)

## 3. Azure

### Azure SQL の Vector search / vector index が GA

**要約**: Azure SQL Database でベクター検索とベクターインデックスが一般提供になりました。T-SQL の CREATE VECTOR INDEX と VECTOR_SEARCH が使えます。

**影響**: 別のベクター DB を立てずに、既存の SQL データに対して RAG や類似検索を実装しやすくなります。

**リンク**: [[Launched] Generally Available: Vector search and vector indexes in Azure SQL](https://azure.microsoft.com/updates?id=571800)

### Azure SQL Dev Hub がパブリックプレビュー

**要約**: Azure SQL でアプリケーションを開発する際の入口となる Azure SQL Dev Hub がパブリックプレビューになりました。直接開発する場合も、AI エージェントを使う場合も対象です。

**影響**: Azure SQL 向けの開発情報が一か所に集まるため、新規プロジェクトの立ち上げ時に参照しやすくなります。

**リンク**: [[In preview] Public Preview: Azure SQL Dev Hub](https://azure.microsoft.com/updates?id=572998)

### JadePuffer 関連の攻撃者が侵害されたサービスプリンシパルで Azure リソースを削除

**要約**: JADEPUFFER に関連する攻撃者が、侵害されたサービスプリンシパルを使って Azure リソースを削除したと報じられています。エージェント型 AI による攻撃という見方もあります。

**影響**: サービスプリンシパルの資格情報管理と最小権限、削除操作の監視やロックの整備が重要になります。

**リンク**: [JADEPUFFER-Linked Attackers Used Compromised Service Principals to Delete Azure Resources - The Hacker News](https://thehackernews.com/2026/09/jadepuffer-linked-attackers-used.html)

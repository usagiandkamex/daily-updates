### Azure Backup、Premium SSD v2 / Ultra Disk の VM でアイテムレベル復旧が GA

**影響**: VM 全体を戻さずに必要なファイルだけを復旧できるため、高性能ディスクを使うワークロードでも運用負荷が下がります。該当ディスクを使っている環境では、バックアップ設計を見直す好機です。

**リンク**: [[Launched] Generally Available: Item Level Recovery for Azure VMs with Premium SSDv2 and Ultra Disks in Azure Backup](https://azure.microsoft.com/updates?id=577963)

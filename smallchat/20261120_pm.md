# 2026/11/20 テクニカル雑談（午後）

## 1. Microsoft

### Microsoft To Do が 2027年6月30日で終了

**要約**: Microsoft は 2015年に買収した Wunderlist をベースに開発してきたタスク管理アプリ「Microsoft To Do」を、2027年6月30日でサービス終了すると発表しました。個人利用者は別アプリへの乗り換えが必要で、法人向けは「Planner」が後継とされています。

**影響**: To Do の API や Outlook 連携、個人のタスク運用に依存している場合は、移行先と移行手段を早めに検討する必要があります。社内ツールや自動化で連携しているチームは、期限までに代替フローを用意しておくと安心です。

**リンク**: [「Microsoft To Do」アプリが2027年6月で廃止、個人の場合は別アプリへの乗り換えが必要に／法人向けは「Planner」が後継](https://forest.watch.impress.co.jp/docs/news/2158040.html)

### Windows PC を USB4 でつなぐ「RDMA over USB4」

**要約**: Microsoft が、Windows PC 同士を USB4 ケーブルだけで接続し、メモリや GPU の計算能力を共有して大型 AI モデルを実行できる「RDMA over USB4」を発表しました。専用機材は不要とされています。

**影響**: 手元の複数 PC をつなぐだけでローカル LLM の実行環境を拡張できる可能性があります。高価な GPU サーバーを用意しなくても、検証用途のクラスターを作る選択肢が増えそうです。

**リンク**: [Windows PCを複数台接続して1個のAI処理クラスターとして扱う機能「RDMA over USB4」をMicrosoftが発表](https://gigazine.net/news/20261120-rdma-over-usb4-windows/)

### 未修正の Windows ゼロデイ「FastUnlock」

**要約**: The Hacker News によると、ロックされた Windows PC を手にした人物がその上でプログラムを実行できてしまう、未修正のゼロデイ脆弱性「FastUnlock」が報じられています。

**影響**: 物理的に端末へ触れられる状況が前提の問題ですが、持ち出しノート PC を使うエンジニアにとっては無視できません。BitLocker など既存の端末保護の見直しと、今後の修正パッチの動向確認が必要です。

**リンク**: [New Unpatched Windows 0-Day FastUnlock Lets Someone Holding a Locked PC Run Programs on It - The Hacker News](https://thehackernews.com/2026/11/new-unpatched-windows-0-day-fastunlock.html)

**リンク**: [AIが追加学習なしで自らのウェイトを書き換えて「自分自身を賢くする」ことに成功](https://gigazine.net/news/20261120-large-language-model-can-rewrite-itself/)

**リンク**: [[Launched] Generally Available: Soft delete in Azure Compute Gallery](https://azure.microsoft.com/updates?id=581907)

**影響**: 次期メジャーバージョンの機能や互換性を、マネージド環境で事前検証できます。アップグレード計画のある方は、アプリの互換性テストを早めに始められます。

**リンク**: [[In preview] Public Preview: PostgreSQL 19 on Azure Database for PostgreSQL](https://azure.microsoft.com/updates?id=574587)

### Azure VM のゾーン耐障害性がパブリックプレビュー

**要約**: 対象となるゾーン VM を、同一リージョン内の別の可用性ゾーンで復旧できる「Zone resilience for Azure VMs」がパブリックプレビューになりました。

**影響**: ゾーン障害時の復旧設計が簡素化される可能性があります。可用性設計や BCP の見直し時に、選択肢として評価する価値があります。

**リンク**: [[In preview] Public Preview: Zone resilience for Azure VMs](https://azure.microsoft.com/updates?id=581254)

### PHP に約20年潜んでいた「httpS://」の脆弱性が解決

**リンク**: [Microsoft releases Windows 11 version 26H2, calls it a "predictable and low-disruption update" with no compatibility concerns - windowscentral.com](https://www.windowscentral.com/microsoft/windows-11/microsoft-releases-windows-11-version-26h2-calls-it-a-predictable-and-low-disruption-update-with-no-compatibility-concerns)

## 3. Azure

### Azure Functions v1 ホスティングモデル（Container Apps）の廃止予告

**要約**: Azure Container Apps 上の Azure Functions v1 ホスティングモデルは 2027 年 9 月 29 日に廃止されます。以降、既存の Functions v1 アプリは影響を受けます。

**影響**: 該当構成のアプリがある場合、期限まで約 1 年です。移行先の確認と計画を今のうちに立てておきましょう。

**リンク**: [Retirement: Azure Functions v1 hosting model on Azure Container Apps](https://azure.microsoft.com/updates?id=570800)

### Lasv5 / Laosv5 ストレージ最適化 VM が GA

**要約**: 第 5 世代 AMD EPYC（Turin）ベースのストレージ最適化 VM シリーズ Lasv5 と Laosv5 が一般提供になりました。

**影響**: ローカルストレージ性能が重要なデータベースやログ処理などのワークロードで、新しい選択肢になります。

**リンク**: [[Launched] Generally Available: Storage optimized Lasv5 and Laosv5 Azure VM series](https://azure.microsoft.com/updates?id=572630)

### VM スケールセットの Automatic Zone Placement（プレビュー）

**要約**: VM スケールセットで、Azure が最適な可用性ゾーンを自動選択する Automatic Zone Placement がパブリックプレビューになりました。

**影響**: ゾーン配置の設計や運用の手間が減る可能性があります。可用性要件との兼ね合いを検証環境で確認するとよいでしょう。

**リンク**: [[In preview] Public Preview: Automatic Zone Placement for Virtual Machine Scale Sets](https://azure.microsoft.com/updates?id=571075)

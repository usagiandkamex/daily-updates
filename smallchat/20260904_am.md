## 1. Microsoft

### Windows 11、2026年10月からメモリ整合性保護をデフォルト有効化へ

**要約**: Microsoftは2026年10月以降、対象となるWindows 11 PCにおいてメモリ整合性保護（Memory Integrity）を自動的に有効化する方針を発表した。

**影響**: カーネルレベルの保護が標準化されることで、ドライバや常駐ソフトの互換性検証が今後より重要になる。開発者は自社アプリがこの保護下でも正常動作するか事前に確認しておく必要がある。

**リンク**: [Microsoft promises to make more Windows 11 PCs secure by default in October 2026](https://www.reddit.com/r/microsoft/comments/1w6hu47/microsoft_promises_to_make_more_windows_11_pcs/)

**リンク**: [Microsoft's latest Windows 11 KB5120998 update breaks mouse and desktop settings](https://www.neowin.net/news/microsofts-latest-windows-11-kb5120998-update-breaks-mouse-and-desktop-settings/)

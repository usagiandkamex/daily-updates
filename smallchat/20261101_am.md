### 新しい Secure Boot 証明書が PC に届かないケース

**要約**: TweakTown が、自分の PC に Microsoft の新しい Secure Boot 証明書が適用されておらず、原因は Windows Update ではなかったという体験記事を公開しています。

**影響**: 証明書の更新は Windows Update だけでなく、ファームウェア（UEFI）側の事情にも左右され得ます。社内端末では、更新状況の確認と BIOS/UEFI の更新計画を早めに棚卸ししておくと安心です。

**リンク**: [My PC missed Microsoft's new Secure Boot certificates, and Windows Update wasn't the problem - TweakTown](https://www.tweaktown.com/guides/11653/my-pc-missed-microsofts-new-secure-boot-certificates-and-windows-update-wasnt-the-problem/index.html)

### .gitignore の `.env` 1 行では不十分

**要約**: Qiita の記事が、git 2.47.3 で検証した結果、`.gitignore` に `.env` と書くだけでは `.env.local` や `.env.bak`、`prod.env` などは無視されないことを示しています。

**影響**: AI エージェントに作業させる機会が増えるほど、秘密情報の誤コミットは身近なリスクになります。`.env*` のようなパターンや `git status` での確認を習慣化したいところです。

**リンク**: [.gitignore の .env 1行では .env.local も .env.bak も無視されない - Qiita](https://qiita.com/supportapp3/items/549333dd043b8f2da8a4)

### CloudFront の AWS WAF SDK 自動統合

**要約**: Classmethod の記事で、CloudFront の AWS WAF SDK 自動統合を有効にすると、アプリや CI/CD にタグを組み込まなくても web ACL の設定だけで WAF SDK のシグナルを Bot Control などの判定に使えることが紹介されています。HTML への script タグ挿入や、ETag と Range 要求の扱いにも影響があります。

**リンク**: [CloudFront の AWS WAF SDK 自動統合を有効にして、HTML への script タグ挿入と応答の変化を確認してみた - DevelopersIO](https://dev.classmethod.jp/articles/waf-cloudfront-automatic-sdk-integration/)

# 2026/10/10 テクニカル雑談（午前）

## 1. Microsoft

### Microsoft 365 のストレージ容量が縮小へ

**要約**: Microsoft 365 の OneDrive ストレージが、ファミリープランなどで 6TB から 2TB に縮小される動きが報じられています。ZDNET Japan は「実質値上げ」と表現しており、Reddit ではユーザーの反発も出ています。

**影響**: OneDrive を大容量のバックアップ先や共有ストレージとして使っている人は、容量の見直しが必要になるかもしれません。代替ストレージへの移行や、不要データの整理を早めに検討しておくと安心です。

**リンク**: [マイクロソフト、「Microsoft 365」のストレージ容量を縮小へ--一部は「実質値上げ」](https://japan.zdnet.com/article/35253416/)

### Surface Laptop Ultra とローカル AI エージェントのプレビュー

**要約**: ZDNET によると、Microsoft は Surface Laptop Ultra と新しいローカル AI エージェントをプレビューしました。The Verge は、Windows を再活性化させる取り組みとして、このイベントを取り上げています。

**影響**: ローカルで動く AI エージェントが Windows の標準機能になれば、クラウドに送りたくない処理をオンデバイスで完結できる可能性があります。Windows アプリ開発者は、今後の API や SDK の動向を押さえておきたいところです。

**リンク**: [Microsoft previews Surface Laptop Ultra, new local AI agents - ZDNET](https://www.zdnet.com/video/microsoft-previews-surface-laptop-ultra-new-local-ai-agents/)

### E5 + Defender で十分か？ メールセキュリティの議論

**要約**: Reddit で、E5 契約で Defender for Office 365 P2 を使っている組織が、サードパーティ製のメールセキュリティ層を追加すべきか議論しています。毎月数件のフィッシングメールがすり抜けているとのことです。

**影響**: 検知漏れは製品を足すだけでなく、ポリシー調整や報告フローの整備でも改善できます。多層防御のコストと運用負荷を天秤にかける、よくある悩みです。

**リンク**: [Do you need a third-party email layer on E5 with Defender?](https://www.reddit.com/r/microsoft/comments/1x1fyuh/do_you_need_a_thirdparty_email_layer_on_e5_with/)

## 2. AI

### Claude Dashboards / Claude Motion がベータ公開

**要約**: Anthropic は 10 月 8 日、Claude の新機能「Claude Dashboards」と「Claude Motion」をベータ版として公開しました。SQL を書かずにデータ分析でき、ダッシュボードを自動生成します。PC Watch によると、Design は無料でも使えるようになりました。

**影響**: 簡単な集計や可視化は、エンジニアを介さずに非エンジニアが自分で作れるようになります。BI 作業の依頼が減る一方、データ品質や権限管理の整備が重要になります。

**リンク**: [Claude、SQL不要でデータ分析可能に - ダッシュボードを自動生成する新機能](https://news.mynavi.jp/techplus/article/20261009-5099252/)

### Gemini API の Deep Research 旧エージェントが 10/23 に終了

**要約**: 2026 年 10 月 8 日付の Gemini API リリースノートで、Deep Research エージェント `deep-research-pro-preview-12-2025` の非推奨化が告知されました。提供終了日は 10 月 23 日で、告知から約 2 週間しかありません。

**影響**: 旧エージェントを使っているアプリは、04-2026 版への移行が必要です。猶予が短いので、早めに利用箇所を洗い出しましょう。

**リンク**: [Gemini API Deep Research 旧エージェントが10/23終了、04-2026版への移行手順](https://qiita.com/picnic/items/e76e1d39801e6e13d383)

### AI で調べた判例が実在せず、書籍が絶版に

**要約**: 琉球大の教授の書籍で、AI を使って検索した裁判事例が実在しなかったことが分かり、出版社が絶版・回収を発表しました。

**影響**: 生成 AI の出力はハルシネーションを含みうるため、引用や事実関係は一次情報で確認する必要があります。業務で AI を使う際も、検証プロセスを組み込むことが大切です。

**リンク**: [【速報】AIで調べた判例実在せず書籍絶版](https://www.47news.jp/15060645.html)

## 3. Azure

### Azure Arc 対応 Kubernetes の Key Vault Secrets Provider 拡張が廃止予定

**要約**: Azure Arc 対応 Kubernetes クラスター向けの Azure Key Vault Secrets Provider Extension が、2027 年 10 月 9 日に廃止されると告知されました。

**影響**: この拡張でシークレットを注入している環境は、廃止までに別の方式へ移行する計画が必要です。期限まで 1 年ありますが、早めの棚卸しをおすすめします。

**リンク**: [Retirement: Azure Key Vault Secrets Provider Extension for Azure Arc enabled Kubernetes clusters](https://azure.microsoft.com/updates?id=570313)

**影響**: IaC 化しておけば、検証環境を低コストで立てて壊せます。閉域構成の PoC を回す際の参考になります。

**リンク**: [IBM Bobと一緒に約75円でAzure BatchのPoCをやってみた](https://qiita.com/takumiida1/items/0bbc471bd9a937f80413)

**要約**: Tom's Hardware は、共有アカウント向けの Microsoft 365 ストレージが縮小され、2TB の上限が 2027 年 4 月以降に適用されると報じています。業界全体のストレージ不足が背景とされています。

**影響**: ストレージ価格の上昇圧力は、クラウド全般のコスト設計にも関わります。容量前提の運用は見直しておくと安心です。

**リンク**: [Microsoft 365 slashes storage capacity for shared accounts amid industry-wide shortages](https://www.tomshardware.com/software/cloud-storage/microsoft-365-slashes-storage-capacity-for-shared-accounts-amid-industry-wide-shortages-2tb-limit-to-take-effect-after-april-2027)

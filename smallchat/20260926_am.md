# 2026/09/26 テクニカル雑談（午前）

## 1. Microsoft

### Microsoft、業務向け新「Copilot」を発表　Home・Code・Autopilotを統合

**要約**: Microsoftがエージェント機能などを統合した新しい業務向け「Copilot」を発表した。新機能として「Home」「Code」「Autopilot」が追加され、チャット・コーディング支援・自動実行を1つのアプリにまとめる構成になっている。

**影響**: 開発者にとってはコーディング支援ツールがより広範な業務アプリと統合されることを意味し、社内ツールの選定や既存Copilot導入プロジェクトの見直しポイントになりうる。料金体系も「進化中」とされており、コスト試算は継続的な確認が必要。

**リンク**: [Introducing the new Copilot with Home, Code and Autopilot - The Official Microsoft Blog](https://blogs.microsoft.com/blog/2026/09/25/introducing-the-new-copilot-with-home-code-and-autopilot/)

### 直近のWindows更新でデスクトップの読み込み不具合が発生

**要約**: BleepingComputerの報道によると、最近のWindows更新プログラム適用後にデスクトップの読み込みに問題が生じるケースが報告されている。

**影響**: 社内展開前の更新プログラムは検証環境での事前確認が引き続き重要。IT管理者は既知の不具合情報を踏まえ、展開スケジュールの調整を検討する必要がある。

**リンク**: [Microsoft: Recent Windows updates cause desktop loading issues - BleepingComputer](https://www.bleepingcomputer.com/news/microsoft/microsoft-recent-windows-updates-cause-desktop-loading-issues/)

### Power BI管理者監視ワークスペースの初期化手順を検証

**リンク**: [Power BI 管理者監視ワークスペース（Admin Monitoring Workspace ）を初期化してみる](https://qiita.com/ryoma-nagata/items/783d1977f59f96fba511)

**影響**: EU市場向けに製品を提供するハードウェア・IoT関連の開発者・企業は、インシデント報告体制の整備が急務となる。コンプライアンス対応の遅れは罰則リスクにつながる。

# 2026/09/19 テクニカル雑談（午前）

## 1. Microsoft

### Windows 2026年9月更新で印刷がまた壊れる

**要約**: Neowinの報道によると、2026年9月のWindows更新プログラム適用後、印刷機能が再び不具合を起こしているという報告が相次いでいる。過去にも同様の印刷トラブルが繰り返されており、今回も複数環境で再現しているとのこと。

**影響**: 業務PCへの月例更新プログラムの適用タイミングやロールバック手順を事前に確認しておく必要がある。印刷業務を含む環境では、適用前の検証フェーズを厚めに取ることが望ましい。

**リンク**: [Latest Windows September 2026 update apparently breaks printing, again](https://www.neowin.net/news/latest-windows-september-2026-update-apparently-breaks-printing-again/)

### Microsoft、Defender Antivirusの誤警告バグを修正

**要約**: BleepingComputerによると、Microsoft Defender Antivirusが「無効化されている」という誤った警告を表示するバグが修正された。実際にはセキュリティ機能は正常に動作していたにもかかわらず、管理者やユーザーに不要なアラートが出ていた。

**影響**: セキュリティ監視ツールやSOC運用で誤検知に振り回されていた現場では、アラートノイズが減ることで対応工数の削減が期待できる。

**リンク**: [Microsoft fixes bug behind 'Defender Antivirus is turned off' alerts](https://www.bleepingcomputer.com/news/security/microsoft-fixes-bug-behind-defender-antivirus-is-turned-off-alerts/)

### Azure AI Search Knowledge Base、SharePoint根拠リンクの開封をワークアラウンドで対応

**要約**: Qiitaの記事では、Azure AI Search の Knowledge Base（Foundry IQ）で SharePoint を根拠に生成した回答について、標準のcitation形式（`[ref_id:<番号>]`）のままではユーザーが元のSharePointリンクを直接開けない問題への回避策が紹介されている。

**影響**: 社内ナレッジ検索やRAG基盤を構築する開発者にとって、根拠リンクの可読性・トレーサビリティ向上に直結する実装ノウハウとなる。

**リンク**: [Azure AI Search Knowledge base (Foundry IQ) で SharePoint の根拠リンクをユーザーが開けるようにするワークアラウンド](https://qiita.com/ryoma-nagata/items/ef962a61568c978d33d2)

## 3. Azure

### Microsoft Foundryのホスト型エージェント向けネットワーク送信制御がプレビュー公開

**要約**: Azure Release Communicationsによると、Microsoft Foundryのホスト型エージェントが行うアウトバウンド接続を管理者が制御できる「Network egress controls」がパブリックプレビューとして公開された。順序付きルールでマッチした通信を許可・拒否できる。

**影響**: エージェント基盤を本番導入する企業にとって、意図しない外部通信によるデータ漏えいリスクを低減できるガバナンス機能であり、セキュリティ要件の厳しい環境での採用障壁が下がる。

**リンク**: [Public Preview: Network egress controls for hosted agents in Microsoft Foundry](https://azure.microsoft.com/updates?id=571821)

### Azure AI FoundryにCVSS 10.0の権限昇格の脆弱性、Microsoftが修正

**要約**: The Hacker Newsの報道によると、Azure AI Foundryに深刻度CVSS 10.0の脆弱性が発見され、未認可のユーザーが権限昇格を行える状態だったが、Microsoftがパッチを適用して修正した。

**影響**: AI基盤サービスを利用する組織は、直ちにパッチ適用状況を確認し、関連するアクセス権限の棚卸しを行う必要がある。AI関連クラウドサービスの攻撃対象領域が拡大していることを示す事例。

**リンク**: [Microsoft Patches CVSS 10.0 Azure AI Foundry Flaw Enabling Unauthorized Privilege Escalation](https://thehackernews.com/2026/09/microsoft-patches-cvss-100-azure-ai.html)

### Azure Database for PostgreSQL、論理レプリケーションスロットの同期状況メトリクスがGA

**要約**: Azure Release Communicationsによると、Azure Database for PostgreSQL Flexible Serverにおいて、論理レプリケーションスロットの同期ステータスを監視できる新メトリクスが正式提供（GA）となった。

**影響**: レプリケーション遅延の可視化により、データ同期の異常を早期検知できるようになり、PostgreSQLを使った分析基盤やレプリケーション構成の運用監視が容易になる。

**リンク**: [Generally Available: Logical replication slot sync status metric for Azure PostgreSQL Flexible Server](https://azure.microsoft.com/updates?id=568414)

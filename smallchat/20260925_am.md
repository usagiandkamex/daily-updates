# 2026/09/25 テクニカル雑談（午前）

## 1. Microsoft

### Surface新製品から「Copilot+」ブランディングが消える

**要約**: 最新のSurface PCシリーズにおいて、これまで前面に押し出されていた「Copilot+ PC」というブランディング表記が姿を消していることが報じられた。ハードウェア自体のAI機能は維持されつつも、マーケティング上の呼称が見直されている模様。

**影響**: エンドユーザー向けの「AI PC」訴求が一巡し、機能そのものよりも実用性で評価される段階に移りつつあることを示唆する。ハードウェア選定の際はスペック表記の変化に注意が必要。

**リンク**: [Microsoft Copilot+ Branding Disappears from Latest Surface PCs](https://www.techpowerup.com/353060/microsoft-copilot-branding-disappears-from-latest-surface-pcs)

### Windows 11、Microsoft 365 のコンパニオンアプリ3種が終了へ

**要約**: Windows 11に同梱されていたMicrosoft 365関連のコンパニオンアプリ3種が、公開からわずか1年ほどで廃止されることが明らかになった。

**影響**: プリインストールアプリへの依存を避け、Web版やストア版など代替手段への移行を検討しておく必要がある。企業のキッティング手順にも影響し得る。

**リンク**: [Windows 11 is about to lose three Microsoft 365 companion apps](https://www.windowscentral.com/microsoft/microsoft-office/these-three-microsoft-365-apps-lasted-just-one-year-before-getting-axed)

### 全国でOfficeのライセンス認証が突然外れる不具合

**要約**: 9月24日時点で、旧製品を中心にMicrosoft Officeが突然消えたり、ライセンス認証を再度求められたりする不具合の問い合わせが多発していると報告された。再インストールなどの対応が必要になるケースもある。

**影響**: 業務用PCで突発的にOfficeが使えなくなるリスクがあるため、ライセンス管理担当者は最新情報を確認し、ユーザーへの周知や復旧手順の準備をしておくと安心。

**リンク**: [日本全国でMicrosoft Officeが突然消えたりライセンス認証が外れる不具合が発生](https://togetter.com/li/2749851)

## 2. AI

### NVIDIA、最大8人識別のリアルタイム文字起こしAIをオープンモデル公開

**要約**: NVIDIAが音声認識AIモデル「NVIDIA Nemotron 3 Diarization」を公開。最大8人の話者を識別しながらリアルタイムで文字起こしができるオープンモデルとして提供される。

**影響**: 会議の議事録作成やコールセンターのログ解析など、話者分離が必要なアプリケーションを自前でホストして構築できる選択肢が増える。ライセンス条件や推論コストの検証は必要。

**リンク**: [最大8人の話者を識別しつつリアルタイム文字起こしできるAIモデル「NVIDIA Nemotron 3 Diarization」がオープンモデルとして公開される](https://gigazine.net/news/20260924-nvidia-nemotron-3-diarization/)

### Notion APIとMCPの「ページアイコン」仕様が変更

**要約**: 2026年9月23日、Notion APIとNotion MCPの「ページアイコン」まわりの仕様が変更された。存在しないアイコン名・色を指定したexternalアイコンURLがvalidation_errorで弾かれるようになったほか、MCP経由でのコピー対応など複数の変更が含まれる。

**影響**: Notion連携ツールやMCPサーバーを自作・利用している開発者は、既存のアイコン指定処理がエラーになる可能性があるため、リリースノートを確認して早めに動作検証しておくべき。

**リンク**: [Notion API変更まとめ:不正アイコンURLはエラーに、MCPでコピーも可能に](https://qiita.com/picnic/items/a42a39aed33ad6d3c814)

### 「初回起動時だけAGENTS.mdが読まれない」不具合、公式Actionでも再現

**要約**: Claude Codeの変更履歴で「CLAUDE.mdが無いプロジェクトではAGENTS.mdを読む」機能が追加されたが、初回起動時に限りAGENTS.mdが読み込まれない現象が公式GitHub Actionと同じ経路でも再現したと報告されている。

**影響**: CI/CDにClaude Codeを組み込んでいるチームは、初回実行時の挙動が期待通りでない可能性があるため、ワークフロー設計時にウォームアップ実行を挟むなどの回避策を検討する必要がある。

**リンク**: [初回の起動だけ AGENTS.md が読まれない——公式Actionと同じ経路でも再現した](https://qiita.com/yurukusa/items/90e50a4e850beeb52acc)

## 3. Azure

### Azure Red Hat OpenShift for Azure Government、IL5認証を取得

**要約**: Microsoft Azure Red Hat OpenShift for Microsoft Azure Governmentが、米国防総省のセキュリティ基準「IL5」認証を取得したと報じられた。

**影響**: 米国政府機関向けのワークロードをコンテナ基盤上で運用する選択肢が広がる。政府系・規制産業向けシステムを扱うエンジニアは、コンプライアンス要件を満たすプラットフォームとして検討候補に加えられる。

**リンク**: [Microsoft Azure Red Hat OpenShift for Microsoft Azure Government Achieves IL5 Certification](https://uk.finance.yahoo.com/news/microsoft-azure-red-hat-openshift-185100538.html)

### VM復元ポイントの「Instant Access」がGA

**要約**: Premium v2またはUltraディスクをデータディスクとして持つ仮想マシンのアプリケーション整合性のある復元ポイントに対し、「Instant Access」機能が一般提供（GA）となった。

**影響**: バックアップからの復元待ち時間を短縮できるため、ディザスタリカバリ設計における目標復旧時間（RTO）の見直しに直結する。対象ディスク種別を利用している環境では設定を確認する価値がある。

**リンク**: [Generally Available: Instant Access for VM restore points](https://azure.microsoft.com/updates?id=572573)

### Azure Communication Services、一部スタンドアロンサービスが2028年に廃止予定

**要約**: Microsoftは、Azure Communication Services（ACS）の一部スタンドアロンサービスを2028年9月30日に廃止すると発表した。

**影響**: リードタイムは長いものの、該当サービスに依存するアプリケーションを持つチームは早めに移行計画を立てておくことで、後になって慌てて対応する事態を避けられる。

**リンク**: [Retirement: Azure Communication Services (ACS) standalone services will be retired on September 30, 2028](https://azure.microsoft.com/updates?id=557117)

# 2026/11/11 テクニカル雑談（午前）

## 1. Microsoft

### パッチ・チューズデーが2か月連続で1,000件超え

**要約**: 11月のパッチ・チューズデーで Microsoft は1,100件近いセキュリティ脆弱性を修正した。The Record も、修正件数が2か月連続で1,000件を超えたと伝えている。

**影響**: 修正量が非常に多く、検証・適用の負荷が増している。優先度付け（悪用確認済み・重大度の高いものから）と段階的な展開リングの整備が、運用チームにとってより重要になる。

**リンク**: [Microsoft Fixes Nearly 1,100 Security Vulnerabilities - Krebs on Security](https://krebsonsecurity.com/2026/11/microsoft-fixes-nearly-1100-security-vulnerabilities/)

### Anthropic が Claude 搭載の Office 競合ツールを発表

**要約**: Anthropic が Claude を活用した表計算などのオフィス向けツールを発表し、Microsoft の株価が下落したと報じられている。

**影響**: 生産性スイートの領域にも AI ネイティブな競合が参入してきた。社内で Microsoft 365 Copilot を前提にしている場合も、他ツールとの連携や乗り換えコストを意識する時期かもしれない。

**リンク**: [Anthropic Goes for Microsoft's Crown With New Claude-Powered Office Tools - Gizmodo](https://gizmodo.com/anthropic-goes-for-microsofts-crown-with-new-claude-powered-office-tools-2000837885)

### Windows 11 の累積更新 KB5132061 / KB5131087 が公開

**要約**: Windows 11 向けの累積更新プログラム KB5132061 と KB5131087 がリリースされた。

**影響**: 大量の修正を含む月例更新と合わせて、検証環境での事前確認が望ましい。

**リンク**: [Windows 11 KB5132061 & KB5131087 cumulative updates released - BleepingComputer](https://www.bleepingcomputer.com/news/microsoft/windows-11-kb5132061-and-kb5131087-cumulative-updates-released/)

## 2. AI

### Claude Opus 5.5 の推論能力が11月3日ごろから低下したとの指摘

**要約**: 開発者が Claude Code の利用履歴約1,400件を分析し、モデル名が変わらないまま11月3日ごろから推論能力が急激に低下した可能性を指摘した。

**影響**: 同じモデル名でも挙動が変わりうる。AI 支援開発に依存する現場では、自前の評価セットで継続的に品質を計測する仕組みが有効になる。

**リンク**: [Claude Opus 5.5の推論能力が11月3日から急激に低下したとの指摘、1400件の利用履歴から変化が判明](https://gigazine.net/news/20261110-claude-opus-nerf/)

### AI 生成 PR の説明文は `<details>` で折りたたむ

**要約**: Simon Willison 氏は、Claude Code や Codex が作成する PR の説明文を `<details><summary>` で折りたたむ運用を紹介している。

**影響**: エージェントが量産する冗長な説明がレビューの妨げになりにくくなる。チームの PR テンプレートに取り入れやすい小さな工夫だ。

**リンク**: [Hide your slop PR descriptions behind <details><summary>](https://simonwillison.net/2026/Nov/9/details-summary/)

### Notion が Fireworks AI のセキュリティインシデントを告知

**要約**: Notion が利用する AI ベンダー Fireworks AI でセキュリティインシデントが発生し、一部の Notion ワークスペースに影響する可能性があるとして告知した。

**影響**: サードパーティの AI ベンダーも自社のサプライチェーンの一部になる。利用中の SaaS がどの AI ベンダーにデータを渡しているかを把握しておきたい。

**リンク**: [一部のNotionワークスペースに影響を与える可能性があるFireworks AIのインシデントに関するお知らせ](https://www.notion.com/ja/help/security-incident-involving-a-third-party-ai-vendor)

## 3. Azure

### Azure Functions が .NET 11 に対応（GA）

**要約**: Azure Functions で .NET 11 を対象にしたアプリを isolated worker モードで構築できるようになり、GA となった。

**影響**: .NET 11 へのアップグレードを計画しているチームは、Functions も含めて移行できる。

**リンク**: [Generally Available: Azure Functions support for .NET 11](https://azure.microsoft.com/updates?id=578773)

### Azure Front Door に gRPC 対応（プレビュー）と edge actions（GA）

**要約**: Azure Front Door Standard / Premium が gRPC をネイティブにサポートし、パブリックプレビューとなった。またエッジでサーバーレスコードを実行できる edge actions が GA した。

**影響**: gRPC アプリを Front Door 経由で配信できるほか、軽量な処理をエッジに寄せられる。プレビュー機能の本番採用は慎重に判断したい。

**リンク**: [Public Preview: Azure Front Door adds native gRPC support](https://azure.microsoft.com/updates?id=579383) / [Generally Available: Azure Front Door edge actions](https://azure.microsoft.com/updates?id=579310)

### AKS 向け Distributed accelerator for cloud storage（プレビュー）

**要約**: AKS 上の AI ワークロード向けに、クラウドストレージを分散的に高速化する DACS がパブリックプレビューになった。

**影響**: 大規模データを読み込む学習・推論ジョブで、ストレージ I/O がボトルネックのときの選択肢になる。

**リンク**: [Public Preview: Distributed accelerator for cloud storage on AKS](https://azure.microsoft.com/updates?id=578454)

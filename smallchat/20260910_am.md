### AWSがフルスタックアプリを丸ごと生成する「Nx Plugin for AWS 1.0」を公開

**要約**: AWSは、AIがアプリケーションの基本コードだけでなく、セキュリティや可観測性の要件を満たしたインフラ構成のコードまで一気通貫で生成できるツール「Nx Plugin for AWS 1.0」をオープンソースとして公開した。

**影響**: フルスタックAWSアプリの立ち上げ工数が大幅に削減され、AIエージェント駆動でのインフラ構築が一段と現実的になる。セキュリティ・可観測性の考慮漏れを防ぐ標準化ツールとしても注目される。

**リンク**: [AWS、AIがフルスタックAWSアプリの基本コードを、セキュリティ、可観測性、インフラまで一気通貫で生成する「Nx Plugin for AWS 1.0」、オープンソースで公開](https://www.publickey1.jp/blog/26/awsaiawsnx_plugin_for_aws_10.html)

### Amazon MWAA ServerlessのVPC有無によるサービス到達性の検証

**要約**: Amazon MWAA Serverlessのタスクから、VPC構成の有無によってどのAWSサービスに到達できるかを検証。VPCなしではS3とCloudWatch Logsのみ到達可能で、NATなし構成ではログが欠落する可能性があると報告している。

**影響**: サーバーレスなAirflow環境のネットワーク設計において、ログ欠落などの見えにくい障害を未然に防ぐための重要な知見となる。

**リンク**: [Amazon MWAA ServerlessのタスクからAWSサービスに到達できる範囲をVPCの有無で確認してみた](https://dev.classmethod.jp/articles/amazon-mwaa-serverless-vpc-network-reachability/)

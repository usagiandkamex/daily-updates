# 2026/08/27 テクニカル雑談（午前）

## 1. Microsoft

### VS Code Agent Host がオープンアーキテクチャに

**要約**: Microsoftは、VS Code上でAIエージェントの永続的なセッションを扱う「Agent Host」を、オープンなアーキテクチャとして正式に位置づけました。エージェントの状態やコンテキストを維持したまま複数ツール間で連携できる基盤として整備が進んでいます。

**影響**: 拡張機能開発者は独自のAIエージェント統合をVS Codeの標準的な仕組みに乗せられるようになり、サードパーティ製ツールとの互換性・持続性が向上します。

**リンク**: [Microsoft Formalizes VS Code Agent Host as Open Architecture for Persistent AI Sessions](https://visualstudiomagazine.com/articles/2026/08/26/microsoft-formalizes-vs-code-agent-host-as-open-architecture-for-persistent-ai-sessions.aspx)

### MCPの新ロードマップが公開、HTTP統一・アイデンティティ強化へ

**要約**: Model Context Protocol（MCP）の新しいロードマップが公開され、今後はAIエージェント対応の強化、通信方式のHTTPへの統一、アイデンティティ管理、開発者体験の向上に注力する方針が示されました。

**影響**: MCPを使ったツール連携を実装しているエンジニアは、今後の通信仕様変更や認証周りの仕様追加を見据えた設計が必要になります。

**リンク**: [MCPの新ロードマップ公開、今後はAIエージェント対応、HTTP通信への統一、アイデンティティ、よりよいデベロッパー体験などに注力](https://www.publickey1.jp/blog/26/mcpaihttp.html)

### Windows 11にデスクトップアプリ向け新プライバシー制御をテスト中

**要約**: Microsoftは、Windows 11のデスクトップアプリに対する新しいプライバシー制御機能をテストしています。アプリごとのデータアクセス権限をより細かく管理できるようになる見込みです。

**影響**: 企業のIT管理者やセキュリティ担当者は、今後のWindows更新でアプリ権限管理のポリシー見直しが必要になる可能性があります。

**リンク**: [Microsoft tests new privacy controls for Windows 11 desktop apps](https://www.bleepingcomputer.com/news/microsoft/microsoft-tests-new-privacy-controls-for-windows-11-desktop-apps/)

## 3. Azure

### Azure Bastion、AKSクラスタへの接続がGA

**要約**: Azure Bastionを使ってAKS（Azure Kubernetes Service）クラスタに直接接続できる機能が一般提供（GA）されました。踏み台サーバーを別途用意せずにセキュアな接続経路を確保できます。

**影響**: Kubernetes運用者は、パブリックエンドポイントを開放せずにクラスタ管理作業を行える構成をシンプルに実現できます。

**リンク**: [Generally Available: Connect to AKS clusters using Azure Bastion](https://azure.microsoft.com/updates?id=570030)

### Azure Bastionでプレビュー機能2件、IPv6デュアルスタックと共有リンク期限設定

**要約**: Azure BastionにIPv6デュアルスタックサポートがパブリックプレビューとして追加され、あわせて共有リンクの有効期限設定機能が一般提供されました。

**影響**: ネットワーク構成にIPv6を採用している組織や、一時的な外部アクセス共有を厳格に管理したい運用チームにとって選択肢が広がります。

**リンク**: [Public Preview: IPv6 dual-stack support for Azure Bastion](https://azure.microsoft.com/updates?id=570025)

### Azure SRE AgentにVNet統合とLive Reportsが登場

**要約**: Azure SRE AgentがVNet統合に対応し一般提供が開始されたほか、稼働状況をリアルタイムに可視化する「Live Reports」機能がパブリックプレビューとして公開されました。

**影響**: SRE運用チームは、閉域ネットワーク内のリソースに対してもAgentを活用したインシデント対応・監視の自動化を進めやすくなります。

**リンク**: [Generally Available: Azure SRE Agent VNet Integration](https://azure.microsoft.com/updates?id=569695)

## 5. セキュリティ

### GiteaのRCE脆弱性が悪用され、マイナー型ペイロード配布

**要約**: セルフホスト型Gitサービス「Gitea」に存在するリモートコード実行（RCE）の重大な脆弱性が実際に悪用され、攻撃者が仮想通貨マイナーのようなペイロードを配布していることが報告されました。

**影響**: Giteaを自前運用している組織は、早急なパッチ適用とアクセスログの確認が必要です。放置するとサーバー乗っ取りや不正なリソース利用につながります。

**リンク**: [Critical Gitea RCE Actively Exploited as Reported Attack Drops Miner-Like Payload](https://thehackernews.com/2026/08/critical-gitea-rce-actively-exploited.html)

**リンク**: [Three 10.0 security flaws fixed across Ubiquiti's UniFi line](https://cyberscoop.com/ubiquiti-unifi-critical-vulnerabilities-patched/)

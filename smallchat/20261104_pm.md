## 1. Microsoft

### メモリ8GBのWindows 11 PCを高速化

**要約**: Microsoftはメモリ圧縮やストレージへのデータ退避の仕組みを最適化し、従来より最大2GB多くのデータをメモリ上に保持できるようにした。マルチタスク処理は最大40％向上し、タブ切り替え時の再読み込みも減るという。スタートメニュー、検索、エクスプローラーなどの操作ではユーザー要求を一時的に優先する。

**影響**: 低スペックな端末でも開発環境やブラウザを並行して使いやすくなる。社内の配布PCや検証用の軽量VMのスペック設計にも関わってくる。

**リンク**: [Microsoft、メモリ8GBのWindows 11 PCを高速化　マルチタスク処理は最大40％向上](https://www.itmedia.co.jp/news/article/2611/04/2000002851/)

**影響**: 開発者としては、8GB環境でも動く軽量なアプリ設計や、メモリ使用量を意識した実装がこれまで以上に求められる可能性がある。

**リンク**: [Microsoft spent two years telling you to buy 16GB of RAM, now it says 8GB is “a great fit” for Windows 11](https://www.windowslatest.com/2026/11/04/microsoft-spent-two-years-telling-you-to-buy-16gb-of-ram-now-it-says-8gb-is-a-great-fit-for-windows-11-as-ram-prices-soar-and-it-promotes-429-8gb-laptops/)

## 2. AI

### Google、小中高の学習用アカウントで検索・AI利用を制限

**要約**: 米Googleは3日、世界各地の小中高の児童生徒が使う学習用アカウントで、インターネット検索やAI機能の利用を制限する方針を発表した。初期設定では機能が無効になる。

**影響**: 教育向けサービスでは「AIは初期オフ」が標準になっていく可能性がある。EdTech系の開発では、管理者による有効化フローやデフォルト設定の設計が重要になる。

**リンク**: [【速報】グーグル、小中高で検索・AIの利用制限へ](https://www.47news.jp/15183028.html)

### Amazon DynamoDBのベクトル検索を検証

**要約**: 2026年8月に一般提供が始まったDynamoDBのベクトル検索について、DynamoDB上のテキストに意味検索を追加できる点が紹介されている。別の検索サービスへデータを複製・同期する仕組みが不要になるのが特徴。

**影響**: RAGなどの小規模な意味検索を、既存のDynamoDBだけで完結できる選択肢が増える。構成要素が減り、運用負荷の低減が期待できる。

**リンク**: [Amazon DynamoDB のベクトル検索機能を検証](https://acro-engineer.hatenablog.com/entry/2026/11/04/120000)

### CVSS 9.0超のCVEは本当に増えたのか

**要約**: NVDデータの検証では、CVSS 9.0以上のCVE件数は2026年7月を境に約3倍になったが、CVE全体も約3.7倍に増えており、深刻なものの割合は増えていない。

**影響**: 件数の増加だけで「AIで深刻な脆弱性が増えた」とは言えない。脆弱性管理では絶対数よりも割合や自社への影響で優先度を判断したい。

**リンク**: [CVSS 9.0超のCVEは本当に増えたのか — NVDデータで検証する](https://qiita.com/Tivo0921/items/28bf9c51f9574e70b3ef)

## 3. Azure

### Application Gateway for ContainersでJWT検証（プレビュー）

**要約**: AuthPolicyカスタムリソースにより、Application Gateway for Containersで一元的なJSON Web Token検証が可能になった。

**影響**: 認証検証をアプリごとに実装せずゲートウェイ側で集約でき、AKS上のマイクロサービスの認可設計が簡素化できる。

**リンク**: [Public Preview: JWT validation for Application Gateway for Containers](https://azure.microsoft.com/updates?id=576382)

### Application Gateway for ContainersでMCPゲートウェイ（プレビュー）

**要約**: 新しいMCPRouteカスタムリソースにより、Model Context Protocolのルーティングに対応した。プラットフォームチームがMCPサーバーを公開できる。

**影響**: AIエージェント向けのMCPサーバーをKubernetes上で公開する際の入口を、既存のゲートウェイで統一管理できる可能性がある。

**リンク**: [Public Preview: MCP gateway for Application Gateway for Containers](https://azure.microsoft.com/updates?id=576388)

### Application Gateway for Containersのプライベートイングレス（プレビュー）

**要約**: 承認されたAzure Private Linkのプライベートエンドポイント経由でのみ到達できるプライベートフロントエンドに対応した。

**影響**: 社内向けAPIやパートナー限定公開のサービスで、パブリック露出を避けた構成が取りやすくなる。

**リンク**: [Public Preview: Private ingress for Application Gateway for Containers](https://azure.microsoft.com/updates?id=576393)

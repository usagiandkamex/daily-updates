# 2026/11/24 テクニカル雑談（午後）

## 1. Microsoft

### Windows 11 のドライバーを Microsoft 標準ドライバーへ置き換え

**要約**: Microsoft は、1 つの不具合ドライバーが PC 全体を落とし得ると認め、プリンター・オーディオ・カメラ向けのドライバーを可能な限り自社提供のものに置き換えると発表したと報じられています。「クラッシュと攻撃経路の削減」が狙いです。

**影響**: サードパーティ製ドライバー起因の BSOD や脆弱性が減る可能性があります。一方、周辺機器ベンダーや業務アプリ開発者は、標準ドライバーに切り替わった際の挙動差を検証しておくと安心です。

**リンク**: [Microsoft admits one failed driver can bring down your PC - Windows Latest](https://www.windowslatest.com/2026/11/24/microsoft-admits-one-failed-driver-can-bring-down-your-pc-so-its-replacing-the-ones-for-printers-audio-and-cameras-with-its-own-wherever-it-can-on-windows-11-promising-fewer-crashes-and-attack/)

### Copilot 責任者「AI エージェントがソフトウェアの主要ユーザーになる」

**要約**: Microsoft の Copilot 責任者が、AI がコーディングの作業の大半を置き換えつつあり、エンジニアはより高次の問題を解くようになっていると語った、という記事です。AI エージェントがソフトウェアの主な利用者になるとも述べています。

**影響**: API やドキュメントを「人間だけでなくエージェントが使う」前提で設計する流れが強まりそうです。仕様の明確さや機械可読性が、これまで以上に重要になります。

**リンク**: ["90% of what I do has been replaced" - Windows Latest](https://www.windowslatest.com/2026/11/24/agents-are-very-harsh-customers-microsofts-copilot-boss-says-ai-agents-will-be-softwares-main-users-and-engineers-are-thinking-harder-than-ever/)

### Microsoft Ignite 2026 キーノートのまとめ

**要約**: Ignite 2026 の 2 時間超のオープニングキーノートで、Satya Nadella 氏の発表に含まれた製品・ソリューション・モデルを、発表順に 2〜3 行ずつ整理した Qiita 記事です。

**影響**: 全体像を短時間で把握でき、今後の Azure や Microsoft 365 のロードマップを追う足がかりになります。

**影響**: AI が書いた仕様や証明をそのまま信用すると誤った安心感につながります。検証プロセス自体を人間がレビューする手順が必要です。

**リンク**: [Museに後れを取るアップルとグーグル](https://www.watch.impress.co.jp/docs/series/nishida/2158551.html)

## 3. Azure

### Foundry IQ の Enterprise Knowledge Graph（パブリックプレビュー）

**要約**: Foundry IQ に、コンテンツ間の関係性に依存する質問向けのナレッジソースとして Enterprise Knowledge Graph が追加されました。あわせて、複雑な質問を分割して反復検索する IQ Retriever Zero もプレビューになっています。

**影響**: RAG で「関係性をたどる質問」への回答精度向上が期待できます。ただしプレビューなので、本番導入前に検証が必要です。

**リンク**: [Enterprise Knowledge Graph in Foundry IQ](https://azure.microsoft.com/updates?id=581333)

### Microsoft Foundry の Guardrails 刷新とエージェント評価

**要約**: Foundry の Guardrails 体験が更新され、分類器・決定的ルール・LLM ベースの制御などを実行時の安全対策として設定できます。また、エージェント評価に人手のアノテーションを加える機能もプレビューで提供されています。

**影響**: エージェントの安全性と品質評価を同じ基盤で扱いやすくなります。

**リンク**: [Updated Guardrails experience in Microsoft Foundry](https://azure.microsoft.com/updates?id=581338)

### Azure API Management の脆弱性に対応

**要約**: エネルギー分野への攻撃と関連する Azure API Management の脆弱性に Microsoft が対処した、と SC Media が報じています。

**影響**: APIM を使っている場合は、公式の案内を確認し、必要な更新やログ確認を行ってください。

**リンク**: [Microsoft addresses Azure API Management vulnerability - SC Media](https://www.scworld.com/brief/microsoft-addresses-azure-api-management-vulnerability-linked-to-energy-sector-attacks)

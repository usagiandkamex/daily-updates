### Brotli の脆弱性「HTTP2Shell」が Microsoft 製品にも波及

**要約**: Brotli の脆弱性「HTTP2Shell」が Microsoft 製品にも影響すると報じられました。これを受けて「.NET」に定例外の更新が出ており、「Visual Studio」と「PowerShell」にもセキュリティアップデートが提供されています。

**影響**: .NET や Visual Studio、PowerShell を開発・運用で使っているチームは、更新の適用状況を確認しておきたいところです。CI のビルドイメージや開発端末に古いランタイムが残っていないかも見ておくと安心です。

**リンク**: [「Brotli」の脆弱性「HTTP2Shell」はMicrosoft製品にも影響、「.NET」に定例外更新／「Visual Studio」、「PowerShell」でもセキュリティアップデート](https://forest.watch.impress.co.jp/docs/news/2151104.html)

**影響**: チャット経由のフィッシングは見落とされがちなので、検出の層が増えるのは歓迎です。一方で、誤検知時の挙動や管理者向け設定は、公開されたら確認しておきましょう。

**リンク**: [Microsoft Teams to Use AI for Detecting Phishing Attacks Using Teams Conversations - CyberSecurityNews](https://cybersecuritynews.com/microsoft-teams-ai-detection/)

### Prefetch を消すと Windows が遅くなる理由

**要約**: 「Prefetch を削除すれば高速化できる」という定番の小技について、実際には PC がかえって遅くなったと報じられ、Microsoft の開発者がその理由を説明しました。Prefetch はアプリ起動を速めるための仕組みです。

**影響**: 古いチューニング術は現行の Windows では逆効果になり得ます。検証端末の最適化や社内向けの手順書に昔の Tips が残っていないか、見直すきっかけになります。

**リンク**: [Deleting Prefetch to speed up Windows actually made PCs slower, and a Microsoft developer explained why - Windows Latest](https://www.windowslatest.com/2026/10/26/microsoft-explains-why-deleting-prefetch-can-slow-down-windows-11-as-its-designed-to-speed-up-app-launches/)

## 1. Microsoft

### Microsoft、3つの犯罪支援サービスの解体に着手

**要約**: 米Microsoftは10月14日、Health-ISACと共同で、フィッシング詐欺に使うアカウントやWebサイトなどを提供する3つの犯罪支援サービスの解体に着手したと発表しました。日本を狙った詐欺に関する警察庁からの情報提供がきっかけで、米裁判所の命令に基づくドメインの差し押さえ等が行われています。

**影響**: フィッシングが「サービス化」されている現状が改めて見えます。開発者としても、メール認証（SPF/DKIM/DMARC）やパスキー対応など、フィッシング耐性のある認証の導入を後回しにしない方がよさそうです。

**リンク**: [Microsoft、3つの国際的な犯罪ネットサービスを解体へ　日本狙った詐欺がきっかけ](https://www.itmedia.co.jp/news/article/2610/15/2000002299/)

## 3. Azure

### Azure Files のリージョン間コピー／同期が Public Preview

**要約**: Azure Storage Mover を使い、同一テナント内でストレージアカウント・リージョン・サブスクリプションをまたいだ Azure Files のデータコピーと同期ができるようになりました（プレビュー）。

**影響**: ファイル共有の移行や DR 用のレプリケーションを、自前スクリプトなしで組みやすくなります。

**リンク**: [Public Preview: Azure Files cross-region data copy and synchronization with Azure Storage Mover](https://azure.microsoft.com/updates?id=576542)

### Standard service endpoint が GA

**要約**: Azure Private Link ファミリーの新機能 Standard service endpoint が一般提供になりました。IaaS ワークロードを、スケーラブルかつ安全に接続する方法を提供します。

**影響**: VM ベースのワークロードでプライベート接続を設計する際の選択肢が増えます。既存構成との違いを確認しておくとよいでしょう。

**リンク**: [Generally Available: Standard service endpoint](https://azure.microsoft.com/updates?id=571025)

### VM Scale Sets の自動ゾーンバランスが GA

**要約**: 複数ゾーンにまたがる Virtual Machine Scale Sets を継続的に監視し、ゾーン間の偏りを自動で調整する機能が一般提供になりました。

**影響**: ゾーン障害後などに偏った配置を手動で直す運用負荷が減り、可用性の維持が楽になります。

**リンク**: [Generally Available: Automatic zone balance for Virtual Machine Scale Sets](https://azure.microsoft.com/updates?id=576334)

## 2. AI

### Google、学習用アカウントで検索・AI 機能を初期設定で無効化

**要約**: 米 Google は11月3日、世界の小中高の児童生徒が使う学習用アカウントで、検索や AI 機能の利用を制限する方針を発表した。初期設定では機能が無効になる。

**影響**: 教育向けサービスでは AI 機能を「デフォルトでオフ」にする設計が求められつつある。EdTech 系のプロダクトを作る開発者は、年齢や用途に応じた機能制御を考えておきたい。

**リンク**: [【速報】グーグル、小中高で検索・AIの利用制限へ](https://www.47news.jp/15183028.html)

**要約**: サイバーエージェントの若年層向け調査で、商品やサービスの情報源として生成 AI の回答を重視する傾向が分かった。生成 AI 利用者の45%が信頼しており、テレビや雑誌よりもわずかに高かった。

**影響**: 検索や SNS だけでなく、生成 AI の回答に自社情報が正しく載るかが重要になる。サービス提供側は、公開情報の構造化や正確性の維持を意識する必要がある。

**リンク**: [商品情報、若年層はインフルエンサーより生成AI信頼　サイバー調査](https://www.nikkei.com/article/DGXZQOUC301IV0Q6A031C2000000/)

## 3. Azure

### Azure Database for PostgreSQL の安定版 REST API 2026-10-01 が GA

**要約**: Azure Database for PostgreSQL Flexible Server の REST API バージョン 2026-10-01 が一般提供となった。この安定版では機能が拡張されている。

**影響**: IaC や自動化スクリプトで API バージョンを固定している場合、新バージョンへの移行を検討できる。Bicep、Terraform、SDK などの対応状況も確認しておきたい。

**リンク**: [Generally Available: Azure Database for PostgreSQL stable REST API version 2026-10-01](https://azure.microsoft.com/updates?id=579300)

### Azure Route Server のルートマップが GA

**要約**: Azure Route Server のルートマップが Azure パブリッククラウドで一般提供となった。インバウンドとアウトバウンドのルート制御を、きめ細かく行える。

**影響**: ハイブリッドやマルチネットワーク構成で、経路制御を柔軟に設計しやすくなる。ネットワークエンジニアは既存の経路ポリシーを見直す余地がある。

**リンク**: [Generally Available: Route maps for Azure Route Server](https://azure.microsoft.com/updates?id=578966)

### Azure Firewall の IPv6 がアプリケーションルールに対応（プレビュー）

**要約**: Azure Firewall の IPv6 で、アプリケーションルールがパブリックプレビューとして利用可能になった。IPv6 の HTTP/HTTPS トラフィックに対して、L7 でのフィルタリングができる。

**影響**: IPv6 環境でも IPv4 と同様の L7 制御を適用できる可能性がある。ただしプレビューなので、本番導入前に検証が必要。

**リンク**: [Public Preview: Azure Firewall IPv6 now supports application rules](https://azure.microsoft.com/updates?id=579507)

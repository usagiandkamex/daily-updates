# 2026/11/06 テクニカル雑談（午後）

## 1. Microsoft

### Intelligent Terminal 0.3 が過去最大のアップデート

**要約**: MicrosoftのAIターミナル「Intelligent Terminal 0.3」が公開された。エージェントとタブを縦に並べるサイドバーが導入され、ウィンドウを閉じても動き続けるヘッドレスモードも追加されている。

**影響**: 複数のAIエージェントを並行で走らせる開発スタイルが一般化する中、ターミナル側がエージェントの管理 UI を持つ流れが強まっている。長時間タスクをウィンドウに縛られず回せるのは、日常のワークフローに効きそうだ。

**リンク**: [MicrosoftのAIターミナル「Intelligent Terminal 0.3」、過去最大のアップデート](https://forest.watch.impress.co.jp/docs/news/2154135.html)

### Windows 11 の検索に Copilot 統合、ただしオプトイン

**要約**: Microsoft は 2026 年内に Windows 11 の新しい検索体験へ Copilot 統合を追加する予定で、オプトアウトではなくオプトイン方式にすると約束したと報じられている。

**影響**: 組織での端末管理では、Copilot の有効化ポリシーが「デフォルトでオフ」になるかどうかで展開の手間が変わる。正式な仕様が出たらグループポリシーや Intune での制御方法を確認しておきたい。

**リンク**: [Microsoft will add Copilot integration to Windows 11's new search experience](https://www.reddit.com/r/microsoft/comments/1xp5pnv/microsoft_will_add_copilot_integration_to_windows/)

### Office 365 A1 と Student Use Benefit が終了、100TB ストレージも廃止

**要約**: Microsoft が Office 365 A1 と Student Use Benefit の提供終了を確認した。あわせて、ベースの 100TB ストレージの提供も終了する。

**影響**: 教育機関のテナントを運用している場合、ライセンス移行やストレージ容量の見直しが必要になる。大容量データを置いていた環境は、早めに使用量の棚卸しをしておくと安心。

**リンク**: [Microsoft retiring Office 365 A1, Student Use Benefit, confirms 100TB base storage removal - Neowin](https://www.neowin.net/news/microsoft-retiring-office-365-a1-student-use-benefit-confirms-100tb-base-storage-removal/)

## 2. AI

### OpenAI が Linux カーネルの脆弱性 948 件を発見

**要約**: OpenAI が、社内で最高のサイバーセキュリティ検証能力を持つというモデル「GPT-6 Cyber」を使い、Linux カーネルの脆弱性を検証したと発表した。報道によれば 948 件の脆弱性が見つかり、費やした API コストは約 1 億 9200 万円とのこと。

**影響**: AI による脆弱性探索が実用規模に達しつつあることを示している。メンテナ側のトリアージ負荷や、パッチ適用の頻度増加に備えたい。

**リンク**: [OpenAIがLinuxの脆弱性948件を発見、費やしたAPIコストは約1億9200万円](https://gigazine.net/news/20261106-openai-built-linux-vulnerability/)

### 動画生成AI「Gemini Omni 1.2 Flash」登場

**要約**: 「そこだけ直して」といった指示で部分的な動画編集ができる動画生成AI「Gemini Omni 1.2 Flash」が登場した。

**影響**: 生成するだけでなく、対話で部分修正できるようになると、プロトタイプや社内向け動画の制作コストが下がる。API で提供される場合は、アプリへの組み込みも検討しやすくなる。

**リンク**: [「そこだけ直して」で動画編集可。動画生成AI「Gemini Omni 1.2 Flash」登場](https://pc.watch.impress.co.jp/docs/news/2154370.html)

### 米住民投票でデータセンター建設に反対相次ぐ

**要約**: 11月3日の米中間選挙に合わせ、AI 向けデータセンター建設の是非を問う住民投票が 10 州で計 41 件行われ、1 件を除いて建設禁止や規制強化が可決された。

**影響**: AI インフラの供給が政治・地域事情に左右されるリスクが見えてきた。リージョン選定や計算資源の調達計画では、電力・立地規制も考慮しておくとよい。

**リンク**: [米住民投票でデータセンター建設に反対相次ぐ](https://www.itmedia.co.jp/news/article/2611/06/2000002949/)

## 3. Azure

### Azure Front Door が TLS 鍵交換ポリシーでポスト量子に対応（GA）

**要約**: Azure Front Door で、ハイブリッド型のポスト量子鍵交換を含む TLS 鍵交換ポリシーを設定できるようになり、一般提供（GA）となった。

**影響**: 将来の量子計算機による「いま盗んで後で解読」型の攻撃への備えを、フロントエンド側の設定で始められる。クライアントやミドルボックスとの互換性を、検証環境で確認してから適用したい。

**リンク**: [Generally Available: Azure Front Door TLS key exchange policy with post-quantum support](https://azure.microsoft.com/updates?id=577668)

### 無料枠の比較: AWS 6 か月 vs Azure 30 日

**要約**: AWS・Azure・Google Cloud の無料枠を比較する記事で、AWS は 6 か月、Azure は 30 日といった期間の違いが取り上げられている。

**影響**: 検証や学習用途では、無料枠の期間とクレジットの条件でクラウドの選び方が変わる。無料枠終了後の課金を防ぐため、予算アラートを最初に設定しておこう。

**リンク**: [Free Cloud Tiers: AWS 6 Months vs Azure 30 Days [2026]](https://tech-insider.org/aws-free-tier-vs-azure-free-account-vs-google-cloud-free-tier-2026/)

## 4. クラウド

### RAG 用資料の「下ごしらえ」で誤答率が 30% から 13% に（Bedrock Knowledge Bases）

**要約**: Bedrock Knowledge Bases で社内資料を検索する RAG を作る際、資料をそのまま置くのではなく事前に整形したところ、誤答率が 30% から 13% に下がったという事例。

**影響**: マネージドサービスの自動チャンク分割に任せきりにせず、入力データの品質を整えることが精度向上の近道になる。

**リンク**: [RAGに入れる資料を「下ごしらえ」したら、誤答率が30%→13%に下がった](https://qiita.com/MURAMASA2470/items/a7c351ba251da81f507e)

### ALB の固定レスポンスで EC2 ダウン時もメンテナンス画面を表示

**要約**: ALB のリスナールールで固定レスポンスを返す設定にし、EC2 が停止していても、サーバーを使わずにメンテナンス案内を出せるようにした事例。

**影響**: 追加のサーバーや S3 を用意せずに済むため、メンテナンス告知の構成をシンプルにできる。

**リンク**: [EC2 がダウンしていてもメンテナンス画面を出せるようにした（ALB の固定レスポンス）](https://qiita.com/Tukirukiki/items/c8ee91004e6d47c5f0a4)

### RDS の audit ログが急増したときの原因切り分け

**要約**: RDS の audit ログがある時刻を境に増えて戻らない場合の、原因切り分け手順を紹介する記事。CloudWatch Logs の取り込み料金や SIEM への転送費用にも影響する。

**影響**: ログ量の急増はコストに直結するため、切り分けの手順をあらかじめ把握しておくと、運用時に慌てずに済む。

**リンク**: [RDS の audit ログがある時刻を境に増えたときの原因切り分け手順](https://qiita.com/hijiri0404/items/9612fa3a4c43a90d4b1a)

## 5. セキュリティ

### 攻撃者がエージェント型 AI ツールで露出シークレットを悪用

**要約**: Microsoft が、攻撃者がエージェント型 AI ツールを使って露出したシークレットを探し出し、悪用していると警告した。関連報道では、クラウドのシークレットが 5 分程度で奪われるとされている。

**影響**: リポジトリや設定ファイル、ログへの認証情報混入は、これまで以上に短時間で悪用される。シークレットスキャンの導入、短寿命トークンへの移行、漏えい時の即時ローテーションを整えておきたい。

**リンク**: [Threat actors use agentic AI tooling to find and abuse exposed secrets - Microsoft](https://www.microsoft.com/en-us/security/blog/2026/11/05/threat-actors-use-agentic-ai-tooling-to-find-and-abuse-exposed-secrets/)

### JNSA の理解度チェックサービスに不正アクセス

**要約**: 日本ネットワークセキュリティ協会（JNSA）は、「情報セキュリティ理解度チェックサービス」が不正アクセスを受け、最大 1 万 5128 件の個人情報が漏えいした可能性があると発表した。利用者の ID やハッシュ化したパスワードなどが対象。

**影響**: セキュリティ啓発団体でも被害に遭うという事実は重い。ハッシュ化していても、パスワードの使い回しがあれば他サービスに波及するため、利用者は変更を検討したい。

**リンク**: [セキュリティ啓発団体に不正アクセス　個人情報最大1.5万件漏えいか](https://www.itmedia.co.jp/news/article/2611/06/2000002978/)

### 脆弱性管理の新しい標準（AI 時代）

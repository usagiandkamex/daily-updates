**リンク**: [Announcing: New Windows App client-side endpoints for Azure Virtual Desktop](https://azure.microsoft.com/updates?id=571360)

### Azure Application GatewayでHTTP/3 over QUICサポートがパブリックプレビューに

**要約**: Azure Application Gatewayにおいて、HTTP/3 over QUICサポートのパブリックプレビューが発表された。HTTP/3はHTTPの次世代仕様で、QUICを用いて接続性能を改善する。

**影響**: レイテンシやパケットロスの多いネットワーク環境でWebサービスを提供する開発者にとって、接続確立の高速化やコネクション切断耐性の向上が期待でき、性能改善の選択肢が広がる。

**リンク**: [Public Preview: HTTP/3 over QUIC support in Azure Application Gateway](https://azure.microsoft.com/updates?id=571123)

**影響**: パスワードレス認証への移行を進める組織にとって、認証フロー自体を悪用する新種の攻撃への備えが必要であり、MFA・パスキー運用のセキュリティレビューが求められる。

## 5. セキュリティ

### GitLabの最大深刻度の脆弱性が既に悪用中とCISAが警告

**要約**: GitLabに存在する最大深刻度（Critical）の脆弱性が攻撃者によって既に悪用されていることを、CISAをはじめとする複数機関が警告した。

**影響**: GitLabを利用する開発チームは、影響を受けるバージョンを速やかに確認し、パッチ適用を最優先で行う必要がある。CI/CDパイプラインを含む開発基盤全体への侵害リスクがある。

**リンク**: [Malicious actors already using critical GitLab flaw, CISA and others warn](https://www.cybersecuritydive.com/news/gitlab-vulnerability-exploitation-cisa-kev/830278/)

### EUサイバーレジリエンス法の脆弱性報告義務が発効、ENISAが単一報告プラットフォームを開始

**要約**: EUのサイバーレジリエンス法（CRA）に基づく脆弱性報告義務が発効し、ENISAが企業向けの単一報告プラットフォーム（Single Reporting Platform）の運用を開始した。

**影響**: EU域内でハードウェア・ソフトウェア製品を提供する開発企業は、脆弱性発見時の報告フローを新プラットフォームに合わせて整備する必要があり、コンプライアンス対応の見直しが求められる。

**リンク**: [ENISA launches Single Reporting Platform as EU Cyber Resilience Act vulnerability reporting obligations take effect](https://industrialcyber.co/regulation-standards-and-compliance/enisa-launches-single-reporting-platform-as-eu-cyber-resilience-act-vulnerability-reporting-obligations-take-effect/)

### AIが人間の見逃した脆弱性を発見、サイバーセキュリティ業界に変革の波

**要約**: AIによる脆弱性発見能力が人間のセキュリティ専門家を上回りつつあり、サイバーセキュリティ業界に大きな変化をもたらすと論じられている。

**影響**: セキュリティ担当者にとって、AIを活用した脆弱性診断ツールの導入検討が急務となる一方、AIによる誤検知や見落としのリスクを補う人間の役割の再定義も求められる。

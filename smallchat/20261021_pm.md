## 1. Microsoft

### Windows 11 の Copilot 機能を縮小

**要約**: Windows Latest によると、Microsoft は Windows 11 で Copilot の見直しに着手し、エクスプローラーから 8 つの AI アクションを外す方針とのことです。同社はこれを「シンプル化」と位置づけています。

**影響**: OS への AI 統合は「何でも載せる」段階から取捨選択の段階に入りつつあります。Windows 向けアプリや社内展開の手順書で Copilot 前提の操作を案内している場合は、UI の変更に注意が必要です。

**リンク**: [Microsoft is now scaling back Copilot in Windows 11 amid Microslop backlash, pulling 8 AI actions from File Explorer and calling it simplifying](https://www.windowslatest.com/2026/10/21/microsoft-is-now-scaling-back-copilot-in-windows-11-amid-microslop-backlash-pulling-8-ai-actions-from-file-explorer-and-calling-it-simplifying/)

### Xbox Labs という新しいゲーム技術部門

**要約**: Microsoft が実験的なゲーム技術を扱う新部門「Xbox Labs」を立ち上げたと報じられています。

**影響**: ゲーム開発者にとっては、今後の SDK やクラウドゲーミング関連の技術動向を追う手がかりになります。詳細は続報を待ちたいところです。

**リンク**: [Xbox Labs: Microsoft's New Gaming Tech Division [2026]](https://tech-insider.org/xbox-labs-microsoft-experimental-gaming-division-2026/)

**要約**: 研究者が約 5 万ページの偽の統計データを載せたサイトを公開したところ、AI から大量のアクセスがあり、論文やニュースにまで引用されたと報じられています。

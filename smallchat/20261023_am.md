# 2026/10/23 テクニカル雑談（午前）

## 1. Microsoft

### 中国政府系ハッカーが AI ツール「ARTEX」で攻撃

**要約**: Microsoft は米国時間 21 日、中国政府と関係するハッカー集団が中国系 AI ツール「ARTEX」を使い、世界の数百組織に自動化されたサイバー攻撃を仕掛けていたことを確認したと発表した。Microsoft が自社クラウドサービスの記録などを調べた結果で、日本企業を標的とした攻撃への関与は明らかになっていない。

**影響**: 攻撃側の自動化が進み、偵察から侵入までの速度と規模が上がっている。防御側も検知・対応の自動化や、クラウドのログ監視を前提に備える必要がある。

**リンク**: [中国政府系ハッカー集団、AI「ARTEX」で攻撃　マイクロソフトが確認 - 日本経済新聞](https://www.nikkei.com/article/DGXZQOUC22AUL0S6A021C2000000/)

### Windows 11 に Windows 95 のメモリ管理機能が残っている

**要約**: 1995 年登場の Windows 95 のメモリ管理機能が、2026 年時点の最新 Windows 11 にも残っていることが分かった。古いソフトを動かすための互換機能「EmulateHeap」に Windows 95 のプログラムが組み込まれており、必要に応じて実際に動作するという。

**影響**: Windows の長い後方互換性を示す話題。レガシーアプリを抱える現場では、互換レイヤーが今も支えになっていることを再認識できる。

**リンク**: [Windows 11には31年前の「Windows 95のメモリ管理機能」が今も隠されている](https://gigazine.net/news/20261022-windows-11-95-memory-manager/)

## 3. Azure

### ABFS Vectored Read が GA

**要約**: Azure Data Lake Storage の ABFS Vectored Read が一般提供になった。互換性のある分析エンジンで、近接するファイル範囲の読み取りをまとめ、選択的な読み取り時のリクエストのオーバーヘッドを減らす。

**影響**: Parquet などを部分的に読むワークロードで、リクエスト数やレイテンシの削減が期待できる。対応エンジンを使っているなら効果を試す価値がある。

**リンク**: [[Launched] Generally Available: ABFS Vectored Read for Azure Data Lake Storage](https://azure.microsoft.com/updates?id=577618)

### ConnectWise 侵害で約 2,250 のクラウドテナントに影響

**要約**: The Register は、Microsoft の発表として、ConnectWise の侵害により中国系のスパイ活動が 2,250 のクラウドテナントに及んだと報じている。

**影響**: MSP や管理ツール経由のアクセスは影響範囲が広い。委任された権限や外部連携アプリの棚卸しを定期的に行いたい。

**リンク**: [Microsoft says ConnectWise breach let Chinese spies loose on 2,250 cloud tenants - The Register](https://www.theregister.com/security/2026/10/22/microsoft-says-connectwise-breach-let-chinese-spies-loose-on-2250-cloud-tenants/5304687)

### LocalStack が Azure 向けパブリックベータを開始

**影響**: ローカルでクラウド環境を再現する開発スタイルが Azure でも選べるようになる可能性がある。CI のコストや開発サイクルの短縮に効くか、注目したい。

**影響**: NAT Gateway の構成や運用の考え方が変わる。既存の AZ ごとの構成を、リージョン単位に整理できるか検討できる。

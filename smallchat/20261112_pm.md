# 2026/11/12 テクニカル雑談（午後）

## 1. Microsoft

### Outlook.com が DMARC 未設定ドメインのメールを拒否

**要約**: 2026年11月5日から9日にかけて、Outlook.com・Hotmail・Live・MSN といった Microsoft のコンシューマー向けメールサービスで、DMARC レコードを公開していないドメインからのメールが一部拒否される事象が発生した。

**影響**: 自社ドメインから通知メールなどを送っているサービス運用者は、SPF / DKIM / DMARC の設定を改めて確認しておきたい。設定漏れは配信障害に直結する。

**リンク**: [Outlook.comがDMARC認証を受けていないドメインからのメールを拒否](https://gigazine.net/news/20261112-outlook-rejecting-email-without-dmarc/)

### 最近の Windows 更新で SQL Server の性能問題

**要約**: Microsoft は、最近の Windows 更新プログラムが SQL Server のパフォーマンス問題を引き起こしていると認めたと報じられている。

**影響**: SQL Server を運用している場合、パッチ適用後にレイテンシやスループットを監視し、段階的な展開とロールバック手順を用意しておくと安心できる。

**リンク**: [Microsoft: Recent Windows updates cause SQL Server performance issues - BleepingComputer](https://www.bleepingcomputer.com/news/microsoft/microsoft-recent-windows-updates-cause-sql-server-performance-issues/)

### Entra ID の新しいセキュリティ機能は管理者が無効化できない

**要約**: Microsoft Entra ID に追加された新しいセキュリティ機能は、管理者が無効化できない仕様であると Techzine が報じている。別の記事では Entra のガバナンスとアクセス制御が AI エージェントやゲストユーザー向けに拡張されたとも伝えられている。

**影響**: テナント管理者は、強制的に有効になる挙動が既存の運用や連携アプリに影響しないか、事前に確認する必要がある。

**リンク**: [New Microsoft Entra ID security feature cannot be disabled by an administrator - Techzine Global](https://www.techzine.eu/news/security/145766/new-microsoft-entra-id-security-feature-cannot-be-disabled-by-an-administrator/)

## 5. セキュリティ

### Synology DSM に深刻度9.8の脆弱性

**要約**: Synology の NAS 用 OS「DSM」に、認証なしで攻撃可能な深刻度9.8の脆弱性が報じられた。回避策はないとされる。

**影響**: NAS を外部公開している場合は特に危険。公開範囲の見直しと、修正版が出次第の適用が必要。

**リンク**: [シノロジーのNAS用OS「DSM」に深刻度9.8の脆弱性](https://news.yahoo.co.jp/articles/9a1657f3cabfab4312e265fdee8a380e28ddce45)

### MongoDB が CVSS 9.5 の重大脆弱性を修正

**要約**: 認証不要で DB を停止させられる恐れのある重大脆弱性について、MongoDB が7系統に更新版を提供した。

**影響**: 利用中のバージョン系統を確認し、速やかに更新版へ上げたい。

**リンク**: [認証不要でDBが停止の恐れ MongoDBが重大脆弱性を修正](https://news.yahoo.co.jp/articles/bbb89edab2023e7ecf2c32894fb533119d00af9f)

### Node.js に深刻度 high の脆弱性7件

**要約**: Node.js で深刻度「high」の脆弱性が7件公表された。認証なしでサーバ停止が可能になるものや、TLS 秘密鍵の漏えいにつながるものが含まれる。

**影響**: Node.js をサーバで使っている場合は、パッチバージョンへの更新と本番・CI のランタイム確認が必要。

**リンク**: [Node.jsに深刻度「high」の脆弱性7件](https://www.sbbit.jp/article/cont1/188342)

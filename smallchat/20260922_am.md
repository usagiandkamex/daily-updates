# 2026/09/22 テクニカル雑談（午前）

## 1. Microsoft

### Excelの「貼り付け」が黙って失敗する不具合、9月の月例更新が原因に

**要約**: Excelでセルの貼り付け操作が何のエラーメッセージも出さずに失敗する不具合が報告されている。原因は9月の月例更新（Windows Update）にあるとされ、一部バージョンでは既に修正が進んでいるという。

**影響**: 業務でExcelを多用する開発者・データ担当者にとっては、エラーが出ないまま処理が失敗するため気づきにくく、パッチ適用状況の確認とワークアラウンドの準備が必要になる。

**リンク**: [「Excel」で貼り付けが“黙って”失敗する不具合、原因は9月の月例更新／一部バージョンで修正が進む](https://forest.watch.impress.co.jp/docs/news/2142530.html)

### Windows 11の緊急アップデート、音声不具合の修正は10月までずれ込む可能性

**要約**: Microsoftは、Windows 11向け緊急アップデートによって発生した音声関連の不具合が依然として解消していないことを認めた。恒久的な修正パッチの提供は10月にずれ込む可能性があるという。

**影響**: 音声デバイスに依存する開発・検証環境やリモート会議用マシンでは、当面ワークアラウンドの適用や更新の見送り判断が必要になる。

**リンク**: [Microsoft admits Windows 11's emergency update still breaks audio, and a fix may not arrive until October - Windows Latest](https://www.windowslatest.com/2026/09/21/microsoft-admits-windows-11s-emergency-update-still-breaks-audio-and-a-fix-may-not-arrive-until-october/)

### Microsoft、インドのクラウドインフラをAI対応強化、南部リージョンをアジア戦略拠点に

**要約**: Microsoftはインドのクラウドインフラ全体にAI対応機能を拡充し、インド南部（South Central）リージョンをアジア・グローバルサウス地域の戦略拠点として位置づけると発表した。

**影響**: アジア圏でのAzureリージョン展開が進むことで、レイテンシやデータ所在地要件を考慮したシステム設計の選択肢が広がる。

**リンク**: [AI ambition into action: Microsoft brings AI-ready capabilities across its India cloud infrastructure, establishes India South Central region as a strategic hub for Asia and Global South - Microsoft Source](https://news.microsoft.com/source/asia/2026/09/21/ai-ambition-into-action-microsoft-brings-ai-ready-capabilities-across-its-india-cloud-infrastructure-establishes-india-south-central-region-as-a-strategic-hub-for-asia-and-global-south/)

## 2. AI

### 無料アプリでApple製AI「Apple Foundation Models」をローカルチャット試用可能に

**要約**: iOS 27・macOS 27に含まれる更新版「Apple Foundation Models」と直接チャットできる無料アプリが登場し、端末上でのオフラインAI処理能力を手軽に試せるようになった。

**影響**: クラウドAPIに依存しないオンデバイスAIの実力を、開発者が実際のレスポンス品質や速度感で検証できる材料が増える。

**リンク**: [iPhoneに搭載されたApple製AIとチャットする方法、無料アプリで「Apple Foundation Models」のローカル処理能力を試せる](https://gigazine.net/news/20260921-locally-ai-apple-foundation-models/)

### Figureの人型ロボットAI「Helix 2.5」、30軒でのゼロショット検証結果を公開

**要約**: 米Figureが人型ロボット向けAIモデル「Helix 2.5」を発表。ゼロショット環境30軒・420タスクで完全成功率56%（237/420）を記録し、行動動画データセット「Index」の有無による課題別の成功率差（67%/62%/40%）も報告されている。

**影響**: 未知環境への汎化性能を数値で示すベンチマークが公開されたことで、ロボティクス向けAIの実用段階での評価軸として参考になる。

**リンク**: [Figure Helix 2.5、30軒ゼロショット: 完全成功237/420(56%)・Indexなし8%・課題別67/62/40%](https://qiita.com/quotidia/items/06f43121dd15c7455188)

### 生成AIの出力を安定させる「入力テンプレート」設計のコツ

**要約**: 生成AIを繰り返し業務利用する際、同じ依頼でも出力形式や品質がぶれる問題に対し、依頼文をテンプレート化して入力を構造化することでばらつきを抑える手法が紹介されている。

**影響**: プロンプト設計を標準化することで、要約・分類・データ整理などの反復タスクにおける後工程の修正コストを削減できる。

**リンク**: [AIツールの出力を安定させるための「入力テンプレート」設計](https://zenn.dev/aiai_tool/articles/c57c0a9f35874a)

## 3. Azure

### VS CodeにAzureアプリ構築を導くGuided Copilot体験がパブリックプレビュー開始

**要約**: GitHub Copilot in VS Codeで、アイデアからデプロイ可能なクラウドアプリまでをガイドしてくれる新しいCopilot体験がパブリックプレビューとして提供開始された。

**影響**: Azureアプリのスキャフォールディングからデプロイまでの初期セットアップをCopilotが支援することで、開発着手までの時間短縮が期待できる。

**リンク**: [[In preview] Public Preview: Introducing a Guided Copilot Experience for Building Azure Apps in VS Code](https://azure.microsoft.com/updates?id=572214)

### Azure Functions、PowerShell 7.6サポートが一般提供開始

**要約**: Azure FunctionsでPowerShell 7.6を用いたアプリ開発が一般提供（GA）となった。ローカルでPowerShell 7.6を使って開発し、そのままAzureへデプロイできる。

**影響**: PowerShellベースの自動化・運用スクリプトをFunctionsに移行する開発者にとって、最新ランタイムの機能を利用した実装が可能になる。

**リンク**: [[Launched] Generally Available: Azure Functions support for PowerShell 7.6](https://azure.microsoft.com/updates?id=572219)

### Azure Sphere OS version 26.09が一般提供開始

**要約**: IoTデバイス向けAzure Sphere OSのバージョン26.09がRetailフィードで一般提供開始された。今回はOS単体の更新でSDKの更新は含まれない。

**影響**: Azure Sphereを利用するIoTデバイス運用チームは、定期的なOS更新の適用計画に組み込む必要がある。

**リンク**: [[Launched] Generally Available: Azure Sphere OS version 26.09 is now available](https://azure.microsoft.com/updates?id=572579)

**影響**: IAMポリシーでタスク起動時のCPU・メモリ条件を制御しようとする場合、公式ドキュメントだけでなく実機検証が必要になる点は注意が必要。

**要約**: 公開されるCVE（共通脆弱性識別子）の件数が過去最多を更新し続けている一方で、実際に悪用されているのは以前から知られている同じ脆弱性群であることが指摘されている。

**影響**: 新規脆弱性への対応だけでなく、既知の未パッチ脆弱性への対処を優先するパッチマネジメント戦略の重要性が改めて浮き彫りになる。

**リンク**: [More CVEs than ever. The same old ones keep getting exploited. - Cybersecurity Dive](https://www.cybersecuritydive.com/spons/more-cves-than-ever-the-same-old-ones-keep-getting-exploited/830366/)

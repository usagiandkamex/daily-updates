# 2026/11/13 テクニカル雑談（午後）

## 1. Microsoft

### Microsoft 365 の長時間障害、ユーザー側では「10時間超」の声

**要約**: Exchange Online を中心とした Microsoft 365 の障害が 10 時間以上続き、Reddit では「回復はわずか」との報告が上がっていた。原因を巡る推測も盛り上がっている。

**影響**: メールや認証に依存する業務は代替手段がないと止まる。障害時の連絡手段や運用手順を事前に決めておく重要性が再認識される。

**リンク**: [Microsoft 365 outage: 10+ hours and counting, only marginal recovery reported. What could be causing such a prolonged disruption?](https://www.reddit.com/r/microsoft/comments/1xv1o63/microsoft_365_outage_10_hours_and_counting_only/)

### 「ほぼ24時間」続いたとの声も

**要約**: 障害は長期化し、「almost 24 hours」とする投稿もあった。別の投稿では Outlook が約 18 時間ぶりに復旧したと報告されているが、Copilot はまだ遅いとの声もある。

**影響**: 復旧後も一部サービスに遅延が残る可能性があり、完全復旧の確認は個別に行う必要がある。

**リンク**: [Microsoft's Outlook back online following 18 hour outage @ 7:05a EST](https://www.reddit.com/r/microsoft/comments/1xv688n/microsofts_outlook_back_online_following_18_hour/)

### 情シスの現場は大荒れ

**要約**: 障害を受け、M365 障害対応を巡って上司と事業部長が口論になったという現場の声が SNS で話題になっている。

**影響**: SaaS 障害は技術面だけでなく、社内コミュニケーションや期待値調整の問題にもなる。可用性の限界を経営層と共有しておきたい。

**リンク**: [Microsoft 365の障害で上司が事業部の部長から「こうなる事を予想して事前に対処しておくのがシステム部だろうが！」と言われ、反抗して早退…連絡の受け手は必然的に私に](https://togetter.com/li/2770045)

## 2. AI

### AI ユーザーの労働時間は最大 90 分長い

**要約**: ActivTrak の調査（467 社・9140 人）で、AI ユーザーは非 AI ユーザーより平均労働時間が最大 90 分長いことが分かった。

**影響**: AI は必ずしも労働時間を減らさない。導入効果は時間短縮だけでなく、仕事量の増え方も合わせて見る必要がある。

**リンク**: [AIユーザーの平均労働時間は非AIユーザーより最大で90分長いことが判明](https://gigazine.net/news/20261113-ai-users-have-long-worktime-than-non-ai-users/)

**要約**: Claude Code を入口に一本化し、判断 AI や権限ルールなどのハーネスを通して、他の AI・スキル・MCP・外部 API に仕事を振る構成を解説する記事。

**影響**: エージェント開発環境の設計は、権限管理と役割分担が鍵になる。自分の環境を見直す参考になる。

**リンク**: [Claude Codeのおすすめ環境を全体図で解説。ハーネス・スキル・MCPの仕組みと実例](https://ktlog.net/posts/claude-code-ai-ecosystem)

**要約**: 首相が 11 月 12 日にフィジカル AI 関連企業の代表を官邸に招き、AI ロボットを体験して意見交換した。官民で社会実装を戦略的に推進する方針。

## 3. Azure

### Azure Front Door で mTLS が GA

**要約**: Azure Front Door Premium で相互 TLS（クライアント証明書認証）が一般提供となった。X.509 クライアント証明書で接続元を検証できる。

**影響**: API や B2B 連携で、エッジ段階でクライアント認証を強制できる。

**リンク**: [Generally Available: Azure Front Door mutual TLS authentication](https://azure.microsoft.com/updates?id=577678)

### Azure Front Door で JWT 検証がパブリックプレビュー

**要約**: Front Door Premium の Auth Policy による JWT 検証がパブリックプレビューになった。ベアラートークンをエッジで検証できる。

**影響**: バックエンドごとにトークン検証を実装する負担を減らせる可能性がある。ただしプレビューなので本番利用は要検討。

**リンク**: [Public Preview: JWT validation with Azure Front Door Auth Policy](https://azure.microsoft.com/updates?id=577673)

### Azure Monitor ワークスペースの取り込み上限が自動スケール

**要約**: Azure Monitor Workspace で、利用実績に応じて取り込み上限をワークスペース単位で自動拡張する機能がパブリックプレビューになった。

**影響**: メトリクス急増時のスロットリングを気にする運用負荷が下がる可能性がある。

**リンク**: [Public Preview: Auto scaling of ingestion limits in Azure Monitor workspace](https://azure.microsoft.com/updates?id=578207)

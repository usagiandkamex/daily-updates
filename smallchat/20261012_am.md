## 1. Microsoft

### Windows 上のエージェント封じ込めレイヤーが一般提供に

**要約**: Microsoft が Windows 向けの「agent containment layer」を一般提供（GA）にしたと Reddit 上で話題になっています。AI エージェントの動作範囲を OS レベルで制限する仕組みです。

**影響**: AI エージェントにローカル操作を任せる開発・運用では、権限の切り分けを OS 側で担保できるようになります。社内でエージェントを導入する際の統制方針を見直すきっかけになりそうです。

**リンク**: [Microsoft makes its agent containment layer generally available on Windows](https://www.reddit.com/r/microsoft/comments/1x33f68/microsoft_makes_its_agent_containment_layer/)

**リンク**: [Microsoft brings full Word, Excel, and PowerPoint experience to the new Copilot app - Neowin](https://www.neowin.net/news/microsoft-brings-full-word-excel-and-powerpoint-experience-to-the-new-copilot-app/)

### GPU 不要のリアルタイム多言語文字起こし「hayamimi」

**要約**: note の記事で、CPU のみで動作するリアルタイム多言語文字起こしツール「hayamimi」が紹介されています。古い PC でも十分動き、翻訳性能も高いとのことです。弱点は複数言語の同時認識ができない点です。

**影響**: GPU がなくてもローカルで音声処理を試せるので、議事録や社内ツールへの組み込みのハードルが下がります。

**要約**: Zenn の記事は、API キー漏洩の経路を Git 履歴、フロントエンド成果物、公開設定ミス、ログ、外部ツール、サーバーの公開ファイル、人為的な共有の 7 つに整理しています。また shattered.io の記事は、CVSS と CISA KEV を比較し、1,739 件の脆弱性で 5 日間のパッチ適用ギャップがあると指摘しています。

## 2. AI

### .npmignore があると .gitignore は使われない

**要約**: .npmignore を置くと npm は .gitignore を読まなくなる。.env や鍵がパッケージに混入しうるため、npm pack --dry-run で確認しようという記事。

**影響**: 公開前に `npm pack --dry-run` を CI に組み込むなど、機密ファイル混入の予防策を取りたい。

**リンク**: [.npmignoreを置くと.gitignoreは使われない：.envと鍵がnpmパッケージに入るのを npm pack --dry-run で確認](https://qiita.com/supportapp3/items/fa4f271888e6f6899100)

## 3. Azure

**要約**: Microsoft は公式ブログでデジタル主権に関する取り組みを発表した。The Next Web によると、ソブリンクラウドに EU のアクセス監視とオフライン AI が追加される。

**リンク**: [Advancing digital sovereignty with greater control and choice - The Official Microsoft Blog](https://blogs.microsoft.com/blog/2026/10/20/advancing-digital-sovereignty-with-greater-control-and-choice/) / [Microsoft adds EU access oversight and offline AI to its sovereign cloud - The Next Web](https://thenextweb.com/news/microsoft-sovereign-cloud-data-guardian-azure-local)

### Application Gateway が Key Vault Managed HSM によるキーレス TLS に対応（GA）

**要約**: 秘密鍵を Azure Key Vault Managed HSM 内に保持したまま、Application Gateway で TLS 終端できるようになった。

**影響**: 秘密鍵が HSM の外に出ないため、高いコンプライアンス要件にも対応しやすい。

**リンク**: [Generally Available: Keyless TLS on Application Gateway with Azure Key Vault Managed HSM](https://azure.microsoft.com/updates?id=577130)

### VNet ピアリングルートの無効化（パブリックプレビュー）と Front Door WAF のサービスタグ条件（GA）

**要約**: ピアリングされた仮想ネットワーク間のトラフィックを制御する、ルートテーブルの機能がプレビュー公開された。また Azure Front Door Premium の WAF カスタムルールで、サービスタグによる一致条件が GA となった。

**影響**: ネットワーク分離とアクセス制御を、よりきめ細かく設計できるようになる。

**リンク**: [Public Preview: Disable VNet peering route](https://azure.microsoft.com/updates?id=576242) / [Generally Available: Service tag match condition for Azure Front Door Premium WAF](https://azure.microsoft.com/updates?id=577156)

## 1. Microsoft

### Windows 11、ピクチャーパスワードを廃止へ

**要約**: Windows 11でピクチャーパスワード機能が段階的に廃止され、PINやパスワード、生体認証への移行が進められている。

**影響**: 認証方式の統廃合により、企業のセキュリティポリシーや社内ヘルプデスクのサポート対応を見直す必要がある。

**リンク**: [Windows 11 is pulling picture passwords and pushing people to PINs, passwords, and biometrics](https://www.reddit.com/r/microsoft/comments/1vlcwgp/windows_11_is_pulling_picture_passwords_and/)

### Microsoft、月例パッチで約400件の脆弱性を修正

**要約**: 2026年8月のPatch Tuesdayで、Microsoftは400件近いセキュリティホールを修正。すでに悪用が確認されている脆弱性も含まれる。

**影響**: 修正件数が非常に多く、優先度付けと迅速な適用計画が管理者にとって重要になる。未適用環境は早急な対応が求められる。

**リンク**: [Microsoft Plugs Nearly 400 Security Holes](https://krebsonsecurity.com/2026/08/microsoft-plugs-nearly-400-security-holes/)

**要約**: Microsoftが月例累積アップデートKB5121003およびKB5120240を公開し、Windows 11の不具合修正と機能改善を実施した。

**影響**: 定例更新のため各社の展開スケジュールに組み込みやすいが、互換性問題の有無を事前に確認しておくことが望ましい。

**リンク**: [Windows 11 KB5121003 & KB5120240 cumulative updates released](https://www.bleepingcomputer.com/news/microsoft/windows-11-kb5121003-and-kb5120240-cumulative-updates-released/)

**影響**: AIコード生成ツールとの相性を考慮した言語選定が、今後のスタック選びの新たな判断軸になり得る。

**影響**: AIの生成速度に人間の作業フローが追いつかない課題は、多くの開発現場で共通しており、ツール連携の工夫が生産性向上の鍵になる。

**リンク**: [AI 駆動開発のボトルネックは人間 ― Raycast で手作業を削る](https://zenn.dev/tokium_dev/articles/21d7e178362377)

### スター3000超のAI監査OSS、ルールエンジンの中身が「return True」だった

**要約**: 「Open Source Palantir」を謳う規制産業向けAI監査基盤OSSを調査したところ、核となるルールエンジンの推論部分が実質的に何も判定していなかったことが判明。

**リンク**: [スター3000超の『規制産業向けAI監査基盤』ルールエンジンがreturn Trueだった](https://zenn.dev/mskbhd/articles/lab-241-semantica-3ai-rete)

## 3. Azure

### Azure FirewallのIDPS処理性能が2.2倍に向上、GA提供開始

**要約**: Azure Firewall PremiumのTLSインスペクション＋IDPS（Denyモード）でスループットが10Gbpsから22Gbpsへ大幅向上し、正式提供が開始された。

**影響**: 大規模トラフィック環境でのセキュリティ検査によるボトルネックが緩和され、Azure Firewallをより高負荷な本番環境に適用しやすくなる。

**リンク**: [Generally Available: 2.2X IDPS performance optimization in Azure Firewall](https://azure.microsoft.com/updates?id=569256)

### Azure Developer CLI拡張フレームワークがGAに

**要約**: azdのextension frameworkが正式提供され、組織固有のコマンドやワークフローを組み込んだAzure開発体験の拡張が可能になった。

**影響**: 社内標準化されたデプロイ手順やスキャフォールディングをazd経由で配布できるようになり、開発チームのオンボーディングやCLI運用の効率化に寄与する。

**リンク**: [Azure Developer CLI extension framework is GA: build dev workflows for apps using Azure](https://devblogs.microsoft.com/azure-sdk/azd-extension-framework-ga/)

### Azure Container Appsから自宅サーバへVPN中継する際の落とし穴

**要約**: Azure Container AppsからVNet外（自宅）のバックエンドへVPN中継する構成で、UDRが効かない問題や504 Gateway Time-outに直面した実測レポート。

**影響**: ハイブリッド構成特有のルーティングやタイムアウトの罠が具体的に共有されており、同様の構成を検討するエンジニアにとって実践的な参考情報となる。

**リンク**: [ACAで自宅サーバを公開](https://qiita.com/potofo/items/451a0a99a67fbbea0a39)

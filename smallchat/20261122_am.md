### Windows でアンチウイルスをカーネル外で動かせるように

**要約**: 大規模な BSOD を引き起こした不具合のあるセキュリティ更新を受け、Microsoft はアンチウイルスを Windows カーネルの外で実行できるようにしたと報じられています。あわせて、アンチウイルスが原因で起動に失敗した場合も Windows 11 が回復できる仕組みが紹介されています。

**影響**: セキュリティ製品を開発・運用する側は、カーネル外動作への移行が選択肢になります。端末管理者にとっては、同種の障害時の復旧性が上がる点が重要です。

## 4. クラウド

### DynamoDB ベクトル検索のインラインフィルタ拡張

**要約**: Amazon DynamoDB のベクトル検索で、インラインフィルタに範囲比較・IN・OR・NOT が追加されました。アプリ側で絞り込むと 0 件だった「価格 10000 以下」の類似検索が、インラインフィルタでは 5 件返った検証が紹介されています。

**影響**: 条件付き類似検索をアプリ側のポストフィルタに頼らず実装でき、結果の取りこぼしを避けやすくなります。

**リンク**: [[アップデート] Amazon DynamoDB のベクトル検索で範囲比較・IN・OR/NOT のインラインフィルタが使えるようになったので試してみた](https://dev.classmethod.jp/articles/20211121-amazon-dynamodb-vector-filters/)

### Bedrock AgentCore Identity が RFC 8414 に対応

**要約**: Amazon Bedrock AgentCore Identity のディスカバリー URL が、OAuth 2.0 認可サーバーメタデータ（RFC 8414）に対応しました。

**影響**: 標準仕様に沿った認可サーバーとの連携がしやすくなり、エージェントの認証設定が簡素化されます。

**リンク**: [[アップデート] Amazon Bedrock AgentCore IdentityのディスカバリーURLがOAuth 2.0の認可サーバーメタデータに対応しました！](https://dev.classmethod.jp/articles/agentcore-identity-oauth2-discovery/)

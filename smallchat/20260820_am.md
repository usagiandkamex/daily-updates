# 2026/08/20 テクニカル雑談（午前）

## 1. Microsoft

### Docker VMM がパブリックベータ公開、コンテナ向け高性能ハイパーバイザ登場

**要約**: Docker社がコンテナ向けの新しい高性能ハイパーバイザ「Docker VMM」をパブリックベータとして公開した。WindowsとmacOSに対応した最新の「Docker Desktop v4.86」で利用可能。

**影響**: コンテナ実行基盤のパフォーマンス向上が期待でき、Windows/macOS上でのDocker開発体験に直結する変化。今後のDocker Desktopアップデートで動作確認しておく価値がある。

**リンク**: [Docker社、コンテナ向けの高性能な新ハイパーバイザ「Docker VMM」パブリックベータ公開](https://www.publickey1.jp/blog/26/dockerdocker_vmm.html)

### Mojo がオープンソース化、Windows版開発も表明

**要約**: PythonライクなプログラミングB言語「Mojo」の開発元Modular社が、MojoをOSSとして公開したことを発表。コンパイラやツールチェーンがGitHubで公開され、Windows版の開発も表明されている。

**影響**: 高速なPython互換言語の選択肢が広がることで、AI/ML分野でのパフォーマンス最適化を検討するエンジニアにとって新しい選択肢が増える。

**リンク**: [Pythonライクな新言語「Mojo」がオープンソースで公開、コンパイラやツールチェーンなど。Windows版の開発も表明](https://www.publickey1.jp/blog/26/pythonmojowindows.html)

### Microsoft、Windows Defenderのクラッシュ問題を修正

**要約**: Microsoftは既知の問題であったWindows Defenderのクラッシュを引き起こす不具合を修正した。

**影響**: Windows環境でセキュリティソフトの安定性に関わる問題であり、業務PCの運用担当者は修正パッチの適用状況を確認しておきたい。

**リンク**: [Microsoft fixes known issue causing Windows Defender crashes](https://www.bleepingcomputer.com/news/microsoft/microsoft-fixes-known-issue-causing-windows-defender-crashes/)

## 2. AI

**影響**: AIサービスの年齢別提供・コンテンツ制御の実装例として参考になる。今後、他のAIサービスでも同様の年齢別ガードレール実装が広がる可能性がある。

**リンク**: [OpenAIが未成年向けの「ティーン向け ChatGPT」を提供開始](https://www.itmedia.co.jp/pcuser/articles/2608/19/news079.html)

**リンク**: [大規模言語モデル（LLM）は「次の単語を当てる」だけなのに、なぜ思考しているように見えるのか](https://togetter.com/li/2734953)

## 3. Azure

### Azure VM、vCoreカスタマイズ機能が一般提供開始

**要約**: Azure仮想マシンのvCoreカスタマイズ機能がGA（一般提供）となった。マルチスレッド無効化と構成可能な制約コア数という2つの新機能が追加されている。

**影響**: CPUライセンスコストの最適化やコンプライアンス要件対応のためにコア数を細かく制御したいワークロードにとって有用な選択肢となる。

**リンク**: [Generally Available: vCore Customization: Disable Multithreading and Configurable Constrained Cores](https://azure.microsoft.com/updates?id=569051)

### Azure Site Recovery、BYON（持ち込みNIC）機能がGA

**要約**: Azure Site Recoveryで、既存のプロビジョニング済みネットワークインターフェースカード（NIC）をターゲットリージョンでテストフェールオーバーやフェールオーバー時に使用できる「BYON」機能が一般提供された。

**影響**: ディザスタリカバリ構成において既存のネットワーク設計を維持したまま柔軟な構成が可能になり、DR担当者の構成自由度が広がる。

**リンク**: [Generally Available: BYON (Bring Your Own NIC) in Azure Site Recovery](https://azure.microsoft.com/updates?id=569515)

### Bicep入門、Windows環境での開発事前準備を解説

**要約**: MicrosoftのAzureリソースデプロイ用ドメイン固有言語「Bicep」について、Windows 11環境でBicep開発を始めるための事前準備手順を解説する入門記事がQiitaに投稿された。

**影響**: これからAzureのIaC（Infrastructure as Code）を始めるエンジニアにとって、環境構築のハードルを下げる実践的な情報源となる。

**リンク**: [【Bicep/Azure-入門編1】Windows環境で始めるBicep開発の事前準備](https://qiita.com/rittan_girla/items/1ec0480530a858739b24)

## 4. クラウド

### Amazon BedrockでGrok 4.6が利用可能に

**要約**: Amazon Bedrockで xAI の Grok 4.6 が2026年8月18日にローンチされ、利用可能になった。AWSの公式ドキュメントにもモデルカードが公開されている。

**影響**: Bedrock経由で多様な基盤モデルを選択できる幅が広がり、既存のAWS認証・課金基盤を使ったまま新しいモデルを試せる点で開発者の選択肢が増える。

**リンク**: [Grok Build CLIでAmazon Bedrock上のGrok 4.6を試してみた](https://dev.classmethod.jp/articles/grok-build-cli-amazon-bedrock-grok-46/)

### DynamoDBがベクトル検索に対応

**要約**: DynamoDBが埋め込みベクトルの保存とそのままの類似度検索に対応した。Terraformでベーステーブルを作成し、未対応部分のベクトルインデックスはAWS CLIで追加する検証記事が公開されている。

**影響**: 専用のベクトルDBを別途構築せずにDynamoDB上でRAGなどの類似度検索を実現できる可能性があり、AWSベースのAI活用アーキテクチャの選択肢が広がる。

**リンク**: [DynamoDB がベクトル検索に対応したので試してみた](https://qiita.com/leomarokun/items/b2e138e16c33d97938cb)

### IAM Policy AutopilotがTerraform planファイルに対応

**要約**: IAMポリシーの実行権限を最小化するツール「IAM Policy Autopilot」が、Terraformのplanファイルに対応した。planファイルから必要なIAMポリシーを自動生成できるようになった。

**影響**: Terraformで実質Admin権限になりがちなIAM運用課題に対し、最小権限化を効率的に実現する手段として、IaC運用担当者にとって有用なアップデート。

**リンク**: [[アップデート] IAM Policy AutopilotがTerraformのplanファイルをサポートするようになりました](https://dev.classmethod.jp/articles/iam-policy-autopilot-supports-terraform-plan-files/)

## 5. セキュリティ

### さくらインターネット、不正アクセスで最大136万アカウントの契約情報が閲覧された可能性

**要約**: さくらインターネットの販売管理システムへの不正アクセスにより、最大約136万アカウントの契約情報が閲覧された可能性があることが明らかになった。同社は第二報として調査状況を継続的に公表している。

**影響**: 大規模なホスティング事業者における情報漏えいは利用企業・個人に広く影響が及ぶ可能性があり、自社が利用しているサービスであれば速報や公式発表を注視する必要がある。

**リンク**: [さくらインターネットの販売管理システムに不正アクセス、最大約136万アカウントの契約情報が閲覧された可能性](https://internet.watch.impress.co.jp/docs/news/2133984.html)

**影響**: 複数の主要プラットフォームで同時に悪用が確認されており、該当製品を運用する組織はパッチ適用状況の緊急確認が必要。

**リンク**: [Critical macOS, SharePoint, vCenter, and Microsoft IKE Flaws Under Active Exploitation](https://thehackernews.com/2026/08/critical-macos-sharepoint-vcenter-and.html)

### Rayフレームワークにリモートコード実行の重大な脆弱性

**要約**: 分散処理フレームワーク「Ray」に、リモートからコードを実行可能にする重大な脆弱性が発見された。

**影響**: 機械学習・AIワークロードの分散実行基盤として広く使われるRayでの脆弱性は、AI基盤を運用する組織にとって早急な対応が求められる案件。

**リンク**: [Critical vulnerability in Ray framework allows remote code execution](https://www.scworld.com/brief/critical-vulnerability-in-ray-framework-allows-remote-code-execution)

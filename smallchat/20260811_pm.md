# 2026/08/11 テクニカル雑談（午後）

## 1. Microsoft

### GitHub Copilot SDK for Java が登場

**要約**: GitHub が Java 向けの Copilot SDK を公開。アノテーションや仮想スレッド（Virtual Threads）など、Java らしい書き方から Copilot を直接呼び出せるようになった。

**影響**: これまで Copilot 連携は主に JS/TS 系エコシステムが中心だったが、エンタープライズ Java 開発者も自前のアプリやツールに AI 機能を組み込みやすくなる。既存の Java 資産に Copilot ベースの補助機能を統合したいチームには追い風。

**リンク**: [Using the GitHub Copilot SDK for Java](https://github.blog/engineering/using-the-github-copilot-sdk-for-java/)

**リンク**: [RTX 4090 × 4枚で Meta の新モデル Muse Glimmer 30B を vLLM (Docker) で動かす](https://qiita.com/engchina/items/b9bba665492ea1fabd5c)

### AI導入前に必要なデータ品質入門

## 3. Azure

### Azure SQL エンジンをそのままローカルコンテナで実行できる Azure SQL Developer

**要約**: 従来のローカル SQL Server イメージとは異なり、Azure SQL と同一のエンジンをコンテナとしてローカルマシン上で動かせる「Azure SQL Developer」が話題に。

**影響**: 本番のAzure SQLとローカル開発環境の挙動差異による不具合を減らせるため、CI/CDでのテスト精度向上やオフライン開発の信頼性向上が期待できる。

**リンク**: [Azure SQL Developer — run the actual Azure SQL engine locally in a container](https://www.reddit.com/r/AZURE/comments/1vkxyuj/azure_sql_developer_run_the_actual_azure_sql/)

**影響**: 既存の管理ツールに縛られずAzure Policyベースで構成ドリフトを検知・是正できるため、マルチクラウドやハイブリッド環境でも一貫した構成管理を実現したいインフラエンジニアに有用。

**リンク**: [VM の構成管理を実現したい！ Azure のマシンの構成を使ってみた](https://qiita.com/iboy/items/23050c265ac9e6e21a1c)

### Azure × Databricks の UDR/Firewall 設計による強制トンネリング

## 4. クラウド

### DynamoDB Zero-ETL → S3 (Iceberg) のクロスアカウント構築

**要約**: DynamoDB の Zero-ETL 統合で、ターゲットを Apache Iceberg 形式の S3 バケットとし、クロスアカウント構成で構築した手順と注意点をまとめた記事。

**影響**: ETL基盤を自前で構築せずにDynamoDBのデータをレイクハウス形式で分析可能にできるため、データ分析基盤のコスト削減・運用簡素化を検討するエンジニアに具体的な実装知見を提供する。

**リンク**: [【クロスアカウント】DynamoDB Zero-ETL → S3（Iceberg）ターゲットの構築手順と注意点](https://qiita.com/swkky/items/0cf7c6f86560e848def9)

### EC2 の新機能「アプリケーションステータスチェック」で自動置換

**要約**: Amazon EC2 に追加された「アプリケーションステータスチェック」により、HTTP/HTTPSでアプリの死活を監視し、異常時は Auto Scaling がインスタンスを自動置換する機能を検証した記事。

**影響**: OS レベルのヘルスチェックだけでなくアプリケーション層の異常も検知して自動復旧できるため、可用性向上の運用負荷を下げたいSRE/インフラ担当者にとって導入検討価値が高い。

**リンク**: [EC2の新機能「アプリケーションステータスチェック」でAuto Scaling自動置換を試してみた](https://dev.classmethod.jp/articles/amazon-ec2-application-status-checks/)

### SageMaker JumpStart に FLUX.2 と Gemma 4 が追加

**要約**: Black Forest Labs の画像生成モデル「FLUX.2-small-decoder」と Google の「gemma-4-12B-it」が Amazon SageMaker JumpStart で利用可能になった。

**影響**: マネージド環境で最新のオープンモデルを手軽に試せるようになり、画像生成やLLM活用のプロトタイピングを迅速に進めたい開発者にとって選択肢が広がる。

**リンク**: [FLUX.2-small-decoder and gemma-4-12B-it models now available on Amazon SageMaker JumpStart](https://aws.amazon.com/about-aws/whats-new/2026/01/flux.2-small-decoder-gemma-4-12B-it-on-sagemaker-jumpstart/)

# 2026/10/17 テクニカル雑談（午前）

## 1. Microsoft

### Windows 11 26H2 でメモリ使用量が減少、Microsoft も改善を公式報告

**要約**: Windows 11 の大型アップデート「26H2」でメモリ使用量が大きく減ったという声が相次いでいます。Microsoft は 10月15日に Windows Blogs でメモリ効率の改善について報告し、話題になっていた現象の具体的な取り組みが明かされました。

**影響**: 開発マシンや VM 上で Windows を使うエンジニアにとって、同じメモリ量でより多くのコンテナや IDE を動かせる可能性があります。ただし数値は環境依存なので、自分の環境で計測して確認したいところです。

**リンク**: [Windows 11の大型アプデ「26H2」で、“メモリ使用量が激減した”と喜びの声相次ぐ](https://automaton-media.com/articles/newsjp/20261016-473910/)

### Windows 11 は日常操作で最大 20% 応答性が向上したと Microsoft

**要約**: Microsoft は Windows 11 が日常的なタスクで最大 20% 応答性が上がったと説明していると報じられています。メモリ効率改善の発表と同じ流れの話題です。

**影響**: 体感速度の改善は開発者向けの作業にも効きますが、「最大」という表現である点には注意が必要です。社内展開や検証用 PC の更新判断では実測を併用するのがよさそうです。

**リンク**: [Microsoft says Windows 11 is now up to 20% more responsive in everyday tasks](https://www.pcguide.com/news/microsoft-says-windows-11-is-now-up-to-20-more-responsive-in-everyday-tasks/)

### Microsoft と JC3、10億件超のフィッシングを支えた犯罪基盤を摘発

**要約**: Microsoft と JC3 が、10億件を超えるフィッシングを支えていたとされる犯罪基盤「YAM Store」「CoGUI」「Iron Man」を無力化したと紹介されています。

**影響**: フィッシングキットの流通基盤が止まることは攻撃全体の抑制につながります。一方で別の基盤へ移行する動きも想定されるため、MFA や FIDO2 など基本対策は引き続き重要です。

**リンク**: [MicrosoftとJC3、10億件超のフィッシングを支えた犯罪基盤を無力化](https://rocket-boys.co.jp/security-measures-lab/microsoft-jc3-yam-store-cogui-iron-man-phishing-takedown/)

## 2. AI

### Liquid AI が意思決定モデル「d1-ultra」を発表

**要約**: Liquid AI が 2026年10月15日に意思決定モデル「d1-ultra」を発表しました。従来の「d1」の改良版で、競合の「Jev 1.14」を性能テストで大きく上回り、判断の正確さや信頼性も向上したとのことです。

**リンク**: [意思決定モデル「d1-ultra」が登場、Jev 1.14を全8分野で上回り判断の信頼性も向上](https://gigazine.net/news/20261016-d1-ultra/)

**リンク**: [[Launched] Generally Available: External key management for Azure Key Vault Managed HSM](https://azure.microsoft.com/updates?id=574296)

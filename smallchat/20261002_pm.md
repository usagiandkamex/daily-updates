# 2026/10/02 テクニカル雑談（午後）

## 1. Microsoft

### Surface の新ノートから Copilot+ PC ブランドが外れる

**要約**: Mashable によると、Microsoft の新しい Surface ノートでは「Copilot+ PC」のブランド表記が使われなくなりました。

**影響**: NPU 搭載 PC の訴求軸が変わる可能性があります。端末選定やオンデバイス AI の要件定義では、ブランド名ではなく実際のスペックを確認する癖をつけておくと安心です。

**リンク**: [Microsoft's new Surface laptops get rid of Copilot+ PC branding - Mashable](https://mashable.com/tech/microsoft-surface-pcs-shed-copilot-plus-pc-branding)

### Windows XP の「アプリに嘘をつく」互換性の仕組み

**影響**: 後方互換を守り続けるコストと工夫の歴史として読めます。レガシー資産を抱える開発者には、互換レイヤー設計の参考になります。

**リンク**: [Microsoft explains why Windows XP ran almost everything, and it lied to apps - Windows Latest](https://www.windowslatest.com/2026/10/02/windows-xp-had-a-hidden-database-of-broken-apps-and-microsoft-used-it-to-trick-them-into-working/)

### LinkedIn 元トップの Roslansky 氏が Microsoft を退社へ

## 2. AI

### AI コーディングツール「Pi 1.0」が正式リリース

**要約**: 機能を絞ったオープンソースのツール Pi が 2026 年 10 月 1 日に 1.0 となり、MCP への標準対応、必要なツールだけを読み込む機能、複数モデルの切り替えが加わりました。

**影響**: ミニマルなエージェント基盤を自分で育てたい人に選択肢が増えました。MCP 対応でツール連携も取り込みやすくなります。

**リンク**: [無料＆オープンソースのAIコーディングツール「Pi 1.0」が正式リリース](https://gigazine.net/news/20261002-pi-1-0/)

### Claude Code に Mod 機能が登場

**要約**: Claude Code の動作や UI を TypeScript で拡張できる Mod 機能が追加されました。Claude Code 自身に Mod の作成を依頼することもできます。

**影響**: チーム固有のワークフローやガードレールをツール側へ組み込みやすくなります。一方で、Mod の配布元や権限管理は慎重に扱う必要があります。

**リンク**: [Claude Codeを自分好みにカスタムできるMod機能が登場](https://gigazine.net/news/20261002-claude-code-customize-mod/)

### NVIDIA が「3 入力でだけ発火する」プロンプト注入を報告

**要約**: 2026 年 9 月 21 日、NVIDIA AI Red Teamが、テキスト・画像・音声が揃ったときだけ狙った出力を引き出すプロンプト注入の実験を報告しました。

**影響**: マルチモーダル要約では、出力に含まれる URL を承認済みの資料に限定するなど、出力側の制御も必要になります。

**リンク**: [NVIDIAが「3入力でだけ発火する攻撃」を報告。要約AIのリンク先を承認済み資料に絞る](https://qiita.com/emi_ndk/items/b4a45c88d6601c745130)

**影響**: マルチアカウント環境での有効化漏れを防ぎやすくなり、運用の自動化が進みます。

**リンク**: [[アップデート] Amazon GuardDuty の有効化を AWS Organizations の宣言型ポリシーで一元管理できるようになりました](https://dev.classmethod.jp/articles/guardduty-org-enablement-policies/)

### Cloudflare Workers の Service Bindings で別 Worker の関数を呼ぶ

**影響**: Worker を機能ごとに分割しても、関数呼び出しの感覚で連携できます。

**リンク**: [Cloudflare WorkersのService Bindingsを使って別Workerの関数を呼び出す](https://dev.classmethod.jp/articles/calling-functions-in-another-worker-using-cloudflare-workers-service-bindings/)

### AWS アカウント侵害後に Lambda が停止、サポートの応答がない

**要約**: Reddit では、9 月 16 日にアカウントが侵害され、自力で対処して通知したものの、8 日後に Lambda の実行が停止されたとの投稿が出ています。同様のサポート不満の投稿も複数見られます。

**リンク**: [AWS Lambda execution suspended 8 days after notifying AWS of a potential compromise on the root account](https://www.reddit.com/r/aws/comments/1wv85l1/aws_lambda_execution_suspended_8_days_after/)

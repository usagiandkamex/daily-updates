## 1. Microsoft

### Microsoftの決算が2008年以来最大の1日株高を記録 ― クラウドとAIが牽引

**要約**: Microsoftの2026年Q2決算が市場予想を大幅に上回り、株価は一日で約4,800億ドルの時価総額増加を記録した。クラウド事業（Azure）とAI関連サービスの好調が主因で、2008年以来最大の1日上昇幅となった。

**影響**: Azure採用を検討しているエンジニア・アーキテクトにとって、Microsoftのクラウド投資継続のシグナルとなる。AI・クラウド案件の予算確保や技術選定において追い風となりそうだ。

### Microsoft Copilotにセキュリティ上の欠陥 ― 顧客情報漏洩のリスク

**要約**: Microsoft Copilotに新たなセキュリティ上の脆弱性が発見された。AIがプロンプトインジェクション等を通じて顧客の機密情報を外部に漏洩しうる可能性が指摘されている。

**影響**: Copilotを業務利用しているチームは、機密情報をプロンプトに含める際のリスク評価を改めて行う必要がある。企業のAIセキュリティポリシー策定が急務となっている。

**参考リンク**: [New Microsoft Copilot Security Flaws Show How AI Can Leak Customer Secrets](https://www.theinformation.com/newsletters/applied-ai/new-microsoft-copilot-security-flaws-show-ai-can-leak-customer-secrets)

### MicrosoftがCopilotをマルチモデル対応のスーパーアプリへ進化

**要約**: MicrosoftはCopilotを単一AIモデルに依存しない「マルチモデルAIスーパーアプリ」として強化する方針を明確化した。複数のAIモデルを状況に応じて使い分けるアーキテクチャを採用し、機能拡充を図る。

**影響**: 開発者はCopilot Studioや関連APIを活用する際、マルチモデル対応を前提とした設計が必要になってくる。生産性ツールとしてのCopilot活用の幅がさらに広がりそうだ。

**参考リンク**: [Microsoft doubles down on multi-model AI as it builds a Copilot super app](https://www.cio.com/article/4203686/microsoft-doubles-down-on-multi-model-ai-as-it-builds-a-copilot-super-app.html)

## 3. Azure

### Azure Automationが PowerShell 7.6 ランブックに正式対応

**要約**: Azure AutomationがPowerShell 7.6のランブックとランタイム環境をGA（一般提供）した。サポート中の最新バージョンに対応したことで、最新のPowerShell機能をAzure Automationで活用できるようになった。

**影響**: 既存のPowerShell 5.1/7.2系のランブックを7.6へ移行することで、パフォーマンス向上や最新モジュールの活用が期待できる。古いランタイムを使っているチームは移行計画を立てるよい機会だ。

**参考リンク**: [Generally Available: Azure Automation supports PowerShell 7.6 runbooks and Runtime environment](https://azure.microsoft.com/updates?id=568102)

### Azure Key Vault PremiumでSymmetric Keys（対称鍵）がパブリックプレビュー

**要約**: Azure Key Vault PremiumにSymmetric Keys（対称鍵）のサポートがパブリックプレビューとして追加された。従来は非対称鍵が中心だったKey Vaultで、AES等の対称鍵管理が可能になる。

**影響**: 暗号化要件のあるアプリケーションでKey Vaultを一元的な鍵管理基盤として活用する道が広がる。HSMバックエンドを持つPremium SKUを利用しているチームはぜひ評価を検討したい。

**参考リンク**: [Public Preview: Symmetric keys on Azure Key Vault Premium](https://azure.microsoft.com/updates?id=566746)

### Azure Developer CLI (azd) 2026年7月版リリース

**要約**: Azure Developer CLI（azd）の2026年7月まとめがリリースされた。前回からの期間中に5回のリリースが行われ、開発者体験の向上やInfrastructure as Codeとの統合強化などが含まれる。

**影響**: azdを使ってAzureアプリのスキャフォールドやデプロイを行っているチームは最新バージョンへのアップデートで新機能を活用できる。CI/CDパイプラインとの組み合わせも引き続き強化されている。

**参考リンク**: [Azure Developer CLI (azd) July 2026](https://devblogs.microsoft.com/azure-sdk/azure-developer-cli-azd-july-2026/)

## 3. Azure

### Azure VM のバージョン変更時の注意点

**要約**: Azure VM のサイズは v3、v5、v7 のように世代があり、世代をまたぐと大きな仕様変更が入ることがある。仕様を把握していないと、バージョンをまたいだサイズや SKU の変更ができない場合がある。

**影響**: VM の世代アップグレードを計画する際は、事前に仕様差分を確認しておく必要がある。

**リンク**: [Azure VMのバージョン変更時における注意点](https://qiita.com/chappy7121/items/6b7ab1ba4725f0775a45)

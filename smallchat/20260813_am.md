## 3. Azure

### Azure Front Doorで「Batch rule updates」が一般提供開始

**要約**: Azure Front Door Standard/Premiumで、ルールの追加・更新・削除をバッチ処理できる「Batch rule updates」が一般提供(GA)となった。

**影響**: 大量のルーティングルールを運用する環境で、変更作業の効率化とAPI呼び出し回数の削減が期待できる。IaC運用時のデプロイ設計の見直しにもつながる。

**リンク**: [[Launched] Generally Available: Batch rule updates for Azure Front Door](https://azure.microsoft.com/updates?id=569246)

### Azure Front Doorに相互TLS（mutual TLS）がプレビュー追加

**要約**: Azure Front Doorに、X.509証明書によるクライアント認証を可能にする相互TLS（mTLS）機能がパブリックプレビューとして追加された。

**影響**: エッジ層でのクライアント証明書認証が可能になり、ゼロトラストアーキテクチャやB2B API連携でのセキュリティ強化に活用できる。

**リンク**: [[In preview] Public Preview: Azure Front Door mutual TLS](https://azure.microsoft.com/updates?id=569251)

### Azure App ServiceにAIエージェント向け「Markdown for Agents」がプレビュー追加

**要約**: Azure App Serviceで、AIエージェントや各種ツールがアプリの情報をより扱いやすい形式で参照できる「Markdown for Agents」機能がパブリックプレビューとして公開された。

**影響**: App Service上のアプリをAIエージェントから操作・連携させる際に、構造化された情報取得がしやすくなり、エージェント統合の実装コストが下がる可能性がある。

**リンク**: [[In preview] Public Preview: Markdown for Agents in Azure App Service](https://azure.microsoft.com/updates?id=568979)

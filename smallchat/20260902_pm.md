## 2. AI

### Geminiが長時間動画を自律分析する「Agentic Video Understanding」

**要約**: Google DeepMindが、Geminiが質問内容に応じて動画内の必要な場面を探索し、文字起こしや再確認を繰り返しながら回答を組み立てる新機能「Agentic Video Understanding」を発表した。長時間動画でも安価に詳細な分析結果を生成できるという。

**影響**: 動画コンテンツを扱うプロダクトでは、事前の全文字起こし・要約処理を省略し、必要な部分だけをエージェントが自律的に探索する設計が可能になる。動画解析APIのコスト構造が変わる可能性がある。

**リンク**: [Geminiが動画を自律的に分析する「Agentic Video Understanding」登場](https://gigazine.net/news/20260902-gemini-agentic-video/)

### Anthropicが「Claude Fable 5.1」「Claude Mythos 5.1」を発表

**要約**: Anthropicが新モデル「Claude Fable 5.1」「Claude Mythos 5.1」を発表。性能向上に加え、エージェント利用時のコストが最大45%減となる実質値下げが行われた。両モデルの違いはセーフガード水準のみとされる。

**影響**: コスト効率が重要なエージェント運用において、モデル選定の基準が変わる。セーフガード水準の違いで用途を使い分ける設計（社内利用と対外公開サービスなど）が現実的になる。

**リンク**: [Anthropic、「Claude Fable 5.1」「Claude Mythos 5.1」を発表](https://forest.watch.impress.co.jp/docs/news/2137456.html)

### AIエージェントの監視を機械に任せる運用ノウハウ

**要約**: 長時間稼働するAIエージェントのジョブが57分間気づかれずに停止していた経験から、見張りスクリプトや状態ファイルの設計、判断待ちの通知方法についてまとめた記事が公開された。

**影響**: AIエージェントを長時間バッチ的に運用する際の実践的な監視パターンとして、実装者が直接参考にできる知見。エージェント運用の信頼性向上に直結する。

## 3. Azure

### Azure Container Apps向けMicrosoft Defender for Cloudの対応がGA

**要約**: Azure Container Apps環境をMicrosoft Defender for CloudのServerless Containers Posture機能に統合できるようになり、一般提供が開始された。

**影響**: サーバーレスコンテナ環境のセキュリティ体制可視化がAzureネイティブで行えるようになり、Container Appsを本番運用しているチームはセキュリティ監査体制を強化しやすくなる。

**リンク**: [Generally Available: Microsoft Defender for Cloud support for Azure Container Apps](https://azure.microsoft.com/updates?id=570282)

### Windows Server 2025 on AKSがGA

**要約**: Azure Kubernetes Service（AKS）上でWindows Server 2025がGeneral Availabilityとなった。旧Windowsサーバーのサポートタイムラインへのプレッシャーがあるなか、モダナイズの選択肢が広がる。

**影響**: WindowsベースワークロードをAKSで運用している、または移行を検討しているチームにとって、サポート期限切れ対策の具体的な移行先ができた。

**リンク**: [Generally Available: Windows Server 2025 on AKS](https://azure.microsoft.com/updates?id=570090)

### MicrosoftがAzureとAWSのマルチクラウド接続サービスを開始

**要約**: MicrosoftがAWSと連携し、Azure・AWS間のハイパースケール接続を実現する「マルチクラウド接続サービス」を発表。Azure MetroをDE-CIXと連携して5都市で展開する動きも同時に報じられている。

**影響**: マルチクラウド構成を採用する企業にとって、クラウド間のネットワーク接続がより低遅延・高帯域で構築しやすくなる可能性があり、ハイブリッド/マルチクラウドアーキテクチャの設計選択肢が広がる。

**リンク**: [Microsoft links Azure with AWS for hyperscale harmony](https://www.sdxcentral.com/news/microsoft-links-azure-with-aws-for-hyperscale-harmony/)

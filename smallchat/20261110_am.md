# 2026/11/10 テクニカル雑談（午前）

## 1. Microsoft

### Windows 11 の「新レジストリ エディター」は単なるサンプルだった

**要約**: Windows 11 向けにモダン化されたレジストリ エディターらしきアプリが話題となり、「公式の置き換えか」と炎上気味になりました。Microsoft 側は「これはサンプルであり、実物ではない」と火消しを行っています。

**影響**: サンプルアプリが製品の予告と受け取られやすいことを示す出来事です。現時点で regedit の仕様変更を前提にした運用やスクリプトの見直しは不要ですが、サンプルリポジトリ公開時の見せ方には注意したいところです。

**リンク**: [No, this isn't Windows 11's new modernized Registry Editor — Microsoft confirms "this is a sample" and not the real thing after outrage online](https://www.reddit.com/r/microsoft/comments/1xrnpqr/no_this_isnt_windows_11s_new_modernized_registry/)

### Outlook の検索が改善、ネットワーク不良時はローカル検索へ自動切替

**要約**: 「Outlook」の検索で待ち時間が削減され、接続状態が悪いときはローカル検索に自動で切り替わる改善が報じられています。独自の小規模言語モデルによるランキングも開発中とのことです。

**影響**: 日常的にメール検索を使うエンジニアには地味ながら嬉しい改善です。小規模モデルをクライアント側のランキングに使う流れは、他のアプリ設計の参考にもなります。

**リンク**: [「Outlook」の検索が改善](https://forest.watch.impress.co.jp/docs/news/2154680.html)

## 3. Azure

### Static Web Apps の .NET 8 / .NET 9 サポートが本日終了

**要約**: Azure Static Web Apps の managed Functions API における .NET 8 と .NET 9 のサポートが 2026 年 11 月 10 日に終了します。.NET 10 への移行が案内されています。

**影響**: 該当する API を使っているプロジェクトは .NET 10 への移行が必要です。ビルドやデプロイが失敗していないか、早めに確認しましょう。

**リンク**: [Retirement: Support for .NET 8 and .NET 9 on Static Web Apps is ending November 10, 2026](https://azure.microsoft.com/updates?id=575106)

### Arc 対応 Windows Server を Azure File Sync でモダナイズ（パブリックプレビュー）

**要約**: Azure File Sync により、Arc 対応の Windows Server からのハイブリッドアクセスや Azure Files へのシームレスな移行を行う機能がパブリックプレビューになりました。

**影響**: ファイルサーバー移行を検討しているチームは、Arc 管理下のサーバーで試す価値があります。プレビューのため本番適用は慎重に判断してください。

**リンク**: [Public Preview: Modernize Arc-enabled Windows Servers with Azure File Sync](https://azure.microsoft.com/updates?id=579854)

### Brotli の不具合で Azure コンテナイメージの再ビルドが必要に

**要約**: Brotli の CVE に関連して、Azure のコンテナイメージの再ビルドが必要になるという解説記事が出ています。

**影響**: 依存ライブラリの脆弱性は、ベースイメージの再ビルドまで含めて対応する必要があります。ACR のイメージスキャンと定期再ビルドの仕組みを整えておきましょう。

**リンク**: [Brotli Bug Forces Azure Image Rebuilds: 3 Fixes [2026]](https://shattered.io/brotli-cve-2026-111497-azure-container-image-rebuild-acr-metrics-2026/)

# 2026/10/09 テクニカル雑談（午前）

## 1. Microsoft

### Microsoft Execution Containers が一般提供開始

**要約**: AI エージェントを安全に動かすための基盤「Microsoft Execution Containers」が一般提供になりました。Windows / macOS / Linux 向けに Rust・.NET・Node.js の SDK が提供されます。

**影響**: エージェントにコード実行やツール操作をさせる際の隔離環境を、自前で作り込まずに済む可能性があります。複数 OS 対応の SDK があるため、既存のエージェント実装への組み込みも検討しやすくなります。

**リンク**: [「Microsoft Execution Containers」が一般提供、AIエージェントを安全に動かす基盤](https://forest.watch.impress.co.jp/docs/news/2146735.html)

### Microsoft、137B コーディング AI を PC ローカル実行へ

**要約**: Microsoft が 137B のコーディング AI を PC 上でローカル実行できるようにすると報じられています。トークン消費の節約が狙いとのことです。

**影響**: ローカル実行が現実的になれば、クラウド API の従量課金や社外へのコード送信を気にする現場で選択肢が増えます。実際に必要なマシンスペックは今後の詳細待ちです。

**リンク**: [Microsoft、137BコーディングAIをPCローカル実行へ。トークン消費を節約](https://pc.watch.impress.co.jp/docs/news/2146632.html)

### Windows を「エージェント型 AI 環境」に

**要約**: Windows を最高のエージェント型 AI 環境にする取り組みが報じられており、OpenClaw も導入しやすくなるとのことです。

**影響**: 開発者の手元の Windows 上でエージェントを動かす前提が強まります。セキュリティ境界や権限管理の設計が、これまで以上に重要になりそうです。

**リンク**: [Windowsを最高のエージェント型AI環境に。OpenClawも導入しやすく](https://pc.watch.impress.co.jp/docs/news/2146754.html)

## 2. AI

### Google が「Nano Banana 2.1」を公開

**要約**: Google が画像生成モデル「Nano Banana 2.1」を公開しました。複雑な解説図や歴史的に正確なシーンも生成でき、「Nano Banana 2」「Nano Banana Pro」を上回る性能とされています。

**影響**: 技術資料やスライド用の図解を生成 AI で作る場面が増えそうです。ただし図の正確性は人間が確認する必要があります。

**リンク**: [Googleが「Nano Banana 2.1」を公開](https://forest.watch.impress.co.jp/docs/news/2146777.html)

### AI 自身がツールを評価する「agent.reviews」

**要約**: AI エージェントが使ったソフトウェアや開発ツールを 5 段階で評価するレビューサイト「agent.reviews」が登場しました。Claude Code や Codex もレビューを投稿しています。

**影響**: エージェントがツールを選ぶ際の参考情報として使われる仕組みで、ツール提供側は「人間だけでなくエージェントにも使いやすいか」を意識する必要が出てきます。

**リンク**: [agent.reviews](https://gigazine.net/news/20261008-agent-reviews/)

### 米政府らが AI 学習用の生物学データセットに投資

**要約**: Biohub の「Virtual Biology Initiative」に米エネルギー省や Google が合流し、AI トレーニング用のオープンな生物学データセット構築に米政府が 5 億ドルを投資すると発表されました。Meta・Google DeepMind・Isomorphic Labs もそれぞれ 3 億ドルを投資します。

**リンク**: [AIトレーニング用のオープンな生物学データセット構築のためアメリカ政府が5億ドルを投資](https://gigazine.net/news/20261008-virtual-biology-initiative/)

## 3. Azure

### Microsoft Dev Box と Azure Deployment Environments の廃止予定

**要約**: Microsoft Dev Box は 2028 年 9 月 18 日、Azure Deployment Environments は 2027 年 2 月 22 日に廃止されます。いずれも 2026 年 9 月 14 日からクローズ作業が始まります。

**影響**: 開発環境の払い出しや環境デプロイの基盤として使っているチームは、移行先の検討と計画が必要です。Deployment Environments は期限が早いため要注意です。

**リンク**: [Retirement: Microsoft Dev Box will be retired on September 18, 2028](https://azure.microsoft.com/updates?id=567933) / [Retirement: Azure Deployment Environments will be retired on February 22, 2027](https://azure.microsoft.com/updates?id=567934)

### WAF の例外設定が GA（Application Gateway / Front Door）

**要約**: Azure Application Gateway と Azure Front Door の WAF で、例外（exceptions）設定が一般提供になりました。

**影響**: 誤検知への対応をきめ細かく行いやすくなり、ルール全体を無効化せずに運用できる場面が増えます。

**リンク**: [Generally Available: Exceptions in WAF for Azure Application Gateway and Azure Front Door](https://azure.microsoft.com/updates?id=574343)

### Microsoft Agent 365 と API Management の統合（パブリックプレビュー）

**要約**: Microsoft Agent 365 と Azure API Management の統合がパブリックプレビューになりました。

**影響**: エージェント関連の API を API Management 経由で集中管理する構成を試せます。プレビューなので本番利用は慎重に判断してください。

**リンク**: [Public Preview: Microsoft Agent 365 integration with Azure API Management](https://azure.microsoft.com/updates?id=574204)

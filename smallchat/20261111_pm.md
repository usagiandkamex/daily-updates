## 2. AI

### 政府が高性能 AI の暴走に対する罰則を検討

**要約**: 政府が、高性能 AI のリスクに対処するため、AI 関連事業者に安全確保を義務付け、罰則を新設する方向で検討していることが 11 日に分かりました。サイバー攻撃への悪用や暴走といった重大な脅威を念頭に置き、年末までに法改正を含む制度見直しの全体像を示す予定です。

**影響**: AI サービスを提供・開発する事業者は、安全対策や運用体制の整備が求められる可能性があります。今後の法改正の動向を追っておきたいところです。

**リンク**: [政府、高性能AI暴走に罰則検討　悪質事業者に対抗手段へ法改正](https://www.47news.jp/15215887.html)

### Notion AI のチャット記録が漏えいの恐れ

**要約**: 米 Notion Labs は 11 月 9 日（現地時間）、Notion AI のチャット記録が漏えいした恐れがあると発表しました。委託先の Fireworks.aiへの不正アクセスが原因で、影響範囲は全ワークスペースの 1％とされています。

**影響**: AI 機能は外部の推論基盤に依存することが多く、委託先のリスクも含めた評価が重要です。AI チャットに機密情報を入力する際の運用ルールを再確認しましょう。

**リンク**: [「AIとのチャット記録」が漏えいか、Notion　委託先に不正アクセス](https://www.itmedia.co.jp/aiplus/article/2611/11/2000003104/)

## 3. Azure

### Azure Functions が .NET 11 に対応（GA）

**要約**: Azure Functions で .NET 11 のサポートが一般提供（GA）になりました。isolated worker モードで .NET 11 を対象にしたアプリを構築できます。

**影響**: 今日リリースされた .NET 11 を、さっそく Functions で試せます。本番投入前に、依存ライブラリの対応状況を確認しておきましょう。

**リンク**: [Generally Available: Azure Functions support for .NET 11](https://azure.microsoft.com/updates?id=578773)

### Azure Front Door が gRPC をネイティブサポート（プレビュー）と edge actions が GA

**要約**: Azure Front Door Standard / Premium で gRPC のサポートがパブリックプレビューになりました。また、エッジでの軽量なサーバーレスコンピューティングを実現する edge actions が一般提供されました。

**影響**: gRPC アプリを Front Door 経由で配信でき、エッジ側で処理を実行することで、構成のシンプル化や低遅延化が期待できます。

**リンク**: [Public Preview: Azure Front Door adds native gRPC support](https://azure.microsoft.com/updates?id=579383) / [Generally Available: Azure Front Door edge actions](https://azure.microsoft.com/updates?id=579310)

### AKS 向け Distributed accelerator for cloud storage（プレビュー）

**要約**: AKS 上の AI ワークロード向けに、Distributed accelerator for cloud storage (DACS) がパブリックプレビューになりました。

**影響**: AI ワークロードのストレージ I/O ボトルネックに悩む場合は、検証する価値がありそうです。

**リンク**: [Public Preview: Distributed accelerator for cloud storage on AKS](https://azure.microsoft.com/updates?id=578454)

## 1. Microsoft

### File Explorer とコンテキストメニューを刷新

**要約**: Microsoft は Windows Blog で、File Explorer とコンテキストメニューを「速く、シンプルに、カスタマイズ可能に」する取り組みを発表した。近年肥大化・鈍重化していたメニュー体系の見直しを進めている。

**影響**: 日常的にファイル操作を行う開発者にとって、右クリックメニューの応答性向上や整理は地味ながら生産性に直結する。今後の Insider ビルドでの挙動変化に注意しておきたい。

**リンク**: [Improving File Explorer & Context Menu: faster, simpler, and more customizable - Windows Blog](https://blogs.windows.com/windows-insider/2026/08/17/improving-file-explorer-context-menu-faster-simpler-and-more-customizable/)

### Windows 11 の「Drag Tray」機能をユーザーの声で撤回

**要約**: Microsoft はファイル共有用に導入していた Windows 11 の「Drag Tray」機能を、ユーザーからのフィードバックを受けてプレビュービルドから一旦取り下げた。改善を検討中としている。

**影響**: プレビュー版の新機能が正式リリース前にフィードバックで方向転換される事例として、Insider Program 参加者やフィードバックを送る開発者の声の重要性を示している。

**リンク**: [Microsoft pulls Windows 11 'Drag Tray' feature for sharing files after user feedback - windowscentral.com](https://www.windowscentral.com/microsoft/windows-11/microsoft-pulls-frustrating-drag-tray-file-sharing-feature-from-windows-11-in-latest-preview-builds-promises-to-explore-improvements-after-feedback-from-users)

### Reddit r/microsoft 週次雇用Q&Aスレッド開始

**要約**: Reddit の r/microsoft コミュニティで、8月17日〜24日分の週次雇用 Q&A スレッドが公開された。Microsoft 関連の就業・キャリアに関する質問を交換する場として運用されている。

**影響**: Microsoft エコシステムで働く/働きたいエンジニアにとって、社内事情やキャリアパスの生の情報源として参考になる。

**リンク**: [Weekly Employment Q&A - August 17, 2026 - August 24, 2026](https://www.reddit.com/r/microsoft/comments/1vr1gjj/weekly_employment_qa_august_17_2026_august_24_2026/)

### 14MBの超軽量AIモデル「Needle 2」を試す

**要約**: GitHub Trending で話題の Cactus Compute 製 Needle 2（45Mパラメータ、ツール呼び出し特化）を検証した記事。DLL1個・RAM 37MB・推論0.5秒と軽量だが、日本語タスクは5問中0問正解だったという結果を報告。

**影響**: エッジデバイスや低リソース環境でのAI活用を検討するエンジニアにとって、超軽量モデルの実力と多言語対応の限界を把握する参考になる。

**リンク**: [14MBのAIモデルは本当に動いた — DLL 1個・RAM 37MB・1回0.5秒、ただし日本語は0/5](https://qiita.com/jqit_suwa/items/acb61138c4550eef4803)

**リンク**: [[In preview] Public Preview: Zone redundancy for Azure SQL Managed Instance Next-gen General Purpose](https://azure.microsoft.com/updates?id=568344)

**要約**: 米CISA（サイバーセキュリティ・インフラセキュリティ庁）は、AIシステムの脆弱性報告を目的とした新プログラム「Gold Eagle」を発表した。

**影響**: AIシステムを開発・運用する組織にとって、脆弱性の報告・対応フローが政府主導で整備されることは、責任あるAI開発の基準づくりに影響する動きとして注視すべきポイントとなる。

**リンク**: [CISA Unveils Gold Eagle for AI Vulnerability Reporting - ExecutiveGov](https://www.executivegov.com/articles/cisa-gold-eagle-ai-vulnerability-tool-launch)

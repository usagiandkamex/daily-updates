# 2026/10/09 テクニカル雑談（午後）

## 1. Microsoft

### Microsoft 365 のストレージ容量が縮小へ

**要約**: Microsoft が M365 Family / Premium の OneDrive ストレージを 6TB から 2TB に縮小すると報じられています。ZDNET Japan は一部プランで「実質値上げ」にあたると伝えており、Reddit でも反発するユーザーの声が出ています。

**影響**: OneDrive をバックアップ先や大容量の作業領域にしている人は、移行や整理を迫られる可能性があります。自分のプランの適用時期と現在の使用量を確認しておくのが無難です。

**リンク**: [マイクロソフト、「Microsoft 365」のストレージ容量を縮小へ--一部は「実質値上げ」](https://japan.zdnet.com/article/35253416/)

### E5 + Defender でメールセキュリティは足りるか

**要約**: E5 を契約している組織が、Defender for Office 365 P2 に加えてサードパーティのメール保護レイヤーが必要か、とコミュニティで相談しています。毎月数件のフィッシングがすり抜けるのが背景です。

**影響**: ライセンスの範囲で十分かどうかは、運用上の検知漏れの実態で判断することになります。ポリシー設定の見直しが先か、多層防御の追加が先かを検討する材料になります。

**リンク**: [Do you need a third-party email layer on E5 with Defender?](https://www.reddit.com/r/microsoft/comments/1x1fyuh/do_you_need_a_thirdparty_email_layer_on_e5_with/)

## 2. AI

### Claude に Dashboards / Claude Motion（ベータ）

**要約**: Anthropic は 10 月 8 日、Claude の新機能「Claude Dashboards」と「Claude Motion」をベータ版として公開しました。SQL を書かずにデータ分析ができ、ダッシュボードを自動生成するとされています。

**影響**: 軽い集計や可視化を依頼する用途で、BI ツールやクエリ作成の手間が減る可能性があります。まだベータ版なので、結果の検証は引き続き必要です。

**リンク**: [Claude、SQL不要でデータ分析可能に - ダッシュボードを自動生成する新機能](https://news.mynavi.jp/techplus/article/20261009-5099252/)

### Qwen3.8-27B を 8GB に圧縮した「Saluki 27B」

**要約**: Qwen3.8-27B を 8GB に凝縮した「Saluki 27B」が登場し、メモリ 16GB のノート PC で動作するとのことです。

**影響**: ローカル LLM の敷居がさらに下がります。機密データを外部に出したくない用途や、オフライン環境での検証に使いやすくなりそうです。

**リンク**: [Qwen3.8-27Bを8GBに凝縮！メモリ16GBのノートで動く「Saluki 27B」](https://pc.watch.impress.co.jp/docs/news/2147095.html)

### Google AI Edge Foresight 公開

**要約**: Google が、EmbeddingGemma 2 や Gemma 4 を使って会議の内容を文字起こし・要約する macOS 向けノートアプリ「Google AI Edge Foresight」を公開しました。

**影響**: オンデバイス寄りの Gemma 系モデルの実用例として参考になります。自社アプリにローカル AI を組み込む際の設計の手がかりにもなります。

**リンク**: [GoogleがGemma 2・Gemma 4などのAIアシスタントで会議を記録するmacOSノートアプリ「Google AI Edge Foresight」リリース](https://gigazine.net/news/20261009-google-ai-edge-foresight/)

## 3. Azure

### AKS で Managed StandardV2 NAT Gateway が GA

**要約**: AKS が、AKS 管理の仮想ネットワークを使うクラスターに StandardV2 NAT Gateway をプロビジョニング・管理するようになりました。StandardV2 が管理 NAT のデフォルトになります。

**影響**: 新規クラスターのアウトバウンド構成が変わります。固定 IP やアウトバウンド制御を前提にしている場合は、構成の差分を確認してください。

**リンク**: [[Launched] Generally Available: Managed StandardV2 NAT Gateway for AKS](https://azure.microsoft.com/updates?id=574430)

### Microsoft Dev Box / Azure Deployment Environments の提供終了予告

**要約**: Microsoft Dev Box は 2028 年 9 月 18 日、Azure Deployment Environments は 2027 年 2 月 22 日に提供終了予定です。どちらも 2026 年 9 月 14 日から終了に向けた手続きが始まります。

**影響**: 開発環境の基盤として使っているチームは、代替サービスへの移行計画が必要です。特に ADE は期限が近いため、早めの棚卸しをおすすめします。

**リンク**: [Retirement: Microsoft Dev Box will be retired on September 18, 2028](https://azure.microsoft.com/updates?id=567933) / [Retirement: Azure Deployment Environments will be retired on February 22, 2027](https://azure.microsoft.com/updates?id=567934)

### PostgreSQL flexible server が East US 3 に対応

**要約**: Azure Database for PostgreSQL flexible server を East US 3 リージョンにデプロイできるようになりました。

**影響**: 米国東部でのレイテンシ要件や、リージョン分散・DR の選択肢が増えます。

**リンク**: [[Launched] Generally Available: Azure Database for PostgreSQL flexible server in East US 3](https://azure.microsoft.com/updates?id=573691)

## 5. セキュリティ

### JR東日本「えきねっと」などで最大約206万件の漏えいの可能性

**要約**: JR東日本は 10 月 9 日、「えきねっと」と「大人の休日倶楽部」で最大約 206 万件の利用者情報が漏えいした可能性があると発表しました。原因は 7 日に IDC フロンティアが公表した不正アクセスで、メール配信用の外部サービスに保存していた情報が閲覧・取得されたとのことです。

**影響**: 委託先や外部サービスに預けたデータも自社の漏えいリスクになります。サプライチェーン全体で、保存データと権限を棚卸ししましょう。

**リンク**: [JR東、「えきねっと」などで漏えいか　メルアドなど最大206万件　IDCFクラウドへの不正アクセスで](https://www.itmedia.co.jp/news/article/2610/09/2000002171/)

### IPA が不正アクセスによる漏えい事案を受けた対策を公表

**要約**: IPA は、国内の金融機関や通信事業者などで不正アクセスによる情報漏えいの公表が相次いでいるとして、速やかに実施すべき対策をまとめました。大量の個人情報を扱うオンラインサービスやアカウントサービスのシステムを特に挙げています。

**影響**: 該当する事業者に限らず、アクセス制御、ログ監視、認証情報の管理を点検するきっかけになります。ページは随時更新される予定です。

**リンク**: [不正アクセスによる漏えい等の事案を踏まえ、速やかに実施すべき対策等について](https://www.ipa.go.jp/security/security-alert/2026/alert20261009.html)

### 米国で運転免許証情報など1億5000万件以上が漏えいか

**要約**: NHK によると、米ルイジアナ州に本社がある ID 確認サービスの企業への不正アクセスで、運転免許証などの個人情報が 1 億 5000 万件以上漏えいした可能性があるとのことです。

**影響**: 本人確認データは悪用されやすく、被害が長引きます。eKYC などで ID 情報を扱うサービスは、保持期間と最小化を見直す必要があります。

**リンク**: [アメリカ 運転免許証などの情報 1億5000万件以上が漏えいか | NHKニュース](https://news.web.nhk/newsweb/na/nd-20261009de57294)

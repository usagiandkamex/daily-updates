**要約**: Microsoft が Windows 11 ではマウスのドラッグでタスクバーを移動できる機能を今後も提供しない方針を明言した。「欠けている機能ではなく意図的な設計判断」という説明で、Windows 10 では可能だった操作が戻ってこないことが確認された。

## 2. AI

### Vercel Labs「agent-desktop」：OS のアクセシビリティツリーでデスクトップ操作

**要約**: vercel-labs が公開した agent-desktop は、AI エージェントにデスクトップアプリの操作（computer use）をさせるための CLI / C ライブラリ。Rust 製で、OS のアクセシビリティツリー経由でアプリの UI 構造を把握し、参照（ref）が安定していて再試行しても安全な操作を狙う。macOS・Windows・Linux に対応する。

**影響**: スクリーンショット頼みの操作より安定した自動化ができる可能性がある。エージェントによる GUI 操作を試したい開発者にとって、検証しやすい選択肢が増えた。

**リンク**: [GitHub - vercel-labs/agent-desktop](https://github.com/vercel-labs/agent-desktop)

**影響**: コンテンツを公開する側は、一度の記述で複数の AI 企業に意思を伝えられるようになる。導入時期は 2027 年とされているため、今のうちに自サイトのポリシーを整理しておくと良い。

**リンク**: [AI学習の可否をrobots.txtで指定 Google、MS、OpenAIらが共通仕様を27年導入 - Impress Watch](https://www.watch.impress.co.jp/docs/news/2152852.html)

### Python asyncio で AI API 呼び出しを並列化する

**要約**: Qiita の記事で、OpenAI の ChatGPT や Google の Gemini など LLM API の呼び出しを Python の asyncio で並列化し、スループットを高める方法が紹介されている。

**影響**: LLM API は応答待ち時間が長いため、I/O バウンドな処理を非同期化するだけで全体の処理時間を大きく短縮できる。バッチ処理や大量リクエストを扱う場合は、レート制限との兼ね合いも含めて試す価値がある。

**リンク**: [Python asyncioでAI APIを爆速化！並列呼び出しによる非同期処理でスループットを最大化 - Qiita](https://qiita.com/Maku-Inc/items/568f924fd3292330118a)

## 5. セキュリティ

### GMO 系サービスで顧客情報 4.5 万人分が漏洩、設定ミスで 9 年間取得可能に

**要約**: GMO インターネットグループは 10 月 30 日、ID やパスワードを管理するサービスで計 4 万 5030 人分の顧客情報が漏洩したと発表した。対象企業は計 2492 社。設定ミスが原因で、情報が 9 年間にわたり外部から取得できる状態だったという。

**影響**: 設定ミスは長期間気付かれないまま残りうる。公開範囲やアクセス制御の定期的な棚卸し・監査の重要性を再認識させる事例だ。

**リンク**: [GMO系、顧客情報4.5万人分漏洩　設定ミスで9年間外部から取得可能 - 日本経済新聞](https://www.nikkei.com/article/DGXZQOUC010ZZ0R01C26A1000000/)

### 楽天証券、NTT データ委託先への不正アクセスで顧客情報流出の可能性

**要約**: 楽天証券は、特典の申し込みなどに使われる外部サービスの基盤である「デジタル証券プラットフォーム」（NTT データの委託先が提供）が不正アクセスを受け、情報が外部に持ち出された可能性があると発表した。発生日時は 10 月 30 日とされる。

**影響**: 自社が堅牢でも、委託先や外部サービス経由で情報が流出するリスクがある。サプライチェーン全体でのセキュリティ管理やデータ受け渡し範囲の最小化が課題となる。

**リンク**: [楽天証券、顧客情報流出の可能性　NTTデータ委託先不正アクセスで - CNET Japan](https://japan.cnet.com/article/35254251/)

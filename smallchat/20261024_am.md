## 1. Microsoft

### Windows 11 Insider ビルドでエクスプローラーの右クリックメニューが軽量化

**要約**: Windows 11 の Insider ビルドで、File Explorer のコンテキストメニューをより高速で散らかりにくくする変更のテストが始まっています。別の報道では、新しい Insider ビルドで Settings の高速化が進む一方、Recall が含まれないことを Microsoft が認めたとされています。

**影響**: 日常的に使う操作の体感速度に直結する改善です。開発者は、Insider ビルドで自分のツールやシェル拡張の挙動が変わっていないかを早めに確認しておくと安心です。

**リンク**: [Windows 11 is getting a faster, less cluttered File Explorer context menu in Insider builds - Windows Central](https://www.windowscentral.com/microsoft/windows-11/microsoft-is-testing-a-cleaner-faster-file-explorer-context-menu-for-windows-11)

**要約**: 新しい Windows 11 Insider ビルドでは Settings アプリの動作が速くなり、Recall が含まれていないことを Microsoft が確認したと Neowin が伝えています。

**影響**: 機能の出し入れが Insider 段階で頻繁に起きることがわかります。特定機能に依存した検証を行う場合は、ビルドごとの差異に注意が必要です。

**リンク**: [Microsoft confirms missing Recall and faster Settings with new Windows 11 Insider builds - Neowin](https://www.neowin.net/news/microsoft-confirms-missing-recall-and-faster-settings-with-new-windows-11-insider-builds/)

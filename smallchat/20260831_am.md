# 2026/08/31 テクニカル雑談（午前）

## 1. Microsoft

### Windows 11 更新プログラム KB5120998 でマウスカーソルが破損、壁紙が黒く表示される不具合

**要約**: Microsoft は Windows 11 向け更新プログラム KB5120998 の適用後、マウスカーソルが表示崩れを起こし、デスクトップの壁紙が黒くなる不具合を確認したと公表した。更新を削除するまで現象が続くケースがあると報告されている。

**影響**: 業務端末に自動配信される更新プログラムでUIが壊れると、サポート対応の工数が急増する。管理者は展開前の検証環境でのステージング適用や、既知の不具合情報を追跡するプロセスを見直す必要がある。

**リンク**: [Microsoft Admits Windows 11 KB5120998 Update Breaks Mouse Cursors, With Wallpapers Turning Black Until You Uninstall It](https://wccftech.com/windows-11-kb5120998-update-breaks-mouse-cursor/)

### Windows Update 適用後にウイルス対策ソフトが誤って「オフ」と表示される不具合をMicrosoftが確認

**要約**: 一部のWindows端末で、Windows Updateの適用後にセキュリティセンターがアンチウイルスの状態を誤って「無効」と表示する事象が報告され、Microsoftが確認済みであるとした。

**影響**: 実際には保護が有効であっても誤警告によりユーザーやIT部門の不安・問い合わせが増える。誤検知と実際の脅威を切り分けるための監視体制、パッチ適用後の状態確認手順の整備が求められる。

**リンク**: ['Antivirus Is Turned Off': Microsoft confirms windows update is triggering false alerts](https://www.firstpost.com/tech/antivirus-is-turned-off-microsoft-confirms-windows-update-is-triggering-false-alerts-14041929.html)

### JetBrainsがMac向けローカル動作コーディングエージェント「Junie Local」を提供開始

**要約**: JetBrainsはローカルマシン上で完結して動くAIコーディングエージェント「Junie Local」の提供を開始した。API利用料やモデル利用料が不要で、Claude Sonnet 4.5相当の性能を持つとされ、RTX対応も開発中という。

**影響**: クラウドAPI課金なしでローカル完結のコーディング支援が使えるようになれば、コスト面・情報漏えいリスク面でのハードルが下がり、セキュリティ制約の強い企業でもAI活用が進む可能性がある。

**リンク**: [JetBrains、Mac上で動作するコーディングエージェント「Junie Local」提供開始。Claude Sonnet 4.5と同等の能力、RTX5909対応も開発中](https://www.publickey1.jp/blog/26/jetbrainsmacjunie_localclaude_sonnet_45rtx5909.html)

## 3. Azure

### AKSのControl Planeメトリクス収集がGA

**要約**: Azure Kubernetes Service（AKS）向けに、Azure Monitor Managed Service for Prometheusを活用したControl Planeメトリクス収集機能が一般提供（GA）された。

**影響**: AKSクラスターの制御プレーンの状態をより詳細に監視できるようになり、運用者はトラブルシューティングやキャパシティプランニングの精度を高められる。

**リンク**: [Generally Available: Control plane metrics collection for AKS with Managed Prometheus](https://azure.microsoft.com/updates?id=568830)

### Premium SSD v2とUltra DiskのLive ResizeがGA

**要約**: Azureの共有Premium SSD v2（Pv2）およびUltraデータディスクにおいて、稼働中のまま容量を動的に拡張できる「Live Resize」機能が一般提供された。

**影響**: ダウンタイムなしでストレージ容量を拡張できるため、本番環境でのメンテナンスウィンドウを確保しにくいシステムでも柔軟なスケーリングが可能になる。

**リンク**: [Generally Available: Live Resize for Shared Premium SSD v2 and Ultra Data Disks](https://azure.microsoft.com/updates?id=569281)

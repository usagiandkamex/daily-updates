### Sticky Keys ポップアップがついに無効化可能に

**要約**: Windows Latest によると、Microsoft は Windows 11 の Sticky Keys ポップアップを無効にできるようにした。登場から 31 年を要し、由来は Windows 95 時代のピンボールゲームだという。

**影響**: Shift キーを連打するゲームや、キーボード操作の多い開発・ターミナル作業での誤爆ストレスが減る。小さいが地味に嬉しい改善。

**リンク**: [Microsoft took 31 years to let you kill Windows 11's Sticky Keys popup, which exists because of a Windows 95-era pinball game - Windows Latest](https://www.windowslatest.com/2026/11/08/microsoft-took-31-years-to-let-you-kill-windows-11s-sticky-keys-popup-which-exists-because-of-a-windows-95-era-pinball-game/)

**リンク**: [Google and Microsoft among those signing up to OpenAI's plan for a new website crawling standard — including opting-out of internet scraping - TechRadar](https://www.techradar.com/pro/google-and-microsoft-among-those-signing-up-to-openais-plan-for-a-new-website-crawling-standard-including-opting-out-of-internet-scraping)

**要約**: Linear で本番トラフィックを 10% ずつ 6 分おきに切り替えると（API 既定値）、待機時間だけで約 54 分かかる。ECS コンソールのデプロイ可観測性がこれらの方式に対応し、進捗や停止の理由を確認しやすくなった。

## 5. セキュリティ

### Claude Code の「今後確認しない」が秘密情報を漏らす

**要約**: Claude Code で「Yes, and don't ask again」を選ぶと、承認したコマンドが `.claude/settings.local.json` に保存される。コマンドにパスワードや API キーが含まれると平文で残り、1,122 件の公開ファイルで 1,379 件の秘密情報が見つかったと報じられている。

**影響**: `.claude/settings.local.json` を `.gitignore` に入れ、秘密情報は環境変数や Secret 管理で渡すのが無難。既存リポジトリの履歴確認とキーのローテーションも検討したい。

**リンク**: [Claude Codeの「今後確認しない」が秘密情報をGitHubに漏らす — 1,122件の公開ファイルに1,379件の秘密情報 - Dev & Gadget Note](https://dev.ponkotsu.dev/entry/claude-code-settings-local-secrets)

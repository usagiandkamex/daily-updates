# 2026/11/28 テクニカル雑談（午前）

## 1. Microsoft

### 業務向け Copilot アプリに Office を統合、Workspaces も登場

**要約**: Ignite 2026 で、業務向け「Copilot」アプリに「Office」を統合することが発表された。人とエージェントが協働する「Workspaces」も紹介され、「Home」は一般提供、自律型の「Autopilot」は Frontier 向けに展開が始まっている。

**影響**: Office 作業と AI エージェントが一つのアプリに集約されていく流れが見える。社内でエージェント活用を進める際は、Frontier 向けの機能から先に検証しておくとよさそう。

**リンク**: [業務向け「Copilot」アプリに「Office」を統合、人とエージェントが協働する「Workspaces」も【Ignite 2026】](https://forest.watch.impress.co.jp/docs/news/2159782.html)

### .NET API「DocumentExtractionClient」をプレビュー発表

**要約**: さまざまなドキュメントを「AI が読める形」にする .NET API として、Microsoft が「DocumentExtractionClient」を発表した。OCR サービスやローカルモデルを切り替えて使える共通の仕組みで、まずはプレビュー提供。

**影響**: RAG などの前処理で、OCR 基盤の差し替えをコード変更なしに近い形で試せるようになる可能性がある。.NET で文書取り込みを作っているチームは注目しておきたい。

**リンク**: [.NET API、Microsoftが「DocumentExtractionClient」を発表](https://forest.watch.impress.co.jp/docs/news/2159777.html)

### Windows 12 はまだ無し、AI の有用性を示す必要があると Windows 責任者

**要約**: Windows 責任者が、Windows 11 の Copilot にユーザーから反発があったことを受け、AI が有用だと証明して「許可を得る」必要があると語ったと報じられている。Windows 12 はまだ予定されていない。

**影響**: OS への AI 統合は、押し付けではなく実用性で評価される段階にある。Windows 向けアプリ開発でも、AI 機能は有用性を示せる形で提供することが重要になりそう。

**リンク**: [No Windows 12 yet: Windows boss says Microsoft must prove its AI is useful](https://www.windowslatest.com/2026/11/27/no-windows-12-yet-windows-boss-says-microsoft-must-prove-its-ai-is-useful-to-earn-permission-after-users-pushed-back-on-copilot-in-windows-11/)

### Elastic Load Balancing for Envoy の ddos_protection と AWS WAF 連携

**要約**: ddos_protection の SYN cookie mode を continuous にすると SYN-ACK の形が変わり、不正な ACK に SYN-ACK を再送しなくなった。AWS WAF の Block ルール（IP 指定、レートルール）による遮断も確認できたとのこと。

**影響**: L4 と L7 の防御を組み合わせた構成の検証例として、DDoS 対策設計の参考になる。

**リンク**: [Elastic Load Balancing for Envoy の ddos_protection と AWS WAF 連携を試してみた](https://dev.classmethod.jp/articles/aws-elb-for-envoy-syn-cookie-waf/)

### Terraform で ALB のリスナールールを使い分ける

**要約**: 1 つの ALB でパスやホスト名ごとに振り分ける方法を、優先度と重み付けの設定とともに Terraform で解説した記事。

**影響**: ALB は個別に料金がかかるため、ルールで集約すればコスト削減につながる。

**リンク**: [【Terraform×AWS】ALBのリスナールールでパスやホスト名ごとに振り分ける](https://qiita.com/ham-nao/items/bb9f76284326df6e7642)

## 5. セキュリティ

### Linux カーネルのバグ「TCPanic」

**要約**: Ikotas Labs が、TCP 通信のみでホスト全体が停止する可能性のある Linux カーネルのバグ「TCPanic」を発見した。Linux 7.3.4 に修正が含まれている。

**影響**: ネットワーク越しにホストを停止させ得るため、該当カーネルを使うサーバーは修正版への更新計画を立てたい。

**リンク**: [Linuxカーネルのバグ「TCPanic」を発見](https://ikotaslabs.com/news/2026-11-27)

### KARTE の情報漏えいが拡大、契約終了後のデータも流出

**要約**: プレイドの CX プラットフォーム「KARTE」が 11 月 13 日に不正アクセスを受け、多数の企業の顧客情報が流出した。契約終了済みの企業の顧客情報も漏えいしたとの発表が相次ぎ、「人的オペレーションと管理の不備」が指摘されている。

**影響**: SaaS 解約後のデータ削除が確実に行われているかは、委託元としても確認すべき点。ベンダー管理のチェック項目に加えたい。

# 2026/10/16 テクニカル雑談（午後）

## 1. Microsoft

### 10月の Windows Update で Wi-Fi/VPN 接続不可、原因は NTLMv1 廃止

**要約**: 2026年10月の Windows Update 後に Wi-Fi や VPN へ接続できない問題が報告されている。記事によれば、これはパッチの不具合ではなく、あらかじめ計画されていた NTLMv1 廃止の影響とのこと。

**影響**: 古い認証方式（NTLMv1）に依存する社内 Wi-Fi や VPN 構成があると、更新適用後に接続できなくなる可能性がある。更新前に認証方式の棚卸しと移行を進めておきたい。

**リンク**: [2026年10月「Windows Update」でWi-Fi/VPNに接続できない問題、脱「NTLMv1」が影響／あらかじめ計画されていた変更、パッチの不具合ではない](https://forest.watch.impress.co.jp/docs/news/2148594.html)

### Windows 11、コントロールパネル廃止が加速？ 設定アプリを Store で配信するテスト

**要約**: Windows Latest によると、Microsoft は設定アプリを Microsoft Store 経由で提供するテストを静かに進めており、コントロールパネルの廃止が早まる可能性がある。

**影響**: 設定アプリが Store 経由で更新されるようになれば、OS 本体の更新を待たずに機能が追加される可能性がある。一方、コントロールパネル前提の手順書やスクリプトは見直しが必要になるかもしれない。

**リンク**: [Windows 11 could kill Control Panel faster, as Microsoft quietly tests Settings in the Microsoft Store - Windows Latest](https://www.windowslatest.com/2026/10/16/windows-11-could-kill-control-panel-faster-as-microsoft-quietly-tests-settings-in-the-microsoft-store/)

### Edge、新機能やパッチを静かに自動インストールする仕組みへ

**要約**: Neowin によると、Microsoft は Edge が新機能やパッチを目立たない形で自動的にインストールする仕組みを紹介している。

**影響**: ブラウザの更新が利用者に意識されにくくなり、セキュリティ修正の適用は早まりそうだ。企業環境では、更新ポリシーや検証タイミングとの兼ね合いを確認しておきたい。

**リンク**: [Microsoft shows how Edge will soon quietly install new features and patches automatically - Neowin](https://www.neowin.net/news/microsoft-shows-how-edge-will-soon-quietly-install-new-features-and-patches-automatically/)

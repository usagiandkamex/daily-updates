## 3. Azure

### Azure Databricks Lakebaseが追加4リージョンでGA

**要約**: Azure Databricks Lakebaseが北米中部、フランス中部、ドイツ西部中央、東アジアの4リージョンで一般提供（GA）を開始した。

**影響**: 対象リージョンで運用するチームは、データレイテンシやコンプライアンス要件に合わせてLakebaseをより近いリージョンで利用できるようになる。

**リンク**: [Generally Available: Azure Databricks Lakebase in four additional regions](https://azure.microsoft.com/updates?id=569684)

### MSSQL拡張機能にSQL FormatterがパブリックプレビューでOSS

**要約**: MSSQL拡張機能にSQLスクリプトをエディタ上で直接整形できる「SQL Formatter」がパブリックプレビューとして追加された。

**影響**: SQL開発者はコードレビュー前の整形作業を自動化でき、チーム内でのSQLコーディング規約の統一がしやすくなる。

**リンク**: [Public Preview: SQL Formatter in MSSQL extension](https://azure.microsoft.com/updates?id=569155)

### MSSQL拡張機能からAzure SQL Databaseを無料でプロビジョニング可能に

**要約**: MSSQL拡張機能から直接、フルマネージドなクラウドデータベースを無料で作成・接続できる「Azure SQL Database provisioning」がGAとなった。

**影響**: 開発者はエディタを離れることなく検証用データベースを素早く用意でき、開発サイクルの短縮につながる。

**リンク**: [Generally Available: Azure SQL Database provisioning in MSSQL extension](https://azure.microsoft.com/updates?id=569160)

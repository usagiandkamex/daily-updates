**要約**: 2026 年 11 月 25 日に Preview の展開が始まった GPT 6.2 Astra を、Kiro Enterprise の管理画面の Model availability から有効化して試した記事です。Kiro IDE のモデル選択に表示されます。

### Cloudflare Email Sending が Free プランで利用可能に

**要約**: Workers Free プランでも、事前承認した verified destination address 宛てならメール送信できるようになりました。送信メールは SPF・DKIM・DMARC がすべて pass だったと報告されています。

**影響**: 通知メールのプロトタイプを無料枠で手軽に試せます。ただし送信先は限定されます。

**リンク**: [Cloudflare Email Sending が Free プランで使えるようになったので試してみた](https://dev.classmethod.jp/articles/cloudflare-email-sending-workers-free/)

## 4. クラウド

### Step Functions で Lambda MicroVMs のジョブを実行

**要約**: MicroVM の起動・ジョブ実行・終了を Step Functions（SDK 統合と JSONata）で組めたとの検証です。同じ MicroVM に送った 2 つのジョブはファイルとメモリを共有でき、ARM と x86 を並列で動かすこともできました。

**影響**: ビルドなど重めの処理を、サーバー管理なしでワークフロー化する選択肢になります。

**リンク**: [Step Functions で Lambda MicroVMs のジョブを実行してみた](https://dev.classmethod.jp/articles/step-functions-lambda-microvms-orchestration/)

### Postgres MCP Server を IAM DB 認証で Aurora に接続

**要約**: パスワードなしの読み取り専用ユーザーとして、IAM DB 認証で Aurora PostgreSQL に Postgres MCP Server をつなぐ方法の解説です。

**影響**: AI エージェントにデータを読ませつつ、書き込みを防ぐ構成の参考になります。

**リンク**: [Postgres MCP Server を IAM DB 認証でパスワードなしの読み取り専用ユーザーとして Aurora に繋ぐ](https://qiita.com/asahide/items/90a744d9cdf33401256e)

### AWS ユーザー向け Google Cloud ファイアウォールルール入門

**要約**: Google Cloud の VPC ファイアウォールルールは AWS のセキュリティグループに近いものの、VM ごとではなく VPC に作成します。default VPC は最初から SSH を許可している点も指摘されています。

**影響**: AWS から GCP に移る際の落とし穴を事前に把握できます。default VPC の設定は見直しが必要です。

**リンク**: [AWS ユーザー向け Google Cloud ファイアウォールルール入門：default VPC は最初から SSH を許可している](https://qiita.com/leomarokun/items/e06db1e7995349d861d8)

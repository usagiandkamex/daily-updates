## 1. Microsoft

### Entra ID と Azure DevOps の認証情報が悪用され、MSP の顧客組織へ被害拡大

**要約**: 攻撃者が Microsoft Entra ID を悪用し、マネージドサービスプロバイダ（MSP）経由で下流の顧客組織を狙ったと報じられています。別の報道では、盗まれた Entra ID と Azure DevOps の認証情報で 27 組織にアクセスされたとされています。

**影響**: 委任管理（GDAP など）や MSP 向けの権限は侵害時の影響範囲が広くなります。外部パートナーに付与した権限の棚卸し、条件付きアクセス、監査ログの監視を見直すきっかけになりそうです。

**リンク**: [Attacker abuses Microsoft Entra ID to target downstream MSP clients - Cybersecurity Dive](https://www.cybersecuritydive.com/news/attacker-microsoft-entra-id-downstream-msp/873744/)

### Windows 11 が RAM を多く使うのは「良いこと」？

**要約**: Microsoft は、Windows 11 がメモリを多く使うこと自体は問題ではなく、重要なのは PC の応答性が保たれているかどうかだと説明しているとのことです。

**影響**: 空きメモリが多いほど良いという前提は、キャッシュを積極的に使う現代の OS には当てはまりません。パフォーマンスの切り分けでは使用率より応答性やスワップの状況を見るのが実用的です。

**リンク**: [Windows 11 using most of your RAM? Microsoft says that's a good thing](https://www.windowslatest.com/2026/11/05/windows-11-using-most-of-your-ram-microsoft-says-thats-a-good-thing-as-the-real-test-is-whether-your-pc-stays-responsive/)

## 4. クラウド

### ECR に push すると 3 件並ぶ正体は provenance attestation

**要約**: GitHub Actions から 1 回 push しただけで ECR に 3 件のイメージが並び、うち 2 件はタグが「-」だった現象の原因が、provenance attestation だったと解説されています。

**影響**: 一覧の件数やサイズを見て不要なイメージと誤認し、削除やライフサイクルルールで壊してしまうリスクがあります。ビルド設定の理解が重要です。

**リンク**: [ECR に1回 push しただけで3件並ぶ正体は、provenance attestation だった](https://qiita.com/ogura-gmoconnect/items/85e75da0f74f9005c1b9)

### CloudFront + Lambda 関数 URL で画像を配信時に縮小

**影響**: 画像最適化は体感速度に効く定番の改善です。CloudFront と Lambda 関数 URL の組み合わせで比較的手軽に実現できます。

**リンク**: [CloudFront + Lambda 関数 URL で画像を配信時に縮小して、ページの画像容量半分以下にした話](https://qiita.com/Tukirukiki/items/8e844dec1fa8e74943b7)

### アルトマン CEO「PC に大量の RAM を積むのは問題」

**要約**: OpenAI の Sam Altman CEO が、PC に大量の DRAM を積むのは「かなりひどい」と発言しました。PC では DRAM がほとんど使われておらず、クラウドに集約して使い切るほうがよい、という主張です。背景にはメモリ不足が続いている状況があります。

## 4. クラウド

### Aurora PostgreSQL と RDS の違いはストレージ層とレプリカ構造にある

**要約**: RDS for PostgreSQL で `max_wal_size` やチェックポイント周りを詰めた設定を、そのまま Aurora PostgreSQL に持ち込んでも期待した効果が出ない、という解説記事です。レプリカ遅延の監視も同様に、構造の違いを踏まえる必要があります。

**影響**: RDS から Aurora への移行時は、パラメータをそのままコピーせず、ストレージ層の違いを理解したうえでチューニングと監視を設計し直す必要があります。

**リンク**: [Aurora PostgreSQLとRDSの違いはストレージ層とレプリカ構造にある](https://qiita.com/techdbblog/items/37915d7e89fd97310dae)

## 1. Microsoft

### 「Microsoft To Do」が2027年6月で廃止

**要約**: 個人向けの「Microsoft To Do」アプリが2027年6月で廃止されると報じられた。個人利用者は別アプリへの乗り換えが必要で、法人向けは「Planner」が後継となる。

**影響**: To Do を使ったタスク管理や、API・自動化で連携しているチームは移行先と期限を早めに洗い出したい。データのエクスポート可否も確認しておくと安心。

**リンク**: [「Microsoft To Do」アプリが2027年6月で廃止、個人の場合は別アプリへの乗り換えが必要に／法人向けは「Planner」が後継](https://forest.watch.impress.co.jp/docs/news/2158040.html)

### 「Windows Server 2028」でレガシー機能の削除が進む

**要約**: 「Windows Server 2028」では「WSUS」「SMB 1.0」「VBScript」などが削除され、「Windows PowerShell 5.1」「WDS」は非推奨になると報じられた。レガシー BIOS での起動も不可になる。

**影響**: WSUS や VBScript、SMB 1.0 に依存した運用スクリプトや古い機器との接続が残っている環境は、今のうちに棚卸しして移行計画を立てるのが良さそう。

**リンク**: [「Windows Server 2028」で「WSUS」や「SMB 1.0」、「VBScript」などが削除へ](https://forest.watch.impress.co.jp/docs/news/2158261.html)

## 4. クラウド

### AWS Lambda durable functions の OpenTelemetry サポート

**要約**: OpenTelemetry プラグインにより、複数回の invocation に分かれる durable execution が1つの trace ID にまとまる。step の所要時間や retry を1本のトレースで追える。

**影響**: 長時間ワークフローのボトルネックや障害原因の特定に役立つ可能性がある。

**リンク**: [AWS Lambda durable functions の OpenTelemetry サポートを試してみた](https://dev.classmethod.jp/articles/lambda-durable-functions-opentelemetry-tracing/)

### Amazon S3 Tables のレプリカを書き込み可能テーブルに昇格

**要約**: 読み取り専用レプリカを書き込み可能なテーブルに昇格できるようになった。namespace とテーブル名は変わらず、リージョン障害時に書き込み先を切り替えられる。

**影響**: S3 Tables を使ったデータ基盤の DR 設計に選択肢が増える。

**リンク**: [[アップデート] Amazon S3 Tables のレプリカを書き込み可能なテーブルに昇格できるようになったので試してみた](https://dev.classmethod.jp/articles/20261120-amazon-s3-tables-replication-writable-tables/)

### Amazon EMR Serverless の Flex execution

**要約**: 余剰のコンピューティング容量を活用し、コストを最大60%削減できるとされる実行オプション。ジョブ投入時のオプション1つで有効にできる。

**影響**: 時間に余裕のあるバッチ処理ではコスト削減の手段になる。実効性は自分のジョブで検証したい。

**リンク**: [Amazon EMR Serverless の新機能「Flex execution」を試してみた](https://dev.classmethod.jp/articles/amazon-emr-serverless-flex-execution/)

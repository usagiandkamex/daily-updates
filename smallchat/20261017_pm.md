## 1. Microsoft

### Windows 11 のアプリ起動を遅くする余分なプロセスを廃止へ

**要約**: Windows Latest によると、Microsoft は Windows 11 のアプリ起動を遅くしていた不要な追加プロセスを取り除く対応を進めている。ただし現時点では手動で強制的に有効化することはできない。

**影響**: 起動時間に敏感なデスクトップアプリや社内ツールの体感速度改善が期待できる。今後の配信を待ち、自作アプリの起動計測を取り直すと効果を確認できる。

**リンク**: [Microsoft is killing a pointless extra process that slows Windows 11 app launches, but you can't force enable it yet](https://www.windowslatest.com/2026/10/17/microsoft-is-killing-a-pointless-extra-process-that-slows-windows-11-app-launches-but-you-cant-force-enable-it-yet/)

### KB5127648 で Smart App Control が有効化できない場合がある

**要約**: gHacks の報道によると、Microsoft は Windows 11 の更新プログラム KB5127648 により、ユーザーが Smart App Control を有効にできなくなる場合があることを認めた。

**影響**: 検証端末や配布済み PC でセキュリティ機能の状態を確認したい管理者・開発者は、更新適用後に設定可否をチェックしておくとよい。

**リンク**: [Microsoft Confirms Windows 11 KB5127648 Update Can Block Users From Turning On Smart App Control](https://www.ghacks.net/2026/10/17/microsoft-confirms-windows-11-kb5127648-update-can-block-users-from-turning-on-smart-app-control/)

### KB5127648 の ISO が公式ツールで USB インストール可能に

**要約**: Neowin によると、Windows 11 KB5127648 の ISO が公式ツール経由で USB からのインストールに使えるようになった。

**影響**: クリーンインストールやキッティング用の最新メディアを用意しやすくなる。上記の Smart App Control の既知事象も踏まえて検証したい。

**リンク**: [Windows 11 KB5127648 ISO now available for USB install via official Microsoft tool](https://www.neowin.net/news/windows-11-kb5127648-iso-now-available-for-usb-install-via-official-microsoft-tool/)

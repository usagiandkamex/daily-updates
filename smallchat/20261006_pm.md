**要約**: Phoronix によると、WSL 3.0.2 で非常に大きなサーバー上でも WSL を実行できるようになり、実験的な Sparse VHD も導入されました。

**影響**: Windows Server 上で WSL を使う開発・検証環境の選択肢が広がります。Sparse VHD は実験的機能なので、本番利用の前に検証が必要です。

**リンク**: [Windows Subsystem For Linux Can Now Run On Very Large Servers, Experimental Sparse VHD - Phoronix](https://www.phoronix.com/news/Microsoft-WSL-3.0.2)

# 2026/09/01 テクニカル雑談（午前）

## 1. Microsoft

### Outlookで数時間規模の大規模障害が発生

**要約**: Microsoft Outlookで数時間続く大規模障害が発生し、多数のユーザーから報告が相次いだ。Microsoftは修正のテストを進めている段階。

**影響**: 業務のコアであるメール基盤が数時間止まると企業活動への打撃は大きく、可用性を前提にした運用設計の見直しやフォールバック手段の準備が改めて重要になる。

**リンク**: [Microsoft tests fix for latest hours-long Outlook outage - TechCrunch](https://techcrunch.com/2026/08/31/microsoft-tests-fix-for-latest-hours-long-outlook-outage/)

### Exchange Onlineでも新たな障害を調査中

**要約**: Microsoftは「EX1464935」として追跡されるExchange Onlineの新たな障害を調査していると発表した。

**影響**: Outlook障害と合わせてメッセージング基盤の不安定さが続いており、監視体制の強化やインシデント対応フローの再確認が求められる。

**リンク**: [Microsoft Investigating New Exchange Online Outage Tracked as EX1464935 [Updated] - CyberSecurityNews](https://cybersecuritynews.com/microsof-new-exchange-online/)

### Microsoft 365 CopilotのWord/Excel/PowerPointエージェントが有償版限定に

**要約**: Microsoft 365無償版のCopilot Chatから、これまで利用できていたWord/Excel/PowerPointエージェントが選択できなくなり、有償版限定機能となったことがユーザー検証で確認された。

**影響**: 無償プランでCopilotの生産性向上機能を試していたユーザーは有償プランへの移行検討が必要になり、社内でのCopilot導入計画の見直しが必要になる場合がある。

**リンク**: [Microsoft 365無償版のCopilot Chatガイド(67)エージェント編 - Qiita](https://qiita.com/Shinyas77/items/bf1bb019bfaabeec0302)

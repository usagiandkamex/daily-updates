## 3. Azure

### Azure の複数サービスでリタイア告知

**要約**: Azure App Service on Azure Stack Hub は2029年9月30日に廃止され、2026年9月30日以降は新規インストールが非対応になります。また App Service の Java 8/11/17 のサポートは2027年9月1日に終了し、アプリは動き続けるもののセキュリティ更新は提供されなくなります。

**影響**: 該当ランタイムを使うアプリは、期限までに新しい Java バージョンへの移行計画が必要です。

**リンク**: [Retirement: Support for Java 8, 11 and 17 will end on September 1, 2027](https://azure.microsoft.com/updates?id=568585)

### Azure SQL Database の Always Encrypted with SGX Enclaves が廃止予定

**要約**: Azure SQL Database の Always Encrypted with Intel SGX enclaves は、SGX 対応 DC シリーズハードウェアのサポート段階的終了に伴い、2027年10月31日に廃止されます。

**影響**: Enclave 機能を使っている場合は、代替の暗号化方式への移行を検討する必要があります。

**リンク**: [Retirement: Always Encrypted with Intel SGX Enclaves](https://azure.microsoft.com/updates?id=569236)

### AKS on bare metal が Ubuntu でパブリックプレビュー

**要約**: オンプレミスの Kubernetes で仮想化レイヤーを挟まず、ベアメタル上で AKS を Ubuntu で動かす構成がパブリックプレビューになりました。

**影響**: 仮想化のオーバーヘッドや運用の複雑さを避けたいオンプレミス環境で、選択肢が増えます。

**リンク**: [Public Preview: AKS on bare metal now on Ubuntu](https://azure.microsoft.com/updates?id=573782)

# 2026/08/22 テクニカル雑談（午前）

## 1. Microsoft

### New OutlookにClassic Outlookテーマが登場

**要約**: MicrosoftはNew Outlookに、旧Outlookの見た目を再現する「Classic」テーマを追加した。New Outlookの新機能はそのままに、UIだけ従来の見慣れた外観に切り替えられる。

**影響**: 移行に抵抗があったユーザー・IT管理者にとって、New Outlookへの移行障壁が下がる。社内展開を検討している運用担当者は評価候補に入れる価値がある。

**リンク**: [Microsoft rolls out Classic Outlook theme for New Outlook users](https://www.bleepingcomputer.com/news/microsoft/microsoft-rolls-out-classic-outlook-theme-for-new-outlook-users/)

### RDCMan v3.20がDev Boxに対応

**要約**: Microsoftのリモートデスクトップ管理ツール「RDCMan」がv3.20にアップデートされ、Microsoft Dev Boxへの接続に対応した。大量端末をリモート管理するエンジニアに長年愛用されているSysinternals系ツール。

**影響**: Dev Boxを使ったクラウド開発環境の管理が、既存の使い慣れたツールで完結できるようになる。複数のDev Boxインスタンスを扱うチームの運用効率化につながる。

**リンク**: [Microsoftのリモートデスクトップ管理ツール「RDCMan」がv3.20に、「Dev Box」に対応](https://forest.watch.impress.co.jp/docs/news/2134394.html)

### Windows 11の8月更新でゲームがクラッシュするバグ

**要約**: Windows 11の8月アップデート適用後、Arc Raidersを含む一部ゲームがクラッシュする不具合が報告されている。Microsoftは原因調査中で、暫定的な回避策も案内されている。

**影響**: 月例更新のたびに何らかの不具合が発生する傾向が続いており、検証環境での事前確認や適用タイミングの見極めが運用担当者にとって重要になる。

**リンク**: ['Every single month the update breaks something': Windows 11 users are getting sick of bugs as August patch crashes some games, including Arc Raiders](https://www.techradar.com/computing/windows/are-your-pc-games-crashing-after-the-latest-windows-11-update-microsoft-is-investigating-whether-a-nasty-new-bug-is-the-cause-but-there-are-workarounds)

## 2. AI

### VS Code 1.134でAgent Hostが登場

**要約**: VS Code 1.134では、AIエージェントが専用プロセス上で動作する「Agent Host」が導入された。エージェントの実行がエディタ本体プロセスと分離される設計になっている。

**影響**: エージェントの安定性・セキュリティ分離が向上し、重い処理やクラッシュがエディタ本体に波及しにくくなる。AI駆動開発を日常的に使う開発者は挙動の変化を把握しておきたい。

**リンク**: [VS Code 1.134のAgent Host — 専用プロセスで動くエージェント](https://zenn.dev/chimao222/articles/ai-dev-vscode-agent-host-20260821)

### Qwen+Gemmaを再学習した「Ornith-1.5」がOpus 4.8に並ぶ性能

**要約**: Qwen系とGemma系モデルを組み合わせて再学習したAIモデル「Ornith-1.5」が、Anthropicの上位モデルOpus 4.8に匹敵する性能を示したと報告されている。

**影響**: オープンウェイト系モデルの改良でトップクラス商用モデルに近づく事例が増えており、コスト重視のプロダクトでモデル選定の選択肢が広がる可能性がある。

**リンク**: [Qwen+Gemmaを鍛え直したらOpus 4.8に並んだAIモデル「Ornith-1.5」](https://pc.watch.impress.co.jp/docs/news/2134570.html)

### AI時代のエンジニア組織、採用基準の変化

**要約**: AI時代のCTOお悩み相談室企画で、「一緒にいて楽しい人を採用するようになった」という声が紹介されている。AIによるコーディング支援が進む中、技術力以外の要素を重視する採用トレンドが語られている。

**影響**: AIがコード生成の多くを担うようになるにつれ、チームのコミュニケーション力や協働姿勢が評価軸として相対的に重要度を増しており、採用・評価制度を見直す材料になる。

**リンク**: [「一緒にいて楽しい人を採用するようになった」── AI時代のCTOお悩み相談室で聞いた、エンジニア組織のこれから](https://qiita.com/inoyu-qiita/items/5a9ea7aa6e5c2ac80023)

## 3. Azure

### Entra IDの最大深刻度の脆弱性が悪用される

**要約**: MicrosoftはEntra IDに存在する「Perfect 10」評価（CVSS満点相当）の脆弱性が実際に攻撃で悪用されていると警告した。リモートコード実行に至る恐れがある深刻な問題とされる。

**影響**: Entra IDを利用する組織は、パッチ適用状況の確認と侵害兆候の調査を最優先で行う必要がある。IDプロバイダーの脆弱性は影響範囲が広いため迅速な対応が求められる。

**リンク**: [Microsoft sounds alarm as perfect-10 Entra ID flaw comes under attack](https://www.theregister.com/cyber-crime/2026/08/21/microsoft-sounds-alarm-as-perfect-10-entra-id-flaw-comes-under-attack/5290925)

### Azure DevOps Remote MCP ServerがGAに

**要約**: Azure DevOpsのリモートMCPサーバーが正式リリース（GA）となった。ただし現時点ではClaude・ChatGPT・Cursorといった主要AIツールからの利用はサポート対象外となっている。

**影響**: MCP経由でAzure DevOpsと連携するAIエージェント開発が本格化する一方、対応クライアントが限定的なため、既存ツールとの統合を検討するチームは対応状況を確認してから採用判断する必要がある。

**リンク**: [Azure DevOps Remote MCP Server Reaches GA, Without Support for Claude, ChatGPT, or Cursor](https://www.infoq.com/news/2026/08/azure-devops-remote-mcp-ga/)

### GitHub ActionsからAzureへOIDCで安全に接続する方法

**要約**: GitHub ActionsからAzureへ接続する際に、シークレットを使わずEntra ID・OIDC・フェデレーション資格情報を用いる方法を解説する記事が公開された。

**影響**: 長期シークレットの管理をなくせるため、CI/CDパイプラインのセキュリティ強化に直結する。Azureと連携するワークフローを持つチームは移行を検討する価値がある。

**リンク**: [GitHub ActionsからAzureへ安全に接続する 〜Entra ID・OIDC・フェデレーション資格情報を理解する〜](https://qiita.com/dev_mtech/items/aebc5be97d0151121a7d)

## 4. クラウド

### Google Cloudが前四半期82%成長、Azure43%・AWS37%を上回る

**要約**: 直近四半期の成長率で、Google Cloudが82%成長と大手3社の中で最も高い伸びを示した。Azureは43%、AWSは37%の成長にとどまったと報じられている。

**影響**: クラウド市場の勢力図が変化しつつある兆候であり、マルチクラウド戦略やベンダー選定を検討する際の参考材料になる。

**リンク**: [Google Cloud Grew 82% Last Quarter. Azure Grew 43% and AWS Grew 37%.](https://www.aol.com/articles/google-cloud-grew-82-last-014601000.html)

### AWSが英国リージョンに新アベイラビリティゾーンを追加

**要約**: AWSは英国クラウドリージョンに新しいアベイラビリティゾーン(AZ)を開設した。既存リージョンの冗長性・可用性がさらに強化される。

**影響**: 英国内でのマルチAZ構成による耐障害性向上や、データレジデンシー要件を満たしたシステム設計の選択肢が広がる。

**リンク**: [AWS launches new availability zone for UK cloud region](https://www.datacenterdynamics.com/en/news/aws-launches-new-availability-zone-for-uk-cloud-region/)

### IAM Identity Centerの組織インスタンスがワンクリックでマルチリージョン化

**要約**: AWS IAM Identity Centerの組織インスタンスが、ワンクリックで複数リージョンに対応できるようになった。従来は構成が煩雑だったマルチリージョン運用が簡略化される。

**影響**: マルチリージョンでシステムを展開する組織にとって、ID管理の一元化・災害対策構成の構築が容易になり、運用負荷の軽減につながる。

**リンク**: [IAM Identity Center の組織インスタンスがワンクリックでマルチリージョン化できるようになりました](https://qiita.com/leomarokun/items/29a2aca398d35a1aae1c)

## 5. セキュリティ

### Entra IDのRCE脆弱性が実際に悪用される

**要約**: Microsoft Entra IDに存在するリモートコード実行(RCE)の脆弱性が、実際の攻撃で悪用されていることが確認された。Microsoftは最大深刻度の脆弱性として警告を出している。

**影響**: Entra IDを使う組織は緊急のパッチ適用と、侵害の痕跡がないかの調査を行う必要がある。IDプラットフォームの侵害は二次被害が広範囲に及ぶリスクが高い。

**リンク**: [Microsoft Entra ID Remote Code Execution Vulnerability Exploited in the Wild](https://cybersecuritynews.com/entra-id-rce-vulnerability-exploited/)

### 楽天ブックス関係会社に不正アクセス、3万3333人分の情報漏えいの可能性

**要約**: 楽天ブックスの関係会社のPCが不正アクセスを受け、ユーザー約3万3333人分の個人情報が漏えいした可能性があると発表された。

**影響**: サプライチェーンや関連会社経由での侵害リスクが改めて浮き彫りになった。委託先・関連会社を含めたセキュリティ管理体制の見直しが求められる。

**リンク**: [楽天ブックス関係会社のPCに不正アクセス、ユーザー3万3333人分の個人情報などが漏えいの可能性](https://internet.watch.impress.co.jp/docs/news/2134682.html)

### CISAがMLflow・Siemens PLCに関する警告を発表

**要約**: CISAがMLflowおよびSiemens製PLC(産業用制御機器)に関するセキュリティ警告を発表した。あわせてCareCloudの情報漏えいも確認されている。

**影響**: MLOps基盤や産業制御システムを運用する組織は、対象製品のパッチ適用状況や設定を早急に確認する必要がある。AI/MLパイプラインを含むインフラのセキュリティ管理が一層重要になっている。

**リンク**: [Cybersecurity News: CISA MLFlow warning, Siemens PLCs warning, CareCloud confirms breach](https://cisoseries.com/cybersecurity-news-cisa-mlflow-warning-siemens-plcs-warning-carecloud-confirms-breach/)

### GitHub outage disrupts developers worldwide

**要約**: GitHubで大規模な障害が発生し、世界中の開発者の作業に支障が出ていると報じられています。Microsoft傘下のコーディングプラットフォームとしては近年たびたび発生している問題の一つです。

**リンク**: [GitHub outage disrupts developers worldwide in latest setback for Microsoft coding platform](https://www.geekwire.com/2026/github-outage-disrupts-developers-worldwide-in-latest-setback-for-microsoft-coding-platform/)

**リンク**: [Visual Studio Code 1.133正式リリース。プロンプトを見失わない固定スクロール、ローカルHTMLファイルの自動リロード、ClaudeとCopilotの混在可能など新機能](https://www.publickey1.jp/blog/26/visual_studio_code_1133htmlclaudecopilot.html)

## 3. Azure

### Azure Linux on WSL がパブリックプレビューに

**要約**: Azure Linuxが「Azure Linux on WSL」としてパブリックプレビュー（ベータ）で利用可能になりました。開発者のワークステーション上でAzure Linux環境を検証できるようになります。

**影響**: 本番環境と同じディストリビューションをローカルのWSL上で事前検証できるため、環境差異に起因する不具合を開発段階で早期に発見しやすくなります。

**リンク**: [[In preview] Public Preview: Azure Linux on WSL](https://azure.microsoft.com/updates?id=569376)

### Azureのクラウド認証情報窃取でMcDonald'sとVodafoneが被害

**要約**: Azureのクラウド認証情報が窃取され、McDonald'sとVodafoneでデータ侵害が発生したと報じられています。

**影響**: マネージドIDやシークレットのローテーション、条件付きアクセスなどAzure環境における認証情報管理の徹底が、企業規模を問わず急務であることを示しています。

**リンク**: [Azure Cloud Credential Theft leads to Data Breach of McDonald's and Vodafone](https://www.cybersecurity-insiders.com/azure-cloud-credential-theft-leads-to-data-breach-of-mcdonalds-and-vodafone/)

### Azure OpenAI Responses APIの会話状態設計

**要約**: Azure OpenAIのResponses APIにおける`previous_response_id`を用いた会話状態管理について、サーバー側に預ける情報と手元に残す情報の設計を解説する連載記事の第1回です。

**影響**: AIエージェントAPIを本番導入する際の会話状態設計のベストプラクティスとして、コスト・レイテンシ・プライバシーのトレードオフを検討する上で参考になります。

**リンク**: [Azure OpenAI Responses API の会話状態設計 — サーバに預けられるもの、手元に残るもの](https://qiita.com/archiningen/items/9734649cc7f48be78ff7)

**要約**: SAP Commerce Cloudに存在する重大な脆弱性について、攻撃者による初期的な悪用の試みが確認されたと報じられています。

### Macの画面共有機能に攻撃者がフルコントロールを奪える脆弱性

**要約**: Macの「画面共有」機能に脆弱性が見つかり、攻撃者がコンピューターを完全に制御できる可能性があると報じられています。ユーザーには早急なアップデートが呼びかけられています。

**影響**: リモートアクセス機能を有効にしている開発環境やチーム利用のMacは、直ちにOSアップデートを適用し、不要な画面共有設定を無効化することが推奨されます。

**リンク**: [Update your Mac: Screen Share vulnerability gives attackers full control of your computer](https://mashable.com/tech/apple-mac-macbook-screen-share-vulnerability)

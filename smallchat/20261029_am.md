## 3. Azure

### Azure Container Apps のログ送信先 Log Analytics がレガシーに

**要約**: Azure Container Apps で、ログの送信先としての Log Analytics がレガシーオプションになり、Azure Monitor への移行が案内されています。

**影響**: 既存環境の設定を確認し、Azure Monitor への移行計画を立てておくと安心です。

**リンク**: [Announcing: Migrate Azure Container Apps logging destination from Log Analytics to Azure Monitor](https://azure.microsoft.com/updates?id=577689)

### Azure Backup のクロステナント復元（パブリックプレビュー）

**要約**: Cross-Tenant Restore により、Azure VM のバックアップを別テナントへ復元する、独立した復旧経路を確立できるようになります。

**影響**: テナント侵害や障害に備えた DR 設計の選択肢が増えます。プレビュー段階なので本番導入は慎重に検証しましょう。

**リンク**: [Public Preview: Cross Tenant Restore with Azure Backup](https://azure.microsoft.com/updates?id=577117)

### Marketplace プライベートオファーの強化が GA

**要約**: Microsoft Marketplace のプライベートオファーの機能強化が一般提供になりました。価格や条件を自社に合わせて調整できます。

**影響**: Marketplace 経由の購入で Azure の支出コミットを活用している組織にとって、調達の柔軟性が高まります。

**リンク**: [Generally Available: Marketplace private offer enhancements](https://azure.microsoft.com/updates?id=576547)

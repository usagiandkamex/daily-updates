### Windows 11 が USB ドライブ上の ReFS をブロックへ

**要約**: Windows Latest によると、Windows 11 は USB ドライブ上の ReFS をブロックする方針とのことです。一方で Microsoft は、NTFS の後継候補である ReFS に大きく賭け続けていると報じられています。

**影響**: ReFS でフォーマットした外付けドライブをデータ持ち運びやバックアップに使っている人は、今後マウントできなくなる可能性があります。可搬メディアは NTFS や exFAT に寄せておくのが無難です。

**リンク**: [Windows 11 will block ReFS on USB drives, even as Microsoft bets big on its NTFS alternative - Windows Latest](https://www.windowslatest.com/2026/10/18/windows-11-will-block-refs-on-usb-drives-even-as-microsoft-bets-big-on-its-ntfs-alternative/)

### オントロジーと LLM の精度

**要約**: オントロジーの意味や、ナレッジグラフとの違い、LLM での効果を解説した記事です。最新世代のモデルでも意味の層を通したほうが精度は高く、文脈付きメタデータを与えると、スキーマのみのプロンプトに比べて SQL 生成精度が 3 倍になったと紹介されています。別の 522 問規模のベンチマークでも 38% の相対改善が報告されているそうです。

**影響**: 「モデルが賢くなれば意味の層は不要」とは限りません。社内データを LLM に扱わせるなら、スキーマだけでなくメタデータや用語定義の整備が効きそうです。

**リンク**: [オントロジーとは？意味・ナレッジグラフとの違い・LLMでの効果](https://fd-x.co.jp/insights/41-what-is-ontology)

### APK から API キーが読めてしまう問題と Lambda の限界

**要約**: Android アプリに埋め込んだ API キーは、APK を逆コンパイルすれば読めてしまいます。キーを Lambda の環境変数に移し、アプリが Lambda 経由で API を呼ぶ構成にしても、それだけでは安全にならないという検証記事です。

**影響**: 「バックエンドを挟めば安全」とは限りません。エンドポイント側での認証や利用制限まで設計する必要があります。

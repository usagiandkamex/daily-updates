**要約**: Microsoft 365 の障害をきっかけに、Exchange への依存関係に改めて注目が集まっているという報道です。

**リンク**: [Microsoft Outage Puts Exchange Dependencies Under the Spotlight - UC Today](https://uctoday.com/microsoft-365-outage-puts-exchange-dependencies-under-the-spotlight)

**要約**: Computerworld は、Microsoft が PC のアップグレードに Cloud PC を活用する、古くて新しいアイデアを打ち出していると伝えています。

**影響**: 端末の更新コストやハードウェア要件に悩む組織にとって、仮想デスクトップ移行は選択肢になります。開発環境や社内ツールがクラウド上で快適に動くか、検証しておくとよいでしょう。

**リンク**: [Microsoft has an old, but new, idea for PC upgrades: Cloud PCs - Computerworld](https://www.computerworld.com/article/4252292/microsoft-has-an-old-but-new-idea-for-pc-upgrades-cloud-pcs.html)

### Windows の新しいセキュリティチェックでアプリがアクセスを制限可能に

**要約**: Malwarebytes は、新しい Windows のセキュリティチェックにより、アプリ側が特定の状況でアクセスをブロックできるようになる可能性を報じています。

**影響**: アプリ開発者は端末の状態に応じた制御を取り入れやすくなる一方、環境によっては利用者が想定外に使えなくなる場合があります。自社アプリの動作確認が必要です。

**リンク**: [New Windows security check could let apps block access - Malwarebytes](https://www.malwarebytes.com/blog/news/2026/11/new-windows-security-check-could-let-apps-block-access)

### Azure API Management の欠陥が悪用されシークレット窃取の標的に

**要約**: Microsoft は Azure API Management Classic の欠陥を修正しました。報道によると、攻撃者がこの欠陥を悪用して顧客のシークレットを狙っていたとのことです。

**影響**: API Management を利用している場合は、Microsoft の案内を確認し、保管しているシークレットやキーのローテーション、アクセスログの確認を検討してください。

**リンク**: [Microsoft Fixes Azure API Management Classic Flaw as Actor Targets Customer Secrets - The Hacker News](https://thehackernews.com/2026/11/microsoft-fixes-azure-api-management.html)

### Azure API Management の欠陥悪用に関する Microsoft の警告

**影響**: 設定にシークレットを直接置いていないか、Key Vault 等への移行や権限の最小化を見直す契機になります。

**リンク**: [Attackers exploited an Azure API Management flaw to steal secrets, Microsoft warns - CSO Online](https://www.csoonline.com/article/4252513/attackers-exploited-an-azure-api-management-flaw-to-steal-secrets-microsoft-warns.html)

# 2026/11/03 テクニカル雑談（午前）

## 1. Microsoft

### GitHub Copilot Fusion が正式リリース

**要約**: GitHub Universe 2026（10月28日・29日、サンフランシスコ）で、新機能「GitHub Copilot Fusion」の正式リリースが発表されました。タスクに応じて最適な AI モデルを選択することで、高性能かつ低コストを両立するという位置づけです。

**影響**: 開発者がモデルを手動で選び分ける手間が減り、コストと品質のバランスを仕組み側に任せられる可能性があります。チームで Copilot を使っている場合は、利用コストの変化も併せて確認しておきたいところです。

**リンク**: [GitHub、「Copilot Fusion」正式リリース。タスクに応じて最適なAIモデル選択で高性能かつ低コストに。GitHub Universe 2026](https://www.publickey1.jp/blog/26/githubcopilot_fusionaigithub_universe_2026.html)

### Windows 11 の新しい速度テストは AI の支援で作られた

**要約**: Microsoft は Windows 11 の新しい速度テスト機能の開発に AI を活用したと報じられています。記事のタイトルでは「vibe coded ではないが AI で作られた」という点が強調されています。

**影響**: OS 標準機能の開発にも AI 支援が入り始めていることを示す事例です。AI を使いつつ品質を担保する開発プロセスの参考になります。

**リンク**: [Microsoft used AI to help build Windows 11's new speed test - Windows Central](https://www.windowscentral.com/microsoft/windows-11/windows-11s-new-speed-test-feature-wasnt-vibe-coded-but-it-was-made-with-ai)

### 新しい Outlook にテンプレートベースの自動返信

**要約**: Microsoft は新しい Outlook に、テンプレートベースの自動返信機能を導入する予定と報じられています。

**影響**: 不在時対応や定型返信の運用が楽になる一方、組織の Exchange / Outlook 運用ポリシーへの影響を確認しておくと安心です。

**リンク**: [Microsoft to Bring Template-Based Automatic Replies to New Outlook - Petri IT Knowledgebase](https://petri.com/microsoft-new-outlook-template-based-automatic-replies/)

## 3. Azure

### Azure Migrate が NAS 共有の検出・評価に対応（パブリックプレビュー）

**要約**: Azure Migrate で、ネットワーク接続ストレージ（NAS）の検出と評価がパブリックプレビューとして利用可能になりました。顧客やパートナーが NAS の移行計画を立てられるようになります。

**影響**: オンプレミスのファイルサーバー移行の事前調査を Azure Migrate で進めやすくなります。プレビュー段階のため、本番計画では制約を確認してください。

**リンク**: [[In preview] Public Preview: On-prem NAS share discovery and assessment are now available using Azure Migrate](https://azure.microsoft.com/updates?id=577975)

### Azure Database for PostgreSQL の VNet 統合からプライベートエンドポイントへの変更が GA

**要約**: Azure Database for PostgreSQL Flexible Server で、既存の VNet 統合構成からプライベートエンドポイント対応のネットワーク構成へ変更できるようになりました（GA）。

**影響**: ネットワーク設計の自由度が上がり、既存サーバーを作り直さずに構成を見直せる場合があります。

**リンク**: [[Launched] Generally Available: Change from virtual network integration to a private endpoint capable network configuration in Azure Database for PostgreSQL flexible server](https://azure.microsoft.com/updates?id=574541)

### Azure Fluid Relay の提供終了予告

**要約**: 2027 年 2 月 2 日をもって Azure Fluid Relay が提供終了となる旨が告知されています。

**影響**: 利用中のワークロードは期日までに移行先の検討が必要です。棚卸しを早めに進めましょう。

**リンク**: [Retirement: Azure Fluid Relay](https://azure.microsoft.com/updates?id=570498)

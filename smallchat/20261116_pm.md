# 2026/11/16 テクニカル雑談（午後）

## 1. Microsoft

### Microsoft 365 / Outlook 障害、7月から潜んでいた不具合が原因に

**要約**: ほぼ丸1日続いた Microsoft 365 と Outlook の障害について、Microsoft が暫定報告を公表した。7月から潜んでいた不具合に、当日の状況が絡み合って連鎖的なダウンにつながったという。ITmedia の記事では、メール到着遅延などの細かい事象は丸1日以上続き、大枠のダウンタイムは平均で半日程度とみられると整理されている。

**影響**: 長期間潜在していた不具合が特定条件で顕在化する典型例といえる。SaaS への依存度が高い組織は、代替連絡手段の確保や SLA クレジットの請求手順の確認を進めておきたい。

**リンク**: [ほぼ丸1日続いた「Microsoft 365」「Outlook」障害の原因は？](https://forest.watch.impress.co.jp/docs/news/2156753.html)

### 障害はサイバー攻撃ではない、ただしフィッシングに注意

**要約**: SecurityWeek によると、Microsoft は今回の障害にサイバー攻撃は関与していないとした。一方で、障害に便乗したフィッシングキャンペーンへの警告も出している。

**影響**: 障害時は「復旧のため」「補償のため」を装った偽メールが増えやすい。社内への注意喚起と、公式のサービス正常性ページ経由での情報確認を徹底したい。

**リンク**: [Microsoft Rules Out Cyberattack in Outage, Warns of Phishing Campaign - SecurityWeek](https://www.securityweek.com/microsoft-rules-out-cyberattack-in-outage-warns-of-phishing-campaign/)

### Windows のライセンス認証失敗に緊急更新

**要約**: BleepingComputer は、Microsoft がアクティベーション（ライセンス認証）の失敗を修正する Windows の緊急更新を配信したと報じている。

**影響**: 認証エラーが出ている端末や VDI 環境を管理している場合は、更新の適用状況を確認しておきたい。

**リンク**: [Microsoft pushes Windows emergency updates to fix activation failures - BleepingComputer](https://www.bleepingcomputer.com/news/microsoft/microsoft-new-windows-emergency-updates-fix-activation-licensing-failures/)

## 2. AI

### レビューは AI が書いて、人が選ぶ

**要約**: Recruit のブログが、AI にレビューコメント案を番号付きで出させ、人間が取捨選択して投稿するワークフローを紹介している。「2番は外して」「3番は nits に下げて」のように短く指示でき、投稿される本文をそのまま見せるため、レビュワーは投稿後の見た目を確認してから選べる。

**影響**: AI にレビューを丸投げせず、人が最終判断を持つ設計は現実的な落としどころ。コメントの粒度や重要度の運用ルールを決めておくと再現しやすい。

**リンク**: [レビューは AI が書いて、人が選ぶ](https://blog.recruit.co.jp/data/articles/ai-review-skills/)

**リンク**: [ZedのコントリビューションポリシーがAI激おこな件](https://scrapbox.io/keroxp/Zed%E3%81%AE%E3%82%B3%E3%83%B3%E3%83%88%E3%83%AA%E3%83%93%E3%83%A5%E3%83%BC%E3%82%B7%E3%83%A7%E3%83%B3%E3%83%9D%E3%83%AA%E3%82%B7%E3%83%BC%E3%81%8CAI%E6%BF%80%E3%81%8A%E3%81%93%E3%81%AA%E4%BB%B6)

## 3. Azure

### Microsoft クラウドの価格改定（2027年）

**要約**: Microsoft がクラウド価格を複数通貨で見直し、国によっては最大20%上がると Computerworld が報じている。The Register はインドで約15%の値上げ、中国では引き下げと伝えており、Techloy はインドでは2027年1月から15.7%としている。

**影響**: 円建てなどで契約している場合も、為替・地域別価格の改定が予算に響く可能性がある。更新時期とコスト試算を早めに見直したい。

**リンク**: [Enterprises to pay up to 20% more for Microsoft cloud services in some countries](https://www.computerworld.com/article/4248407/enterprises-to-pay-up-to-20-more-for-microsoft-cloud-services-in-some-countries.html)

### Azure Linux が Fedora ベースで主流ワークロードへ

**要約**: The Register は、Azure Linux が Fedora を取り入れ、より一般的なワークロード向けに装いを新たにすると報じている。

**影響**: コンテナホストや AKS ノードで Azure Linux を使っている場合、今後のベース OS やパッケージ構成の変化を注視したい。

**リンク**: [Microsoft's Azure Linux dons Fedora to dress itself up for mainstream workloads](https://www.theregister.com/os-platforms/2026/11/16/microsofts-azure-linux-dons-fedora-to-dress-itself-up-for-mainstream-workloads/5310016)

### AWS・Azure・Google Cloud のデータ転送料金比較

**要約**: JournalArta が、3大クラウドのデータ egress（外向き転送）料金を2026年時点で比較した記事を公開している。

**影響**: egress 料金はマルチクラウド構成や移行時の隠れコストになりやすい。アーキテクチャ検討時にデータの流れを見積もっておきたい。

**リンク**: [AWS, Azure and Google Cloud Data Egress Fees Compared](https://journalarta.com/en/2026/11/16/aws-azure-google-cloud-egress-fees-2026/)

## 4. クラウド

### API Gateway 構成のセキュリティ見直し（BOLA 編）

**要約**: 今年は API が悪用された大規模な情報漏洩が相次いだことを受け、API Gateway で構成されるアーキテクチャを BOLA（オブジェクトレベル認可の不備）の観点で見直した Qiita 記事。JPCERT/CC の注意喚起にも触れている。

**影響**: ゲートウェイでの認証だけでは認可不備は防げない。バックエンド側でオブジェクト単位の所有者チェックがあるか点検するきっかけになる。

**リンク**: [API Gatewayで構成されるアーキテクチャのセキュリティを見直してみた（BOLA編）](https://qiita.com/mtmt_factory/items/ad843efb84b03f9c3654)

### Terraform の default_tags で AWS コストを環境別に可視化

**要約**: Terraform の AWS プロバイダーで default_tags を使ってタグを統一し、Cost Explorer で環境別・システム別にコストを見られるようにする方法の解説。

**影響**: タグ付けを IaC で一元化すれば付け忘れを防げる。コスト配分の透明化に直結する地味に効く施策。

**リンク**: [【Terraform×AWS】default_tagsでタグを統一し、コストを環境別に見える化する](https://qiita.com/ham-nao/items/c5dfdc5805e370ec38ce)

### SQS と Lambda の非同期処理：DLQ と再試行

**要約**: メール送信や画像変換など時間のかかる処理を SQS に入れ、Lambda で後から処理する構成を Terraform で作る解説。DLQ と再試行の設定も扱う。

**影響**: Web 側の応答を速く保てる定番パターン。再試行と DLQ の設計が運用品質を左右する。

**リンク**: [【Terraform×AWS】SQSとLambdaで非同期処理を作る：DLQと再試行の設定](https://qiita.com/ham-nao/items/36dcc424519d67e9b9d0)

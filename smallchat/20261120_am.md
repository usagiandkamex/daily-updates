# 2026/11/20 テクニカル雑談（午前）

## 1. Microsoft

### Edge に GPU API を無効化する Lockdown Mode をテスト中

**要約**: Microsoft が Edge の新機能「Lockdown Mode」をテストしている。有効にすると GPU 関連の API が無効化され、攻撃面を減らす狙いがある。

**影響**: WebGL / WebGPU に依存する Web アプリは動作や描画に影響が出る可能性がある。高リスクな環境向けの機能として、検証時の挙動確認が必要になりそうだ。

**リンク**: [Microsoft tests new Edge Lockdown Mode that disables GPU APIs](https://www.bleepingcomputer.com/news/microsoft/microsoft-tests-new-edge-lockdown-mode-that-disables-gpu-apis/)

### Microsoft が Azure 向けの新たな AI チップ供給契約を確保

**要約**: Microsoft が Azure の成長に向けた新しい AI チップの供給契約を確保したと報じられている。

**影響**: AI ワークロード向けの計算リソース拡充につながる可能性があり、GPU 枯渇やクォータ制約の緩和が期待される。

**リンク**: [Microsoft (MSFT) Secures New AI Chip Supply Deal For Azure Growth](https://finance.yahoo.com/technology/ai/articles/microsoft-msft-secures-ai-chip-151529450.html)

### Google・Microsoft・OpenAI が相次いで新 AI モデルを発表

**影響**: モデルの選択肢が増える一方、性能・価格・提供形態の比較評価が欠かせない。

**リンク**: [Amid Anthropic's IPO, Google, Microsoft and OpenAI Drop New AI Models](https://www.cnet.com/tech/services-and-software/openai-chatgpt-astra-6-2-microsoft-ignite-news/)

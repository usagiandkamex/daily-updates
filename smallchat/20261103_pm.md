# 2026/11/03 テクニカル雑談（午後）

## 1. Microsoft

### Windows 11 のリデザインが古いデフラグツールにも波及

**要約**: Windows 11 の刷新が、長年手つかずだったデフラグツールにまで及んでいると Windows Latest が報じている。長年の WebView 偏重から、WinUI への再投資に舵を切りつつあるという見立て。

**影響**: Windows ネイティブアプリを作る開発者にとって、WinUI が再び「公式の本命 UI フレームワーク」として扱われる兆しになる。技術選定の際は今後の動向を注視したい。

**リンク**: [Windows 11’s big redesign now covers even its ancient defrag tool, as Microsoft finally bets on WinUI after years of neglect and pushing WebView - Windows Latest](https://www.windowslatest.com/2026/11/03/windows-11s-big-redesign-now-covers-even-its-ancient-defrag-tool-as-microsoft-finally-bets-on-winui-after-years-of-neglect-and-pushing-webview/)

### Microsoft の 250 億ドル借入と大規模な早期退職募集

**要約**: Economic Times が、Microsoft が 60,000 人規模の早期退職（バイアウト）を提示した一方で 250 億ドルの借入を行う理由を取り上げている。

**影響**: 巨額の資金調達と人員の再編が同時に進んでおり、投資の重心が変化していることがうかがえる。Microsoft 製品やロードマップに依存するチームは、組織変化が製品方針に与える影響を意識しておくとよい。

**リンク**: [Why is Microsoft borrowing $25 billion after offering buyouts to 60,000 employees? - The Economic Times](https://m.economictimes.com/news/new-updates/why-is-microsoft-borrowing-25-billion-after-offering-buyouts-to-60000-employees/articleshow/135481921.cms)

### 元 Xbox COO の Helen Chiang 氏が LinkedIn で投稿

**要約**: 解任された元 Xbox COO の Helen Chiang 氏が、LinkedIn の投稿「Clarity is Kindness」で Microsoft のポリシー違反を否定した。Xbox CEO の Asha Sharma 氏への当てつけとも受け取られている。

**影響**: Xbox 組織の体制変更は、ゲーム開発者やプラットフォームパートナーにとって今後の戦略を読む材料になる。

## 2. AI

### Anthropic の売上は前年同期比 13 倍、AI 開発支出は 140 兆円超

**要約**: NHK によると、Anthropic は IPO に向けた書類の改訂版を公表し、1〜9 月の売上が前年同期の 13 倍になったことを明らかにした。一方、AI 開発にかかる支出は 140 兆円余にのぼる。

**影響**: 急成長と巨額の計算資源投資が並走している実態がわかる。AI サービスを使う側としては、価格やモデルの提供方針が今後も動く前提で設計しておくのが安全。

**リンク**: [米アンソロピック 売り上げ13倍もAI開発への支出は140兆円余に | NHKニュース](https://news.web.nhk/newsweb/na/nd-20261103de69869)

### LLM はニューラルネットの重みを読み書きできる？

**要約**: 「Sparks of Weight-Space Programming」と題したブログで、最先端の LLM がニューラルネットワークの重みを驚くほどうまく読み書きできることが報告されている。

**影響**: 重みを直接扱う「重み空間プログラミング」という新しい発想の入口として興味深い。内容は一次報告の段階なので、再現性や適用範囲は自分で確認したい。

**リンク**: [Sparks of Weight-Space Programming: LLMs can natively read & write neural network weights](https://rikiyat.github.io/blog/weight-space-programming/)

## 3. Azure

### Azure Migrate が オンプレ NAS 共有の探索・評価に対応（プレビュー）

**要約**: Azure Migrate で、オンプレミスの NAS 共有の探索と評価がパブリックプレビューとして利用可能になった。Dell PowerScale などの移行計画に使える。

**影響**: ファイルサーバーや NAS のクラウド移行で、事前調査を Azure Migrate に集約しやすくなる。

**リンク**: [[In preview] Public Preview: On-prem NAS share discovery and assessment are now available using Azure Migrate](https://azure.microsoft.com/updates?id=577975)

### Microsoft Defender for IoT の OT セキュリティが廃止予定

**要約**: Microsoft Defender for IoT の運用技術（OT）セキュリティコンポーネントについて、廃止の正式通知が出た。

**影響**: OT 環境で利用しているチームは、代替手段の検討と移行スケジュールの確認が必要になる。

**リンク**: [Retirement: OT security in Microsoft Defender for IoT](https://azure.microsoft.com/updates?id=576255)

### Azure Database for PostgreSQL の VNet 統合からプライベートエンドポイントへの変更が GA

**要約**: Azure Database for PostgreSQL Flexible Server で、既存の VNet 統合構成からプライベートエンドポイント対応の構成へ変更できるようになった（GA）。

**影響**: ネットワーク設計の見直しを、DB の作り直しなしで進められる可能性がある。

**リンク**: [[Launched] Generally Available: Change from virtual network integration to a private endpoint capable network configuration in Azure Database for PostgreSQL flexible server](https://azure.microsoft.com/updates?id=574541)

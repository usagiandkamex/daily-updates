### Copilot Chat、ライセンス未購入ユーザーへの利用制限を開始

**要約**: CRN によると、Microsoft は有料ライセンスを持たないユーザーに対して Copilot Chat の利用に制限をかけ始めた。

**影響**: 組織内で無償の Copilot Chat を前提に業務フローを組んでいる場合、利用上限に当たる可能性がある。情報システム部門は有料ライセンスの配布範囲を見直しておきたい。

**リンク**: [Microsoft Starts Limiting Copilot Chat Usage For Users Without Paid Licenses - CRN](https://www.crn.com/news/ai/2026/microsoft-starts-limiting-copilot-chat-usage-for-users-without-paid-licenses)

### Windows 11 の古いダイアログボックスを刷新へ

**要約**: Windows Latest によると、Microsoft は Windows 11 に残る古い時代のダイアログボックスを置き換える方針で、現時点でも開ける 25 種類が紹介されている。

**影響**: UI の統一は見た目だけでなく、ダークモードや高 DPI への対応、アクセシビリティの改善にもつながる。Windows アプリを作る開発者も、独自のダイアログ実装を見直す機会になりそうだ。

**リンク**: [Microsoft is killing Windows 11's ancient dialog boxes, and here are 25 you can still open today - Windows Latest](https://www.windowslatest.com/2026/11/10/microsoft-finally-wants-to-kill-windows-11s-ancient-dialog-boxes-and-these-are-the-ones-you-still-see-today/)

### Windows ペイントの RCE 脆弱性を修正

**要約**: Dark Reading は、Windows ペイントのリモートコード実行（RCE）の不具合を Microsoft が修正したと報じている。見出しでは、修正までに数週間の混乱があったとされている。

**影響**: 標準アプリであっても RCE の対象になり得る。月例パッチの適用状況を確認し、ファイルを開くだけで影響を受けるケースに備えて、不審なファイルの取り扱いも周知したい。

**リンク**: [Microsoft Fixes RCE Bug in Windows Paint After Weeks of Confusion - Dark Reading](https://www.darkreading.com/application-security/microsoft-rce-bug-windows-paint-confusion)

## 3. Azure

### Static Web Apps の .NET 8 / .NET 9 サポートが本日終了

**要約**: Azure Static Web Apps の管理された Functions API における .NET 8 と .NET 9 のサポートが 2026 年 11 月 10 日に終了する。.NET 10 への移行が案内されている。

**影響**: 該当する API を使っている場合は .NET 10 への移行が必要。ランタイムのバージョンと CI/CD の設定を確認しておきたい。

**リンク**: [Retirement: Support for .NET 8 and .NET 9 on Static Web Apps is ending November 10, 2026](https://azure.microsoft.com/updates?id=575106)

**影響**: classic CDN に依存している構成は、移行計画を早めに立てておくのが無難。新規追加が必要になる前に後継サービスを検証したい。

**リンク**: [Can anyone with an *existing* Azure CDN (classic) profile confirm whether new endpoints can still be created?](https://www.reddit.com/r/AZURE/comments/1xsjheu/can_anyone_with_an_existing_azure_cdn_classic/)

### Entra ID サインインログのエラーコードの読み方

**要約**: 悪意ある IP からの 50053（パスワード誤り）の直後に、同じ CorrelationId で 50074 や 53003 が記録されるパターンについて、パスワードが正しかったのかを問う議論が r/AZURE に投稿されている。

**影響**: ログ上のエラーコードは文脈次第で意味が変わる。条件付きアクセスや MFA でブロックされたケースの解釈を整理し、侵害の有無を判断する手順を持っておくと安心だ。

**リンク**: [Entra ID: 50053 (malicious IP, "Incorrect password") followed <1s later by 50074 or 53003 in the same CorrelationId — was the password correct?](https://www.reddit.com/r/AZURE/comments/1xs11vy/entra_id_50053_malicious_ip_incorrect_password/)

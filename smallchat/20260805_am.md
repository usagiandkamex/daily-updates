## 1. Microsoft

### アプリの遅さの原因をAIが調査「Windows Performance Analyzer MCP」プレビュー公開

**要約**: マイクロソフトは、Windowsアプリの動作が遅くなる原因調査をAIに任せられるツール「Windows Performance Analyzer MCP」（WPA MCP）のアーリープレビューを公開した。トレースログをMCP経由でAIに渡し、ボトルネック分析を自動化する狙い。

**影響**: パフォーマンス調査のような専門知識と時間を要する作業をAIエージェントに委譲できるようになり、Windowsアプリ開発者のデバッグ工数削減が期待できる。GitHub Copilotなどのエージェントとの連携も見込まれる。

**参考リンク**: [アプリが遅い原因をAIがトレースログから分析してくれる「Windows Performance Analyzer MCP」（WPA MCP）、マイクロソフトがプレビュー公開](https://www.publickey1.jp/blog/26/aiwindows_performance_analyzer_mcpwpa_mcp.html)

**参考リンク**: [Microsoft Agent Framework、4カ月の進化を6本で整理した](https://qiita.com/kai_kou/items/906a2162d0d401b8fd2d)

## 3. Azure

### Azure DNS、Traffic Manager統合によるDNSベースのロードバランシングをプレビュー公開

**要約**: Azure DNSがAzure Traffic Managerとシームレスに統合され、DNSベースのトラフィックルーティングが可能になった。Azureリソースを直接関連付けられる新機能がパブリックプレビューとして提供開始。

**要約**: 仮想ネットワーク間のプライベート接続を専用ハードウェアで実現する「Azure Virtual Network routing appliance」がGA（一般提供）になった。

**影響**: ネットワークアプライアンスを介した仮想ネットワーク間ルーティングが正式にサポートされ、複雑なハブ&スポーク構成やセキュリティアプライアンス経由の通信設計が容易になる。

**参考リンク**: [[Launched] Generally Available: Azure Virtual Network routing appliance](https://azure.microsoft.com/updates?id=568605)

**要約**: csoonline.comの報道によると、Azure Cosmos DBに存在した重大な脆弱性により、クロステナントでのデータベース乗っ取りが可能な状態だったことが明らかになった。

## 5. セキュリティ

### 公衆Wi-Fiの接続案内画面を悪用する攻撃活動「CaptiveCrunch」が発覚

**要約**: Microsoft Threat Intelligenceは、ホテルや会議施設が提供する公衆Wi-Fi（キャプティブポータル）の通信を操作し、偽のブラウザやOSアップデート画面を通じてマルウェアを配布、認証情報やセッション情報を窃取する攻撃活動「CaptiveCrunch」を報告した。

**影響**: 出張やカンファレンス参加時など公衆Wi-Fi利用が多いエンジニアにとって、キャプティブポータル経由の偽アップデート表示に注意が必要であり、VPN利用や端末の自動更新設定の見直しが求められる。

**参考リンク**: [公衆Wi-Fiの接続案内画面を悪用した攻撃活動CaptiveCrunchについてまとめてみた](https://piyolog.hatenadiary.jp/entry/2026/08/04/183114)

### 数十年来のBMC脆弱性、多数のデータセンターを危険にさらす

**要約**: securityweek.comの報道によると、長年存在していたBMC（Baseboard Management Controller）の脆弱性により、数多くのデータセンターが攻撃リスクにさらされていることが判明した。

**影響**: サーバーの管理チップという低レイヤーの脆弱性であり、パッチ適用が困難なハードウェアも多いため、影響範囲の特定とファームウェア更新計画の優先度引き上げが必要になる。

**参考リンク**: [Decades-Old BMC Vulnerability Exposes Thousands of Data Centers to Attacks](https://www.securityweek.com/decades-old-bmc-vulnerability-exposes-thousands-of-data-centers-to-attacks/)

### CISA、悪用が確認されたN-able N-centralの脆弱性をKEVに追加

**要約**: The Hacker Newsによると、CISAは顧客環境での侵害が確認されたN-able N-centralの脆弱性を「既知の悪用された脆弱性（KEV）」カタログに追加した。

**影響**: RMM（遠隔監視管理）ツールを利用する組織は、KEVカタログ掲載の脆弱性に対する迅速なパッチ適用が連邦機関同様に強く推奨されており、サプライチェーン管理ツールのセキュリティ監視強化が急務となる。

**参考リンク**: [CISA Adds Exploited N-able N-central Flaw to KEV After Customer Compromises](https://thehackernews.com/2026/08/cisa-adds-exploited-n-able-n-central.html)

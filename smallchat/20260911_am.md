## 1. Microsoft

### .NET 11 Release Candidate 1が登場、非同期ネイティブ対応やAOT高速化を実装

**要約**: MicrosoftはNET 11の最初のリリース候補版「.NET 11 Release Candidate 1」を公開した。.NETランタイムの非同期ネイティブ対応、プロセッサ数上限の撤廃、AOTコンパイラによるネイティブバイナリ生成の高速化などが盛り込まれている。

**影響**: 非同期処理のオーバーヘッド低減や大規模マルチコア環境でのスケーラビリティ向上が期待でき、AOTビルドの高速化はCI/CDパイプラインの短縮にもつながる。.NETを使う開発者はRC版での事前検証を進めておく価値がある。

**リンク**: [.NET 11リリース候補版が登場。.NETランタイムが非同期ネイティブ対応、プロセッサ数の上限がなくなる、AOTコンパイラによるネイティブバイナリの高速化など](https://www.publickey1.jp/blog/26/net_11netaot.html)

### Windows 11の9月アップデートでタスクバー操作性が復活、995件のセキュリティ脆弱性も修正

**要約**: 最新のWindows 11アップデートで、一部で不評だったタスクバーの操作制限が緩和され、従来の使い勝手が戻った。同時に995件にのぼるセキュリティ脆弱性の修正パッチも適用されている。

**影響**: UI変更で業務に支障が出ていた現場では操作性改善が歓迎される一方、脆弱性修正件数の多さから、企業環境では速やかな検証・適用スケジュールの確保が求められる。

**リンク**: [Latest Windows 11 update restores your taskbar control, patches 995 security flaws - ZDNET](https://www.zdnet.com/uncategorized/windows-11-september-2026-update/)

## 3. Azure

**要約**: Azure Functions Flex ConsumptionにおけるTLS/SSL証明書およびエンドツーエンドTLS暗号化サポートが一般提供（GA）となった。サイトスコープの新しい証明書モデルを通じて提供される。

**影響**: サーバーレス環境でのエンドツーエンド暗号化がGAレベルでサポートされることで、金融・医療など高いセキュリティ要件を持つワークロードでもFlex Consumptionを選択しやすくなる。

**リンク**: [[Launched] Generally Available: TLS/SSL certificate and end-to-end TLS encryption support for Azure Functions Flex Consumption](https://azure.microsoft.com/updates?id=570940)

### Azure Copilot Troubleshooting Agentが一般提供開始

**影響**: 障害発生時の原因調査がAIエージェントによって効率化され、運用チームの一次対応の負荷軽減が期待できる。Azure運用担当者は既存の運用フローへの組み込みを検討する価値がある。

**リンク**: [[Launched] Generally Available: Azure Copilot Troubleshooting Agent](https://azure.microsoft.com/updates?id=570980)

**リンク**: [【Rubrik × Azure VM｜セキュリティ編】暗号化されたVMも守れる？ADE・CMK・Azure Policyの注意点](https://qiita.com/hmy8727/items/d91ff4e5beec08d291a7)

## 5. セキュリティ

### Palo Alto PAN-OSに任意コード実行を許す脆弱性

**要約**: Palo Alto NetworksのPAN-OSに、root権限での任意コード実行を可能にする脆弱性が確認された。

**影響**: ファイアウォール製品の根幹に関わる脆弱性であり、該当製品を利用する組織は速やかなパッチ適用状況の確認と対応優先度の引き上げが求められる。

**リンク**: [Palo Alto PAN-OS Vulnerability Enables Arbitrary Code Execution as Root User - CyberSecurityNews](https://cybersecuritynews.com/palo-alto-pan-os-vulnerability-code-execution/)

### 重大なNetScaler脆弱性が実際の攻撃で悪用

**要約**: Citrix NetScalerに存在する重大な脆弱性が、既に実際の攻撃キャンペーンで悪用されていることが確認された。

**影響**: 悪用が既に進行しているため、NetScalerを利用する組織は緊急パッチ適用とログの侵害有無の確認を最優先で行う必要がある。

**リンク**: [Critical NetScaler Vulnerability Exploited in Attacks - SecurityWeek](https://www.securityweek.com/critical-netscaler-vulnerability-exploited-in-attacks/)

### サイバーレジリエンス法、2026年9月から脆弱性・インシデント報告義務が発効

**要約**: EUのサイバーレジリエンス法（Cyber Resilience Act）に基づく脆弱性・インシデントの報告義務が2026年9月から発効することが解説されている。

**影響**: EU市場向けにデジタル製品を提供する企業は、脆弱性発見時やインシデント発生時の報告フローを整備する必要があり、開発チームにも脆弱性管理プロセスの見直しが求められる。

**リンク**: [Cyber Resilience Act: obligations to report vulnerabilities and incidents from September 2026 - ecija.com](https://www.ecija.com/en/news-and-insights/cyber-resilience-act-obligations-to-report-vulnerabilities-and-incidents-from-september-2026/)

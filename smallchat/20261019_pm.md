# 2026/10/19 テクニカル雑談（午後）

## 1. Microsoft

### 10月の Windows 更新が Exchange Server のメールサービスに影響

**要約**: Microsoft が、10月の Windows 更新プログラムが Exchange Server のメールサービスに不具合を起こし得ることを認めたと報じられています。

**影響**: Exchange をオンプレミスで運用している場合、更新の適用前に既知の問題と回避策を確認し、検証環境で動作を見てから本番へ展開するのが安全です。

**リンク**: [Microsoft Confirms October Windows Updates Can Break Exchange Server Email Services - CyberSecurityNews](https://cybersecuritynews.com/october-updates-break-exchange-server/)

### Edge が再起動不要のシームレス更新をテスト中

**要約**: Microsoft Edge で、ブラウザーを再起動せずに更新を適用する仕組みがテストされていると gHacks が伝えています。

**影響**: 更新のためにブラウザーを再起動する手間が減り、セキュリティ修正の適用が早まる可能性があります。企業の更新管理にも関わるため、正式提供の動向を追っておきたいところです。

**リンク**: [Microsoft Edge Tests Seamless Updates That Apply Without Restarting the Browser - gHacks](https://www.ghacks.net/2026/10/19/microsoft-edge-tests-seamless-updates-that-apply-without-restarting-the-browser/)

### Intune / Autopilot のアプリ展開で失敗しないための考え方

**リンク**: [【Microsoft Intune】Windows Autopilot のアプリ展開で失敗する前に考えるべきこと](https://qiita.com/runwaylabo/items/60c9f4a723e9484f2444)

## 5. セキュリティ

### ソースネクストの情報漏えい：パスワード平文保存の疑いに回答

**要約**: ソースネクストの会員情報取得 API が不正アクセスを受け、最大約2252万件の氏名・住所・パスワードなどが漏えいしました。同社広報は ITmedia の取材に、暗号化していたが鍵にアクセスできるシステムに侵入された、と説明しています。

**影響**: 暗号化していても鍵の管理や、鍵にアクセスできる範囲が弱ければ意味が薄れます。パスワードはハッシュ化し、鍵管理とアクセス権を分離する設計を見直す契機になります。

**リンク**: [ソースネクスト、パスワードなぜ平文で流出　「暗号化していたが、鍵にアクセスできるシステムに侵入された」](https://www.itmedia.co.jp/news/article/2610/19/2000002372/)

### AI による脆弱性発見のスピードに防御側は追いつけるか

**要約**: IBM が、AI が重大な脆弱性をかつてない速さで見つけられるようになったなか、防御側が追随できるかを論じています。InfoWorld も、AI によるハッキングの脅威への対応として情報の集約窓口（クリアリングハウス）が答えになるかを取り上げています。

**リンク**: [AI can find serious vulnerabilities at unprecedented speed. Can defenders keep up? - IBM](https://www.ibm.com/think/x-force/ai-vulnerability-discovery)

### Linux カーネルの脆弱性「PwnEscape」で Contabo が VPS ホストを再起動

**要約**: Linux カーネルの脆弱性 PwnEscape を受けて、Contabo が VPS ホストの再起動を行うと報じられています。

**影響**: VPS やホスティングを利用している場合、事業者側のカーネル修正に伴うメンテナンス再起動が発生し得ます。サービスの冗長化と再起動後の自動復旧を確認しておくと安心です。

**リンク**: [PwnEscape Linux kernel vulnerability forces Contabo to reboot its VPS hosts - Pasquale Pillitteri](https://pasqualepillitteri.it/en/news/25544/pwnescape-linux-kernel-vulnerability-contabo-vps-reboot)

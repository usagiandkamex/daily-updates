## 1. Microsoft

### Windows 10 更新 KB5126256 後に Copilot が勝手に起動しクラッシュ

**要約**: ファイルをクリックするたびに Copilot がバックグラウンドで起動し、エクスプローラーが落ちるという報告が出ています。信頼性モニターにはクラッシュ元として Copilot ではなく Microsoft Edge が記録されるとのことです。

**影響**: ログ上の原因表示と実際の挙動がずれているため、切り分けに手間取りそうです。社内端末に更新を配布する管理者は、段階的な展開と Copilot 関連の挙動確認をしておくと安心です。

**リンク**: [Windows 10更新KB5126256後にCopilotが勝手に起動してクラッシュ、ログにはEdgeと記録](https://joho-todai.com/windows-10-kb5126256-copilot-crash-edge/)

## 2. AI

### Gemini の「Gem」が廃止、11 月 17 日から「スキル」へ

**要約**: Google は Gemini のカスタム bot 機能「Gem」を廃止し、後継の「スキル」へ移行すると告知しています。Gem 管理画面には「11 月 17 日より Gem がスキルに」と表示されており、既存の Gem は同日から自動で移行される旨が案内されています。

**影響**: Gem を業務で使っているチームは、移行後の挙動や共有設定に差が出ないか事前に確認しておくとよさそうです。

**リンク**: [OpenAIが「GPT-6.1 Astra」の一般公開を中止、安全基準を満たさないため](https://gigazine.net/news/20260929-openai-abandons-plan-to-release-gpt-6-1-astra/)

### AI の誤った要約が「自分で見た出来事」の記憶まで歪める

**要約**: ジョージタウン大学とワシントン大学の研究チームが、生成 AI の要約に誤情報が含まれていると、元の映像を自分で見ていても誤情報に沿って出来事を思い出してしまう可能性があると報告しました。

**影響**: 議事録や障害報告などで AI 要約を使う際は、人間による原典との突き合わせを省かない運用が大切です。

**リンク**: [AIの間違った要約を読むと「自分で見た出来事」まで間違って記憶することが実験で判明](https://gigazine.net/news/20260929-misleading-ai-generated-summaries/)

## 3. Azure

### Azure SQL Database でベクトル検索とベクトルインデックスが GA

**要約**: `CREATE VECTOR INDEX` と `VECTOR_SEARCH` の T-SQL 機能を使ったベクトル検索とベクトルインデックスが、Azure SQL Database で一般提供になりました。

**影響**: 既存の RDB のまま RAG などのベクトル検索を組み込める選択肢が本番利用可能になり、別途ベクトル DB を用意しない構成も検討できます。

**リンク**: [[Launched] Generally Available: Vector search and vector indexes in Azure SQL](https://azure.microsoft.com/updates?id=571800)

### Azure SQL Dev Hub がパブリックプレビュー

**要約**: Azure SQL でアプリを開発する際の起点となる Azure SQL Dev Hub が公開されました。直接開発する場合も AI エージェントを使う場合も対象です。

**影響**: 開発の入口が一本化されるため、新規メンバーのオンボーディングに役立つ可能性があります。

**リンク**: [[In preview] Public Preview: Azure SQL Dev Hub](https://azure.microsoft.com/updates?id=572998)

### Azure SQL Managed Instance の 2026 年 9 月下旬アップデート

**要約**: 2026 年 9 月下旬に Azure SQL Managed Instance の更新と機能強化が行われ、フレキシブルメモリ機能などが含まれています。

**影響**: SQL MI を運用している場合は、更新内容を確認してサイジングや構成見直しの材料にできます。

**リンク**: [[Launched] Generally Available: Azure SQL Managed Instance updates for late-September 2026](https://azure.microsoft.com/updates?id=571632)

# 2026/11/19 テクニカル雑談（午後）

## 1. Microsoft

### Microsoft Embedding 1 が登場

**要約**: Microsoft Ignite 2026 で、Azure Cosmos DB と Microsoft Research が共同開発したマルチモーダル埋め込みモデル「Microsoft Embedding 1」が発表されました。

**影響**: テキストと画像などを同じベクトル空間で扱えるため、RAG やセマンティック検索の設計で選択肢が増えます。Cosmos DB との組み合わせも検討しやすくなりそうです。

**リンク**: [「Ignite 2026 速報」最先端のマルチモーダル埋め込みモデル「Microsoft Embedding 1」が登場！](https://qiita.com/nohanaga/items/c4e7787d8f77d015ee9c)

### Microsoft 365 Copilot が OneDrive のファイルを直接編集可能に

**要約**: Microsoft 365 Copilot が OneDrive 上のファイルを直接編集できるようになったという紹介記事です。カスタム指示と OneDrive を組み合わせ、AI に自分専用の知識を蓄積させる使い方が語られています。

**影響**: GitHub Copilot のように、手元のドキュメントやナレッジを AI と一緒に育てるワークフローが取りやすくなります。ドキュメント運用の自動化にも応用できそうです。

**リンク**: [【朗報】Microsoft 365 CopilotがOneDriveのファイルを直接編集できるようになってた！CoworkなしでGitHub Copilotみたいに使える件](https://qiita.com/yuyanz/items/c3bb4801c105d96fa79d)

## 2. AI

### OpenAI が AI を使ってチップ設計を改善

**要約**: OpenAI が自社製 AI を使い、独自開発チップ「Jalapeño」や AMD 製 GPU の性能向上を実現したと発表しました。半導体設計向けの専用 AI モデルも開発しているとのことです。

**影響**: AI がハードウェア設計の改善にも使われ始めています。推論基盤の性能やコストに、中長期で効いてくる可能性があります。

**リンク**: [OpenAIがAIを用いてAMD製GPUや独自開発AIチップの改善に成功、半導体設計の専用AIモデルも開発](https://gigazine.net/news/20261119-openai-jalapeno-amd-advancing-chip/)

### 128GB メモリで 120B クラスの LLM が動くミニ PC

**要約**: マウスコンピューターの DAIV ブランドから、ローカル AI 向けミニ PC「DAIV CX」が登場しました。Ryzen AI Max+ 395 と 128GB メモリを搭載し、120B クラスの LLM の利用を想定しています。

**影響**: 機密データを外に出さずに大規模モデルを試せる環境が、卓上サイズで手に入ります。社内 PoC やローカル開発の選択肢になります。

**リンク**: [128GBメモリで120BクラスのLLMが動く！　マウスコンピューターの卓上ローカルAI向けミニPC「DAIV CX」の実力](https://www.itmedia.co.jp/pcuser/articles/2611/19/news047.html)

### AI にコードを書かせる前にテーブル設計は自分で決める

**要約**: Laravel の実務で AI を使いつつも、テーブル設計だけは自分で決めているという体験談です。AI に丸投げするとテーブルまで含めて作られてしまう点が背景にあります。

**影響**: データモデルは後から変更しにくいため、どこまで AI に任せるかの線引きが重要です。設計判断は人間が持つ運用が、品質維持の一つの考え方になります。

**リンク**: [AIにLaravelのコードを書かせる前に、テーブル設計だけは自分で決めています](https://qiita.com/Engineering-seiya/items/39ce10abd362dbb9d09e)

## 3. Azure

### Azure Front Door Premium WAF に AI bot ルールセット（Public Preview）

**要約**: Azure Front Door Premium の WAF に、AI クローラーやエージェントのアクセスを扱う AI bot ルールセットがパブリックプレビューで追加されました。

**影響**: 自サイトへの AI ボットのアクセスを、WAF 側で制御・可視化しやすくなります。コンテンツ保護や負荷対策の手段が増えます。

**リンク**: [[In preview] Public Preview: AI bot ruleset for Azure Front Door Premium WAF](https://azure.microsoft.com/updates?id=581604)

### Azure Backup が VM のサブスクリプション間バックアップに対応（GA）

**要約**: Azure Backup で、Azure Virtual Machines のクロスサブスクリプションバックアップが一般提供になりました。

**影響**: VM とは別のサブスクリプションにある Recovery Services コンテナーで保護できます。バックアップを分離して管理したい構成で役立ちます。

**リンク**: [[Launched] Generally Available: Cross-subscription backup for Azure Virtual Machines in Azure Backup](https://azure.microsoft.com/updates?id=581048)

### Azure Linux 4 は追加ライセンス料なし

**要約**: Help Net Security が、Azure Linux 4 が Microsoft のクラウドサービスを支える OS として、VM 上で追加ライセンス料なしで使えると報じています。

**影響**: Azure 上の Linux ディストリビューション選定で、コスト面を含めた比較対象になります。

**リンク**: [Azure Linux 4 puts the OS behind Microsoft's cloud services on your VMs at no extra license fee - Help Net Security](https://www.helpnetsecurity.com/2026/11/19/microsoft-azure-linux-4/)

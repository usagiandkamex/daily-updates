# 2026/10/28 テクニカル雑談（午前）

## 1. Microsoft

### Microsoft が大規模な希望退職の募集を実施

**要約**: Microsoft が従業員向けに自主的な買い取り（バイアウト）を提示したと報じられています。報道では対象は約6万人、全従業員の3割近くに及ぶとされ、AI へのシフトが進む中での動きと伝えられています。

**影響**: 社内体制の変化は、製品のサポートやロードマップ、OSS への関与にも波及する可能性があります。Microsoft 製品に依存する開発者は、今後の公式発表を注視しておくとよいでしょう。

**リンク**: [Microsoft offers voluntary buyout to 60,000 employees - Yahoo Finance](https://finance.yahoo.com/technology/article/microsoft-offers-voluntary-buyout-to-60000-employees-160011034.html)

### 証明書更新を含む Windows の臨時（OOB）修正プログラム

**要約**: Microsoft が証明書の更新を伴う Windows の定例外（out-of-band）修正プログラムを公開したと The Register が伝えています。

**影響**: 証明書関連の更新は、適用漏れや期限切れで認証・起動周りの障害に直結しがちです。管理者は配布状況と検証環境での動作確認を早めに進めておきたいところです。

**リンク**: [Microsoft releases out-of-band Windows fixes with certificate updates - The Register](https://www.theregister.com/security/2026/10/27/microsoft-releases-out-of-band-windows-fixes-with-certificate-updates/5305637)

### Edge サイドバーで Copilot が使えなくなるケース

**要約**: Edge への Copilot 統合を推し進める中、移行の過程で一部ユーザーがサイドバーから Copilot にアクセスできなくなる事象が Windows Central により報じられています。数日間使えない場合もあるとのことです。

**影響**: 業務でサイドバーの Copilot を前提にしている場合、移行期間は代替手段を用意しておくと安心です。

**リンク**: [Microsoft pushed Copilot hard in Edge, now some users can't access it in the Sidebar - Windows Central](https://www.windowscentral.com/artificial-intelligence/microsoft-copilot/microsofts-copilot-migration-can-leave-edge-sidebar-users-without-the-ai-assistant-for-days)

## 2. AI

### コードを読まずにマージするために必要なこと

**要約**: AI に実装を任せると PR が次々にできあがり、人間のレビューがボトルネックになります。人がコードを読まずにマージする「no look merge」を実現するために何が必要かを考察した記事です。

**影響**: レビュー待ち PR の山をどう減らすかは、AI 開発の生産性を左右する課題です。テストや自動検証の整備など、レビュー以外の品質担保の仕組みを考えるきっかけになります。

**リンク**: [コードを読まずにマージするために必要なこと](https://zenn.dev/nrs/articles/c777388530aa84)

### Claude 便利術 20 選を Terraform で試す

**要約**: 構成図の画像を貼って Terraform コードを生成し、/goal で trivy の指摘を修正させるなど、Claude の機能を 1 つの Terraform コードを通して 20 個試した記録です。

**影響**: 単発の機能紹介ではなく、IaC 作業の流れの中での使い方が分かるため、自分のワークフローへ取り入れやすい内容です。

**リンク**: [実際に試したClaude便利術20選 まとめ - Qiita](https://qiita.com/N-Kyo/items/bf4a3a2185db2d28eee5)

### AMD と Intel、x86 CPU 向け PyTorch 最適化を統合へ

**要約**: PC Watch によると、AMD と Intel が x86 CPU 向けの PyTorch 最適化を統合する方向とのことです。

**影響**: CPU 推論の最適化が一本化されれば、ベンダーを問わずパフォーマンスを得やすくなり、GPU のない環境での AI 活用にも追い風になりそうです。

**リンク**: [AMDとIntel、x86 CPU向けPyTorch最適化を統合へ](https://pc.watch.impress.co.jp/docs/news/2151484.html)

### Azure Front Door でプロファイル／ルート単位の WAF ポリシーが GA

**要約**: Azure Front Door Premium で、Azure WAF のプロファイルレベルおよびルートレベルのポリシーが一般提供となりました。

**影響**: ルートごとに異なる WAF ポリシーを適用できるため、アプリケーション単位のきめ細かな防御設計がしやすくなります。

**リンク**: [Generally Available: Azure Front Door profile and route level WAF policies](https://azure.microsoft.com/updates?id=578153)

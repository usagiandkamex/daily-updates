# 2026/11/12 テクニカル雑談（午前）

## 1. Microsoft

### Outlook ゼロデイが悪用中、月例パッチは 1,259 件

**要約**: Microsoft は月例パッチで多数の脆弱性を修正しました。その中には、NTLMv2 ハッシュが漏えいし得る Outlook の脆弱性が含まれ、実際に悪用が確認されていると報じられています。Microsoft 自身も新しい Outlook ゼロデイの悪用を認めたとのことです。

**影響**: Outlook を使う組織は、パッチ適用の優先度を上げる必要があります。NTLM 認証の利用範囲や外向き SMB 通信の制限も、この機会に見直しておくと安心です。

**リンク**: [Microsoft Patches 1,259 Flaws, Including Exploited Outlook Bug That May Expose NTLMv2 Hashes - The Hacker News](https://thehackernews.com/2026/11/microsoft-patches-1259-flaws-including.html)

### Microsoft 365 Education の新プランで無料プラン廃止とストレージ制限

**要約**: Microsoft は 11 月 5 日（米国時間）、教育機関向け Microsoft 365 Education の新プランを発表しました。無料プランの廃止とストレージ制限が話題になっており、記事では Google への対抗戦略としての「アメとムチ」が論じられています。

**影響**: 教育機関の IT 管理者は、移行計画とストレージ容量の見直しが必要になりそうです。Google Workspace for Education との比較検討にも影響します。

**リンク**: [無料プラン廃止とストレージ制限の衝撃！　「Microsoft 365 Education」新プランに見る――“アメとムチ”の戦略でGoogleの牙城は崩せるか](https://www.itmedia.co.jp/pcuser/articles/2611/11/news066.html)

### 遊休 GPU で AI を学習させる特許

**要約**: Microsoft がゲーマーの遊休 GPU を AI 学習に活用し、対価を支払う仕組みの特許を出願していたと報じられています。

**要約**: AWS がオープンソースの「AWS Emulator」を公開しました。AWS の API をローカルマシンや開発サーバー上でエミュレートし、実際に AWS を呼ばずにアプリをテストできます。

**影響**: 開発やテストでのコストと待ち時間を減らせる可能性があります。CI での利用も検討できます。

**リンク**: [Test your applications against AWS locally with AWS Emulator - Amazon Web Services (AWS)](https://aws.amazon.com/blogs/aws/test-your-applications-against-aws-locally-with-aws-emulator/)

### Amazon ECS が NVIDIA MPS による GPU 共有に対応

**要約**: 2026 年 10 月 27 日、Amazon ECS が NVIDIA Multi-Process Service (MPS) による GPU 共有に対応しました。1 つの GPU 上で複数の ECS タスクを同時に実行できます。

**影響**: GPU の利用効率が上がり、推論ワークロードなどのコスト最適化に役立ちます。

**リンク**: [Amazon ECS の GPU 共有(NVIDIA MPS)対応のまとめ](https://qiita.com/Haruki-N/items/28d5066684551df08179)

# 2026/09/24 テクニカル雑談（午前）

## 1. Microsoft

### Microsoft、AI悪用の大規模アカウント侵害プラットフォーム「EvilTokens」を摘発

**要約**: MicrosoftはAIを活用したアカウント侵害プラットフォーム「EvilTokens」を摘発し、これまでに約1万2000件のアカウント侵害に関与していたことを明らかにした。同プラットフォームは大量アカウント侵害をエンドツーエンドで支援していたという。

**影響**: 攻撃者側でもAIを活用した大規模自動化が進んでいることが裏付けられており、認証・アカウント保護の運用担当者はAI悪用を前提とした検知ロジックの見直しが求められる。

**リンク**: [Microsoft disrupts AI-assisted platform that compromised 12,000 accts.](https://www.reddit.com/r/microsoft/comments/1wo4lhw/microsoft_disrupts_aiassisted_platform_that/)

### Windows 11の2026年9月更新、バックアップ機能が無効化されるバグが判明

**要約**: Microsoftは2026年9月のWindows 11更新プログラムに含まれる新たなバグにより、一部環境でファイルのバックアップが静かに停止していたことを確認した。

**影響**: バックアップの停止に気付かないままデータ損失リスクが蓄積する恐れがあるため、Windows環境を管理するIT担当者は該当更新の適用状況とバックアップの稼働確認を急ぐ必要がある。

**リンク**: [Microsoft confirms Windows 11 quietly stopped backing up your files due to a new bug in September 2026 update - Windows Latest](https://www.windowslatest.com/2026/09/23/microsoft-confirms-windows-11-quietly-stopped-backing-up-your-files-due-to-a-new-bug-in-september-2026-update/)

### Microsoft Defender、エージェント時代のSOCを再構想する新戦略を発表

**要約**: MicrosoftはMicrosoft Defenderブログにて、AIエージェントが台頭する時代に合わせたSOC（セキュリティオペレーションセンター）の再設計方針を発表した。

**影響**: SOC運用にAIエージェントを組み込む動きが本格化しており、セキュリティ担当者は検知・対応フローの自動化・エージェント連携を見据えた体制整備を検討する時期に来ている。

**リンク**: [Reimagining the SOC for the agentic era in Microsoft Defender - Microsoft](https://www.microsoft.com/en-us/security/blog/2026/09/23/reimagining-the-soc-for-the-agentic-era-in-microsoft-defender/)

## 3. Azure

### PowerShell 7.4のAzureサポート、2026年11月10日に終了

**要約**: Azure Functionsにおいて、PowerShell 7.4のサポートが2026年11月10日に終了することが発表された。該当バージョンを使用しているアプリはPowerShell 7.6への移行が推奨されている。

**影響**: サポート終了後もアプリ自体は動作を続けるが、セキュリティ更新が提供されなくなるため、Azure Functionsを運用する開発者は早めのランタイムアップグレード計画が必要になる。

**リンク**: [Retirement: Support for PowerShell 7.4 ends on November 10, 2026](https://azure.microsoft.com/updates?id=572770)

### .NET 8・.NET 9のAzureサポート、2026年11月10日に終了

**要約**: Azure Functionsにおける.NET 8および.NET 9のサポートが2026年11月10日に終了することが発表された。該当バージョンのアプリは.NET 10への移行が求められている。

**影響**: .NET 8/9で構築されたAzure Function Appsは動作自体は継続するもののセキュリティパッチが提供されなくなるため、運用チームは移行スケジュールを早期に策定する必要がある。

**リンク**: [Retirement: Support for .NET 8 and .NET 9 ends on November 10, 2026—upgrade your apps to .NET 10](https://azure.microsoft.com/updates?id=572838)

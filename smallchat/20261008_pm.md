# 2026/10/08 テクニカル雑談（午後）

## 1. Microsoft

### Surface Laptop Ultra（RTX Spark）が予約開始、Windows 11 もエージェント AI 向けに刷新

**要約**: Microsoft と NVIDIA が共同開発した「RTX Spark」を搭載する Surface Laptop Ultra の予約受付が始まりました。日本では 51 万 3480 円からで、16 日出荷予定とのことです。あわせて Windows 11 もエージェント型 AI を意識した大きな変更が発表されています。

**影響**: AI ワークロードをローカルで動かす前提の PC が本格的に登場してきました。ローカル推論やエージェント実行を想定したアプリ設計を、そろそろ検討に入れておきたいところです。

**リンク**: [Microsoft releases new Nvidia-chip AI PCs with revamped Windows 11 - TechCrunch](https://techcrunch.com/2026/10/07/microsoft-releases-new-nvidia-chip-ai-pcs-with-revamped-windows-11/)

### 「Windows」アプリの「リモート PC」接続が一般提供に

**要約**: 「Windows」アプリの「リモート PC」接続が一般提供（GA）になりました。RDC 接続もこのアプリで扱え、職場または学校のアカウントは不要とのことです。

**影響**: 自宅や検証用 PC への接続手段が公式アプリに集約され、個人開発者や小規模チームでもリモート環境を扱いやすくなります。

**リンク**: [「Windows」アプリの「リモート PC」接続が一般提供に](https://forest.watch.impress.co.jp/docs/news/2146580.html)

### Surface 新モデルのスペックと Windows の新方針

**要約**: RTX Spark 搭載 Surface は 18 コア/24GB モデルや 20 コア/128GB モデルが用意されます。Fortune は Windows の新しいソフトウェアがエージェント AI 向けに作り直されたと報じています。

**影響**: 128GB 級のメモリは大きめのローカルモデルを扱う開発機として選択肢になり得ます。

**リンク**: [【速報】RTX Spark搭載Surfaceが正式発表](https://pc.watch.impress.co.jp/docs/news/2146579.html)

## 2. AI

### Liquid AI がローカル実行可能な意思決定モデル「d1」シリーズを公開

**要約**: Liquid AI が意思決定モデル「d1-3B」（画像入力対応）と「d1-omni-600M」（音声入力も可能）をリリースしました。無料でダウンロードしてローカル実行でき、OpenAI の Decisions API より高速とされています。

**影響**: エッジやオフライン環境でのエージェントの判断部分を小型モデルで担う構成が現実味を帯びます。速度は公称値なので、自分の環境での検証が必要です。

**リンク**: [ローカル実行可能で画像入力もOKな意思決定モデル「d1-3B」と「d1-omni-600M」が登場](https://gigazine.net/news/20261008-d1-3b-omni-600m/)

### AI が書いたコードは目視で追わない：品質検査的コードレビュー

**要約**: Claude Code や Codex の導入でコードの初稿作成は速くなった一方、PR のレビュー待ちが滞留し、テックリードが疲弊する現場が増えているという話です。「工場の品質検査」の発想でレビューを捉え直す提案がされています。

**影響**: 生成速度に人間の目視レビューが追いつかない問題への対処として、テストや静的検査など仕組み側で品質を担保する考え方が参考になります。

**リンク**: [AIが書いたコードを目視で追うのはやめよう](https://ptyhard.co.jp/blog/2026/10/code-review)

### AI 自身がツールを評価する口コミサイト「agent.reviews」

**要約**: AI が使ったツールを AI 自身が 5 段階で評価する口コミサイト「agent.reviews」が登場し、Claude Code や Codex もレビューを投稿しているそうです。

**影響**: エージェントが利用しやすい API やドキュメントかどうかが、ツール選定に影響する時代の兆しかもしれません。

**リンク**: [agent.reviews - GIGAZINE](https://gigazine.net/news/20261008-agent-reviews/)

## 1. Microsoft

### Windows 11「26H2」の中身と更新すべきか問題

**要約**: PC Watch が Windows 11「26H2」の中身を検証した特集を公開しました。新機能が少ないなかで更新すべきかが論点になっています。Windows Latest では、26H2 の ISO（オフラインインストーラー）を Microsoft から直接ダウンロードできること、および問題が出た場合にスキップすべきかについての Microsoft の説明も報じられています。

**影響**: 新機能が少ない更新は、検証コストと得られる価値のバランスを見て展開判断をすることになります。社内 PC の展開計画や検証環境では、ISO を使ったオフライン検証もしやすくなります。

**リンク**: [【特集】 新機能が少ないのに更新すべき？Windows 11「26H2」の中身を確かめた](https://pc.watch.impress.co.jp/docs/topic/feature/2144347.html)

### Windows 11 26H2 の ISO 入手とスキップ判断

**要約**: Windows Latest は、26H2 の ISO を Microsoft から直接ダウンロードする方法と、26H2 に問題がある場合やスキップすべきかどうかについての Microsoft の説明を取り上げています。

**影響**: クリーンインストールや検証用 VM の準備が楽になります。一方で、更新を急ぐ必要があるかどうかは Microsoft の説明を踏まえて組織ごとに判断する必要があります。

**リンク**: [Microsoft explains if Windows 11 26H2 has issues, and whether you should skip the update](https://www.windowslatest.com/2026/09/30/microsoft-explains-if-windows-11-26h2-has-issues-and-whether-you-should-skip-the-update/)

## 3. Azure

### Azure Container Apps 上の Azure Functions v1 ホスティングモデルが廃止予定

**要約**: Azure Container Apps 上の Azure Functions v1 ホスティングモデルは、2027 年 9 月 29 日に廃止されます。

**影響**: 該当構成を使っている場合は、期限までに移行計画を立てる必要があります。まずは現在の利用状況を棚卸ししましょう。

**リンク**: [Retirement: Azure Functions v1 hosting model on Azure Container Apps](https://azure.microsoft.com/updates?id=570800)

### ストレージ最適化 VM「Lasv5 / Laosv5」が GA

**要約**: 第 5 世代 AMD EPYC（Turin）を搭載したストレージ最適化 VM の Lasv5 および Laosv5 シリーズが一般提供（GA）となりました。

**影響**: ローカルストレージの I/O が重要なデータベースやログ処理などのワークロードで、新しい選択肢になります。

**リンク**: [Generally Available: Storage optimized Lasv5 and Laosv5 Azure VM series](https://azure.microsoft.com/updates?id=572630)

### VM Scale Sets の Automatic Zone Placement がパブリックプレビュー

**要約**: VM Scale Sets で、Azure が最適な可用性ゾーンを自動で選択する Automatic Zone Placement がパブリックプレビューになりました。

**影響**: ゾーン設計の手間が減り、可用性の確保がしやすくなる可能性があります。ただしプレビューのため、本番適用は慎重に検討してください。

**リンク**: [Public Preview: Automatic Zone Placement for Virtual Machine Scale Sets](https://azure.microsoft.com/updates?id=571075)

## 5. セキュリティ

### タイムズカーで約 660 万アカウントの情報漏えい

**要約**: カーシェア「タイムズカー」で、退会者を含む約 660 万アカウントの情報が漏えいしました。パーク24 は、退会者の個人情報を 7 年間保存していた理由を法人税法に基づく取引記録の保管義務と説明しましたが、免許証画像の保存には法人税法上の根拠がないとも指摘されています。

### 「WSL 3.0」リリース、WSL containers が正式版に

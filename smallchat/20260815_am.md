## 1. Microsoft

### MicrosoftのAIターミナル「Intelligent Terminal 0.2」公開

**要約**: MicrosoftがAIターミナル「Intelligent Terminal 0.2」を公開。ローカルモデル対応、OpenCode対応、スラッシュコマンドの拡充、WSL内エージェントの改善などが行われた。

**リンク**: [MicrosoftのAIターミナル「Intelligent Terminal 0.2」が公開](https://forest.watch.impress.co.jp/docs/news/2132156.html)

**影響**: エディタとエージェント機能が疎結合になることで、他のIDEやツールチェーンでも同様のエージェント機能を再利用しやすくなる可能性があり、エコシステム全体への波及が見込まれる。

**リンク**: [Microsoft Decouples AI Agents From the VS Code Editor in Latest Release](https://devops.com/microsoft-decouples-ai-agents-from-the-vs-code-editor-in-latest-release/)

**影響**: 業務メールでCopilotに依存しているユーザーは一時的に機能が使えなくなる可能性があり、企業の運用担当者はアップデート状況の確認が必要になる。

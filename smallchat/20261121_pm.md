## 3. Azure

### Foundry のガバナンスポリシーガイダンスが GA

**要約**: Microsoft Foundry のガバナンスポリシーガイダンスが、Foundry Canvas と Foundry Toolkit for Visual Studio Code で一般提供（GA）になりました。

**影響**: エージェントを開発しながらガバナンス要件を確認できるため、手戻りの削減につながります。エンタープライズでのエージェント開発では導入を検討する価値があります。

**リンク**: [[Launched] Generally Available: Governance policy guidance in Foundry Canvas and VS Code](https://azure.microsoft.com/updates?id=581463)

### Programmed Training と Multi-turn evaluation がパブリックプレビュー

**要約**: Foundry で、オープンウェイトモデル向けに独自の後学習ループを構築できる API「Programmed Training」がパブリックプレビューになりました。また、エージェントの会話全体を品質基準で評価する Multi-turn evaluation もプレビューです。

**影響**: モデルのカスタマイズと、エージェントの会話単位での評価をどちらも Foundry 上で試せます。プレビューなので、本番利用前に仕様や制限の確認が必要です。

**リンク**: [[In preview] Public Preview: Programmed Training in Microsoft Foundry](https://azure.microsoft.com/updates?id=581713)

### Azure Functions OpenAI 拡張のサポートが 2027 年 4 月 20 日に終了

**要約**: Azure Functions OpenAI 拡張のサポートは 2027 年 4 月 20 日に終了します。OpenAI、Microsoft Foundry、Azure AI Search の SDK を直接使う形への移行が案内されています。

**影響**: 拡張を使っている関数アプリは、期限までに SDK 直接利用へ移行する計画が必要です。まず利用箇所の棚卸しから始めましょう。

**リンク**: [Retirement: Support for Azure Functions OpenAI Extension ends on April 20, 2027](https://azure.microsoft.com/updates?id=579952)

# 2026/09/28 テクニカル雑談（午後）

## 1. Microsoft

### 新しいCopilot「Home」「Code」「Autopilot」が発表

**要約**: Microsoftは米国時間9月25日、Home・Code・Autopilotの3つの新機能を備えた新しいCopilotを発表した。AI at Work担当CMOのジャレッド・スパタロー氏によるブログで詳細が紹介されている。

**影響**: Copilotの適用範囲が「日常業務」から「コーディング」「自律実行（Autopilot）」まで広がることで、開発者は日常的なタスクの自動化余地がさらに増える。今後のロールアウト状況を注視したい。

**リンク**: [Home、Code、Autopilotを備えた新しいCopilotを発表](https://news.microsoft.com/source/asia/features/introducing-the-new-copilot-with-home-code-and-autopilot/?lang=ja)

### Windows 11でサインイン後に画面が真っ黒になる不具合

**要約**: Microsoftは9月24日、8月27日公開のプレビュー更新プログラム適用後、一部デバイスでサインイン後に画面が真っ黒になりデスクトップが正常に読み込めない事象を確認したと発表。暫定的な回避策も案内されている。

**影響**: 業務PCへの適用タイミング次第では社内サポートに問い合わせが増える可能性がある。IT管理者は該当更新プログラムの適用状況を確認し、暫定策を周知しておくとよい。

**リンク**: [Windows 11でサインイン後に「画面が真っ黒になる」事象が確認される　発生時は暫定解決策あり](https://www.itmedia.co.jp/pcuser/articles/2609/28/news079.html)

### Excelに「1セル＝複数値」を実現する新機能

**要約**: Excelにおいて、1つのセルに複数の値を格納できる「リスト」「セル内の配列」「入れ子の配列」といった新機能が導入され、対応する関数も4種類追加される見込み。40年来の「1セル＝1値」という前提を覆す変更となる。

**影響**: 既存のExcel関数やマクロ、外部ツール連携が新しいデータ構造にどう対応するかが今後の焦点。VBAやOffice Scriptsを使った自動化を行っているエンジニアは仕様変更への追随が必要になりそうだ。

**リンク**: [「Excel」40年の常識“1セル＝1つの値”を打ち破る新機能](https://forest.watch.impress.co.jp/docs/news/2143595.html)

## 2. AI

### サム・アルトマン氏、国連演説で「訓練すべきでないAI」に言及

**要約**: OpenAIのサム・アルトマンCEOは9月23日、国連安全保障理事会で演説し、人間の制御下に置き続けられると強く論証できないAIモデルは「訓練すべきではない」と発言。演説の2日後にはOpenAIが最上位モデルの訓練停止を公表したという。

**影響**: フロンティアモデルの安全性検証プロセスが今後さらに厳格化される可能性があり、APIやモデルのアップデートサイクルにも影響が出る可能性がある。AI活用サービスを構築するエンジニアは、上位モデルの提供停止リスクも織り込んだ設計が求められる。

**リンク**: [広がる「AIで人類滅亡」論、サム・アルトマン氏が語ったこと](https://japan.cnet.com/article/35253028/)

### タスク難易度に応じてAIモデルを自動選択する「Jev Router」登場

**要約**: 複数のLLMから最適なモデルを瞬時に選択する「Jev Router」がOpenRouter上で利用可能に。既存のOpenRouterのルーターより高精度にタスク難易度を判断できるという。

**影響**: マルチモデル運用を行うプロダクトにおいて、コストと精度のバランスを取るルーティング層の実装が今後の差別化ポイントになりそうだ。自前でルーターを実装しているチームは比較検討の価値がある。

**リンク**: [どのAIを使うかをJevで自動選択する「Jev Router」が登場](https://gigazine.net/news/20260928-openrouter-jev-router/)

### エージェントのコストを設計変数として扱う考え方

**要約**: Zennの記事では、AIエージェントのコスト最適化を「プロンプトを短くする」で終わらせず、プレフィックス安定性・ルーティング損益分岐・予算の仮押さえという3つの設計論点に整理。管理単位は「成功1件あたり単価」としている。

**影響**: エージェント運用のコスト管理指標として「成功率がそのままコストに直結する」という視点は、本番運用中のAIプロダクトの予算設計に直接応用できる。

**リンク**: [エージェントのコストは設計変数である](https://zenn.dev/xim2jp_tokyo/articles/f11a0a0568e0c1)

## 3. Azure

**要約**: JADEPUFFERと関連付けられる攻撃者グループが、侵害したサービスプリンシパルを悪用してAzureリソースを削除する攻撃を行っていたことが報じられた。

**リンク**: [JADEPUFFER-Linked Attackers Used Compromised Service Principals to Delete Azure Resources](https://thehackernews.com/2026/09/jadepuffer-linked-attackers-used.html)

**リンク**: [Microsoft (MSFT) Reportedly Plans a Vast Data Center Expansion. Can Azure Justify the Cost?](https://finance.yahoo.com/technology/ai/articles/microsoft-msft-reportedly-plans-vast-001144437.html)

**リンク**: [Durable Entities はいつ使う？ 在庫予約と口座間送金で試してみた](https://qiita.com/tyamashita1114/items/936c3c72dcb8f3e21a99)

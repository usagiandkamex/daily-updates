# 2026/11/19 テクニカル雑談（午前）

## 1. Microsoft

### Microsoft Ignite 2026 で AI 攻撃対抗サービス「Microsoft Perception」

**要約**: Microsoft は日本時間 11 月 18 日未明に開幕した年次イベント「Microsoft Ignite 2026」で、AI によるサイバー攻撃に AI エージェントで対抗する新サービス「Microsoft Perception」の提供開始を発表しました。

**影響**: 攻撃側の AI 活用が進むなか、防御側もエージェントによる自動化が前提になりつつあります。SOC やセキュリティ運用担当は、導入時の検知・対応範囲を早めに把握しておくとよさそうです。

**リンク**: [マイクロソフト、AIによるサイバー攻撃にAIエージェントで対抗する新サービス「Microsoft Perception」提供開始](https://www.publickey1.jp/blog/26/aiaimicrosoft_perception.html)

### Copilot を「仕事の新しい OS」に

**要約**: Ignite で Microsoft は、Copilot を「仕事の新しい OS」と位置付け、AI とセキュリティの強化を打ち出しました。

**影響**: Microsoft 365 を使う組織では、Copilot が業務の入口になる前提で、権限設計やデータ管理を見直す必要が出てきます。

**リンク**: [Copilotを「仕事の新しいOS」に　MicrosoftがAI・セキュリティ強化](https://www.watch.impress.co.jp/docs/news/2157470.html)

### Licensed Weights で自社データによるモデルのカスタマイズ

**要約**: ZDNET によると、Microsoft は Ignite 2026 で「Licensed Weights」を発表し、企業が自社データで AI モデルをカスタマイズできるようにします。

**影響**: 自社データを活かしたモデル調整の選択肢が増えます。ライセンス条件や運用コストの確認は欠かせません。

**リンク**: [Microsoft’s new Licensed Weights lets businesses customize AI models with their own data](https://www.zdnet.com/innovation/microsoft-licensed-weights-ai-models-ignite-2026/)

## 3. Azure

### Azure Front Door Premium WAF に AI bot ルールセット（パブリックプレビュー）

**要約**: Azure Front Door Premium の WAF で、AI クローラーやエージェントのアクセスに対応する AI bot ルールセットがパブリックプレビューになりました。

**影響**: AI クローラーによる負荷やコンテンツ取得を制御しやすくなります。公開サイトの運営者は検証してみる価値があります。

**リンク**: [[In preview] Public Preview: AI bot ruleset for Azure Front Door Premium WAF](https://azure.microsoft.com/updates?id=581604)

### Azure Backup の Azure VM クロスサブスクリプションバックアップが GA

**要約**: Azure Backup で、Recovery Services vault を別サブスクリプションに置いたまま Azure VM を保護できるクロスサブスクリプションバックアップが一般提供になりました。

**影響**: バックアップ用サブスクリプションを分離する設計がしやすくなり、ランサムウェア対策や権限分離にも役立ちます。

**リンク**: [[Launched] Generally Available: Cross-subscription backup for Azure Virtual Machines in Azure Backup](https://azure.microsoft.com/updates?id=581048)

### Modernize CLI（パブリックプレビュー）

**要約**: Modernize CLI は、アプリとデータベースのモダナイズを、アセスメントから一連のエージェント型プロセスとして支援するツールで、パブリックプレビューになりました。

**影響**: レガシー移行の調査工数を減らせる可能性があります。移行案件を抱えるチームは、まず小さなアプリで試すのがよさそうです。

**リンク**: [[In preview] Public Preview: AI-powered application and database modernization with Modernize CLI](https://azure.microsoft.com/updates?id=579943)

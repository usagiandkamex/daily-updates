### GPT-6 Astra が Microsoft Foundry で一般提供開始

**要約**: OpenAIの最新モデル「GPT-6 Astra」が、Microsoft Foundry Limited Access Programを通じて業務向けフロンティアAIとして提供が始まり、対象顧客への展開が順次拡大している。

**影響**: Azure上で最新フロンティアモデルを直接利用できるようになり、企業は既存のAzure基盤にそのままAstraを組み込めるようになる。

**リンク**: [GPT-6 Astra: Frontier intelligence for work, now generally available in Microsoft Foundry](https://azure.microsoft.com/en-us/blog/gpt-6-astra-frontier-intelligence-for-work-now-available-in-microsoft-foundry/)

### Azure Virtual Network Manager の IPAM 機能が追加リージョンで一般提供

**要約**: Azure Virtual Network Manager の IP アドレス管理（IPAM）機能が、US Gov Virginia/Texas/Arizona および China North 3/East 3 で一般提供された。

**影響**: 複雑なネットワーク環境を持つ企業がIPアドレス管理を一元化できる範囲が広がり、政府系・中国リージョンでの運用効率化につながる。

**リンク**: [Generally Available: Azure Virtual Network Manager IPAM in additional Azure regions](https://azure.microsoft.com/updates?id=570557)

### Azure Front Door にプロファイル／ルート単位の WAF ポリシーがプレビュー追加

**要約**: Azure Front Door の Web Application Firewall（WAF）が、プロファイル単位およびルート単位でのポリシー関連付けにパブリックプレビューで対応した。

**影響**: 基本的な保護を全体に適用しつつ、特定ルートだけ個別のセキュリティ設定を追加できるようになり、WAF運用の柔軟性が向上する。

**リンク**: [Public Preview: Azure Front Door profile and route level WAF policies](https://azure.microsoft.com/updates?id=569804)

### AKS 向け Windows Server 2025 と Artifact Streaming が一般提供

**要約**: Azure Kubernetes Service（AKS）で、Windows Server 2025 ノードプールと、Azure Container Registry連携によるArtifact Streamingがそれぞれ一般提供となった。

**影響**: Windowsワークロードのモダナイズやコンテナイメージの起動高速化がしやすくなり、AKS運用のスケーラビリティ向上に寄与する。

**リンク**: [Generally Available: Windows Server 2025 on AKS](https://azure.microsoft.com/updates?id=570090)

### Azure Firewall の自動学習 SNAT ルートが一般提供

**要約**: Azure Firewallの「auto-learn SNAT routes」機能が一般提供され、登録済み・プライベート宛先プレフィックスを定期的に学習してNo-SNAT範囲に自動適用できるようになった。

**影響**: SNAT設定の手動メンテナンスが減り、大規模ネットワークでの送信元アドレス変換の運用負荷が軽減される。

**リンク**: [Generally Available: Azure Firewall auto-learn SNAT routes](https://azure.microsoft.com/updates?id=570474)

### Azure Monitor の Auxiliary Logs プランが政府・中国リージョンでも一般提供

**要約**: コンプライアンス・監査向けの大量ログを低コストで扱えるAzure Monitor Auxiliary Logsプランが、Azure GovernmentおよびChinaリージョンでも一般提供された。

**影響**: 規制の厳しい業種や特定リージョン限定の顧客も、コストを抑えたログ保持基盤を利用できるようになる。

**リンク**: [Generally Available: Azure Monitor Auxiliary Logs Plan in Azure Government and China regions](https://azure.microsoft.com/updates?id=569899)

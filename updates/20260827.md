## 1. Azure アップデート情報

### Azure Bastion 共有リンクに有効期限設定機能が一般提供開始

**要約**: Azure Bastion の共有リンク機能に有効期限を指定できる機能が一般提供（GA）となった。管理者は共有リンク作成時に失効日時を設定できる。

**影響**: 一時的な外部アクセス許可を明確に期限管理できるようになり、セキュリティ運用の負担が軽減される。

**リンク**: [Generally Available: Azure Bastion shareable link expiration](https://azure.microsoft.com/updates?id=570020)

### Azure Bastion が IPv6 デュアルスタック構成をパブリックプレビューでサポート

**要約**: Azure Bastion で IPv4/IPv6 のデュアルスタック構成が利用可能になり、新規作成の Bastion で設定できる。

**影響**: IPv6 移行を進める企業ネットワークでも Bastion 経由の安全な接続を維持しやすくなる。

**リンク**: [Public Preview: IPv6 dual-stack support for Azure Bastion](https://azure.microsoft.com/updates?id=570025)

### AKS クラスターへの Azure Bastion 接続が一般提供開始

**要約**: Azure Kubernetes Service（AKS）と Azure Bastion の統合が GA となり、ローカル端末から安全なトンネルを確立して接続できるようになった。

**影響**: 踏み台サーバーを別途用意せずに AKS クラスターへ安全にアクセスでき、運用コストと攻撃対象領域を削減できる。

**リンク**: [Generally Available: Connect to AKS clusters using Azure Bastion](https://azure.microsoft.com/updates?id=570030)

### Azure SRE Agent に「Live Reports」がパブリックプレビューで登場

**要約**: 運用チーム向けに、動的な運用状況ビューを作成できる Live Reports 機能が Azure SRE Agent にプレビュー追加された。

**影響**: インシデント対応や日常運用の可視化が強化され、SRE チームの状況把握が迅速になる。

**リンク**: [Public Preview: Introducing Live Reports for Azure SRE Agent](https://azure.microsoft.com/updates?id=569690)

### Azure SRE Agent の VNet 統合が一般提供開始

**要約**: Azure SRE Agent が既存の仮想ネットワーク制御内で動作できる VNet 統合機能が GA となった。

**影響**: 既存のネットワークセキュリティポリシーを維持したまま SRE Agent を導入できるため、企業のガバナンス要件に適合しやすくなる。

**リンク**: [Generally Available: Azure SRE Agent VNet Integration](https://azure.microsoft.com/updates?id=569695)

### Azure SRE Agent、30日間の無料トライアルを提供開始

**要約**: 新規顧客が Azure SRE Agent を試せる30日間トライアル体験が開始され、トライアル中に SRE Agent の作成・接続が可能になった。

**影響**: 導入前の検証ハードルが下がり、AIOps/SRE自動化の採用検討が加速すると見込まれる。

**リンク**: [Generally Available: Azure SRE Agent 30-Day Trial](https://azure.microsoft.com/updates?id=569760)

### Azure Repos 向け GitHub Copilot コードレビューがパブリックプレビュー開始

**要約**: GitHub Copilot Code Review が Azure Repos にも対応し、すべての Azure DevOps 顧客が利用できるパブリックプレビューとして公開された。

**影響**: Azure DevOps を使う開発チームでも AI によるコードレビュー支援を受けられるようになり、レビュー品質と速度の両立が期待できる。

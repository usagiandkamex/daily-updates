# 2026/10/06 デイリーアップデート

## 1. Azure アップデート情報

### Azure HorizonDB が追加リージョンへ拡大（パブリックプレビュー）

**要約**: PostgreSQL ワークロード向けの Azure HorizonDB が、パブリックプレビューとして追加の Azure リージョンで利用可能になりました。アプリケーションに近いリージョンへデプロイする柔軟性が高まります。

**影響**: データの所在地やレイテンシ要件で採用を見送っていた開発チームも、リージョン選択肢が増えたことで検証しやすくなります。プレビュー段階のため、本番投入前に対応リージョンと提供条件の確認が必要です。

**リンク**: [Public Preview: Azure HorizonDB expands to additional regions](https://azure.microsoft.com/updates?id=572940)

### SQL Server on Azure Virtual Machines が Azure Bleu で一般提供開始

**要約**: フランスのソブリンクラウドである Azure Bleu で、SQL Server on Azure Virtual Machines が一般提供（GA）になりました。SQL Server ワークロードのデプロイと管理が可能です。

**影響**: 主権性や規制対応が求められる欧州の公共・金融などの領域で、既存の SQL Server 資産をクラウドへ移行する選択肢が広がります。

**リンク**: [Generally Available: SQL Server on Azure Virtual Machines in Azure Bleu](https://azure.microsoft.com/updates?id=571499)

### OneLake カタログ検索でテーブル検出が可能に（10月15日開始）

**要約**: 2026年10月15日から、Microsoft Fabric の検索がセマンティックモデル、レイクハウス、ミラーリングされたデータベースのテーブルを個別の検索結果として返すようになります。

**影響**: データ利用者は必要なテーブルを素早く探せるようになり、データ探索の効率化が期待できます。検索結果の見え方が変わるため、利用者向けの周知が望まれます。

**リンク**: [Announcing: Table discovery in OneLake Catalog search](https://azure.microsoft.com/updates?id=573875)

### PostgreSQL フレキシブルサーバー／エラスティッククラスター向け Azure Backup（v2）がプレビュー

**要約**: Azure Backup for PostgreSQL flexible server and elastic cluster (v2) がパブリックプレビューとなり、PostgreSQL にエンタープライズ水準の長期保持（long-term retention）を提供します。

**影響**: 監査や規制で長期のバックアップ保持が必要な PostgreSQL 運用で、バックアップ設計の選択肢が増えます。本番適用前にプレビューの制約を確認してください。

**リンク**: [Public Preview: Azure Backup for PostgreSQL flexible server and elastic cluster (v2)](https://azure.microsoft.com/updates?id=573425)

### Application Gateway WAF が IPv6 に対応（パブリックプレビュー）

**要約**: Application Gateway の Web Application Firewall (WAF) で IPv6 のサポートがパブリックプレビューとして発表されました。

**影響**: IPv6 クライアントやデュアルスタック構成のサービスでも WAF による保護を適用しやすくなり、ネットワーク・セキュリティ担当者にとって設計上の制約が減ります。

**リンク**: [Public Preview: IPv6 Support for Application Gateway WAF](https://azure.microsoft.com/updates?id=573861)

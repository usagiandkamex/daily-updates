# 2026/11/25 デイリーアップデート

## 1. Azure アップデート情報

### Azure Site Recovery が Ultra ディスクのゾーン間 DR に対応（一般提供）

**要約**: Azure Site Recovery が Azure Ultra ディスクを対象とした Zone-to-Zone Disaster Recovery（Zonal DR）をサポートし、一般提供となった。高性能が求められる仮想マシンを、同一リージョン内のゾーン障害から保護できる。

**影響**: データベースなど高 IOPS を必要とするワークロードでも、リージョン間 DR を組まずにゾーン障害対策を実装できる。可用性設計の選択肢が広がる。

**リンク**: [Generally Available: Azure Site Recovery support for zonal disaster recovery for Ultra disks](https://azure.microsoft.com/updates?id=582171)

### Foundry Agent Service：インサイトからのエージェント最適化（パブリックプレビュー）

**要約**: Foundry ポータルで、プロンプトエージェントのトレースから得られる対象のインサイトを起点にエージェントを最適化できる機能がパブリックプレビューで提供された。

**影響**: エージェントの改善サイクルをポータル上で回しやすくなる。プレビューのため、本番適用は仕様変更を前提に検証したい。

**リンク**: [Public Preview: Optimize agents from insights in Foundry Agent Service](https://azure.microsoft.com/updates?id=581483)

### Foundry Agent Service：自社ゲートウェイ経由の MCP ツール制御（パブリックプレビュー）

**要約**: MCP ツールへのトラフィックを、既存の AI Gateway や Azure API Management のエンドポイント経由でルーティングできるようになった（パブリックプレビュー）。

**影響**: 既存の API 管理基盤で認証・監視・ガバナンスを一元化でき、エージェントが外部ツールに接続する際の統制を取りやすくなる。

**リンク**: [Public Preview: Govern MCP tools with your own gateway in Microsoft Foundry Agent Service](https://azure.microsoft.com/updates?id=581498)

### Azure AI Search / Foundry IQ で Azure Storage のアクセス権限を利用可能に（一般提供）

**要約**: Azure AI Search と Foundry IQ が、対応する Azure Storage の権限を使って検索結果へのアクセスを制御できるようになり、一般提供となった。

**影響**: 社内文書を使った RAG で、元データの権限設定を検索結果に反映しやすくなり、情報漏えいリスクの低減につながる。

**リンク**: [Generally Available: Use Azure Storage permissions in Azure AI Search and Foundry IQ](https://azure.microsoft.com/updates?id=581303)

### Foundry Agent Service：ホステッドエージェントのネイティブ A2A パススルー（パブリックプレビュー）

**要約**: 既存の Agent2Agent（A2A）エージェントを、プロトコル変換層なしで Agent Service に持ち込めるようになった。従来は受信した A2A リクエストが変換されていた。

**影響**: 他基盤で構築済みの A2A エージェントを移行・連携しやすくなり、マルチエージェント構成の相互運用性が高まる。

**リンク**: [Public Preview: Native A2A passthrough for hosted agents in Foundry Agent Service](https://azure.microsoft.com/updates?id=581313)

### Foundry のコスト制御とホステッドエージェントの送信先ガバナンス（パブリックプレビュー）

**要約**: Foundry リソース／プロジェクトにトークンや支出の予算を設定し、しきい値に達した際の制御ができるコスト制御がプレビューで提供された。あわせて、Azure Policy でホステッドエージェントの送信先ドメインを管理者が統制する機能も公開された。

**影響**: エージェント運用で課題になるコスト超過と外部通信を、組織ポリシーとして管理できる。全社展開時のガードレールとして有用。

**リンク**: [Public Preview: Cost controls for model and agent spending in Microsoft Foundry](https://azure.microsoft.com/updates?id=581323) / [Public Preview: Central governance of hosted-agent outbound domains in Foundry Agent Service](https://azure.microsoft.com/updates?id=581328)

### GitHub.com の通知が 12 月 1 日から「より予測可能」に

**要約**: 2026 年 12 月 1 日から約 1 週間かけて GitHub.com の通知を移行する。手動で購読解除したスレッドは、コメント・レビュー送信・状態変更・マージキュー操作では再購読されなくなる（メンション・アサイン・レビュー依頼では引き続き再購読）。チームメンション通知は現在のメンバーシップとメンションを反映し、Subscriptions ページには手動購読したスレッドのみ表示される。GitHub Enterprise Server は対象外。

**影響**: 通知量や届く条件が変わる可能性があり、通知フィルターやメール振り分けルールの見直しが必要になる場合がある。対応は不要だが、移行期間中は挙動がユーザーごとに異なり得る。

**リンク**: [More predictable notifications on GitHub.com](https://github.blog/changelog/2026-11-24-more-predictable-notifications-on-github-com)

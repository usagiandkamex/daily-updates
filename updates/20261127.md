### Azure Virtual Network の ECMP Nexthop がパブリックプレビュー

**要約**: Azure Virtual Network 向けの Equal-Cost Multi-Path（ECMP）ルーティングがパブリックプレビューとして提供開始された。複数の等コスト経路にトラフィックを分散できる機能で、提供状況はプレビュー段階。リンク先の詳細ページは本文を取得できなかったため、対象シナリオや設定方法などの詳細は確認できていない。

**影響**: ネットワーク構成で経路分散や帯域の有効活用を検討している設計者にとって、検証対象に加える価値がある。ただしプレビューのため、本番適用は SLA やサポート範囲を確認したうえで判断する必要がある。

**リンク**: [[In preview] Public Preview: ECMP Nexthop](https://azure.microsoft.com/updates?id=582326)

### Visual Studio Code 1.149 (Insiders) のリリースノート

**要約**: VS Code 1.149 Insiders のリリースノート（2026/11/26 更新）では、2026/11/25 分として 2 点が記載されている。1 つ目は、リモートワークスペースでエージェントが入れ子のセッションを検出・確認・メッセージ送信できるようになる変更（実験的機能）。2 つ目は、リモートワークスペースで「About」ダイアログやコピーされる詳細情報に、接続タイプと（取得できる場合）リモート OS・アーキテクチャが含まれるようになる変更。なお、同ページにはローカルハーネスが非推奨で 2027 年 2 月に削除予定との告知もある。

**影響**: リモート環境でエージェントを使う開発者は、リモートのサブセッション連携が改善される可能性がある（ただし実験的機能）。サポート時の環境情報共有も楽になる。ローカルハーネスを利用しているチームは、Copilot ハーネスへの移行計画を早めに立てる必要がある。Insiders ビルド向けの内容であり、安定版への反映は別途確認が必要。

**リンク**: [Visual Studio Code 1.149 (Insiders)](https://code.visualstudio.com/updates/v1_149)

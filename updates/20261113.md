## 1. Azure アップデート情報

### Azure Front Door Auth Policy で JWT 検証がパブリックプレビュー

**要約**: Azure Front Door Premium の Auth Policy による JSON Web Token（JWT）検証がパブリックプレビューになった。Front Door のエッジでベアラートークンを検証できる機能で、プレビュー段階での提供。詳細な設定項目は本文を確認できていない。

**影響**: 認証・認可の一部をバックエンドではなくエッジ側へ寄せられる可能性がある。API 保護の実装負荷を下げる選択肢だが、プレビューのため本番適用前に SLA やサポート範囲の確認が必要。

**リンク**: [Public Preview: JWT validation with Azure Front Door Auth Policy](https://azure.microsoft.com/updates?id=577673)

### Azure Front Door の相互 TLS（mTLS）認証が一般提供

**要約**: Azure Front Door Premium でクライアント証明書（X.509）を用いた相互 TLS 認証が一般提供（GA）となった。

**影響**: B2B API や IoT など、クライアント証明書による相互認証が求められる構成で、Front Door 経由でも正式サポートのもとで運用できる。ゼロトラスト設計の要件を満たしやすくなる。

**リンク**: [Generally Available: Azure Front Door mutual TLS authentication](https://azure.microsoft.com/updates?id=577678)

### Azure Monitor ワークスペースで取り込み上限の自動スケールがプレビュー

**要約**: Azure Monitor Workspace（AMW）で、観測された使用パターンに基づきワークスペース単位で取り込み上限を自動的に拡張する機能がパブリックプレビューになった。

**影響**: メトリクス急増時の取り込み制限による欠損や手動での上限引き上げ作業を減らせる見込み。一方でコスト管理の観点から、スケール挙動の把握が必要。

**リンク**: [Public Preview: Auto scaling of ingestion limits in Azure Monitor workspace](https://azure.microsoft.com/updates?id=578207)

### Azure SQL Managed Instance 向けマネージドのパフォーマンス監視がプレビュー

**要約**: Microsoft が管理する Azure SQL Managed Instance 向けのパフォーマンス監視機能がパブリックプレビューとして利用可能になった。

**影響**: ビジネスクリティカルなワークロードの監視を、独自の監視基盤を構築せずに始められる可能性がある。既存の監視ツールとの役割分担を検討する材料になる。

**リンク**: [Public Preview: SQL performance monitoring for Azure SQL Managed Instance](https://azure.microsoft.com/updates?id=574158)

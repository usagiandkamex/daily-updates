## 1. Azure アップデート情報

### Microsoft Sentinel の SAP アプリケーション向けコンテナ型データコネクタエージェントが廃止予定

**要約**: 2026年9月14日をもって、Microsoft Sentinel の SAP アプリケーション向けソリューションで使われているコンテナ型データコネクタエージェントが廃止される。廃止後は後継の接続方式への移行が必要になる。

**影響**: SAP 環境をSentinelで監視している企業は、廃止日までに移行計画を立てる必要があり、セキュリティ運用チームの対応工数増加につながる。

**リンク**: [Retirement: Containerized data connector agent for the Microsoft Sentinel solution for SAP applications](https://azure.microsoft.com/updates?id=568457)

**影響**: 大規模な配信ルール群を運用するチームにとって、設定変更の作業効率が向上し、運用ミスのリスク低減にもつながる。

**リンク**: [[Launched] Generally Available: Batch rule updates for Azure Front Door](https://azure.microsoft.com/updates?id=569246)

### Azure Front Door に相互TLS（mTLS）機能がパブリックプレビュー

**要約**: Azure Front Door でクライアント証明書による相互TLS認証がパブリックプレビューとして利用可能になった。

**影響**: 金融・医療など高いセキュリティ要件を持つ業種で、エッジ層でのゼロトラスト認証強化が可能になり、バックエンドの負荷軽減にも寄与する。

**リンク**: [[In preview] Public Preview: Azure Front Door mutual TLS](https://azure.microsoft.com/updates?id=569251)

### Azure App Service で「Markdown for Agents」がパブリックプレビュー

**要約**: Azure App Service に、AIエージェント向けの構成情報などをMarkdown形式で記述・管理できる新機能がパブリックプレビューとして追加された。

**影響**: App Service上でAIエージェントを構築・運用する開発者にとって、エージェントの振る舞いや設定をドキュメントとして一元管理しやすくなる。

## 1. Azure アップデート情報

### PowerShell 7.4 のサポートが2026年11月10日に終了

**要約**: Azure Functions における PowerShell 7.4 のサポートが2026年11月10日に終了することが発表された。既存アプリはそのまま動作するが、Microsoftは期限までに PowerShell 7.6 への移行を推奨している。

**影響**: PowerShell ベースの Azure Functions を運用しているチームは、セキュリティ更新の提供対象から外れる前にランタイムのアップグレード計画を立てる必要がある。

**リンク**: [Retirement: Support for PowerShell 7.4 ends on November 10, 2026](https://azure.microsoft.com/updates?id=572770)

### .NET 8/9 のサポートが2026年11月10日に終了、.NET 10への移行を推奨

**要約**: .NET 8 および .NET 9 のサポートが2026年11月10日に終了することが発表された。Azure Function Apps は稼働を継続するが、Microsoftは期限までに .NET 10 への移行を求めている。

**影響**: .NET 8/9 上で Azure Functions を運用する開発チームは、サポート終了後のセキュリティリスクを避けるため、早めにランタイム更新の計画を進める必要がある。

**リンク**: [Retirement: Support for .NET 8 and .NET 9 ends on November 10, 2026—upgrade your apps to .NET 10](https://azure.microsoft.com/updates?id=572838)

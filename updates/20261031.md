### Azure SQL Database でデータベースレベルのマネージド ID（FIC 含む）がパブリックプレビュー

**要約**: Azure SQL Database で、データベースごとにユーザー割り当てマネージド ID を設定できるデータベースレベルのマネージド ID（フェデレーション ID 資格情報 FIC を含む）がパブリックプレビューになりました。この ID を使い、Azure Blob Storage 上のファイルへのクエリなどをデータベース単位の権限で実行できます。

**影響**: サーバー単位の ID を共有せず、データベースごとに最小権限でストレージアクセスを設計できるため、マルチテナント構成やセキュリティ監査での権限分離がしやすくなります。プレビューのため、本番適用は仕様と制限事項の確認が必要です。

**リンク**: [[In preview] Public Preview: Support database-level managed identity (including FIC) in Azure SQL Database](https://azure.microsoft.com/updates?id=577491)

**リンク**: [Generally Available: Vector search and vector indexes in Azure SQL](https://azure.microsoft.com/updates?id=571800)

**リンク**: [Generally Available: Azure SQL Managed Instance updates for late-Sept](https://azure.microsoft.com/updates?id=571632)

### Azure Extended Zones にルクセンブルクが登場

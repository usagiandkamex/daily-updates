## 1. Azure アップデート情報

### Foundry IQ に Enterprise Knowledge Graph がパブリックプレビュー

**要約**: Foundry IQ に「Enterprise Knowledge Graph」がナレッジソースとして追加された。コンテンツ間の関係性に依存する質問に答えるためのもので、インデックス作成時にコンテンツから情報を抽出して関係を構造化する。提供状況はパブリックプレビュー。

**影響**: 複数文書にまたがる関係性（取引先と契約、部門と製品など）を問うエージェントの回答品質向上が期待できる。ただしプレビューのため、本番採用は精度とコストの検証後が現実的。

**リンク**: [Public Preview: Enterprise Knowledge Graph in Foundry IQ](https://azure.microsoft.com/updates?id=581333)

### Foundry IQ の IQ Retriever Zero と Files ナレッジソース

**要約**: IQ Retriever Zero（パブリックプレビュー）は、複雑な質問を焦点を絞った複数の検索に分解し、結果を見て再検索する反復型の検索モデル。あわせて Files ナレッジソースが一般提供（GA）となり、ファイルを管理対象のナレッジソースへ直接アップロードすると、Foundry IQ が処理・インデックス化し、ナレッジベース経由で検索できる。

**影響**: 独自の取り込みパイプラインを組まなくても社内ファイルを RAG に使えるため、PoC の立ち上げが速くなる。反復検索は精度向上が見込める一方、検索回数増による遅延・コストの確認が必要。

**リンク**: [Public Preview: IQ Retriever Zero in Foundry IQ](https://azure.microsoft.com/updates?id=581343) / [GA: Files knowledge source for Foundry IQ](https://azure.microsoft.com/updates?id=581368)

**リンク**: [Public Preview: Updated Guardrails experience in Microsoft Foundry](https://azure.microsoft.com/updates?id=581338)

### Foundry の Agent insights が GA、人手による評価アノテーションはプレビュー

**要約**: Agent insights はエージェントのトレースを分析して繰り返し現れるパターンを抽出し、関連する問題をグループ化する機能で GA となった。インサイトと根拠となるトレースを併せて確認できる。また、エージェント評価に人手によるアノテーションを加える機能がパブリックプレビューで提供される。

**影響**: 大量のトレースを目視で追う負担が減り、改善点の優先順位付けがしやすくなる。自動評価に人の判断を重ねられるため、評価の信頼性向上にも寄与する。

**要約**: model router をあらかじめデプロイしなくても利用できるようになった。対応リージョンで Responses API の model に `auto` を指定する方式。さらに Messages API への対応や、既存のモデルデプロイをルーティング先に使う機能もプレビューで追加された。

**影響**: モデル選択をルーターに任せる導入の手間が下がり、既存デプロイとの併用で移行も容易になる。コスト・品質の最適化を試しやすくなる。

**リンク**: [Public Preview: Call model router without a deployment](https://azure.microsoft.com/updates?id=581378) / [Use the Messages API with model router](https://azure.microsoft.com/updates?id=581383) / [Use your model deployments with model router](https://azure.microsoft.com/updates?id=581388)

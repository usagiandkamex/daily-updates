### DCsv3 / DCdsv3 シリーズ Azure VM の提供終了を告知

**要約**: 2029年10月31日をもって、DCsv3 および DCdsv3 シリーズの Azure Linux・Windows・Dedicated Host 仮想機器が廃止されます。それ以降は利用できなくなります。

**影響**: Confidential Computing 系 VM を利用しているチームは、後継シリーズへの移行計画を早めに立てる必要があります。猶予は数年ありますが、構成の棚卸しと検証を段階的に進めるのが現実的です。

**リンク**: [Retirement: DCsv3 and DCdsv3-series Azure Virtual Machines will be retired](https://azure.microsoft.com/updates?id=569592)

**リンク**: [GitHub-hosted agents with Pay-as-you-Go pricing are now generally available in Azure Pipelines](https://devblogs.microsoft.com/devops/github-hosted-agents-with-pay-as-you-go-pricing-are-now-generally-available-in-azure-pipelines/)

# 2026/09/30 デイリーアップデート

## 1. Azure アップデート情報

### Azure Container Apps 上の Azure Functions v1 ホスティングモデルが廃止予定

**要約**: Azure Container Apps 上の Azure Functions v1 ホスティングモデルが 2027 年 9 月 29 日に廃止されることが告知されました。廃止日以降、該当モデルで動作する既存の Functions アプリは影響を受けます。

**影響**: 該当のアプリを運用している開発者・運用チームは、廃止日までに後継のホスティングモデルへの移行計画を立てる必要があります。1 年ほどの猶予があるため、棚卸しと検証を早めに進めるのが得策です。

**リンク**: [Retirement: Azure Functions v1 hosting model on Azure Container Apps](https://azure.microsoft.com/updates?id=570800)

### ストレージ最適化 VM「Lasv5 / Laosv5」シリーズが一般提供開始

**要約**: 第 5 世代 AMD EPYC（Turin）プロセッサベースのストレージ最適化 VM、Lasv5 および Laosv5 シリーズが一般提供（GA）となりました。

**影響**: ローカルストレージの I/O 性能が重要なデータベースやログ処理などのワークロードで、新世代 CPU への更新候補になります。リージョンや価格は公式情報で確認してください。

**リンク**: [Generally Available: Storage optimized Lasv5 and Laosv5 Azure VM series](https://azure.microsoft.com/updates?id=572630)

### VM Scale Sets の Automatic Zone Placement（パブリックプレビュー）

**要約**: VM Scale Sets において、Azure が最適な可用性ゾーンを自動的に選択する Automatic Zone Placement がパブリックプレビューとして公開されました。

**影響**: ゾーン配置の設計・運用の手間が減り、容量不足によるデプロイ失敗の回避にもつながる可能性があります。プレビュー段階のため、本番適用は仕様と制限を確認したうえで判断してください。

**リンク**: [Public Preview: Automatic Zone Placement for Virtual Machine Scale Sets](https://azure.microsoft.com/updates?id=571075)

### Azure Database for PostgreSQL に Ultra Disk サポート（パブリックプレビュー）

**要約**: Azure Database for PostgreSQL フレキシブルサーバーで、Azure 最高性能のマネージドディスクである Ultra Disk がパブリックプレビューで利用可能になりました。

**影響**: 高い IOPS やスループットを要する PostgreSQL ワークロードでの性能改善が期待できます。プレビューのため、性能検証とコスト確認から始めるのが現実的です。

**リンク**: [Public Preview: Azure Database for PostgreSQL Ultra Disk](https://azure.microsoft.com/updates?id=571909)

### Azure SQL Database の SQL パフォーマンス監視（パブリックプレビュー）

**要約**: Microsoft が管理するパフォーマンス監視機能が Azure SQL Database 向けにパブリックプレビューとなりました。

**影響**: 監視基盤を自前で構築せずにパフォーマンス状況を把握しやすくなり、運用負荷の軽減が見込まれます。

**リンク**: [Public Preview: SQL Performance Monitoring for Azure SQL Database](https://azure.microsoft.com/updates?id=571867)

### PostgreSQL フレキシブルサーバーがクロステナントのカスタマーマネージドキーに対応

**要約**: Azure Database for PostgreSQL フレキシブルサーバーが、別テナントの Key Vault に保管したキーによるクロステナントのカスタマーマネージドキー（CMK）暗号化に対応し、GA となりました。

**影響**: 複数テナントにまたがる組織や、マネージドサービス提供事業者で、鍵管理を分離したままデータ暗号化を行う要件に応えやすくなります。

**リンク**: [Generally Available: Azure Database for PostgreSQL Flexible Server supports cross-tenant CMK](https://azure.microsoft.com/updates?id=571783)

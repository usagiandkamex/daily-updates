### Azure Arc 対応 Kubernetes 向け Key Vault Secrets Provider 拡張機能の提供終了を告知

**要約**: Azure Arc 対応 Kubernetes クラスター向けの「Azure Key Vault Secrets Provider Extension」が 2027 年 10 月 9 日に提供終了となることが告知されました。現在この拡張機能を利用しているユーザーが対象です。本日の収集分では Azure の更新情報はこの 1 件のみでした。

**影響**: 提供終了まで約 1 年の猶予があります。Arc 対応クラスターでシークレット連携に利用している場合は、代替手段の確認と移行計画を早めに立てておくことが重要です。

**リンク**: [Retirement: Azure Key Vault Secrets Provider Extension for Azure Arc enabled Kubernetes clusters](https://azure.microsoft.com/updates?id=570313)

### [Launched] Generally Available: NAT64 on StandardV2 NAT Gateway

**要約**: StandardV2 NAT GatewayがNAT64をサポートするようになり、IPv6ワークロードがIPv4のみのインターネット宛先と通信できるようになりました。

**影響**: このアップデートにより、IPv6を採用している組織が、既存のIPv4インフラストラクチャとの互換性を維持しながら、よりスムーズに移行を進めることが可能になります。

**リンク**: [Generally Available: NAT64 on StandardV2 NAT Gateway](https://azure.microsoft.com/ja-jp/updates?id=568409)

### [Launched] Generally Available: Application Routing with Gateway API

**要約**: Kubernetesの最新標準を採用しながら、既存のデプロイメントを維持するためのアプリケーションルーティングが一般提供されました。この機能は、Gateway APIを活用して、インバウンドトラフィックの管理を簡素化します。

**影響**: Kubernetesクラスタの管理者は、アプリケーションルーティングの効率を向上させ、モダナイゼーションの取り組みを加速することができます。

**リンク**: [Generally Available: Application Routing with Gateway API](https://azure.microsoft.com/ja-jp/updates?id=567944)

### [Launched] Generally Available: Resource placement in Azure Kubernetes Fleet Manager

**要約**: Azure Kubernetes Fleet Managerでのリソース配置機能が一般提供されました。この機能により、複数のクラスタ間でのリソース管理が効率化されます。

**影響**: Kubernetesクラスタを複数運用している組織は、更新作業や一貫性の維持にかかる手間を大幅に削減できるようになります。

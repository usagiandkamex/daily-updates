### GitHub Copilot Fusion が正式リリース

**要約**: GitHub は 10 月 28〜29 日に開催した GitHub Universe 2026 で、マルチモデル機能「GitHub Copilot Fusion」の正式リリースを発表した。タスクの特性（推論・コード生成・デバッグ・ツール利用など）を評価し、Single（単一モデル）、Cascade（効率的なモデルが案を作り、検証用モデルが上位モデルへのエスカレーション要否を判断）、Critique（別系統のモデルが独立レビューし、指摘を基に 1 回だけ修正）のいずれかのパターンを自動選択する。品質・コスト・待機時間のバランスを調整する負荷レベルとして Standard / High / Max が用意され、Fast は高速モデルが必要な場面で自動選択され利用者は指定できない。パブリックプレビューとして、Fusion Standard でローカルにインストールした MAI Code 1.1 Flash または Qwen3.8 Flash Next モデルを選択して実行することもできる。

**影響**: 開発者はモデル選択を個別に管理する負担が減り、性能とコストのバランスを機能側に任せられる。チームでは、負荷レベルの選び方が AI 利用コストの運用ポイントになる。

**リンク**: [GitHub、「Copilot Fusion」正式リリース。タスクに応じて最適なAIモデル選択で高性能かつ低コストに。GitHub Universe 2026](https://www.publickey1.jp/blog/26/githubcopilot_fusionaigithub_universe_2026.html)

### Visual Studio Code 1.145 (Insiders): Agents ウィンドウの改善

**要約**: Insiders 版 1.145 のリリースノート（10 月 26〜28 日分）では、Agents ウィンドウで一括ワークツリー削除の進捗を追跡でき、完了結果を表示したまま失敗した削除を再試行できるようになった。また、リモートエージェントホスト上で動作する Web アプリを Agents ウィンドウの統合ブラウザーでプレビューできる（実験的機能）。スクリーンリーダーモードでの MCP 認証プロンプトのキーボード操作も修正された。いずれも Insiders ビルドでの変更であり、リリースノートは随時更新される。

**影響**: エージェント中心の開発フローで増えるワークツリーの管理や、リモート環境での動作確認が扱いやすくなる。実験的機能や Insiders 限定の変更が含まれるため、安定版への反映は今後のリリースで確認が必要。

**リンク**: [Visual Studio Code 1.145 (Insiders)](https://code.visualstudio.com/updates/v1_145)

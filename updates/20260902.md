# 2026/09/02 デイリーアップデート

## 1. Azure アップデート情報

### Microsoft Defender for Cloud が Azure Container Apps に対応

**要約**: Azure Container Apps 環境を Microsoft Defender for Cloud の「Serverless Containers Posture」に統合できるようになった。サーバーレスコンテナ環境のセキュリティ姿勢を可視化・評価できる機能が一般提供開始となった。

**影響**: サーバーレスコンテナを採用する企業にとって、脆弱性やミスコンフィグレーションの早期発見がしやすくなり、セキュリティ運用の一元管理が進む。

**リンク**: [Generally Available: Microsoft Defender for Cloud support for Azure Container Apps (Serverless Containers Posture)](https://azure.microsoft.com/updates?id=570282)

### AKS で Windows Server 2025 が一般提供開始

**要約**: Azure Kubernetes Service (AKS) 上で Windows Server 2025 ベースのノードプールが利用可能になった。既存 Windows ワークロードのサポート期限対応やモダナイゼーションを後押しする。

**影響**: Windows 資産を抱える企業がコンテナ移行を進めやすくなり、サポート切れリスクの回避と運用効率化につながる。

**リンク**: [Generally Available: Windows Server 2025 on AKS](https://azure.microsoft.com/updates?id=570090)

### AKS で Artifact Streaming が一般提供開始

**要約**: Azure Container Registry (ACR) と連携し、コンテナイメージを事前にフルダウンロードせず起動できる Artifact Streaming が GA。大規模イメージの起動時間を短縮する。

**影響**: コンテナのコールドスタート時間が短縮され、スケールアウトやデプロイの高速化を求める開発チームにメリットがある。

**リンク**: [Generally Available: Artifact Streaming on AKS](https://azure.microsoft.com/updates?id=570095)

### Azure Linux 向け機密仮想マシンが GA

**要約**: AKS 上で Azure Linux 向けの Confidential VM (CVM) が一般提供開始。強固なセキュリティと機密性をコンテナ基盤でも実現する。

**影響**: 金融・医療など機密データを扱う業界で、ハードウェアレベルの分離を伴う安全なワークロード実行が選択肢として広がる。

**リンク**: [Generally Available: Confidential VMs for Azure Linux](https://azure.microsoft.com/updates?id=570100)

### Azure Firewall の SNAT ルート自動学習が GA

**要約**: Azure Firewall が登録済み・プライベートの宛先プレフィックスを定期的に自動学習し、SNAT 除外ルートを自動更新する機能が一般提供開始。

**影響**: ネットワーク管理者の手動設定負荷が減り、アドレス変更にも自動追随するため運用ミスによる通信障害リスクが下がる。

**リンク**: [Generally Available: Azure Firewall auto-learn SNAT routes](https://azure.microsoft.com/updates?id=570474)

### Azure Copilot Observability Agent が Basic/Auxiliary テーブルプランに対応

**要約**: Azure Monitor の AI 運用支援エージェントである Azure Copilot Observability Agent が、Log Analytics の Basic および Auxiliary テーブルプランのデータもカバーするようになった。

**影響**: コスト重視の低頻度アクセスログでも AI による運用支援を受けられるようになり、大規模ログ運用のコストとオブザーバビリティの両立がしやすくなる。

**リンク**: [Generally Available: Azure Copilot Observability Agent supports Basic and Auxiliary table plans](https://azure.microsoft.com/updates?id=570250)

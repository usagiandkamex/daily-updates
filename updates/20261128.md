### MCP に「Skills over MCP」がβ版で追加

**要約**: AI エージェントと外部ツールをつなぐ MCP に、ツールの使い方を記したスキルを MCP サーバ経由で提供する「Skills over MCP」がβ版として加わりました。従来は SKILL.md などのスキルファイルをエージェント実行環境に置いて渡しており、ツール更新後にスキルが古いまま残る、多数のスキルを最初から読み込むとコンテキストが増える、といった課題がありました。新機能では最新のスキルを MCP サーバから取得でき、必要なときだけ読み込めます。

**影響**: MCP サーバの提供者はツールと使い方を一体で配布・更新でき、利用側はスキル管理の手間とコンテキスト消費を抑えられます。ただしβ版のため仕様変更の可能性があります。

**リンク**: [MCPに新機能「Skills over MCP」登場](https://www.itmedia.co.jp/news/article/2611/27/2000003513/)

### Claude の MCP 連携が 4 機能に対応

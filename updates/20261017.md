### Azure Databricks の Private network gateway がパブリックプレビュー

**要約**: Azure Databricks の Private network gateway がパブリックプレビューとして提供開始されました。サーバーレスコンピューティングから、利用者の仮想ネットワーク（VNet）内のリソースへ接続できるようになります。

**影響**: サーバーレスのデータ処理基盤を使いながら、VNet 内のデータソースへプライベートに接続する構成を取りやすくなります。ネットワーク要件の厳しい企業でのサーバーレス採用の後押しになりますが、プレビュー段階のため本番適用前に仕様確認が必要です。

**リンク**: [[In preview] Public Preview: Azure Databricks Private network gateway](https://azure.microsoft.com/updates?id=576556)

### Azure Key Vault Managed HSM の外部キー管理が一般提供開始

**要約**: Azure Key Vault Managed HSM の外部キー管理（External key management）が、すべての Azure パブリックリージョンで一般提供（GA）となりました。

**影響**: 暗号鍵の管理をより柔軟に制御したい金融・公共などの規制業界にとって、鍵管理の選択肢が広がります。GA により本番ワークロードでも採用を検討しやすくなります。

**リンク**: [[Launched] Generally Available: External key management for Azure Key Vault Managed HSM](https://azure.microsoft.com/updates?id=574296)

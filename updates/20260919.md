**要約**: Microsoft Foundry Agent Service において、エージェントの処理フローを再利用可能な形で定義できる新機能「Foundry Routines」がパブリックプレビューとして提供開始された。

**要約**: Microsoft Foundry のエージェントを、Agent 365 上で有効化・無効化できる管理機能が一般提供（GA）となった。組織内で稼働するエージェントの管理者による制御が可能になる。

**影響**: エージェントが急増する企業において、ガバナンスやコンプライアンス上の理由から特定エージェントを即座に停止できるようになり、AIエージェント運用のリスク管理が強化される。

**リンク**: [[Launched] Generally Available: Enable and disable controls for Microsoft Foundry agents in Agent 365](https://azure.microsoft.com/updates?id=571826)

### ホスト型エージェント向けネットワーク送信制御がパブリックプレビュー

**要約**: Microsoft Foundry でホストされるエージェントに対し、ネットワークの送信（egress）トラフィックを制御できる機能がパブリックプレビューとして公開された。

**影響**: エージェントが外部リソースへ不必要にアクセスするリスクを抑えられ、セキュリティ要件の厳しい業界でのエージェント導入のハードルが下がる。

**リンク**: [[In preview] Public Preview: Network egress controls for hosted agents in Microsoft Foundry](https://azure.microsoft.com/updates?id=571821)

### Microsoft Foundry エージェントを Microsoft 365 Copilot と Teams に公開する機能が一般提供開始

**要約**: Microsoft Foundry で構築したエージェントを、Microsoft 365 Copilot および Teams 上に直接公開できる機能が一般提供（GA）となった。

**影響**: 業務アプリ側での追加開発なしに、社内向けカスタムエージェントを日常業務のツールに組み込めるようになり、AIエージェントの社内展開が加速する。

**リンク**: [[Launched] Generally Available: Publishing Microsoft Foundry agents to Microsoft 365 Copilot and Teams](https://azure.microsoft.com/updates?id=571816)

### Azure Database for PostgreSQL でトラブルシューティングガイドが刷新

**要約**: Azure Database for PostgreSQL 向けに、新しく改善されたトラブルシューティングガイドが一般提供（GA）として公開された。

**影響**: 運用担当者が障害発生時に迅速に原因を特定しやすくなり、PostgreSQL運用の負荷軽減とダウンタイム短縮につながる。

**リンク**: [[Launched] Generally Available: New and improved troubleshooting guides for Azure Database for PostgreSQL](https://azure.microsoft.com/updates?id=571042)

### Azure Database for PostgreSQL 弾力性クラスターが PostgreSQL 18 に対応

**要約**: Azure Database for PostgreSQL の弾力性クラスター（elastic clusters）が、最新のPostgreSQL 18に対応したことが発表され、一般提供（GA）となった。

**影響**: 最新バージョンの機能・パフォーマンス改善を大規模分散PostgreSQL環境で早期に活用できるようになり、データベース基盤の刷新を検討する企業にとって選択肢が広がる。

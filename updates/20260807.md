## 1. Azure アップデート情報

### Azure Databricks Genie One / Genie Agents の無料利用が2027年1月末まで延長

**要約**: Azure Databricks の生成AI機能「Genie One」「Genie Agents」の無料利用期間が、従来の2026年7月31日から2027年1月31日まで延長されると発表された。

**影響**: 有償化前に無料でGenie系エージェント機能を試せる期間が半年延びるため、データ分析・BI領域でのAIエージェント活用を検討する企業にとって、導入検証のハードルが下がる。

**参考リンク**: [Announcing: Azure Databricks Genie One and Genie Agents Free Usage Extended Through January 31, 2027](https://azure.microsoft.com/updates?id=568964)

### AWS FSx for Windows File Server から Azure Files への移行が Azure Storage Mover でプレビュー開始

**要約**: Azure Storage Mover が、AWS FSx for Windows File Server（SMB）から Azure Files（SMB）へのエージェントレスなクラウド間移行をプレビューでサポートした。

**影響**: マルチクラウド環境からAzureへファイルサーバーを移行したい企業にとって、専用エージェント不要で移行作業を簡素化できる選択肢が増える。クラウド移行プロジェクトの工数削減につながる。

**参考リンク**: [[In preview] Public Preview: Migrate from AWS FSx for Windows File Server to Azure Files with Azure Storage Mover](https://azure.microsoft.com/updates?id=567979)

### Azure Boards の作業項目カードにプルリクエストの注釈を表示

**要約**: Azure DevOps の Kanban ボードにおいて、作業項目カード上に直接プルリクエストの状態を表示できるようになった。ボードを離れずに開発進捗を追跡できる。

**影響**: 開発チームのリード・マネージャーは、別画面を開かずにPRのレビュー状況を確認でき、進捗管理の手間が減る。開発の可視性向上に寄与する。

**参考リンク**: [Pull request annotations on work item cards](https://devblogs.microsoft.com/devops/pull-request-annotations-on-work-item-cards/)

### PAT やビルドセッショントークンに代わる Azure DevOps Service Connection

**要約**: パイプラインから Azure DevOps へアクセスする新しい方式として、Microsoft Entra ワークロードIDベースの「Azure DevOps service connection」が発表された。

**影響**: 個人アクセストークン（PAT）の管理・失効リスクを避けられるため、セキュリティ担当者やDevOpsエンジニアにとって認証情報管理の負担軽減とセキュリティ強化につながる。

**参考リンク**: [You can now use the Azure DevOps Service Connection instead of a PAT or Build Session token](https://devblogs.microsoft.com/devops/you-can-now-use-the-azure-devops-service-connection-instead-of-a-pat-or-build-session-token/)

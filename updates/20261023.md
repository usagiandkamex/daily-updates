## 1. Azure アップデート情報

### Azure Data Lake Storage の ABFS Vectored Read が一般提供（GA）

**要約**: Azure Data Lake Storage 向けの「ABFS Vectored Read」が GA となりました。対応する分析エンジンが、選択的な読み取り（必要な部分だけを読む処理）でのリクエストのオーバーヘッドを減らせる機能です。

**影響**: Parquet などのカラムナー形式を扱う分析基盤で、読み取りリクエスト数の削減によるレイテンシ短縮・コスト低減が期待できます。データ基盤を運用する開発者は、利用中のエンジンが対応しているか確認する価値があります。

**リンク**: [Generally Available: ABFS Vectored Read for Azure Data Lake Storage](https://azure.microsoft.com/updates?id=577618)

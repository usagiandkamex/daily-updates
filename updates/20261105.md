## 1. Azure アップデート情報

### Azure Database for PostgreSQL の安定版 REST API 2026-10-01 が一般提供

**要約**: Azure Database for PostgreSQL Flexible Server の REST API バージョン 2026-10-01 が一般提供（GA）になった。プレビューではなく安定版の API として、機能拡張が加えられている。個別の追加項目は元記事の詳細を確認できなかったため、ここでは GA となった事実のみを記載する。

**影響**: IaC（Bicep / ARM / Terraform など）や自動化スクリプトで安定版 API バージョンを指定できるようになり、本番運用でも新しい API 仕様を採用しやすくなる。API バージョンの更新時は既存テンプレートの互換性確認が望ましい。

**リンク**: [[Launched] Generally Available: Azure Database for PostgreSQL stable REST API version 2026-10-01](https://azure.microsoft.com/updates?id=579300)

### Azure Route Server のルートマップが一般提供

**要約**: Azure Route Server の「ルートマップ」が Azure パブリッククラウドで一般提供となった。ルートマップは、インバウンド／アウトバウンドのルートに対して細かな制御を行う機能である。

**影響**: NVA（ネットワーク仮想アプライアンス）や SD-WAN と連携するハブ&スポーク構成で、経路広告のフィルタリングや調整を柔軟に行える。ネットワーク設計者にとって、経路制御のためにアプライアンス側へ依存する部分を減らせる可能性がある。

**リンク**: [Generally Available: Route maps for Azure Route Server](https://azure.microsoft.com/updates?id=578966)

### Azure Firewall の IPv6 でアプリケーションルートがパブリックプレビュー

**要約**: Azure Firewall が IPv6 の HTTP/HTTPS トラフィックに対するレイヤー 7 のアプリケーションルールをパブリックプレビューでサポートした。

**影響**: IPv6 対応が進むワークロードでも、FQDN ベースなどのアプリケーション層フィルタリングを適用できる方向に進む。プレビュー段階のため、本番適用前に制約と SLA の確認が必要。

**リンク**: [Public Preview: Azure Firewall IPv6 now supports application rules](https://azure.microsoft.com/updates?id=579507)

### Premium SSD v2 / Ultra Disk 搭載 VM のマルチディスク クラッシュ整合性復元ポイント（プレビュー）

**要約**: SCSI ディスクコントローラーを使う Azure VM で、Premium SSD v2 および Ultra Disk のデータディスクに対するマルチディスクのクラッシュ整合性復元ポイントがパブリックプレビューとして利用可能になった。

**影響**: 高性能ディスクを複数使うデータベースなどのワークロードで、ディスク間の整合性を保った復旧ポイントを取得しやすくなる。バックアップ・DR 設計の選択肢が増えるが、プレビューのため要件確認が必要。

**リンク**: [Public Preview: Multi-disk crash-consistent VM restore points for Premium SSD v2 and Ultra Disks on VMs with SCSI disk controller](https://azure.microsoft.com/updates?id=579162)

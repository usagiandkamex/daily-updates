### Visual Studio Code 1.147 Insiders：エディターのタブバーと Agents ウィンドウの強化

**要約**: 2026年11月13日更新のリリースノート（11月10〜12日分）によると、エディターのタブバーに「+」ボタンが追加され、テキストファイル・Markdown・チャット・統合ブラウザのタブを作成できます（実験的機能）。新規の無題ファイルでは、コード生成、チャット開始、言語選択などの操作候補を表示する試みもあります。Agents ウィンドウでは、Open Folder ダイアログが選択中フォルダーの親から始まり、ワークツリーのクリーンアップエディターでフィルターと並べ替えが使えます。エージェントセッションは、同じエージェントホストを使う WSL・Remote - SSH・Dev Container のウィンドウ間で共有できます。チャットに貼り付けた画像は元ファイル名で命名され、HTML/CSS の `#region` コメントがミニマップのセクションヘッダーに表示されます。タイトルバーにボタンを追加する `contribTitleBar` API が提案され、実験的な「AI Usage Statistics」ステータスバーウィジェットは削除されました。いずれも Insiders ビルドの内容で、多くは実験段階です。

**影響**: リモート開発環境とローカルでエージェントセッションを共有できるため、複数環境をまたぐ AI 支援開発の作業継続性が高まります。拡張機能開発者は新しい提案 API の動向を確認しておくとよいでしょう。実験的機能は安定版への反映時期が未確定のため、業務利用は正式提供を待つのが無難です。

**リンク**: [Visual Studio Code 1.147 (Insiders)](https://code.visualstudio.com/updates/v1_147)

### Cloudflare、AI 専用の軽量ヘッドレスブラウザ「Kitesurf」をオープンソース化

**要約**: Kitesurf は、タブや拡張機能を持たない AI エージェント専用のヘッドレスブラウザです。Cloudflare によると Chromium 比で CPU・メモリ効率が 3〜7 倍優れています。主に Rust で書かれ、WebAssembly にコンパイルして Cloudflare Workers 上で動作し、Wrangler でローカル実行もできます。Chrome DevTools Protocol に対応し、Puppeteer などから接続できます。

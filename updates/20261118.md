# 2026/11/18 デイリーアップデート

## 1. Azure アップデート情報

### Azure Disk Storage のイミュータブルスナップショットがパブリックプレビュー

**要約**: Azure Disk Storage のイミュータブル（変更不可）スナップショットがパブリックプレビューになった。Azure Backup のイミュータブル Vault を補完する位置づけの機能。

**影響**: ランサムウェアや誤操作によるバックアップ改ざん・削除への備えとして、ディスク単位の保護を強化できる。プレビューのため、本番適用前に仕様と制限の確認が必要。

**リンク**: [Public Preview: Immutable snapshots for Azure Disk Storage](https://azure.microsoft.com/updates?id=581503)

### Azure Boost による NVMe ディスクの可観測性ツールを発表

**要約**: 互換性のある Azure VM 内で実行するオープンソースのコマンドラインツール「Azure Boost observability for NVMe disks」が発表された。Azure Boost を基盤とするツールで、NVMe ディスクの状況を可視化する。

**影響**: ストレージ性能の調査をゲスト OS 側から行いやすくなり、I/O 遅延などのトラブルシューティングに役立つ。

**リンク**: [Announcing: Azure Boost observability for NVMe disks](https://azure.microsoft.com/updates?id=581227)

### Cobalt 200 搭載の Arm ベース VM 各シリーズが一般提供

**要約**: Cobalt 200 を採用した Dpsv7・Dplsv7（汎用）、Epsv7（メモリ最適化）、Mpsv4（大容量メモリ）、Lpsv5（高密度ストレージ）の各 VM が一般提供（GA）になった。

**影響**: 用途別に Arm ベースの選択肢が揃い、コスト効率や電力効率を重視するワークロードの移行検討がしやすくなる。

**リンク**: [Generally Available: Cobalt 200 Arm-based Dplsv7, Dpsv7, Epsv7, Mpsv4, and Lpsv5-series Virtual Machines](https://azure.microsoft.com/updates?id=581298)

### Azure Database for PostgreSQL に Intel/AMD v6（ローカル一時ディスク付き）が GA

**要約**: Azure Database for PostgreSQL Flexible Server で、ローカル一時ディスクを備えた Intel および AMD v6 コンピュートティアが一般提供された。

**影響**: 一時ディスクを多用するクエリ（ソートや一時テーブルなど）を持つワークロードで、ハードウェア選択の幅が広がる。

**リンク**: [Generally Available: Intel and AMD v6 with temp disk for Azure Database for PostgreSQL](https://azure.microsoft.com/updates?id=579590)

### Azure Database for PostgreSQL に Cobalt 200 コンピュートが GA

**要約**: Azure Database for PostgreSQL Flexible Server で、Arm ベースの Cobalt 200 コンピュートが一般提供された。同サービスの選択肢を拡張するもの。あわせて Intel/AMD v5 のディスクレス（diskless）ティアも GA となっている。

**影響**: データベース基盤でも Arm の選択肢が現実的になり、コスト最適化の検討対象が増える。

**リンク**: [Generally Available: Cobalt 200 compute for Azure Database for PostgreSQL](https://azure.microsoft.com/updates?id=579585)

### Azure HorizonDB でジオ冗長バックアップと復元が利用可能に

**要約**: Azure HorizonDB でジオ冗長バックアップと復元が利用可能になった。ジオ冗長バックアップを使うことで、別リージョンにバックアップを保持して復元できる。

**影響**: リージョン障害を想定した DR 要件を満たしやすくなる。

**リンク**: [Generally Available: Geo-redundant backup and restore for Azure HorizonDB](https://azure.microsoft.com/updates?id=574168)

## 2. Microsoft アップデート情報

### MAI Code 2 / MAI Code 2 Flash が GitHub Copilot に登場

**要約**: Microsoft AI の次世代コーディングモデル「MAI Code 2」（汎用・複雑なデバッグや複数ファイル実装向け）と「MAI Code 2 Flash」（軽量・低コストで日常作業向け）が GitHub Copilot で利用可能に。MAI Code 2 は Pro / Pro+ / Max / Business / Enterprise、Flash は Free / Student を含む各プランで、VS Code、Copilot CLI、github.com、JetBrains などのモデルピッカーから選択できる。使用量ベース課金の対象。

**影響**: タスクの重さに応じてモデルを使い分けられる。Business / Enterprise では管理者がモデルポリシーでアクセスを制御でき、新モデルは既定で有効になる点に注意。

**リンク**: [MAI Code 2 and MAI Code 2 Flash in GitHub Copilot](https://github.blog/changelog/2026-11-17-mai-code-2-and-mai-code-2-flash-in-github-copilot)

### Copilot code review に Adaptive（適応型）レビュー、シークレット検出など

**要約**: PR の複雑さとリスクに応じて Lite / Balanced / Max から自動でレビュー深度を選ぶ「Adaptive」がパブリックプレビューに。関連する公開リポジトリを参照するクロスリポジトリコンテキストや、露出したシークレットの検出も追加された。Adaptive は組織・リポジトリで設定した上限を超えない。

**影響**: ドキュメント修正は軽く、認証ロジック変更は深く、といった運用を手動設定なしで実現できる。レビューコストと精度のバランスを取りやすい。

**リンク**: [Copilot code review: Adaptive effort, secret detection, and more](https://github.blog/changelog/2026-11-17-copilot-code-review-adaptive-effort-secret-detection-and-more)

### GitHub Copilot CLI が Microsoft Entra サインインに対応（プレビュー）

**要約**: Copilot CLI で Microsoft Entra 認証がパブリックプレビューに。OIDC 利用の Enterprise Managed User 向けサイレント SSO や、Microsoft 365 Copilot ライセンス（Frontier 組織・使用量ベース課金）の利用が可能。現在は Windows と macOS が対象で、Linux は今後対応。CLI 1.0.113 以降が必要。

**影響**: 企業の ID 基盤に沿った認証で CLI を展開しやすくなる。M365 Copilot 経由では GitHub アカウント不要となる。

**リンク**: [GitHub Copilot CLI adds Microsoft Entra sign-in as a preview](https://github.blog/changelog/2026-11-17-github-copilot-cli-adds-microsoft-entra-sign-in-as-a-preview)

### GitHub Copilot Evals がパブリックプレビュー

**要約**: スキル・エージェント・MCP ツールの挙動を繰り返し検証できる「GitHub Copilot Evals」が公開された。`/eval` コマンドなどで eval を作成・実行し、合否や失敗理由、カスタマイズ前後の比較を確認できる。VS Code 拡張、Copilot CLI プラグイン、Copilot アプリで利用可能。

**影響**: プロンプトやスキル変更時の回帰確認を定量的に行え、Copilot のカスタマイズを属人的な感覚に頼らず改善できる。

**リンク**: [GitHub Copilot Evals is now in public preview](https://github.blog/changelog/2026-11-17-github-copilot-evals-is-now-in-public-preview)

### GitHub Copilot の活動を Microsoft Agent 365 へストリーミング

**要約**: GitHub Copilot のエージェント活動を Microsoft Agent 365 に連携できるようになった。cloud agent、Copilot CLI、VS Code、Visual Studio、JetBrains・Eclipse などの活動を対象に、プロンプト・応答・ツール呼び出しや利用傾向を確認でき、Purview と Defender でリスク調査も可能。Enterprise Managed Users を使う GitHub Enterprise Cloud 向け。

**影響**: AI ワークロード全体の統制・監査に Copilot を含められ、ガバナンス要件の厳しい企業で導入しやすくなる。

**リンク**: [Monitor GitHub Copilot activity through Microsoft Agent 365](https://github.blog/changelog/2026-11-17-monitor-github-copilot-activity-through-microsoft-agent-365)

### Copilot code review の結果をリポジトリ Insights で追跡

**要約**: 各リポジトリで Copilot code review のフィードバックがどう扱われたかを確認できる「Repository insights」ページが追加された。

**影響**: レビュー AI の効果測定ができ、導入効果の説明や設定見直しの材料になる。

**リンク**: [Track Copilot code review outcomes in Repository insights](https://github.blog/changelog/2026-11-17-track-copilot-code-review-outcomes-in-repository-insights)

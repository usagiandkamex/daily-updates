# 2026/09/08 デイリーアップデート

## 1. Azure アップデート情報

### Azure Container Apps が Microsoft Defender for Cloud のサーバーレスコンテナ態勢管理に対応

**要約**: Azure Container Apps 環境を Microsoft Defender for Cloud の「Serverless Containers Posture」機能に取り込めるようになり、一般提供が開始されました。コンテナのセキュリティ姿勢を可視化・管理できます。

**影響**: サーバーレスコンテナの脆弱性や設定不備を継続的に把握できるようになり、セキュリティ担当者の運用負荷軽減につながります。

**リンク**: [Generally Available: Microsoft Defender for Cloud support for Azure Container Apps (Serverless Containers Posture)](https://azure.microsoft.com/updates?id=570282)

### Windows Server 2025 on AKS が一般提供に

**要約**: Azure Kubernetes Service（AKS）上で Windows Server 2025 ベースのワークロードを実行できるようになり、GA（一般提供）が発表されました。

**影響**: 古い Windows Server のサポート終了に伴うモダナイズ需要に応えるもので、Windows 依存のエンタープライズワークロードをコンテナ化しやすくなります。

**リンク**: [Generally Available: Windows Server 2025 on AKS](https://azure.microsoft.com/updates?id=570090)

### AKS の Artifact Streaming が一般提供

**要約**: Azure Container Registry（ACR）と連携する Artifact Streaming が AKS で GA となり、コンテナイメージの取得を高速化できるようになりました。

**影響**: 大規模イメージのプル時間短縮によりデプロイやスケールアウトが迅速化し、CI/CD パイプラインの待ち時間削減に寄与します。

**リンク**: [Generally Available: Artifact Streaming on AKS](https://azure.microsoft.com/updates?id=570095)

### Azure Linux 向け Confidential VM が一般提供

**要約**: AKS 上で Azure Linux 向けの Confidential VM（機密仮想マシン）が GA となり、より高いセキュリティと機密性を提供します。

**影響**: 機密性の高いデータを扱うワークロードをコンテナ基盤上でも安全に運用できるようになり、金融・医療など規制業種での採用が進む可能性があります。

**リンク**: [Generally Available: Confidential VMs for Azure Linux](https://azure.microsoft.com/updates?id=570100)

### Azure Database for MySQL に Reader Endpoint がプレビュー提供

**要約**: 複数のリードレプリカを使う際の接続管理を簡素化する Reader Endpoint 機能が、Azure Database for MySQL でパブリックプレビューとして提供開始されました。

**影響**: 読み取り負荷分散の設定が容易になり、アプリケーション側の接続文字列管理の手間が減ります。

**リンク**: [Public Preview: Reader Endpoint for Azure Database for MySQL](https://azure.microsoft.com/updates?id=569653)

### Azure Front Door に プロファイル/ルート単位の WAF ポリシーがプレビュー

**要約**: Azure Front Door の Web Application Firewall（WAF）が、プロファイル単位・ルート単位でのポリシー関連付けをパブリックプレビューでサポートしました。

**影響**: きめ細かいセキュリティポリシー設計が可能になり、マルチテナントやマイクロサービス構成でのセキュリティ管理を柔軟に行えます。

**リンク**: [Public Preview: Azure Front Door profile and route level WAF policies](https://azure.microsoft.com/updates?id=569804)

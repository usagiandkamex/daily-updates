## 1. Azure アップデート情報

### Azure Database for PostgreSQL に PostgreSQL スキルと MCP プラグインが登場

**要約**: Azure Database for PostgreSQL 向けに、PostgreSQL の運用を支援するスキルと MCP（Model Context Protocol）プラグインがパブリックプレビューとして公開された。

**影響**: AI エージェントから PostgreSQL の運用・診断を直接呼び出せるようになり、DBA 業務の一部を自動化しやすくなる。

**リンク**: [Public Preview: PostgreSQL skills and MCP plugin for Azure Database for PostgreSQL](https://azure.microsoft.com/updates?id=569664)

### Azure PostgreSQL Flexible Server に PG18 対応の新機能が続々 GA

**要約**: Azure Database for PostgreSQL 関連では、論理レプリケーションスロットの同期状態メトリクスや、PostgreSQL 18 対応のトラブルシューティングガイド、Elastic Cluster での PG18 サポートなどが一般提供となった。

**影響**: 最新の PostgreSQL バージョンへの移行を検討する企業にとって、監視・トラブルシューティング環境が整い、移行リスクを下げられる。

**リンク**: [Generally Available: PG18 support for Azure Database for PostgreSQL elastic clusters](https://azure.microsoft.com/updates?id=571047)

### AKS 向け「Flex Nodes」がパブリックプレビュー

**要約**: Azure Kubernetes Service（AKS）向けに、ワークロードに応じて柔軟にノード構成を切り替えられる「Flex Nodes」がパブリックプレビューとして公開された。

**影響**: Kubernetes 運用チームはリソース配分の最適化がしやすくなり、コストとスケーラビリティのバランスを取りやすくなる。

**リンク**: [Public Preview: Flex Nodes for AKS](https://azure.microsoft.com/updates?id=571919)

### Microsoft Foundry の Agent Service に Foundry Routines がプレビュー追加

**要約**: Microsoft Foundry の Agent Service に、定型処理をルーティン化できる「Foundry Routines」がパブリックプレビューとして公開された。

**影響**: 繰り返し発生するエージェントタスクをテンプレート化でき、開発・運用コストの削減につながる。

**リンク**: [Public Preview: Foundry Routines in Foundry Agent Service](https://azure.microsoft.com/updates?id=563536)

### Microsoft Foundry エージェントの Agent 365 統合が GA

**要約**: Microsoft Foundry で作成したエージェントを Agent 365 上で有効化・無効化できる管理コントロールが一般提供となり、Microsoft 365 Copilot や Teams への公開機能も GA 済み。

**影響**: 企業内で多数のエージェントを展開する際のガバナンスが強化され、大規模導入時の管理負荷を抑えられる。

**リンク**: [Generally Available: Enable and disable controls for Microsoft Foundry agents in Agent 365](https://azure.microsoft.com/updates?id=571826)

### GPT-6 Astra・Sol・Luna が Microsoft Foundry で本番エージェント向けに提供

**要約**: Microsoft Foundry ブログで、新モデル群「GPT-6 Astra」「Sol」「Luna」が本番運用のエージェント向けに提供されることが紹介された。

**影響**: Azure 上でモデル選択の幅が広がり、用途（コスト重視・高精度重視など）に応じたエージェント設計がしやすくなる。

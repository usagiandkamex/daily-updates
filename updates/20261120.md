# 2026/11/20 デイリーアップデート

## 1. Azure アップデート情報

### Azure Compute Gallery のソフト削除が一般提供開始

**要約**: Azure Compute Gallery のソフト削除が一般提供（GA）になった。誤って削除したイメージバージョンを、設定した保持期間内であれば復旧できる。

**影響**: VM イメージのゴールデンイメージ運用で起こりがちな誤削除を、バックアップ運用に頼らず復旧できるようになる。インフラ運用チームは保持期間の方針を決めて有効化を検討したい。

**リンク**: [Generally Available: Soft delete in Azure Compute Gallery](https://azure.microsoft.com/updates?id=581907)

### Azure VM のゾーン回復性がパブリックプレビュー

**要約**: 対象となるゾーン配置の VM を、同一リージョン内の別の可用性ゾーンへ復旧できる「Zone resilience for Azure VMs」がパブリックプレビューとして公開された。

**影響**: ゾーン障害時の復旧手順を簡素化できる可能性がある。プレビューのため、本番適用前に対象 VM の条件と制限を確認する必要がある。

**リンク**: [Public Preview: Zone resilience for Azure VMs](https://azure.microsoft.com/updates?id=581254)

### Azure Database for PostgreSQL で PostgreSQL 19 のパブリックプレビュー

**要約**: Azure Database for PostgreSQL – Flexible Server で PostgreSQL 19 を、東アジアリージョンのパブリックプレビューとして試せるようになった。

**影響**: 次期メジャーバージョンの互換性を早期に検証できる。提供は東アジアに限られるプレビューのため、検証・評価用途が前提となる。

**リンク**: [Public Preview: PostgreSQL 19 on Azure Database for PostgreSQL](https://azure.microsoft.com/updates?id=574587)

### Azure Database for PostgreSQL に Database Agent（プレビュー）

**要約**: データベースの健全性やパフォーマンスの問題を、検出・理解・対応しやすくする Database Agent がパブリックプレビューとして提供された。

**影響**: 障害・性能劣化の一次切り分けを支援する機能として、DBA 不在のチームでも運用負荷の軽減が期待できる。精度や適用範囲はプレビュー期間中に評価が必要。

**リンク**: [Public Preview: Database Agent for Azure Database for PostgreSQL](https://azure.microsoft.com/updates?id=579579)

### Azure DevOps と GitHub Copilot アプリの統合（パブリックプレビュー）

**要約**: GitHub Copilot アプリから Azure DevOps に直接つながるエージェントセッションを開始できる統合が、パブリックプレビューとして発表された。

**影響**: Azure DevOps を使い続けている組織でも、Copilot のエージェント機能を開発フローに取り込める余地が広がる。詳細な対応範囲はプレビューのため公式情報で確認したい。

**リンク**: [Azure DevOps integration with the GitHub Copilot app (public preview)](https://devblogs.microsoft.com/devops/azure-devops-integration-with-the-github-copilot-app-public-preview/)

### Microsoft Marketplace のマルチパーティプライベートオファーがマレーシアとサウジアラビアに拡大

**要約**: Microsoft パートナーが、サードパーティのクラウド・AI ソリューションを Marketplace 経由で顧客向けに調達できるマルチパーティプライベートオファーの提供国が、マレーシアとサウジアラビアに拡大された。

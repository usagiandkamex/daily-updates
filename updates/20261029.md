## 1. Azure アップデート情報

### Azure Container Apps のログ出力先で Log Analytics がレガシー扱いに

**要約**: Azure Container Apps のログ出力先として Log Analytics が「レガシー」の選択肢になったことが告知された。既存環境は Azure Monitor へ移行する形となる。

**影響**: Log Analytics 前提でログ基盤や運用ツールを構築している開発・運用チームは、Azure Monitor への移行計画とクエリ・アラートの見直しが必要になる。

**リンク**: [Announcing: Migrate Azure Container Apps logging destination from Log Analytics to Azure Monitor](https://azure.microsoft.com/updates?id=577689)

### Azure Backup の Cross Tenant Restore がパブリックプレビュー

**要約**: Cross-Tenant Restore (CTR) は、Azure VM のバックアップを別テナントへ復元できる機能で、組織が独立した復旧経路を確保できるようにするもの。パブリックプレビューとして提供が始まった。

**影響**: テナントが侵害された場合などに備えた事業継続・ランサムウェア対策の選択肢が広がる。ただしプレビュー段階のため、本番適用前に仕様と制約の確認が必要。

**リンク**: [[In preview] Public Preview: Cross Tenant Restore with Azure Backup](https://azure.microsoft.com/updates?id=577117)

### Microsoft Marketplace のプライベートオファー機能強化が一般提供（GA）

**要約**: Microsoft Marketplace のプライベートオファーについて、組織の購買力を最適化し、価格や条件を自社に合わせやすくする機能強化が GA となった。

**影響**: Marketplace 経由で Azure 関連ソフトウェアを調達する企業や、ISV として販売する事業者にとって、個別条件での取引を進めやすくなる。

**リンク**: [[Launched] Generally Available: Marketplace private offer enhancements](https://azure.microsoft.com/updates?id=576547)

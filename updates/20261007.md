# 2026/10/07 デイリーアップデート

## 1. Azure アップデート情報

### AKS ベアメタル環境が Ubuntu 上で利用可能に（パブリックプレビュー）

**要約**: オンプレミスで Kubernetes を運用する際、仮想化レイヤーの追加や不慣れなインフラへの適合、ハードウェア制御の放棄といった課題が生じがちです。今回、AKS on bare metal が Ubuntu 上で動作するパブリックプレビューが公開されました。

**影響**: 仮想化基盤を挟まずにベアメタルへ AKS を展開できる選択肢が増えます。オンプレミスや閉域環境で Kubernetes を運用する企業は、ハードウェアを直接制御しつつ Azure の管理モデルを活用できるか検証する価値があります。

**リンク**: [[In preview] Public Preview: AKS on bare metal now on Ubuntu](https://azure.microsoft.com/updates?id=573782)

### AKS のポッド名ディメンションが Azure Monitor プラットフォームメトリクスから廃止へ

**要約**: 2027 年 9 月 30 日以降、AKS の一部の Azure Monitor プラットフォームメトリクスにおけるポッド名ディメンションのサポートが終了します。

**影響**: ポッド名でメトリクスを分割するダッシュボードやアラートルールを使っている場合、期限までに代替手段（Prometheus 系メトリクスなど）への移行計画が必要です。まず現行のクエリ・アラートの棚卸しを行いましょう。

**リンク**: [Retirement: Pod name dimension in AKS pod platform metrics](https://azure.microsoft.com/updates?id=570232)

### App Service の Java 8 / 11 / 17 サポートが 2027 年 9 月 1 日に終了

**要約**: 2027 年 9 月 1 日に Java 8、11、17 のサポートが終了します。App Service 上のアプリは引き続き動作しますが、セキュリティ更新は提供されなくなります。

**影響**: 古い Java ランタイムに依存する業務アプリはセキュリティリスクが高まります。新しい LTS への移行テストを計画的に進める必要があります。移行には依存ライブラリの互換性確認が伴うため、早めの着手が望ましいです。

**リンク**: [Retirement: Support for Java 8, 11 and 17 will end on September 1, 2027](https://azure.microsoft.com/updates?id=568585)

### Azure Stack Hub 上の Azure App Service が 2029 年 9 月 30 日に退役

**要約**: Azure App Service on Azure Stack Hub は 2029 年 9 月 30 日に退役します。2026 年 9 月 30 日以降は新規インストールがサポートされなくなります。

**影響**: Azure Stack Hub で PaaS 型の Web ホスティングを利用している組織は、すでに新規導入ができない段階に入っています。代替のホスティング方式を中期計画に組み込む必要があります。

**リンク**: [Retirement: Azure App Service on Azure Stack Hub](https://azure.microsoft.com/updates?id=568178)

### Azure SQL Database の Intel SGX enclave を使う Always Encrypted が 2027 年 10 月 31 日に退役

**要約**: SGX 対応の DC シリーズハードウェアのサポートが段階的に終了することに伴い、Azure SQL Database における Intel SGX enclave を使った Always Encrypted が 2027 年 10 月 31 日に退役します。

**影響**: enclave を利用したリッチクエリ（暗号化列に対する計算）を使っている場合は、設計の見直しが必要です。機密データを扱うシステムでは、代替の保護方式を早期に検討してください。

**リンク**: [Retirement: Always Encrypted with Intel SGX Enclaves](https://azure.microsoft.com/updates?id=569236)

# 2026/10/21 デイリーアップデート

## 1. Azure アップデート情報

### VNet ピアリング経路を無効化する機能がパブリックプレビュー

**要約**: ピアリングされた仮想ネットワーク間のトラフィックをより細かく制御できる、ルートテーブルの機能「disable VNet peering route」がパブリックプレビューとして発表されました。

**影響**: ハブ&スポーク構成などで意図しない経路を明示的に排除でき、ネットワーク設計・セキュリティ運用の柔軟性が高まります。プレビューのため本番適用前に検証が必要です。

**リンク**: [[In preview] Public Preview: Disable VNet peering route](https://azure.microsoft.com/updates?id=576242)

### Azure Front Door Premium WAF のサービスタグ一致条件が一般提供開始

**要約**: Azure Front Door Premium の Web Application Firewall カスタムルールで、サービスタグを条件にできる機能が GA となりました。

**影響**: 既知のサービス由来のトラフィックを IP 列挙なしでルール化でき、WAF ルールの保守負荷を減らせます。

**リンク**: [[Launched] Generally Available: Service tag match condition for Azure Front Door Premium WAF](https://azure.microsoft.com/updates?id=577156)

### Application Gateway が Key Vault Managed HSM の鍵による Keyless TLS に対応

**要約**: 秘密鍵が Azure Key Vault Managed HSM 内に留まる証明書を使った TLS 終端が、Application Gateway で GA となりました。

**影響**: 秘密鍵がゲートウェイ側に出ないため、厳格な鍵管理が求められる金融・公共系などのコンプライアンス要件に対応しやすくなります。

**リンク**: [[Launched] Generally Available: Keyless TLS on Application Gateway with Azure Key Vault Managed HSM](https://azure.microsoft.com/updates?id=577130)

### Azure Monitor の高度なプラットフォームメトリックが一般提供開始

**要約**: より細かい粒度のシグナルを提供する Azure Monitor の Advanced platform metrics が GA となりました。

**影響**: 障害の早期検知や性能分析の精度向上が期待でき、SRE・運用チームの監視設計に選択肢が増えます。

**リンク**: [[Launched] Generally Available: Advanced platform metrics for Azure Monitor](https://azure.microsoft.com/updates?id=575329)

### Azure DevOps プラグインが Microsoft Copilot で利用可能に

**要約**: Azure DevOps Plugin が Microsoft Copilot で利用できるようになり、Copilot Chat、Cowork、Code から Azure DevOps の情報を扱えます。

**影響**: 開発者は作業管理や開発情報へのアクセスを Copilot 上で完結でき、コンテキスト切り替えの削減につながります。

**リンク**: [Azure DevOps available in Microsoft Copilot](https://devblogs.microsoft.com/devops/azure-devops-available-in-microsoft-copilot/)

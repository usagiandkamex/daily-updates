## 1. Azure アップデート情報

### Microsoft Foundry Agent Service に「Foundry Routines」がパブリックプレビュー

**要約**: Foundry Agent Service に、公開済みエージェントをスケジュールやビジネスイベント発生時に自動実行できる新しいトリガー機能「Foundry Routines」がパブリックプレビューとして追加された。

**影響**: 定期実行や外部イベント連動の仕組みを自前で組み上げる必要がなくなり、本番運用向けエージェントの構築・保守コストを下げられる。

**リンク**: [[In preview] Public Preview: Foundry Routines in Foundry Agent Service](https://azure.microsoft.com/updates?id=563536)

### SAP向けMdsv4・Msv4シリーズ仮想マシンがパブリックプレビュー

**要約**: 第6世代インテルXeonスケーラブル・プロセッサーを搭載したメモリ最適化VMシリーズ「Mdsv4」「Msv4」が、SAPワークロード向けにパブリックプレビュー開始となった。Azure Boostによるセキュリティ強化も特徴。

**影響**: メモリ集約型のSAP基幹システムをAzure上で稼働させる企業にとって、性能とセキュリティを両立した新しい選択肢が増える。

**リンク**: [[In preview] Public Preview: Mdsv4 and Msv4 Series Virtual Machines for SAP](https://azure.microsoft.com/updates?id=571530)

### Microsoft Foundryエージェント、Agent 365でのオン/オフ制御機能が一般提供開始

**要約**: Agent 365のガバナンス基盤上で、Foundryエージェントの有効化・無効化を管理者が制御できる機能が一般提供（GA）となった。Microsoft Admin Centerから操作できる。

**影響**: 社内で稼働するエージェントが急増する中、問題発生時に即座に停止できる統制手段が整い、AIエージェント運用のリスク管理が強化される。

**リンク**: [[Launched] Generally Available: Enable and disable controls for Microsoft Foundry agents in Agent 365](https://azure.microsoft.com/updates?id=571826)

### ホスト型エージェント向けネットワーク送信制御がパブリックプレビュー

**要約**: Microsoft Foundryでホストされるエージェントが行う外部への通信（アウトバウンド接続）を、順序付きルールで制御できる機能がパブリックプレビューとして公開された。

**影響**: エージェントが意図しない外部リソースへアクセスするリスクを抑制でき、セキュリティ要件の厳しい業界でのエージェント導入が進めやすくなる。

**リンク**: [[In preview] Public Preview: Network egress controls for hosted agents in Microsoft Foundry](https://azure.microsoft.com/updates?id=571821)

### Microsoft Foundryエージェントの Microsoft 365 Copilot / Teams への公開が一般提供開始

**要約**: Foundryで構築したエージェントを、Microsoft 365 CopilotおよびTeams上に直接公開できる機能が一般提供（GA）となった。

**影響**: 業務アプリ側での追加開発なしに、社内向けカスタムエージェントを日常業務のツールへ組み込めるようになり、社内展開のハードルが下がる。

**リンク**: [[Launched] Generally Available: Publishing Microsoft Foundry agents to Microsoft 365 Copilot and Teams](https://azure.microsoft.com/updates?id=571816)

### Azure Database for PostgreSQL 弾力性クラスターがPostgreSQL 18に対応

**要約**: Azure Database for PostgreSQLの弾力性クラスター（elastic clusters）が最新版PostgreSQL 18に対応し、一般提供（GA）となった。

**影響**: 最新バージョンの機能・性能改善を分散型・大規模なPostgreSQL環境で早期に活用できるようになり、データベース基盤刷新の選択肢が広がる。

**リンク**: [[Launched] Generally Available: PG18 support for Azure Database for PostgreSQL elastic clusters](https://azure.microsoft.com/updates?id=571047)

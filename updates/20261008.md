## 1. Azure アップデート情報

### Anyscale on Azure が一般提供（GA）

**要約**: 分散 Python ワークロードを Ray 上で実行するためのマネージドプラットフォーム「Anyscale on Azure」が一般提供となりました。Azure 上に直接デプロイして利用できる形で提供されます。

**影響**: 機械学習の学習・推論やデータ処理を分散実行したい開発者が、Azure 環境内で Ray ベースの基盤を運用負荷を抑えて利用できるようになります。AI ワークロードの基盤選択肢が広がります。

**リンク**: [[Launched] Generally Available: Anyscale on Azure](https://azure.microsoft.com/updates?id=573744)

### SQL Server on Linux で bulkadmin 固定サーバーロールが利用可能に

**要約**: SQL Server 2025 CU9 および SQL Server 2022 CU27 以降、SQL Server on Linux で bulkadmin 固定サーバーロールと ADMINISTER BULK OPERATIONS 権限がサポートされ、一般提供となりました。

**影響**: 一括データ取り込みに必要な権限を最小限で付与できるため、Linux 上の SQL Server でも最小権限の原則に沿った運用がしやすくなります。Windows 版からの移行や併用を行う運用チームにとって差異が減ります。

**リンク**: [[Launched] Generally Available: Enabling the Bulk admin role for SQL Server on Linux](https://azure.microsoft.com/updates?id=573443)

### インフラのライフサイクル全体に広がる AI 変革（Azure ブログ）

**要約**: Microsoft の Azure ブログが、サプライチェーンからフリート運用まで、インフラの設計・調達・運用の各段階で AI を活用する考え方を紹介しています。個別タスクの高速化にとどまらず、経験から学習し続ける仕組みの構築が狙いとされています。

**影響**: データセンターや大規模インフラを扱う企業にとって、AI を部分最適ではなくライフサイクル全体で捉える視点が示されています。インフラ戦略や投資計画を検討する際の参考になります。

**リンク**: [AI transformation across the infrastructure lifecycle: From supply chain to fleet operations](https://azure.microsoft.com/en-us/blog/ai-transformation-across-the-infrastructure-lifecycle-from-supply-chain-to-fleet-operations/)

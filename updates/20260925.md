## 1. Azure アップデート情報

### Azure Communication Services（ACS）のスタンドアロンサービスが2028年9月30日に廃止予定

**要約**: Microsoftは、Azure Communication Services（ACS）のスタンドアロン提供サービスの一部を2028年9月30日に廃止すると発表した。廃止日以降、対象サービスは利用できなくなる。

**影響**: ACSのスタンドアロン機能を組み込んだ通信基盤を運用している企業は、廃止スケジュールを踏まえて代替サービスへの移行計画を早期に検討する必要がある。

**リンク**: [Retirement: Azure Communication Services (ACS) standalone services will be retired on September 30, 2028](https://azure.microsoft.com/updates?id=557117)

### VMの復元ポイント向け「Instant Access」が一般提供開始

**要約**: Premium v2またはUltraディスクをデータディスクに持つ仮想マシンのアプリケーション整合性のある復元ポイントに対応する「Instant Access」機能が、一般提供（GA）となった。

**影響**: 大容量ディスクを使う基幹システムなどで、バックアップからの復旧時間を大幅に短縮できるようになり、事業継続計画（BCP）の実効性向上に寄与する。

**リンク**: [\[Launched\] Generally Available: Instant Access for VM restore points](https://azure.microsoft.com/updates?id=572573)

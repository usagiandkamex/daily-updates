## 1. Azure アップデート情報

### Azure Virtual Network の ECMP ネクストホップがパブリックプレビュー

**要約**: Azure Virtual Network 向けの Equal-Cost Multi-Path（ECMP）ルーティングがパブリックプレビューとして提供開始された。複数の等コスト経路にトラフィックを分散できる機能で、提供状況はプレビュー。詳細な設定条件は本稿作成時点で確認できていない。

**影響**: 仮想アプライアンスや複数経路を使うネットワーク設計で負荷分散・帯域活用の選択肢が増える可能性がある。プレビューのため、本番適用前にSLAやリージョン対応の確認が必要。

**リンク**: [[In preview] Public Preview: ECMP Nexthop](https://azure.microsoft.com/updates?id=582326)

### Azure Functions の Java 8/11/17 サポートが 2027年9月1日に終了

**要約**: Azure Functions 上での Java 8・11・17 のサポートが 2027年9月1日に終了する旨が告知された。既存アプリは引き続き動作するとされているが、サポート終了後の扱いの詳細は元ページで確認できていない。

**影響**: Java で Functions を運用している開発チームは、新しい Java バージョンへの移行計画を前もって立てる必要がある。期限まで約 9 か月あり、テストを含む移行スケジュールの確保が求められる。

**リンク**: [Retirement: Support for Java 8, 11 and 17 in Azure Functions ends on September 1, 2027](https://azure.microsoft.com/updates?id=568586)

## 2. Microsoft アップデート情報

### Copilot コードレビューの課金先が既定で組織へ（2026年12月30日〜）

**要約**: Copilot ライセンスを持つメンバーの Copilot コードレビューについて、課金先を未選択の場合、2026年12月30日から所有組織への課金が既定になる。Copilot Business / Enterprise の組織・企業が対象。すでに「Member」または「Organization」を選択済みなら変更なし。AI Credits の従量課金が無効、課金ロックあり、課金対象顧客なしのアカウントは Member に設定される。

**影響**: 現状維持したい管理者は期限前に「Member」を明示選択する必要がある。放置すると組織側のコストが増える可能性があるため、課金ポリシーの見直しが必要。

**リンク**: [Copilot code review billing will default to the organization](https://github.blog/changelog/2026-11-25-copilot-code-review-billing-will-default-to-the-organization)

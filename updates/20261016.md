## 1. Azure アップデート情報

### Azure Files：リージョン間のデータコピー・同期がパブリックプレビュー

**要約**: Azure Files で、ストレージアカウントや Azure リージョンをまたいでファイル共有のデータをコピー・同期できる機能がパブリックプレビューとして提供開始されました。

**影響**: リージョン間のデータ移行や DR 用途のレプリケーションを、自前のスクリプトやツールに頼らず運用できる可能性があります。プレビュー段階のため、本番適用前に対応範囲と制限の確認が必要です。

**リンク**: [[In preview] Public Preview: Azure Files cross-region data copy and synchronization](https://azure.microsoft.com/updates?id=576542)

### Private Link ファミリーの「Standard service endpoint」が一般提供開始

**要約**: Azure Private Link ファミリーの新機能「Standard service endpoint」が一般提供（GA）となりました。スケーラブルでセキュアな接続手段を提供する機能と案内されています。

**影響**: サービス提供者・利用者間をプライベートに接続する設計の選択肢が増えます。大規模なマルチテナント構成やネットワーク分離を求める企業のアーキテクチャ検討に関わります。

**リンク**: [[Launched] Generally Available: Standard service endpoint](https://azure.microsoft.com/updates?id=571025)

### Virtual Machine Scale Sets の自動ゾーンバランスが一般提供開始

**要約**: Virtual Machine Scale Sets の「Automatic zone balance」が一般提供となりました。ゾーン間のインスタンス配置の偏りを自動で是正する機能です。

**影響**: ゾーン障害時の可用性を保つためのリバランス作業を手動で行う負担が減り、可用性設計の運用が楽になります。

**リンク**: [[Launched] Generally Availabile: Automatic zone balance for Virtual Machine Scale Sets](https://azure.microsoft.com/updates?id=576334)

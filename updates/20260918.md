## 1. Azure アップデート情報

### Azure Payments HSM v2 がパブリックプレビューに

**要約**: 決済処理・クレデンシャル発行・PIN処理・鍵管理を担う単一テナント専用のペイメントHSM「Azure Payments HSM v2」がパブリックプレビューとして提供開始された。高可用性を備えたハードウェアセキュリティモジュールとして、決済関連の厳格なセキュリティ要件に対応する。

**影響**: 金融・決済業界でPCI DSSなど厳格な準拠要件を満たしつつクラウド上で決済処理基盤を構築できるようになり、オンプレミスのHSM運用からの移行を検討する事業者にとって選択肢が広がる。

**リンク**: [[In preview] Public Preview: Azure Payments HSM v2](https://azure.microsoft.com/updates?id=570509)

### Azure Virtual Network Manager の高スケールメッシュが一般提供開始

**要約**: Azure Virtual Network Manager の「接続グループ」を用いた高スケールメッシュ機能が一般提供（GA）となった。対応リージョンでは、多数の仮想ネットワークを相互接続するメッシュ型トポロジーを大規模に構築できる。

**影響**: マルチリージョン・マルチVNet構成を持つ大規模企業にとって、ネットワーク管理の複雑さを軽減しつつ、拠点間やサービス間の通信をスケーラブルに構成できるようになる。

**リンク**: [[Launched] Generally Available: High-scale mesh in Azure Virtual Network Manager](https://azure.microsoft.com/updates?id=571572)

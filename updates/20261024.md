## 1. Azure アップデート情報

### Azure Backup：Premium SSD v2 / Ultra Disk 搭載 VM でアイテムレベルリカバリ（ILR）が一般提供

**要約**: Azure Backup が、Premium SSD v2 および Ultra Disk を使用する Azure 仮想マシンのアイテムレベルリカバリ（ILR）を一般提供（GA）した。512 バイトおよび 4KB の論理セクターサイズのディスクが対象となる。

**影響**: VM 全体を復元せずに必要なファイルだけを取り出せるため、高性能ディスクを使うデータベースや基幹ワークロードでも、復旧時間と運用負荷を抑えやすくなる。

**リンク**: [[Launched] Generally Available: Item Level Recovery for Azure VMs with Premium SSDv2 and Ultra Disks](https://azure.microsoft.com/updates?id=577963)

### OpenAI が ChatGPT のストレージ基盤を解説：Azure Cosmos DB でマルチテナント・グローバルキャッシュを実現

**要約**: OpenAI は、10 億人超の ChatGPT ユーザーを支えるストレージ基盤「Habitat」の拡張について Part II を公開した。信頼性の高いマルチテナンシー、グローバルキャッシュ、Azure Cosmos DB を組み合わせ、ChatGPT の読み取りを 12 倍高速化したとしている。

**影響**: 大規模サービスで Azure Cosmos DB を使う実例として、キャッシュ設計やマルチテナント分離を検討する開発者の参考になる。

**リンク**: [Rapidly scaling online storage to serve over 1 billion ChatGPT users (Part II)](https://openai.com/index/scaling-storage-one-billion-users-part-two)

## 1. Azure アップデート情報

### Azure Cloud HSM でハードウェア監査ログが一般提供（GA）

**要約**: Azure Cloud HSM の「Hardware Audit Logging」が一般提供となりました。HSM の管理操作に対して、ハードウェアが生成する監査記録を取得できる機能です。

**影響**: 暗号鍵管理に厳格な監査要件を持つ金融・公共系の組織にとって、管理操作の証跡をハードウェアレベルで確保できる点が有用です。コンプライアンス対応や内部統制の説明資料づくりにも役立ちます。

**リンク**: [[Launched] Generally Available: Azure Cloud HSM hardware audit logging](https://azure.microsoft.com/updates?id=576377)

### Azure Site Recovery が Azure Arc 対応の Windows VMware／物理サーバーをサポート

**要約**: Azure Site Recovery (ASR) が、Azure Arc 対応の Windows VMware 仮想マシンおよびオンプレミスの物理サーバーに対する災害復旧をサポートしました（GA）。

**影響**: Azure Arc で管理しているハイブリッド環境でも、Azure を復旧先とした DR 構成を取りやすくなります。オンプレミス資産を多く抱える企業の事業継続計画（BCP）の選択肢が広がります。

**リンク**: [[Launched] Generally Available: Azure Site Recovery Support for Azure ARC-enabled Windows VMWare/Physical servers](https://azure.microsoft.com/updates?id=576214)

# 2026/11/03 デイリーアップデート

## 1. Azure アップデート情報

### Azure Migrate が NAS 共有の検出・評価に対応（パブリックプレビュー）

**要約**: Azure Migrate でオンプレミスのネットワーク接続ストレージ（NAS）の検出と評価が可能になった。Dell PowerScale などが対象で、顧客やパートナーが移行計画を立てられる。現在はパブリックプレビュー。

**影響**: ファイルサーバー移行の事前調査をツールで行えるようになり、容量・共有構成の把握が効率化する。プレビューのため本番計画では GA 時期と制限事項の確認が必要。

**リンク**: [[In preview] Public Preview: On-prem NAS share discovery and assessment are now available](https://azure.microsoft.com/updates?id=577975)

### Azure Database for PostgreSQL：VNet 統合からプライベートエンドポイントへの変更が GA

**要約**: Azure Database for PostgreSQL Flexible Server で、既存の VNet 統合構成からプライベートエンドポイント構成へ変更できる機能が一般提供となった。

**影響**: ネットワーク設計の見直し時にサーバーを作り直す必要が減り、接続方式の変更が柔軟になる。構成変更時の接続影響は事前に検証したい。

**リンク**: [[Launched] Generally Available: Change from virtual network integration to a private endpoint](https://azure.microsoft.com/updates?id=574541)

### Azure Storage Actions が自動タスク更新などの機能強化で GA

**要約**: Azure Storage Actions に、タスク管理を簡素化し自動化されたデータ操作の制御を強化する 3 つの機能強化が一般提供された。タスクの自動更新などが含まれる。

**影響**: ストレージのデータ管理（ライフサイクルや整理）の運用負荷を下げられる。大規模データを持つ組織で運用自動化の恩恵が大きい。

**リンク**: [[Launched] Generally Available: Azure Storage Actions adds automatic task updates](https://azure.microsoft.com/updates?id=578628)

### Azure Service Bus Premium：パーティション化された名前空間でジオレプリケーションが GA

**要約**: Service Bus Premium で、パーティション化された名前空間とジオレプリケーションを組み合わせて使えるようになった。スループットの利点と地理的な冗長性を両立できる。

**影響**: 高スループットなメッセージング基盤でも災害対策を組み込みやすくなり、可用性要件の高いシステム設計の選択肢が広がる。

**リンク**: [[Launched] Generally Available: Geo-Replication on partitioned namespaces for Azure Service Bus](https://azure.microsoft.com/updates?id=579021)

### Azure Site Recovery が Azure Local に対応（GA）

**要約**: Azure Site Recovery の Azure Local 向けサポートが一般提供となった。企業向けのディザスタリカバリをより簡単に設定できるとされている。

**影響**: オンプレミス／ハイブリッド環境（Azure Local）でも Azure を使った DR を構築しやすくなり、事業継続計画の強化につながる。

**リンク**: [[Launched] Generally Available: Azure Site Recovery for Azure Local](https://azure.microsoft.com/updates?id=579111)

### 【廃止予告】Azure Fluid Relay は 2027 年 2 月 2 日に提供終了

**要約**: Azure Fluid Relay は 2027 年 2 月 2 日に提供終了となる。以降は継続して利用しているワークロードに影響が出る。

**影響**: 利用中のチームは代替手段の検討と移行計画を早めに進める必要がある。

**リンク**: [Retirement: Azure Fluid Relay](https://azure.microsoft.com/updates?id=570498)

## 2. Microsoft アップデート情報

### GitHub：pull_request_target が 12 月 2 日から公開リポジトリで既定ブロックに

**要約**: 2026 年 12 月 2 日以降、GitHub Actions はすべてのパブリックリポジトリで pull_request_target イベントを既定でブロックする（該当する Actions ポリシーが適用される場合を除く）。

**影響**: 同イベントに依存するワークフロー（フォーク PR のラベル付けや自動処理など）が動かなくなる可能性がある。期日前にワークフローの見直しとポリシー設定の確認が必要。

**リンク**: [pull_request_target blocked by default December 2](https://github.blog/changelog/2026-11-02-pull_request_target-blocked-by-default-december-2)

### GitHub：セキュリティリスク評価に「リポジトリ保護状況」が追加

**要約**: GitHub のコードセキュリティリスク評価とシークレットリスク評価で、検出結果が保護されたリポジトリか未保護のリポジトリかを表示するようになった。

**影響**: 保護が不十分なリポジトリの検出結果を優先して対処でき、組織のセキュリティ対策の優先順位付けがしやすくなる。

**リンク**: [Security risk assessments include repository protection status](https://github.blog/changelog/2026-11-02-security-risk-assessments-include-repository-protection-status)

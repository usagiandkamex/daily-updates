### Static Web Apps の .NET 8 / .NET 9 サポートが本日終了

**要約**: Azure Static Web Apps の管理対象 Functions API における .NET 8 と .NET 9 のサポートが 2026 年 11 月 10 日に終了する。提供元は、API を .NET 10 へ移行するよう案内している。

**影響**: 該当の API を使うアプリは、サポート終了後に更新や障害対応を受けられなくなる恐れがある。.NET 10 への移行計画と動作確認を早めに進める必要がある。

**リンク**: [Retirement: Support for .NET 8 and .NET 9 on Static Web Apps is ending](https://azure.microsoft.com/updates?id=575106)

**リンク**: [[In preview] Public Preview: Modernize Arc-enabled Windows Servers with Azure File Sync](https://azure.microsoft.com/updates?id=579854)

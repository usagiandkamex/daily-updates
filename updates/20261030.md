# 2026/10/30 デイリーアップデート

## 1. Azure アップデート情報

### Azure MCP Server 3.0 が一般提供開始

**要約**: Azure MCP Server 3.0 が GA となり、AI エージェントや開発者ツールが Azure と連携する手段が拡充された。

**影響**: AI エージェントから Azure リソースを操作する開発・運用シナリオを、本番利用を見据えて検討しやすくなる。

**リンク**: [Generally Available: Azure MCP Server 3.0](https://azure.microsoft.com/updates?id=578662)

### Azure Front Door Premium WAF に HTTP DDoS ルールセットが GA

**要約**: Azure Front Door Premium の WAF 向け HTTP DDoS ルールセットが一般提供された。

**影響**: アプリケーション層の DDoS 対策を WAF で強化でき、公開 Web サービスの防御設計に選択肢が増える。

**リンク**: [Generally Available: HTTP DDoS ruleset for Azure Front Door Premium WAF](https://azure.microsoft.com/updates?id=578681)

### Azure Confidential VM 移行向け Large OS Disk Encryption が GA

**要約**: Azure Confidential VM の移行シナリオで、Large OS Disk Encryption (LOSDE) が一般提供となった。

**影響**: 大容量 OS ディスクを持つ既存ワークロードを機密コンピューティングへ移行する際の障壁が下がる。

**リンク**: [Generally Available: Large OS Disk Encryption for Azure Confidential VM migration](https://azure.microsoft.com/updates?id=578850)

# 2026/10/09 デイリーアップデート

## 1. Azure アップデート情報

### AKS：マネージド StandardV2 NAT Gateway が一般提供開始

**要約**: AKS が、AKS 管理の仮想ネットワークを使うクラスター向けに StandardV2 NAT Gateway をプロビジョニング・管理するようになりました。StandardV2 が管理対象 NAT Gateway の既定の選択肢となります。

**影響**: クラスターのアウトバウンド通信の構成を AKS 側に任せやすくなり、運用負荷の軽減が期待できます。新規クラスター設計時は既定値の変更点を確認しておくとよいでしょう。

**リンク**: [[Launched] Generally Available: Managed StandardV2 NAT Gateway for AKS](https://azure.microsoft.com/updates?id=574430)

### Azure Database for PostgreSQL flexible server が East US 3 リージョンで利用可能に

**要約**: East US 3 リージョンで Azure Database for PostgreSQL flexible server をデプロイできるようになりました。

**影響**: 米国東部での選択肢が増え、データ所在地や遅延、冗長構成を考慮したリージョン設計の幅が広がります。

**リンク**: [[Launched] Generally Available: Azure Database for PostgreSQL flexible server in East US 3](https://azure.microsoft.com/updates?id=573691)

### Microsoft Dev Box が 2028年9月18日に提供終了

**要約**: Microsoft Dev Box は 2028年9月18日に提供終了となり、2026年9月14日からクローズダウンのプロセスが始まります。

**影響**: 開発者向けクラウド PC として利用中の組織は、代替環境への移行計画を早めに検討する必要があります。

**リンク**: [Retirement: Microsoft Dev Box will be retired on September 18, 2028](https://azure.microsoft.com/updates?id=567933)

### Azure Deployment Environments が 2027年2月22日に提供終了

**要約**: Azure Deployment Environments は 2027年2月22日に提供終了となり、2026年9月14日からクローズダウンのプロセスが始まります。Dev Box より終了時期が早い点に注意が必要です。

**影響**: セルフサービスで環境を払い出している開発基盤チームは、IaC パイプラインなどへの移行準備が必要です。

**リンク**: [Retirement: Azure Deployment Environments will be retired on February 22, 2027](https://azure.microsoft.com/updates?id=567934)

### Application Gateway / Front Door の WAF 例外設定が一般提供開始

**要約**: Azure Application Gateway と Azure Front Door の Web Application Firewall で「例外（Exceptions）」機能が一般提供となりました。

**影響**: 誤検知への対応を、ルール全体を無効化せず細かく制御しやすくなり、セキュリティを保ちながら正常な通信を通す運用が可能になります。

**リンク**: [[Launched] Generally Available: Exceptions in WAF for Azure Application Gateway and Azure Front Door](https://azure.microsoft.com/updates?id=574343)

### Microsoft Agent 365 と Azure API Management の統合がパブリックプレビュー

**要約**: Microsoft Agent 365 と Azure API Management の統合がパブリックプレビューで利用可能になりました。集中管理されたガバナンスと連携する仕組みです。

**影響**: AI エージェントが呼び出す API の統制を API Management 側で行う流れが進み、エージェント活用時のガバナンス設計に関わる開発者・管理者は動向を押さえておく価値があります。

**リンク**: [[In preview] Public Preview: Microsoft Agent 365 integration with Azure API Management](https://azure.microsoft.com/updates?id=574204)

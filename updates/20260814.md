## 1. Azure アップデート情報

### AKS で Managed Prometheus によるコントロールプレーンメトリクス収集が GA

**要約**: Azure Kubernetes Service（AKS）のコントロールプレーンメトリクス収集が、Azure Monitor Managed Service for Prometheus と連携する形で一般提供（GA）となった。

**影響**: kube-apiserver や etcd などコントロールプレーン内部の状態を Prometheus 形式で可視化できるようになり、大規模クラスタ運用時の障害切り分けやキャパシティ計画がしやすくなる。

**リンク**: [[Launched] Generally Available: Control plane metrics collection for AKS with Managed Prometheus](https://azure.microsoft.com/updates?id=568830)

### Shared Premium SSD v2 / Ultra Disk のライブリサイズが GA

**要約**: 共有型 Premium SSD v2（Pv2）および Ultra Disk において、ディスクを稼働させたまま容量を動的に拡張できる「Live Resize」機能が一般提供された。

**影響**: メンテナンスウィンドウを確保せずにストレージ容量を拡張できるため、負荷急増時のダウンタイムなしでの対応が可能になり、可用性要件の高いワークロードの運用負荷が下がる。

**リンク**: [[Launched] Generally Available: Live Resize for Shared Premium SSD v2 and Ultra Data Disks](https://azure.microsoft.com/updates?id=569281)

### Azure Database for PostgreSQL Flexible Server にアップグレード前検証チェックが GA

**要約**: PostgreSQL のメジャーバージョンアップグレード前に、互換性や設定上の問題を事前検証できる機能が一般提供された。

**影響**: アップグレード失敗のリスクを事前に洗い出せるようになり、本番データベースのバージョンアップ作業における計画精度と安全性が向上する。

**リンク**: [[Launched] Generally Available: Pre-upgrade validation checks for Azure Database for PostgreSQL Flexible Server](https://azure.microsoft.com/updates?id=568419)

### Azure Linux 3.0.20260809、233件超のセキュリティ修正を提供

**要約**: Microsoft Azure Linux の最新パッチ「3.0.20260809」がリリースされ、233件を超えるセキュリティ修正が適用された。

**影響**: AKS や仮想マシンなどで Azure Linux を利用している環境では、既知の脆弱性対応のため速やかな適用が推奨される。パッチ適用サイクルの見直しにもつながる規模の更新。

**リンク**: [Microsoft Azure Linux 3.0.20260809、233件超のセキュリティ修正を提供](https://finance.biggo.jp/news/38399458-f08a-43ba-8e04-548df041ff3d)

## 1. Azure アップデート情報

### ネットワークセキュリティペリメーターに「Perimeter link」機能がプレビュー公開

**要約**: Azure Network Security Perimeter に、複数のセキュリティペリメーター同士を接続する「Perimeter link」機能がパブリックプレビューとして提供開始された。

**影響**: 複数部門・複数サブスクリプションにまたがるネットワーク境界を統合管理できるようになり、大規模組織でのゼロトラスト設計がしやすくなる。

**参考リンク**: [Public Preview: Perimeter link feature in network security perimeter](https://azure.microsoft.com/updates?id=568837)

### Azure Private Link が IPv6 に対応（プレビュー）

**要約**: Azure Private Link が IPv6 アドレス経由での接続をサポートするパブリックプレビューを開始した。

**影響**: IPv6 環境を採用する企業でもプライベートエンドポイント経由の安全な接続が可能になり、将来的なネットワーク移行の選択肢が広がる。

**参考リンク**: [Public Preview: Azure Private Link support over IPv6](https://azure.microsoft.com/updates?id=568842)

### Azure DNS と Traffic Manager の連携で DNS ベースの負荷分散が可能に

**要約**: Azure DNS が Traffic Manager と統合し、DNS ベースの負荷分散をプレビューで実現する機能が公開された。

**影響**: マルチリージョン構成のアプリケーションで、DNS レイヤーでのトラフィック制御が容易になり、可用性設計の柔軟性が高まる。

**参考リンク**: [Public Preview: Azure DNS enables DNS-based load balancing through Traffic Manager integration](https://azure.microsoft.com/updates?id=565214)

### Azure Virtual Network ルーティングアプライアンスが一般提供開始

**要約**: 仮想ネットワーク内のトラフィックを柔軟にルーティングできる「Azure Virtual Network routing appliance」が GA（一般提供）となった。

**影響**: サードパーティ製のネットワークアプライアンスをより自然に組み込めるようになり、既存オンプレミス構成からの移行や高度なルーティング要件への対応がしやすくなる。

**参考リンク**: [Generally Available: Azure Virtual Network routing appliance](https://azure.microsoft.com/updates?id=568605)

# 2026/09/22 デイリーアップデート

## 1. Azure アップデート情報

### Azure Sphere OS version 26.09 が一般提供開始

**要約**: Azure Sphere OS version 26.09 が Retail フィードで一般提供となった。今回のリリースは Azure Sphere OS 自体の更新のみで、SDK 側の更新は含まれない。

**影響**: IoT デバイスの運用担当者は、既存の Sphere デバイス群に対する OS 更新の適用スケジュールを検討する必要がある。SDK 変更が無いため、既存アプリの互換性への影響は限定的と見られる。

**リンク**: [Generally Available: Azure Sphere OS version 26.09 is now available](https://azure.microsoft.com/updates?id=572579)

### VS Code に Azure アプリ構築のためのガイド付き Copilot 体験がプレビュー公開

**要約**: GitHub Copilot を使い、アイデアからデプロイ可能なクラウドアプリまでを導く新しいガイド付き体験が VS Code でパブリックプレビューとして公開された。

**影響**: 開発者は要件整理からインフラ選定、コード生成までを対話形式で進められるようになり、Azure アプリ開発の立ち上げ工数を削減できる可能性がある。

**リンク**: [Public Preview: Introducing a Guided Copilot Experience for Building Azure Apps in VS Code](https://azure.microsoft.com/updates?id=572214)

### Azure Functions が PowerShell 7.6 に対応、一般提供開始

**要約**: Azure Functions における PowerShell 7.6 サポートが一般提供となった。ローカル開発から Azure へのデプロイまで PowerShell 7.6 で行えるようになる。

**影響**: PowerShell ベースの関数アプリを運用するチームは、最新ランタイムへの移行によって新しい言語機能やパフォーマンス改善の恩恵を受けられる。移行計画の検討が推奨される。

**リンク**: [Generally Available: Azure Functions support for PowerShell 7.6](https://azure.microsoft.com/updates?id=572219)

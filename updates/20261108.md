## 1. Azure アップデート情報

### Azure Front Door の WAF で HTTP DDoS ルールセットが GA

**要約**: Azure Front Door の WAF で、HTTP DDoS ルールセットが一般提供（GA）となった。WAF ポリシーを Front Door プロファイルに関連付けると、プロファイルごとに通常のリクエスト数の基準値を自動計算し、プロファイル全体と送信元 IP ごとの双方が基準値を超えた送信元に Log や Block などのルール動作を適用する。ルールグループ ExcessiveRequests にはルール 500100 などが含まれ、感度は 3 段階（既定は Medium）。記事筆者の検証時点では、ポータル上の表示が「HTTP DDoS Rule Set 1.0 (プレビュー)」のままで、GA 発表と表示が食い違っていた。

**影響**: 固定のしきい値を自分で決めずに、通常時の通信量に応じた分散型ボット攻撃への対策を追加できる。IP フィルターや固定のレート制限では追従しにくい攻撃への備えとして検討価値がある。ただし、ポータル表示と一部ルール（国・地域ベースの 500310/500320 はプレビュー扱いとの記載）の提供状況を、導入前に確認したい。

**リンク**: [[アップデート] Azure Front Door の WAF で HTTP DDoS ルールセットが GA になっていたので確認してみた](https://dev.classmethod.jp/articles/azure-front-door-waf-http-ddos-ga/)

## 2. Microsoft アップデート情報

### VS Code が「Local harness」を 2027年2月に廃止

**要約**: Visual Studio Code 1.146 で、GitHub Copilot エージェントセッションを調整する従来のソフトウェア「Local harness」が非推奨になりました。2027年2月に削除され、後継の「Copilot harness」は VS Code 1.143 から新規セッションの既定です。移行期間中は組織ポリシーが許す範囲で Local harness も使えますが、新機能は Copilot harness に集中します。Copilot harness を選んでもファイルがクラウドに移ることはなく、コマンドは引き続きローカルで実行されます。Copilot connectors や canvases はプレビューです。

**影響**: VS Code でエージェントを使っている開発者・管理者は、約3か月の移行期間内に Copilot harness へ切り替える必要があります。管理者はマネージドな権限やサンドボックス制限を適用できる一方、サンドボックスは別途設定が必要です。

**リンク**: [VS Code retires the Local harness in February 2027](https://github.blog/changelog/2026-11-16-vs-code-retires-the-local-harness-in-february-2027)

### GitHub Copilot のモデル非推奨（11月16日付）

**要約**: 11月16日付で、Claude Opus 4.8、Claude Opus 5、GPT-5.6 Terra が Copilot Chat・インライン編集・ask/agent モード・コード補完など大半の体験で非推奨になりました。代替として Claude Opus 5.5、GPT-6.1 Sol または GPT-6 Luna が案内されています。Claude Opus 4.8 は年額プランの個人契約者には引き続き利用可能で、Claude Opus 5 はモデルピッカーから外れましたが、実行時の拒否フォールバック用には残ります。

**影響**: モデル名を固定したワークフローや連携は更新が必要です。既定のモデル有効化設定では代替モデルが自動で有効になりますが、エンタープライズのモデルポリシーは従来どおり適用されます。

**リンク**: [GitHub Copilot models deprecated on November 16, 2026](https://github.blog/changelog/2026-11-16-github-copilot-models-deprecated-on-november-16-2026)

### Copilot のカスタマイズ元をプラグイン／管理設定に限定可能に

**要約**: エンタープライズ管理者は、`strictPluginOnlyCustomization` 管理設定により、ユーザーやプロジェクト単位の独自設定を遮断し、プラグインまたは管理設定由来のものだけを許可できます。対象は skills、カスタムエージェント、hooks、MCP サーバー、実行可能な Copilot 拡張の5カテゴリで、全体にも個別にも適用できます。マーケットプレイス制限（`strictKnownMarketplaces`）と組み合わせる前提で、許可リストそのものではありません。GitHub Enterprise Cloud の Copilot Business／Enterprise が対象です。

**影響**: MCP ツールなどを全面禁止せず、承認済みのものだけを共有プラグインで配布する運用が可能になり、ガバナンスと利便性を両立しやすくなります。

**リンク**: [Control where GitHub Copilot customizations come from](https://github.blog/changelog/2026-11-16-control-where-github-copilot-customizations-come-from)

### Copilot 週次リリース（11月9日週）：GHES 対応が一般提供に

**要約**: Copilot アプリで GitHub Enterprise Server のリポジトリ・Issue・PR を扱う機能が一般提供になりました（クラウドセッションは GHES では非対応）。Slack 等の MCP サーバーへ会話内で再サインインでき、Project 自動化を分単位や cron で指定可能です。モデルは Claude Fable 5.2 と Gemini 4 Carbon が Pro+・Max・Business・Enterprise で利用可能になり、Fable 5.2 は既定でデータ保持が必要で Business/Enterprise では管理者がポリシーを有効にする必要があります。

**影響**: 社内 GHES を使う組織でも Copilot アプリを導入しやすくなります。新モデルはデータ保持要件を確認してから有効化する必要があります。

**リンク**: [GitHub Copilot weekly releases — November 9](https://github.blog/changelog/2026-11-16-github-copilot-weekly-releases-november-9)

### AI Scan for repositories を最大20リポジトリ一括開始（パブリックプレビュー）

**要約**: 既定ブランチの脆弱性を検出する AI Scan を、組織レベル設定の有効化時や code scanning の組織アラートページから最大20リポジトリまとめて開始できるようになりました。CodeQL が対応しない言語も対象で、Copilot ライセンスは不要です。github.com と GHEC のデータレジデンシーで利用でき、一括開始はパブリックプレビューです。

**影響**: セキュリティ担当者は、CodeQL では拾えないバックログを大規模に洗い出しやすくなります。プレビューのため本番運用前に検証が必要です。

**リンク**: [Bulk start AI Scan for repositories](https://github.blog/changelog/2026-11-16-bulk-start-ai-scan-for-repositories)

### Dependabot のアラート却下リクエストの保持期間が1年に

**影響**: 期限切れによる再申請の手間が減り、セキュリティレビューの運用負荷が下がります。

**リンク**: [Dependabot alert dismissal requests now last one year](https://github.blog/changelog/2026-11-16-dependabot-alert-dismissal-requests-now-last-one-year)

**要約**: サブスクリプションあたり・リージョンあたりのストレージアカウントのリソースクォータが引き上げられ、標準エンドポイントのストレージアカウントを1リージョンで最大1,000個まで作成できるようになりました。一般提供（GA）です。

**リンク**: [Generally Available: Azure Front Door profile and route level WAF policies](https://azure.microsoft.com/updates?id=578153)

**要約**: 次期 Azure DevOps Server のリリース候補（RC）が公開されました。クラウド版の Azure DevOps で先行提供されていた新機能がオンプレミス版にも取り込まれます。

## 1. Azure アップデート情報

### AKS 向け分散アクセラレーター（DACS）がパブリックプレビュー

**要約**: Azure Kubernetes Service（AKS）上の AI ワークロード向けに、クラウドストレージ用の分散アクセラレーター（Distributed accelerator for cloud storage, DACS）がパブリックプレビューとして提供開始された。提供形態の詳細（キャッシュ方式など）は収集データの範囲では確認できていない。

**影響**: AI の学習・推論ではストレージ I/O がボトルネックになりやすく、AKS 利用者にとって性能改善の選択肢が増える。プレビューのため、本番導入前に検証が必要。

**リンク**: [Public Preview: Distributed accelerator for cloud storage on AKS](https://azure.microsoft.com/updates?id=578454)

### Azure Functions が .NET 11 に一般提供で対応

**要約**: Azure Functions で .NET 11 を対象とするアプリを、分離ワーカーモード（isolated worker）で構築できるようになった。提供状況は一般提供（GA）。

**影響**: .NET の新バージョンへ早期に移行したい開発チームが、本番ワークロードでも Functions 上で .NET 11 を採用できる。移行計画の前提が整う。

**リンク**: [Generally Available: Azure Functions support for .NET 11](https://azure.microsoft.com/updates?id=578773)

### Azure Front Door が gRPC をネイティブサポート（プレビュー）

**要約**: Azure Front Door Standard / Premium で gRPC アプリケーションの配信が可能になった。パブリックプレビューでの提供。

**影響**: マイクロサービス間通信などで使われる gRPC を、グローバルな入口である Front Door 経由で配信できる可能性が広がる。プレビューのため SLA や制約の確認が必要。

**リンク**: [Public Preview: Azure Front Door adds native gRPC support](https://azure.microsoft.com/updates?id=579383)

### Azure Front Door の edge actions が一般提供

**要約**: エッジで軽量なサーバーレスコードを実行できる Azure Front Door edge actions が一般提供となった。

**影響**: リクエスト処理の一部をユーザーに近いエッジで実行でき、オリジンへの負荷や遅延の低減につながる。本番利用が可能になった点が大きい。

**リンク**: [Generally Available: Azure Front Door edge actions](https://azure.microsoft.com/updates?id=579310)

### Azure Route Server が IPv4/IPv6 デュアルスタックに対応（プレビュー）

**要約**: Azure Route Server が IPv4/IPv6 デュアルスタックモードをパブリックプレビューでサポートし、ハイブリッド構成で両アドレスファミリーのルート交換が可能になる。

**影響**: IPv6 を併用するハイブリッドネットワークを運用する企業にとって、ルーティング構成の簡素化が期待できる。

**リンク**: [Public Preview: Azure Route Server dual-stack IPv4/IPv6 support](https://azure.microsoft.com/updates?id=579746)

## 1. Azure アップデート情報

### Azure VMのディスク単位レジリエンシがパブリックプレビューに

**要約**: Azureは、アタッチされたマネージドディスクへのアクセスが長時間失われた際に、VMを自動復旧させる「Per-disk resiliency」のパブリックプレビューを開始した。従来は影響を受けたVMがシャットダウンされ再起動される仕組みだったが、ディスク単位での対応が可能になる。

**影響**: ディスク障害時の可用性が向上し、ストレージ関連の一時的な障害によるワークロード停止のリスクを抑えられる。運用チームの障害対応負荷軽減にもつながる。

**リンク**: [Public Preview: Per-disk resiliency for Azure VMs](https://azure.microsoft.com/updates?id=569711)

### Azure Multicloud Interconnectがパブリックプレビューに

**要約**: Azureと他クラウドプロバイダー間のプライベート接続を提供するマネージドサービス「Azure Multicloud Interconnect」のパブリックプレビューが発表された。

**影響**: マルチクラウド構成を採用する企業にとって、クラウド間のセキュアかつ低遅延な接続を容易に構築できるようになり、ネットワーク設計の選択肢が広がる。

**リンク**: [Public Preview: Azure Multicloud Interconnect](https://azure.microsoft.com/updates?id=570364)

### Enterprise Live Migrationsがパブリックプレビューに

**要約**: Azure DevOpsリポジトリをGitHub Enterprise Cloudへ、データレジデンシーを維持しながら移行できる「Enterprise Live Migrations」がパブリックプレビューとなった。

**影響**: Azure DevOpsからGitHubへの移行を検討する企業にとって、業務への影響を抑えつつ大規模な移行を進められる選択肢が増える。

**リンク**: [Enterprise Live Migrations is now in public preview](https://devblogs.microsoft.com/devops/enterprise-live-migrations-public-preview/)

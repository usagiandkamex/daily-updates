## 1. Azure アップデート情報

### Azure Files CSI ドライバーがワークロードID認証をGA

**要約**: Azure Kubernetes Service（AKS）のAzure Files Container Storage Interface（CSI）ドライバーが、Pod単位のワークロードID認証に正式対応した。従来はマネージドIDを用いた認証のみだったが、より細やかな認可制御が可能になった。

**影響**: マルチテナントなAKS環境でファイル共有アクセスをPod単位で最小権限に絞れるようになり、ゼロトラスト設計を進める企業にとってセキュリティガバナンス強化の選択肢が広がる。

**リンク**: [Generally Available: Workload identity support for Azure Files CSI driver (SMB) in Azure Kubernetes Service](https://azure.microsoft.com/updates?id=570120)

### Azure Bastionに共有リンクの有効期限設定機能がGA

**要約**: Azure Bastionの「共有可能リンク」機能に有効期限を設定できる仕組みが正式提供された。管理者はリンク作成時に失効日時を指定でき、期限切れ後は自動的にアクセスできなくなる。

**影響**: 一時的な外部委託先やベンダーへのアクセス権限付与を安全に自動失効させられるようになり、証跡管理・アクセス棚卸しの運用負荷を軽減できる。

**リンク**: [Generally Available: Azure Bastion shareable link expiration](https://azure.microsoft.com/updates?id=570020)

### Azure Bastionでプレビュー中のIPv6デュアルスタック対応

**要約**: Azure BastionがIPv4とIPv6のデュアルスタック構成のパブリックプレビューを開始した。新規作成のBastionデプロイでIPv4とIPv6の両方のパブリックIPアドレスを同時に構成できる。

**影響**: IPv6移行を進める企業ネットワークにおいて、踏み台サーバー基盤を段階的にデュアルスタック化できるようになり、将来的なIPv4アドレス枯渇リスクへの備えとなる。

**リンク**: [Public Preview: IPv6 dual-stack support for Azure Bastion](https://azure.microsoft.com/updates?id=570025)

### Azure SRE AgentにVNet統合機能がGA、30日間トライアルも開始

**要約**: 運用自動化サービス「Azure SRE Agent」がVNet統合に対応し正式提供された。ネットワークセキュリティグループやプライベートエンドポイントなど既存のネットワーク制御内でエージェントを稼働できる。あわせて新規顧客向けの30日間無料トライアルも開始された。

**リンク**: [Generally Available: Azure SRE Agent VNet Integration](https://azure.microsoft.com/updates?id=569695)

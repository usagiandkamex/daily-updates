### VS Code 1.146 リリース：Inbox モード、モデル比較、チャット専用ウィンドウ

**要約**: 11 月 11 日公開の VS Code 1.146 では、複数プロジェクトにまたがり注意が必要なエージェントセッションだけを表示し他をスヌーズできる「Inbox モード（実験的）」、Copilot Fusion を含めて結果を比較する「モデル比較（プレビュー）」、チャットを独立ウィンドウとして配置できる「チャットウィンドウ（プレビュー）」、Agents ウィンドウでの拡張機能の検索・インストール（実験的）が追加された。あわせて Local ハーネスが非推奨となり、2027 年 2 月に削除される予定。Copilot ハーネスは 1.143 から新規セッションの既定で、Agent Host 経由でバックグラウンド実行でき、管理されたサンドボックス／権限ポリシーを適用できる。

**影響**: Local ハーネスは今後 3 か月は使えるが機能は凍結され新機能は Copilot ハーネス中心になる。Local ハーネスを使っている開発者や、既定を Local に戻す設定（vscode.temporaryDefaultToLocalHarness）を使う企業管理者は、2027 年 2 月までに移行計画を立てる必要がある。

**リンク**: [Visual Studio Code 1.146](https://code.visualstudio.com/updates/v1_146)

### GitHub の Issue タイプと Issue フィールドが個人アカウントでも一般提供

**要約**: 個人アカウント所有のリポジトリで Issue タイプと Issue フィールドが一般提供となった。Issue タイプは既定で Bug・Task・Feature、最大 25 種まで作成可能。Issue フィールドは既定で Priority・Effort・Start date・Target date、テキスト・数値・日付・単一選択・複数選択に対応し最大 25 個作成でき、特定の Issue タイプに固定することもできる。設定は個人アカウントの「Planning」配下で行う。

**影響**: 個人開発者や OSS メンテナーも、組織向けと同等の分類・優先度管理をリポジトリ横断で標準化できる。Projects と組み合わせたビュー作成にも使えるため、Issue 運用の整理が容易になる。

**リンク**: [Issue types and fields are available for personal accounts](https://github.blog/changelog/2026-11-11-issue-types-and-fields-are-available-for-personal-accounts)

### Google が Gemini Decisions API を発表

**要約**: 新モデル「Gemini Decision 1」(gemini-decision-1) を使う、閉じた選択肢向けの新エンドポイント。テキスト・画像・音声・動画・PDF を最大 256K トークンまで入力し、最大 1,000 の独立した質問に対して、トークン生成ではなく 1 回の順伝播で候補をスコアリングし確率と信頼度を返す。エンドツーエンドで 150〜250ms、入力 100 万トークンあたり $0.10、出力トークンの課金なし。ツール選択、ポリシーチェック、モデルルーティング、コンテキスト評価などに向く。Google AI Studio の API キーで利用できる。

**影響**: エージェントの前段ルーティングやコンテンツ審査を低遅延・低コストで置き換えられる可能性がある。LLM に生成させるより安定した分岐判断が得られるため、エージェント基盤の設計に新しい選択肢となる。

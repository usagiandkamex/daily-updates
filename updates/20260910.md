## 1. Azure アップデート情報

### User-bound user delegation SAS が GA、Azure Storage の認証がさらに強固に

**要約**: Azure Storageにおいて、ユーザー委任SAS（shared access signature）の柔軟性と、ユーザーに紐づく強固なセキュア認証を組み合わせた「User-bound user delegation SAS」が一般提供（GA）となった。

**影響**: SASトークンが特定ユーザーIDに紐づくことで、トークン漏洩時のなりすましリスクが低減し、Azure Storageを扱うアプリケーションのセキュリティ設計をより堅牢にできる。

**リンク**: [[Launched] Generally Available: User-bound user delegation SAS for Azure Storage](https://azure.microsoft.com/updates?id=569241)

### Azure Ephemeral OS Disk のフルキャッシュ対応が GA

**要約**: 新規VM・Virtual Machine Scale Sets向けに、Azure Ephemeral OS Diskのフルキャッシュ機能が一般提供された。OSディスクの内容をキャッシュすることで読み書き性能が向上する。

**影響**: ステートレスなVMワークロードのブート・再展開速度やI/O性能が改善され、大規模スケールアウト環境でのコスト効率とパフォーマンスの両立が可能になる。

**リンク**: [[Launched] Generally Available: Azure Ephemeral OS Disk with full caching for VM/VMSS](https://azure.microsoft.com/updates?id=570551)

### Azure Virtual Desktop Hybrid が GA、ただしライセンス詳細は未公開

**要約**: Microsoftは「Azure Virtual Desktop Hybrid」を一般提供したと発表したが、具体的なライセンス体系の詳細はまだ公開されていない。

**影響**: オンプレミス環境でAVDの機能を利用したい企業にとって選択肢が広がる一方、コスト試算のためにはライセンス詳細の公開を待つ必要があり、導入計画は慎重な見極めが求められる。

**リンク**: [Azure Virtual Desktop Hybrid Reaches GA with Licensing Details Unpublished](https://www.infoq.com/news/2026/09/avd-hybrid-ga/?utm_campaign=infoq_content&utm_source=infoq&utm_medium=feed&utm_term=global)

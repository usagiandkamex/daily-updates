# 2026/11/04 デイリーアップデート

## 1. Azure アップデート情報

### Application Gateway for Containers が JWT 検証をプレビュー提供

**要約**: Application Gateway for Containers で、AuthPolicy カスタムリソースを通じた JSON Web Token（JWT）の一元的な検証がパブリックプレビューとして利用可能になった。

**影響**: 認証検証をゲートウェイ側に集約でき、各アプリケーションで個別に JWT 検証を実装する負担を減らせる。ただしプレビューのため、本番適用は仕様変更を前提に検討したい。

**リンク**: [Public Preview: JWT validation for Application Gateway for Containers](https://azure.microsoft.com/updates?id=576382)

### Application Gateway for Containers に MCP ゲートウェイ機能

**要約**: 新しい MCPRoute カスタムリソースにより、Model Context Protocol（MCP）のルーティングを Application Gateway for Containers で扱えるようになった（パブリックプレビュー）。

**影響**: AI エージェント向けの MCP サーバーを Kubernetes 上で公開する際、既存のゲートウェイ基盤で入口を管理できる可能性がある。

**リンク**: [Public Preview: MCP gateway for Application Gateway for Containers](https://azure.microsoft.com/updates?id=576388)

### Application Gateway for Containers がプライベート Ingress に対応

**要約**: 承認された Azure 内のネットワーク経路からのみ到達できるプライベートフロントエンドをサポート（パブリックプレビュー）。

**影響**: 社内向けサービスをインターネットに公開せずにコンテナーへ配信でき、ネットワーク分離要件のある企業に有用。

**リンク**: [Public Preview: Private ingress for Application Gateway for Containers](https://azure.microsoft.com/updates?id=576393)

### Azure Storage Discovery に高度な容量インサイト

**要約**: Azure Storage Discovery で、高度な容量インサイトがプレビューとして提供開始された。

**影響**: 大規模なストレージ環境の容量の把握・コスト最適化の判断材料が増える。詳細な指標の内容は元記事の概要からは確認できていない。

**リンク**: [Public Preview: Advanced capacity insights are now available in Azure Storage](https://azure.microsoft.com/updates?id=578655)

### Azure SQL Database の PITR バックアップで不変性を延長

**要約**: ポイントインタイムリストア（PITR）バックアップについて、保持期間を設定した保持期間に合わせてロックし、それを超えて不変性を延長できる機能がプレビューで提供される。

**影響**: ランサムウェア対策やコンプライアンス上、バックアップ改ざん・削除を防ぎたい組織にとって有効な選択肢となる。

**リンク**: [Public Preview: Extend immutability for PITR backups for Azure SQL Database](https://azure.microsoft.com/updates?id=579305)

### Azure Site Recovery が VMSS Flex 向け体験を強化（GA）

**要約**: Virtual Machine Scale Sets（VMSS）Flex 上の仮想マシンに対し、Azure Site Recovery の災害復旧体験が強化され、一般提供となった。

**影響**: スケールセットを利用するワークロードの DR 構成が取りやすくなり、本番環境でも採用しやすい。

**リンク**: [Generally Available: Enhanced Azure Site Recovery support for VMSS Flex](https://azure.microsoft.com/updates?id=578926)

## 2. Microsoft アップデート情報

### Windows 11：8 GB メモリ PC の応答性を改善

**要約**: Microsoft は 7 月に着手したメモリ最適化の成果を公表。メモリの有効活用、負荷時にも即応性が必要な操作の保護、Windows と主要アプリの必要メモリ削減の 3 点で取り組み、8 GB PC で応答性が最大 20% 向上、マルチタスクが最大 40% 高速化したとしている（同社ラボテスト）。

**影響**: 低スペック端末が残る教育・中小企業環境で、ハード更新を待たず体感改善が期待できる。数値は社内ラボ結果である点に留意。

**リンク**: [Raising the bar for 8 GB Windows 11 PCs](https://blogs.windows.com/windowsexperience/2026/11/03/raising-the-bar-for-8-gb-windows-11-pcs-whats-improved-and-how-to-get-it/)

### Dependabot が Agent Package Manager（APM）に対応

**要約**: apm.yml に宣言された git 依存関係の更新 PR を Dependabot が作成し、apm.lock.yaml があれば再生成する。バージョン更新のみでセキュリティ更新は対象外。github.com の全プランで一般提供、GitHub Enterprise Server 3.24 でも提供予定。

**影響**: AI エージェントのスキル・プロンプト・指示を依存関係として継続的に更新でき、エージェント資産の陳腐化を防げる。

**リンク**: [Dependabot version updates support Agent Package Manager](https://github.blog/changelog/2026-11-03-dependabot-version-updates-support-agent-package-manager)

### GitHub Copilot が JetBrains Air で利用可能に

**要約**: Agent Client Protocol（ACP）を使い、JetBrains Air からコーディングタスクの委任・実行ガイド・結果レビューが可能。複数エージェントセッションの並行管理、Air Teams 経由のクラウドタスク実行に対応し、タスクは JetBrains AI クレジットではなく Copilot プランを使用する。

**影響**: JetBrains 中心の開発チームも既存の Copilot 契約でエージェント型開発を試せる。

**リンク**: [GitHub Copilot is now available in JetBrains Air](https://github.blog/changelog/2026-11-03-github-copilot-is-now-available-in-jetbrains-air)

### CodeQL 2.27.3 が Python 3.15 機能と JSON データ拡張に対応

**要約**: コードスキャンの静的解析エンジン CodeQL 2.27.3 で、Python 3.15 の機能と JSON データ拡張のサポートが追加された。

**影響**: Python 3.15 を採用するプロジェクトでも解析精度を維持しやすい。

**リンク**: [CodeQL 2.27.3 adds Python 3.15 features and JSON data extensions](https://github.blog/changelog/2026-11-03-codeql-2-27-3-adds-python-3-15-features-and-json-data-extensions)

### Dependabot が Python 3.15 をサポート

**要約**: Python 3.15 へアップグレードしたプロジェクトでも、Dependabot の更新を引き続き受けられるようになった。

### GitHub Desktop が短命の認証トークンを導入

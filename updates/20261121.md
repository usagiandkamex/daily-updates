# 2026/11/21 デイリーアップデート

## 1. Azure アップデート情報

### Microsoft Foundry に「Programmed Training」がパブリックプレビュー

**要約**: オープンウェイトモデルに対する独自のポストトレーニングのループを構築できる API「Programmed Training」が、Microsoft Foundry でパブリックプレビューとして提供開始された。提供状況はプレビューで、詳細な利用条件は RSS の説明から確認できた範囲に限る。

**影響**: モデルの追加学習を自社のロジックで制御したい開発チームにとって、Foundry 上でカスタマイズの自由度が高まる。ただしプレビュー段階のため、本番採用前に仕様変更や制限を確認する必要がある。

**リンク**: [Public Preview: Programmed Training in Microsoft Foundry](https://azure.microsoft.com/updates?id=581713)

### Microsoft Foundry の「Multi-turn evaluation」がパブリックプレビュー

**要約**: エージェントの個々の応答だけでなく、会話全体を品質基準に照らして評価できるマルチターン評価がパブリックプレビューになった。

**影響**: 複数ターンにわたるエージェントの品質（一貫性や目的達成）を定量評価しやすくなり、AI エージェントの運用前テストや継続的な改善に役立つ。

**リンク**: [Public Preview: Multi-turn evaluation in Microsoft Foundry](https://azure.microsoft.com/updates?id=581746)

### Azure Firewall for Containers がパブリックプレビュー

**要約**: Azure Firewall の保護をコンテナ化されたワークロードに拡張し、ネットワークトラフィックを集中的に保護する方式を提供する。パブリックプレビューでの提供。

**影響**: コンテナ環境のネットワークセキュリティを既存の Azure Firewall のポリシー運用に寄せられる可能性があり、セキュリティ管理の一元化を検討する組織に関係する。

**リンク**: [Public Preview: Azure Firewall for Containers](https://azure.microsoft.com/updates?id=581963)

### Azure Compute Gallery のソフトデリートが一般提供

**要約**: 誤って削除したイメージバージョンを復旧できるソフトデリートが一般提供（GA）となった。保持期間を設定できる。

**影響**: VM イメージの誤削除による環境構築の停止リスクを減らせる。イメージ管理の運用ミス対策として有効化を検討できる。

**リンク**: [Generally Available: Soft delete in Azure Compute Gallery](https://azure.microsoft.com/updates?id=581907)

### Azure Database for PostgreSQL で PostgreSQL 19 がプレビュー

**要約**: Azure Database for PostgreSQL – Flexible Server で PostgreSQL 19 を、East Asia リージョンでパブリックプレビューとして試せる。

**影響**: 次期メジャーバージョンへの互換性検証を早期に始められる。プレビューのため本番ワークロードには適さない。

**リンク**: [Public Preview: PostgreSQL 19 on Azure Database for PostgreSQL](https://azure.microsoft.com/updates?id=574587)

### Azure Functions OpenAI 拡張のサポートが 2027年4月20日に終了

**要約**: Azure Functions OpenAI 拡張のサポートが 2027年4月20日で終了する。移行先として OpenAI、Microsoft Foundry、Azure AI Search の各 SDK を直接利用することが案内されている。

**影響**: 同拡張を利用中のアプリは期限までに SDK 直接利用への書き換えが必要。猶予は約 5 か月で、早めの棚卸しが望ましい。

**リンク**: [Retirement: Support for Azure Functions OpenAI Extension ends on April 20, 2027](https://azure.microsoft.com/updates?id=579952)

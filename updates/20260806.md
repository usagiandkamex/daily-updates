# 2026/08/06 デイリーアップデート

## 1. Azure アップデート情報

### Azure Firewall の明示的プロキシ機能が一般提供開始

**要約**: Azure Firewall の「Explicit proxy」機能が GA（一般提供）となった。アプリケーションやブラウザ側でプロキシを明示的に設定することで、HTTP/HTTPS トラフィックを Azure Firewall 経由で送信できるようになる。

**影響**: 従来の透過的なトラフィックリダイレクトが難しかった環境でも、明示的なプロキシ設定によりネットワークセキュリティポリシーの適用が容易になる。企業のネットワーク管理者にとって、既存アプリケーションを大きく変更せずにファイアウォール経由の通信制御を導入できる選択肢が増える。

**参考リンク**: [[Launched] Generally Available: Explicit proxy in Azure Firewall](https://azure.microsoft.com/updates?id=568825)

### 機密コンピューティング向け cc_v5 VM シリーズが2026年9月に退役

**要約**: Azure の機密仮想マシン（Confidential VM）シリーズである cc_v5 が、2026年9月1日をもって退役することが発表された。同日以降は新規利用・購入ができなくなる。

**影響**: cc_v5 を利用している企業は、退役前に後継シリーズへの移行計画を立てる必要がある。機密コンピューティングを前提としたワークロードを運用する開発者・インフラ担当者は、早めの移行検証が求められる。

**参考リンク**: [Retirement: Nested confidential (cc_v5) VMs will be retired on September 1, 2026](https://azure.microsoft.com/updates?id=568661)

### Azure DevOps Remote MCP Server が一般提供開始

**要約**: Azure DevOps の MCP（Model Context Protocol）サーバーが GA となった。AI アシスタントが Azure DevOps のリソースに安全にアクセスできるようになる仕組みを標準機能として提供する。

**影響**: 開発チームは AI エージェントを介した作業アイテム管理やパイプライン操作を、公式にサポートされた形で組み込めるようになる。DevOps ワークフローへの AI 統合を検討している企業にとって、導入障壁が下がる。

**参考リンク**: [Azure DevOps Remote MCP Server is generally available](https://devblogs.microsoft.com/devops/azure-devops-remote-mcp-server-ga/)
